# spinner-bot

用于后续研究的项目目录。

当前实验严格使用本目录中的 `model/Qwen3.5-4B` 副本和 `data/vision_opd_6k` 数据。
由于图像归档尚未下载完成，正式推理必须在归档落入数据目录后执行；脚本会拒绝静默跳过图像。

## Text grounding 预实验定义

本预实验研究的是文本模态特权信息，不使用 Vision-OPD 的 crop image 或红框图作为实验变量。四个推理条件均输入原始图片，分别为：

1. `orig`: 原始图片 + 原始问题
2. `separator`: 原始图片 + 原始问题 + 分隔问题
3. `grounding`: 原始图片 + 原始问题 + grounding 分隔问题
4. `all_text`: 原始图片 + 原始问题 + 分隔问题 + grounding 分隔问题

分隔问题由 Vision-OPD-6K 每条样本的原始 `problem` 派生，保留原问题的目标和任务形式，不泄露答案。它要求模型先明确“要观察哪个目标、判断该目标的什么属性”，再回答原始选择题。grounding 分隔问题进一步要求模型只检查数据集标注的证据区域；bbox 只作为原始数据集的区域元信息，不作为答案或外部视觉描述。

当前版本是无需外部生成模型的可复现实验基线。正式训练前可用同一规则或固定的本地生成模型批量生成更细粒度的分步问题，但必须冻结生成结果后再比较模型组。
