# Text Grounding 预实验协议

## 研究变量

本实验只研究文本模态的引导性问题。四个条件使用同一张 `original_images` 原图，答案、选项、解码参数和模型权重完全一致。

| 条件 | 原始问题 | 分隔问题 | grounding 分隔问题 | 视觉输入 |
|---|---:|---:|---:|---|
| `orig` | 是 | 否 | 否 | 原始图片 |
| `separator` | 是 | 是 | 否 | 原始图片 |
| `grounding` | 是 | 否 | 是 | 原始图片 |
| `all_text` | 是 | 是 | 是 | 原始图片 |

## 分隔问题设计

Vision-OPD-6K 的 `problem` 是选择题，且每题由合成流程指定一个需要仔细观察的细粒度目标。分隔问题不能改变任务答案，也不能加入选项对应的正确内容。因此基线模板只拆解任务：

> 在回答选择题前，先明确题目要求观察的视觉目标，以及需要判断该目标的哪一种属性。

grounding 分隔问题再加入数据集本身的区域语义：

> 先检查该样本标注的证据区域，再仅依据该区域回答原始问题。

这是一种保守、可复现的文本特权定义。它不调用外部大模型生成新的事实，不把 bbox 坐标解释为图像内容，也不泄露答案。

## 主要指标

- 四条件选项准确率
- 无效输出率：未能解析为 A-D 的回答比例
- 配对变化：同一 index 下 `separator`/`grounding` 相对 `orig` 的增益或损失
- 交集分析：只有文本引导正确、只有原始问题正确、两者都正确、两者都错误
- 分组分析：按题干中的颜色、数量、形状、材质、物体类别和空间关系关键词分组

## 解释边界

本预实验只能判断“固定文本引导模板是否有即时推理效用”，不能直接证明文本特权信息能通过 OPD 训练提升长期能力。正式实验需要冻结生成数据，分别训练学生、Text teacher、Vision teacher 和双 teacher 组，并使用未见问题评估迁移。
