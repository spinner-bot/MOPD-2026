## 一、项目目标

**研究方向**：多模态在线策略蒸馏（MOPD）中的跨模态教师对齐动力学

**核心问题**：在多模态 OPD 训练过程中，VL 教师（视觉-语言教师）与 Text 教师（纯文本教师）之间的语义对齐度如何演化？是否存在相变点？是否与最终性能相关？

**研究方法**：
- 在训练过程中定期（每 N 步）对固定的 probe batch 计算两教师的输出分布
- 使用 JS 散度（Jensen-Shannon Divergence）和 Top-1 一致率量化对齐度
- 分析对齐度随训练步数的变化曲线，寻找模式

**目标会议**：ICLR / CVPR / ECCV（按现象发现的重要性决定）

#### Probe Logging 核心逻辑
- **文件**：`verl/workers/actor/dp_actor.py`
- **方法**：`_run_probe_logging(global_step)`
- **功能**：
  - 每 N 步（可配置，默认 10 步）对 probe batch 跑两个教师的 forward
  - 计算每个 token 的 JS 散度和 Top-1 一致率
  - 保存为 JSONL 格式到 `probe_logs/` 目录
- **集成点**：在 `update_policy()` 方法开头调用

```python
def _run_probe_logging(self, global_step: int) -> None:
    # 加载 probe batch
    # 对每个样本：
    #   - VL 教师 forward（teacher_module 或 actor_module）
    #   - Text 教师 forward（self.text_teacher）
    #   - 计算 JS 散度、Top-1 一致率
    # 保存到 probe_logs/step_{global_step:06d}.jsonl
```

## 四、关键技术细节

### 4.1 Probe Logging 工作原理

```python
# 在 dp_actor.py 的 update_policy 中
def update_policy(self, data: DataProto):
    self._current_global_steps = data.meta_info.get("global_steps")
    
    # 运行 probe logging
    if self._current_global_steps is not None:
        self._run_probe_logging(self._current_global_steps)
    
    # 继续正常训练流程...
```

### 4.2 对齐度计算

```python
# JS 散度
vl_probs = softmax(vl_logits, dim=-1)
text_probs = softmax(text_logits, dim=-1)
m_probs = 0.5 * (vl_probs + text_probs)
kl_vl_m = sum(vl_probs * log(vl_probs / m_probs), dim=-1)
kl_text_m = sum(text_probs * log(text_probs / m_probs), dim=-1)
js_div = 0.5 * (kl_vl_m + kl_text_m)

# Top-1 一致率
top1_agree = (argmax(vl_logits) == argmax(text_logits)).float()
```

### 4.3 预期输出格式

  "js_divergence_max": 0.456,

}
