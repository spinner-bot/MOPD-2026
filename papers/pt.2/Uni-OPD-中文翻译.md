## 摘要

在策略蒸馏（OPD）近来已成为一种有效的后训练范式，用于将多个专门化专家模型的能力整合到单个学生模型中。尽管取得了实证成功，但 OPD 产生可靠改进的条件仍未被充分理解。本文中，我们识别了限制有效 OPD 的**两个基础瓶颈**：学生对有信息量状态的探索不足，以及教师对学生 rollout 的监督不可靠。基于这一洞察，我们提出 **Uni-OPD**，一个跨越 LLM 和 MLLM 的统一 OPD 框架，核心是一种**双视角优化策略**。具体而言，从学生视角出发，我们采用离线难度感知和在线正确率感知两种数据平衡策略，促进训练期间对有信息量的学生生成状态的探索。从教师视角出发，我们证明可靠的监督取决于聚合后的 token 级引导是否与结果奖励保持**顺序一致**。为此，我们提出一种结果引导的边距校准机制，恢复正确与错误轨迹之间的顺序一致性。我们在 5 个能力域和 16 个基准上进行了广泛实验，覆盖多样化场景，包括 LLM 和 MLLM 的单教师与多教师蒸馏、强到弱蒸馏和跨模态蒸馏。结果验证了 Uni-OPD 的有效性和通用性，为可靠的 OPD 提供了实践洞见。

## 1 引言

将复杂推理能力、领域知识和人类偏好注入 LLM 和 MLLM 仍是后训练阶段的核心挑战。传统方法通常遵循两阶段范式：先监督微调（SFT），后强化学习（RL）。SFT 虽然利用专家数据进行训练，但其固有的离策略性质引入了显著的曝光偏差——推理时进入很少覆盖的错误状态可能导致错误级联放大。另一方面，在策略 RL（如 GRPO）通过在线采样缓解了分布偏移，但主要依赖序列级或终端奖励，使得细粒度归因困难，限制了长期训练的稳定性。

近来，在策略蒸馏（OPD）作为一种有前景的后训练范式出现，用于高效地将领域专家的知识和能力迁移到单一统一模型中。它结合了 RL 和 SFT 的优势——即在策略采样和 token 级监督。具体而言，OPD 在学生的自采样轨迹上以反向 KL 目标配合教师反馈进行训练。

尽管取得了实证成功，当前 OPD 研究仍然主要局限于 LLM 蒸馏。虽然有少数近期工作将 OPD 扩展到 MLLM，但仅限于单一模态内的有限任务子集（如视频或语音）。为此，我们首先旨在为 LLM 和 MLLM 开发一个统一的 OPD 框架，实现跨任务和跨模态的有效知识蒸馏。

**关键观察。** 在统一框架之外，我们提出了一个更根本的问题：**什么使 OPD 成为一个可靠的优化范式？** 我们认为有效的 OPD 依赖于两个因素。第一，学生必须充分探索有信息量的状态——即多样且难度适中的自生成轨迹。第二，教师的 token 级监督在学生 rollout 上必须保持可靠。特别是，当 token 级引导在轨迹级聚合后与结果奖励保持顺序一致（即正确轨迹获得比错误轨迹更高的聚合得分）时，监督的可靠性显著增强。结果奖励因此为校准不可靠的教师监督提供了全局锚点。这些观察促成了双视角优化策略——联合改进学生探索和教师信号的可靠性。

**我们的配方。** 基于这些洞察，我们引入 **Uni-OPD**，一种从学生和教师的基本角色出发优化 OPD 的双视角策略。在此统一框架中，我们采用两种互补的数据平衡策略——离线难度感知和在线正确率感知平衡——来促进对有信息量的学生生成状态的探索。我们进一步提出了一种新颖的结果引导边距校准机制，以获得可靠的教师监督。在 LLM 和 MLLM 上的广泛实验验证了我们的配方。

**我们的贡献有三方面：**

- **OPD 的关键瓶颈。** 我们识别了 OPD 中的两个核心瓶颈：对有信息量状态的探索不足，以及教师对学生 rollout 的监督不可靠。我们的分析揭示了可靠的教师监督很大程度上取决于 token 级引导是否与结果奖励保持顺序一致。

- **双视角优化配方。** 我们提出了一种统一 OPD 的双视角优化配方，联合改进学生探索和教师监督。具体而言，我们结合了离线和在线数据平衡与结果引导的边距校准机制，实现更有效的优化。

- **全面的实验验证。** 我们在 5 个领域和 16 个基准上进行了广泛实验，覆盖多样化场景——LLM 和 MLLM 的单教师与多教师蒸馏、强到弱蒸馏和跨模态蒸馏（即结合纯文本和多模态任务）。结果验证了 Uni-OPD 的有效性和通用性，为可靠的 OPD 提供了实践洞见。

## 2 相关工作

**LLM 和 MLLM 的知识蒸馏。** 知识蒸馏旨在将知识从较大的教师模型迁移到较小的学生模型。传统方法通常依赖离策略的前向 KL 散度在静态数据集上对齐学生和教师的生成分布。另一条工作线将对教师生成 token 的 SFT 视为替代的离策略蒸馏策略。尽管有效，这些离策略方法本质上模仿教师行为，限制了学生超越教师的能力，并使学生容易出现曝光偏差。

**在策略蒸馏。** OPD 允许更优秀的教师对学生自身的在策略轨迹提供反馈。这一范式有效缓解了曝光偏差并提升了学生性能的上限。基于这些优势，OPD 已成为将多个专家能力合并到单个学生模型的高效方式，也支持强到弱蒸馏。当前 OPD 研究沿多个关键方向展开：从教师视角——无教师自蒸馏范式、黑盒 OPD 方法、跨模型家族的蒸馏；从优化角度——统一训练框架、稳定优化策略、与 RL 结合等。少数工作将 OPD 扩展到多模态领域。本文以双视角配方推动 OPD 发展，促进学生探索和教师可靠性，泛化到 LLM 和 MLLM。

## 3 方法论

我们提出 **Uni-OPD**，一个跨越 LLM 和 MLLM 的统一 OPD 框架。我们的设计由 OPD 的两个基础瓶颈驱动：对学生有信息量状态的探索不足，以及教师对学生 rollout 的监督不可靠。Uni-OPD 以双视角配方应对这些瓶颈——增强学生探索并校准教师监督以对齐结果奖励。

### 3.1 预备知识

**在策略蒸馏。** OPD 保留了优化的在策略性质，同时提供 token 级归因，实现有效的后训练。训练期间，学生策略 $\pi_\theta$ 采样自身轨迹，并通过最小化与教师策略 $\pi_T$ 在这些样本上的反向 KL 散度来优化：

$$J_{OPD}(\theta) = \min_\theta \mathbb{E}_{q \sim \mathcal{D}, \tau \sim \pi_\theta(\cdot|q)} D_{KL}\left(\pi_\theta(\tau | q) \| \pi_T(\tau | q)\right) \tag{1}$$

OPD 的梯度公式化自然地诱导出每一步 $t$ 的 token 级奖励，类似于标准 RL：

$$r_t^{OPD} = \log \pi_T(o_t | q, o_{<t}) - \log \pi_\theta(o_t | q, o_{<t}) = \log \frac{\pi_T(o_t | q, o_{<t})}{\pi_\theta(o_t | q, o_{<t})} \tag{3}$$

这一公式化在 token 级别提供了细粒度归因信号。

**分析 OPD 中的教师监督。** 如公式（3）所示，OPD 依赖教师为学生生成的轨迹提供细粒度监督。为实现有效优化，该信号应与整体轨迹正确性对齐。在实践中，这种对齐并不保证，可能以几种典型方式失败：（a）**OOD 退化**——当学生 rollout 进入教师分布的稀疏或分布外区域时，教师 log-prob 可能噪声化，破坏正确与错误轨迹之间的排序；（b）**高估错误轨迹**——错误轨迹可能因局部 token 模式匹配教师高置信区域而获得异常高分；（c）**低估正确轨迹**——正确轨迹可能因其生成路径偏离教师主流区域而获得异常低分，从而压制有用的推理路径。这些现象表明教师监督并非始终可靠，促使我们引入结果奖励作为校准轨迹级监督的全局锚点。

### 3.2 Uni-OPD 概览

给定 $M$ 个专业于不同领域的专家教师 $\{\pi_{T_1}, \pi_{T_2}, \ldots, \pi_{T_M}\}$，并令 $w_i$ 表示分配给教师 $\pi_{T_i}$ 的权重，定义 Uni-OPD 目标为：

$$J_{Uni-OPD}(\theta) = \sum_{i=1}^{M} w_i \cdot D_{KL}\left(\pi_\theta \| \pi_{T_i}\right) \tag{4}$$

这一公式化为单教师和多教师蒸馏提供了统一目标（通过聚合多个专家的监督）。

在此目标基础上，我们从两个基本角色优化 OPD：

- **学生视角**：引入数据平衡策略，通过**离线难度感知**和**在线正确率感知**选择来促进探索。
- **教师视角**：开发**结果引导的边距校准**机制，通过强制执行与结果奖励的一致性来修正不可靠的 token 级监督。

### 3.3 联合离线与在线数据平衡策略（学生探索）

从学生视角来看，生成轨迹的充分多样性以及适当的难度水平对有效 OPD 至关重要。为此，我们提出离线和在线互补的数据平衡策略。

**离线难度感知数据平衡。** RL 中的普遍实践是通过多次 rollout 估计 prompt 难度，然后滤除过于简单（全对）或过于困难（全错）的样本。然而，对于小规模模型，训练数据常呈现**镜像 J 形或 U 形分布**——大多数样本集中在极难或极易两端。严格移除这些简单或困难样本会大幅减少数据多样性，限制对有信息量状态的探索。我们的实证发现表明这种过滤在 OPD 中导致显著的性能退化。

基于这一观察，我们采用**难度感知平衡策略**，选择性地**上采样**中等难度样本（即在多次 rollout 中仅部分正确的样本）。该策略将数据分布重塑为更均匀的形式，同时保留多样性和难度谱——使学生能生成更有信息量的轨迹，探索更广阔的解空间。

**在线正确率感知数据平衡。** 在应用离线难度感知平衡后，我们进一步观察到探索不足会导致模型在训练期间坍缩到局部最优，尤其是当 rollout 组缺乏足够的结果多样性时（例如，仅包含错误轨迹）。为缓解这一问题，我们显式地在训练期间**强制每个 rollout 组内正确和错误轨迹的均衡组合**。这防止了所有样本共享相同结果从而产生无信息量梯度的退化情况。通过维持这种平衡，我们确保学生持续收到有意义的对比信号进行稳定的在策略学习。实验表明，合适的正确/错误比（≈0.75–1.0）比仅使用正确样本或过高比例产生更好的性能。

### 3.4 结果引导的边距校准（教师监督）

OPD 的一个基本前提是：教师对正轨迹和负轨迹展现出方向性的似然偏好——相对于学生，教师应对正确轨迹赋予更高似然，对错误轨迹赋予更低似然。在此前提下，所得蒸馏信号应在轨迹级别与结果级正确性保持一致。

**轨迹级蒸馏回报。** 为刻画沿 rollout 轨迹的整体监督信号，我们定义轨迹级蒸馏回报为教师与学生之间平均对数概率差：

$$G_{OPD}(q, \tau) = \frac{1}{|\tau|} \sum_{t=1}^{|\tau|} \log \frac{\pi_T(o_t | q, o_{<t})}{\pi_\theta(o_t | q, o_{<t})} = \frac{1}{|\tau|} \sum_{t=1}^{|\tau|} r_t^{OPD} \tag{5}$$

**顺序一致性作为轨迹级判据。** 对于给定问题 $q$，令 $R(q, \tau) \in \{0, 1\}$ 表示采样轨迹 $\tau$ 的结果奖励（1=正确，0=错误）。定义正负轨迹集：

$$S^+(q) = \{\tau | R(q, \tau) = 1\}, \quad S^-(q) = \{\tau | R(q, \tau) = 0\} \tag{6}$$

将完整推理 rollout 视为单一宏动作，结果 RL 回报自然满足 $G_{RL}(q, \tau^+) > G_{RL}(q, \tau^-)$。在蒸馏前提下，期望 $G_{OPD}$ 继承相同排序：

$$G_{OPD}(q, \tau^+) \geq G_{OPD}(q, \tau^-), \quad \forall \tau^+ \in S^+(q), \tau^- \in S^-(q) \tag{8}$$

**教师监督可能违反排序。** 在实践中，教师的监督并不总是可靠的——可能在稀疏 OOD 区域退化、高估错误轨迹或低估正确轨迹。这些问题在 token 级监督聚合到轨迹级后可能仍存在。

**结果引导的边距校准。** 基于以上分析，在 OPD 训练期间，公式（8）的约束在每个 prompt 的正负轨迹之间应当成立。我们考虑最低得分正确轨迹与最高得分错误轨迹之间的**边距（margin）**，这直接刻画了最对抗情况下排序是否被违反：

$$m(q) = \min_{\tau \in S^+(q)} G_{OPD}(q, \tau) - \max_{\tau \in S^-(q)} G_{OPD}(q, \tau) \tag{9}$$

$m(q) \geq 0$ 表示严格顺序一致性。为提高鲁棒性，我们进一步要求：

$$m(q) \geq \delta \tag{10}$$

其中 $\delta > 0$ 定义了对抗估计噪声和有限样本波动的安全边距。

**边距校准策略。** 基于公式（10），我们提出两种校准策略：

1. **边距掩码（Margin Mask）**：仅保留满足 $m(q) \geq \delta$ 的 prompt 组，丢弃违反的组——更保守的方案。
2. **边距平移（Margin Shift）**：对 $m(q) < \delta$ 的组，施加**最小加性修正**来修复：

$$\Delta(q) = \delta - m(q), \quad \tilde{G}_{OPD}(q, \tau) = G_{OPD}(q, \tau) + \Delta(q) \cdot \mathbf{1}\{R(q, \tau) = 1\} \tag{11}$$

平移后保证 $\min_{S^+} \tilde{G}_{OPD} - \max_{S^-} \tilde{G}_{OPD} = \delta$。Margin Shift 以最小 group 级修正恢复结果一致的排序，被采用为主方法。

## 4 实验与分析

### 4.1 实验设置

**模型。** 文本实验使用 Qwen3-4B/1.7B 学生模型，通过领域特定 RL 获得同规模专门化教师，强到弱设置使用 Qwen3-30B-A3B-Instruct-2507 作为强教师。多模态实验使用 Qwen3-VL-2B/4B-Instruct 学生模型。

**蒸馏场景。** 覆盖四种场景：（1）单教师蒸馏（LLM 的数学/代码，MLLM 的数学/逻辑/文档）；（2）多教师蒸馏（合并多个领域专家能力）；（3）强到弱蒸馏（30B → 4B/1.7B）；（4）跨模态蒸馏（结合文本代码和多模态数学在一个 MLLM 学生中）。

**基准。** 5 个能力域 16 个基准：
- 文本数学推理：AIME 2024/2025、HMMT 2025（2月/11月）
- 文本代码生成：HumanEval+、MBPP+、LiveCodeBench
- 多模态数学推理：MathVision、DynaMath、WeMath
- 多模态逻辑推理：LogicVista、VisuLogic
- 文档理解：AI2D、ChartQA、DocVQA、InfoVQA

### 4.2 LLM 和 MLLM 的单教师与多教师蒸馏

**LLM 结果。** Uni-OPD 在单教师和多教师设置下均达到最佳整体性能。单教师蒸馏：数学平均 48.7（+4.1 over OPD），代码平均 63.2（+3.0 over OPD）。多教师蒸馏：数学 48.5（+1.5），代码 63.6（+3.4），有效将不同教师的能力合并到单个学生中。

**MLLM 结果。** 单教师蒸馏：数学推理 63.9、逻辑推理 51.7、文档理解 83.7——三个领域均为最佳。多教师蒸馏：数学 57.9→61.0（+3.1）、逻辑 50.0→52.5（+2.5）、文档 83.4→83.9（+0.5），一致超越标准 OPD。

### 4.3 强到弱蒸馏

从 Qwen3-30B 教师蒸馏到 4B/1.7B 学生：
- 4B 学生：Uni-OPD 数学 42.9（+1.7）、代码 60.8（+1.8）
- 1.7B 学生：Uni-OPD 数学 25.0（+1.2）、代码 52.7（+3.6）

Uni-OPD 有效弥合了能力差距，使较小学生能更有效地吸收和复制强教师的复杂推理行为。

### 4.4 跨模态蒸馏

在 Qwen3-VL-4B-Instruct 学生上，从文本代码教师和多模态数学教师联合蒸馏：
- 文本代码生成：64.1→65.6（+1.5），三个代码基准全部提升，LCB 提升最大（38.6→41.3）
- 多模态数学推理：62.7→63.9（+1.2），MathVision 和 DynaMath 均有提升

Uni-OPD 能有效吸收和协调来自文本和多模态领域的能力在一个统一学生模型中，而非以牺牲一个领域为代价来提升另一个。

### 4.5 消融研究

在 Qwen3-4B 学生上系统消融三种核心策略：

| 配置 | 数学平均 | 代码平均 |
|------|---------|---------|
| OPD（基线） | 47.0 | 60.2 |
| Uni-OPD（完整） | **48.5** | **63.6** |
| 无离线数据平衡 | 47.5 | 62.3 |
| 无在线数据平衡 | 47.8 | 62.6 |
| 无边距校准 | 47.3 | 61.2 |

**三种策略各自贡献显著**——移除任一项均导致性能下降。数据平衡解决探索不足，边距校准提升监督可靠性。

**Margin Mask vs. Margin Shift。** 两者均持续优于基线（+3.1/+3.5 over OPD），Margin Shift 略优于 Margin Mask（48.1 vs 47.7），被采用为主方法。

### 4.6 定性评估

通过 token 级奖励热力图可视化边距校准的效果。左侧显示两种典型失败模式——错误轨迹因局部匹配获得高蒸馏回报（红色 tokens），正确轨迹因已被学生良好覆盖而获得低蒸馏回报（浅色/蓝色 tokens）。右侧显示经 Margin Shift 后，逐 token 奖励被统一平移，使轨迹级聚合与结果奖励对齐，恢复了正确与错误轨迹的正确排序。

### 4.7 分析与核心洞见

**1. 平衡推理能力与效率。** Uni-OPD 以比 RL 更少的优化步数达到最佳性能，一致交付跨多样化领域的强推理能力。

**2. 教师价值来自能力差距，而非绝对强度。** 即使使用相同的 4B backbone，领域特定的 RL 教师注入新能力和知识，驱动学生改进甚至超越教师。双视角配方进一步将差距转化为学生收益。

**3. OPD 蒸馏推理是一种模态无关的能力。** 在文本和多模态数据上联合训练时，多模态学生的文本代码和多模态数学/逻辑推理同时提升。逐 token 信号携带的推理模式很大程度上独立于模态。

**4. OPD 干净地合并专门化能力，相关能力互相强化。** 扩展到三个教师，联合提升所有能力。OPD 因此为合并多个专家到一个推理器提供了可扩展的途径。

## 5 结论与未来工作

我们提出了 **Uni-OPD**，一个统一 OPD 框架，泛化至 LLM 和 MLLM。我们识别了有效 OPD 的两个关键瓶颈：学生探索不足和教师监督不可靠。为应对这些问题，我们提出了双视角优化策略：（i）离线和在线数据平衡促进学生探索；（ii）结果引导的边距校准提升教师监督可靠性。在 16 个基准上覆盖多教师、强到弱和跨模态场景的广泛实验证明了 Uni-OPD 的有效性和通用性。

未来方向包括：（a）将 Uni-OPD 扩展到更大规模教师蒸馏；（b）应用于更广泛的能力合并场景（如智能体规划、工具使用、长程决策）；（c）揭示 OPD 的机制性原理——特别是其如何塑造训练动力学和参数几何。

## 附录要点速览

### A. 数据平衡细节

**离线难度感知平衡：** 训练前用学生模型对全部训练数据执行一次性离线 rollout（N=8），用验证器判定正确数，以经验通过率 k/N 作为难度代理。对 U 形分布——上采样中等难度（1-7/8 正确）；对镜像 J 形分布——上采样所有非平凡样本（1-8/8 正确）。效果：展平难度分布，确保 token 级信用信号在各难度级别均匀分布。

**在线正确率感知平衡：** 训练时每个 batch 维持目标正确/总数比 $\rho \approx 0.5$，当偏差超过容忍度 $\epsilon$ 时对过度代表侧降采样，保持在 $\rho \pm \epsilon$ 区间内。

### B. 边距校准细节

轨迹即单一动作视角下，结果 RL 回报 $G_{RL}(q, \tau) = R(q, \tau)$，天然满足正 > 负排序。蒸馏前提期望 $G_{OPD}$ 继承相同排序，但这是期望而非保障——实证中排序违反普遍存在（见附录统计证据），促使边距掩码和边距平移两种校准策略的提出。
