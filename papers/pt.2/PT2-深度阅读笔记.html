1. 两篇论文的定位与关系

1.1 OPD 研究版图全景

在理解这两篇论文之前，必须先看清楚 On-Policy Distillation (OPD) 研究的整体版图。

OPD 的起源与核心思想：传统大模型后训练流程是 SFT → RLVR。但 SFT 存在 exposure bias（训练-推理分布不一致），RLVR 只能给序列级别的稀疏奖励。OPD 的解决方案是：让学生模型在自己生成的 on-policy 轨迹上接受教师的 token 级密集监督。这结合了 RL 的 on-policy 采样优势和 SFT 的细粒度信号优势。

PT.1（上一阶段） 已经覆盖了两篇 OPD 的基础论文：

  • PRISM：将 OPD 作为 SFT 和 RLVR 之间的中间对齐阶段，用对抗式 MoE 判别器修正分布漂移
  • Uni-OPD：将 OPD 作为独立的后训练范式，系统性解决探索不足和监督不可靠两个瓶颈

PT.2（本阶段） 覆盖的是 OPD 研究版图的两个前沿扩展方向：

扩展维度 论文 核心问题
效率维度 Prune-OPD OPD 在长程推理中如何不浪费计算？
范式维度 Flow-OPD OPD 能否从文本 LLM 迁移到流匹配图像生成？

1.2 两篇论文的共同基础

两篇论文虽然领域不同（一个是 LLM 数学推理，一个是 T2I 图像生成），但共享 OPD 的理论基础：

  1. On-Policy 采样：学生模型根据自己的当前策略生成轨迹，而非使用离线数据集
  2. 密集教师监督：教师沿整条轨迹的每一步（而非仅最终输出）提供 token 级或向量场级的反馈信号
  3. Reverse KL 散度：核心优化目标是最小化学生分布与教师分布之间的 reverse KL
  4. 可靠性问题：两篇论文都认识到——不是所有的教师监督信号都同等可信

1.3 两篇论文的互补关系

Prune-OPD 解决的是"OPD 内部的效率问题"：

  • 前提：OPD 已经在 LLM 推理中有效
  • 问题：长链推理时，学生前缀偏离教师后，后续 OPD 奖励不可靠 → 浪费计算
  • 方案：动态监测师生兼容度，衰减不可靠奖励，截断浪费的 rollout

Flow-OPD 解决的是"OPD 的范式扩展问题"：

  • 前提：OPD 在 LLM 中成功，但 T2I 领域没有等效方法
  • 问题：流匹配模型的奖励稀疏 + 多任务梯度干扰 → 跷跷板效应
  • 方案：将 OPD 首次引入流匹配模型，证明 Flow-KL 退化为加权 L2 距离

关键理解：这两篇论文不是竞争关系，而是从效率（如何更省） 和范式（能用在哪儿） 两个维度共同扩展了 OPD 的研究版图。

2.2 核心动机：长程推理中 OPD 的可靠性悖论

问题本质

OPD 在长程推理（如数学证明，单题可达数千 token）中面临一个根本性矛盾：


学生的生成前缀 不可避免地偏离 教师的思维过程
    ↓
教师在偏离后的 token 级密集奖励 → 局部不可利用（locally unexploitable）
    ↓
继续在发散轨迹上生成和监督 → 仅浪费大量计算 + 可能降低训练质量

"前缀漂移"（Prefix Drift） 是 Prune-OPD 的核心诊断概念。它不是指学生最终答案错了，而是指：在生成过程中的某个位置，学生选择的推理方向与教师预期的不一致。此时教师在该位置之后的 token 级反馈就变得"空头支票"——从局部来看，教师建议的 token 对于学生的当前推理状态已经没有可执行的指导意义。

现有 OPD 实践的困境

当前 OPD 的做法是：

  1. 生成前确定一个 rollout 预算（如最大 12288 token）
  2. 沿整条学生轨迹均匀地应用教师密集奖励

这造成了两难困境：

  • 预算太短：丢弃了有用的长推理链监督
  • 预算太长：大量计算花费在"已漂移"的后缀上，这些位置的教师信号已局部不可用

Prune-OPD 的核心洞察：OPD 需要的不是"更多或更少的密集奖励"，而是判断哪些位置的密集奖励足够可靠，值得训练。

2.3 方法：可靠性感知三组件框架

Prune-OPD 将长程 OPD 重新定义为可靠性分配问题（reliability-allocation problem），由三个组件构成级联系统。

组件 1：逐位 Top-k 重叠率监测（检测层）

在每个生成位置 t，计算学生与教师 top-k 预测的交集比例：

$$\text{OverlapRate}(t) = \frac{|\text{TopK}(\pi_\theta, t) \cap \text{TopK}(\pi_T, t)|}{k}$$

  • 默认 k = 20，阈值 τ = 0.7
  • 重叠率低于阈值 → 记录一次"前缀漂移事件"（prefix-drift event）
  • 为什么是 Top-k 而非 Top-1？ Top-1 只看最优选择可能过于敏感——偶尔一次 token 分歧不代表"思维分叉"。Top-k 捕获的是候选集层面的语义对齐：如果学生的 top-20 候选和教师的 top-20 候选大部分重叠，说明思考方向仍然一致

累计漂移计数：C(t) = Σᵢ₌₁ᵗ 𝟙[OverlapRate(i) < τ]

C(t) 单调递增——每次低于阈值就 +1。C(t) 越大，说明前缀偏离越远。

组件 2：单调可靠性权重与动态截断（决策层）

可靠性权重公式：

$$R = \text{clip}(1 - w_{\text{drop}} \cdot C,\ 0,\ 1)$$

  • w_drop 为衰减速率（默认 0.01）
  • R 从 1.0 开始，随着累计漂移事件数 C 增长逐渐衰减至 0
  • 单调不可逆属性：R 只能下降不能上升——一旦信任降低就永久降低

实际损失权重：

$$L = R + w_{\text{base}}$$

  • w_base = 0.5，确保即使 R→0，仍有基础信任度保留微弱的教师信号
  • 缩放后的 OPD 奖励：$\tilde{r}_{t,j} = L \cdot r_{t,j}$

动态截断触发：当 R → 0 时，立即终止该 rollout——不再生成后续 token，将节省的计算资源重新分配给其他更有希望的 prompt。

设计哲学："及时止损优于强行续写"——一旦学生的推理路径已偏离教师，后续的监督信号本身已不可用，计算它们就是浪费。

为什么 R 是单调不可逆的？ 前缀漂移是路径依赖的——一旦在位置 p 处学生选了与教师不同的方向，后续所有 token 都建在这个分叉之上。单个 token 的"重新对齐"无法消除前缀的分叉效应。

组件 3：动态响应预算控制器（调度层）

M_max 在 2048~12288 之间根据 batch 命中率自适应调整：

  • 高命中率（足够多的有效可靠长度达到当前上限）→ M_max 扩展（+100），探索更长推理链
  • 低命中率持续 P 步（patience=3）→ M_max 收缩（-100），保护计算资源

与组件 2 的耦合：已触发漂移截断的 prompt 自动释放预算给其他 prompt。

为什么固定预算不够？ 简单 prompt 不需要长链但被分配相同预算（浪费），困难 prompt 需要深度推理但被截断（不足）。动态预算 = "好钢用在刀刃上"。

Qwen3 配对的特殊现象：为什么 Prune-OPD 能同时提升效率和准确率？

Table 1 中，两个 Qwen3 配对是唯一同时获得效率和准确率提升的场景。附录 A.11 解释了原因：

  1. 极度低兼容度：Qwen3-1.7B-Base 与 Qwen3-4B (Non-thinking) 之间的 top-k 重叠率极低
  2. Prune-OPD 的有效 OPD 长度仅几百 token，而 OPD 基线使用最大 12288 token
  3. 未剪枝 OPD 的失败模式：只有早期前缀包含局部可利用的教师监督，但长后缀（占据绝大多数 token）贡献了大量在漂移、低重叠前缀上计算的梯度——这些梯度噪声淹没了有用信号
  4. Prune-OPD 通过衰减和截断低可靠性后缀，将优化集中在教师仍然可执行的前缀上——这不仅是效率机制，也是梯度去噪机制

权重随位置衰减曲线（Figure 5）

  • 训练初期（step 1）：权重衰减不明显，因为模型尚未学到可能导致漂移的行为

含义：Prune-OPD 的可靠性信号本身是学习到的——随着训练的进行，模型逐渐形成自己的推理风格，与教师的差异（或一致）也逐渐固化。

2.8 方法局限性与批判分析

  1. w_base = 0.5 是启发式超参：没有理论推导或自动学习机制。对于不同的师生配对，最优 w_base 可能不同
  2. Top-k 重叠率可能不捕获语义级发散：两个模型可能在 top-k 中有很多重叠（词汇层面），但推理语义已经分叉。例如，都在 top-20 中包含 "因此"，但一个在做正确推导，一个在胡言乱语
  3. 线性衰减假设：R = 1 - w_drop × C 假设每个漂移事件同等重要，但实际上某些位置的漂移可能更关键（如第一个分叉点）
  4. 截断为二值硬决策：R → 0 时硬截断。可考虑软截断（如逐渐降低生成温度）
  5. 仅测试数学推理：代码、通用对话、多轮交互等场景的泛化性未知
  6. 需要白盒教师 logits：API-only 场景不适用——必须能访问教师的 top-k 分布
  7. 附录指出的限制：overlap metric 可能遗漏"共享候选 token 但排序/分数差异很大"的情况；线性衰减假设在"低重叠前缀后来回到教师兼容状态"时可能过度惩罚

3.2 核心动机：T2I 多任务对齐的两大瓶颈

瓶颈 1：奖励稀疏性

Flow Matching 文本到图像模型的推理过程是多步去噪轨迹（典型 10-40 步）。但标准 RL 方法只给每张最终图像一个标量分数：


去噪步 1 → 去噪步 2 → ... → 去噪步 N → 最终图像 → 标量奖励 (一个数字)

学生不知道在哪一步开始走偏。这类似于考试只告诉学生"你得了 70 分"但不告诉哪道题错了。

瓶颈 2：梯度干扰（跷跷板效应/Seesaw Effect）

T2I 多任务对齐需要同时满足：

  • 文本忠实度（GenEval：对象存在、属性绑定、空间关系）
  • 文字渲染清晰度（OCR：图像中文字可辨认）
  • 视觉美学（DeQA：画面好不好看）
  • 整体质量（PickScore：人类偏好对齐）

这些目标的梯度相互冲突：

  • 提升 OCR 准确率 → 倾向于生成"白底黑字的教科书" → 美学崩塌
  • 提升美学分数 → 倾向于艺术化渲染 → 文字变得模糊
  • 混合多奖励直接优化 → "按下一个葫芦浮起一个瓢" → 所有指标均退化

Experimental Evidence（Table 1）：


SD-3.5-M:           GenEval 0.63, OCR 0.59
+GenEval (GRPO):    GenEval 0.94, OCR 0.65  ← GenEval大幅提升
+OCR:               GenEval 0.89, OCR 0.91  ← GenEval下降5%！
+PickScore:         GenEval 0.82, OCR 0.86  ← 继续退化
+DeQA:              GenEval 0.73, OCR 0.83  ← 灾难性遗忘

每增加一个奖励目标，之前的优化成果就被部分覆盖。这就是"稀疏信息瓶颈"——将多维冲突压缩为单一标量优势函数，不可避免地导致零和博弈。

3.3 方法：两阶段多教师 OPD 框架

Flow-OPD 的核心思想来自 LLM 领域 OPD 的成功经验（DeepSeek-V4、MiMo、GLM-5 都使用 OPD 整合多域能力），将其首次迁移到流匹配模型。

阶段 1：领域专精教师培养

每位教师通过单奖励 GRPO 在各自维度训练到性能天花板：

教师 专攻维度 奖励信号 底座
GenEval 教师 文本-图像对齐 GenEval score SD3.5 Medium
OCR 教师 图像中文字渲染 OCR accuracy SD3.5 Medium
DeQA 教师 视觉美学 DeQA + PickScore (4:6) SD3.5 Medium
PickScore 教师 整体质量 PickScore SD3.5 Medium

为什么用单奖励？ 确保每位教师在其领域无干扰地达到性能天花板——不存在跷跷板效应，因为只有一个目标。

为什么共享底座？ 所有教师从同一 SD3.5 Medium 初始化——"说同一种语言，各有专长"。这保证了后续多教师融合时的参数空间兼容——权重可以直接插值（模型合并）或输出可以直接聚合（SFT 合并）。

阶段 2：多教师 OPD 融合

Step 1：冷启动（Cold Start）

两种互补策略：

策略 做法 优势 局限
SFT 合并 聚合各领域教师的最佳生成输出，在学生上做监督微调 广泛适用，可扩展 需要额外训练
模型合并 对教师 checkpoint 做权重插值 零额外训练成本 要求教师架构同质

目的："从一个融合点出发，而非从零开始"——冷启动确保 on-policy OPD 循环的初始分布不会离任何教师太远。

Step 2：On-Policy 采样

将确定性 ODE 转化为随机 SDE 以注入探索噪声：

$$dx_t = \left[v_\theta(x_t, t) + \frac{\sigma_t^2}{2t}(x_t + (1-t)v_\theta(x_t, t))\right]dt + \sigma_t d\bar{w}$$

通过 Euler-Maruyama 离散化，学生的转移行为成为局部各向同性高斯策略：

$$\pi_\theta(x_{t-\Delta t}|x_t, c) = \mathcal{N}(\mu_\theta(x_t, t), \sigma_t^2 \Delta t \mathbf{I})$$

每个 prompt 采样 G 条独立轨迹，生成 on-policy 边际分布。

Step 3：任务路由标记（Task Routing Labeling）

这是 Flow-OPD 的关键设计——让学生知道"这一步该听哪位老师的话"：

$$\mathbf{v}_{\text{target}}(x_t, t, c) = \mathbf{v}_k(x_t, t, c), \quad \text{where } k = \mathcal{R}(c)$$

  • $\mathcal{R}(c)$ 是确定性的任务→教师路由函数
  • 硬路由：每个 prompt 只激活一个领域教师——消除跨域梯度干扰
  • 学生按 prompt 类别接收不同教师的密集监督

3.4 Flow-KL 定理：最核心的理论贡献

这是 Flow-OPD 最重要的理论贡献，也是理解该方法的关键。

推导过程（从 KL 散度到加权 L2）

步骤 1：两个高斯策略的 KL 散度

学生策略和教师的目标策略都是 d 维多元高斯分布，且共享相同的各向同性协方差矩阵 $\Sigma_t = \sigma_t^2 \Delta t \mathbf{I}$（协方差仅由 SDE 噪声调度决定，与学生/教师无关）。

两个高斯分布 $N_1(\mu_1, \Sigma_1)$ 和 $N_2(\mu_2, \Sigma_2)$ 的 KL 散度：

$$D_{KL}(N_1 \| N_2) = \frac{1}{2} \left[\text{tr}(\Sigma_2^{-1}\Sigma_1) - d + (\mu_1 - \mu_2)^T \Sigma_2^{-1}(\mu_1 - \mu_2) + \ln\frac{\det \Sigma_2}{\det \Sigma_1}\right]$$

步骤 2：利用协方差相等简化

因为 $\Sigma_1 = \Sigma_2 = \Sigma_t$：

  • $\text{tr}(\Sigma_t^{-1}\Sigma_t) = \text{tr}(\mathbf{I}) = d$ → 与 -d 抵消
  • $\ln(\det \Sigma_t / \det \Sigma_t) = \ln(1) = 0$
  • 只剩下马氏距离项

$$D_{KL}(\pi_\theta \| \pi_{\text{target}}) = \frac{1}{2}(\mu_\theta - \mu_{\text{target}})^T \Sigma_t^{-1}(\mu_\theta - \mu_{\text{target}})$$

步骤 3：均值由向量场参数化

根据 Euler-Maruyama 离散化，去噪转移的均值由预测的向量场 $\mathbf{v}$ 确定：

$$\mu_\theta(x_t, t) = x_t + \left[\mathbf{v}_\theta(x_t, t, c) + \frac{\sigma_t^2}{2t}(x_t + (1-t)\mathbf{v}_\theta(x_t, t, c))\right]\Delta t$$

$\mu_{\text{target}}$ 同理。两者的状态依赖基础项 $x_t$ 在相减时抵消。

步骤 4：最终简洁形式

$$D_{KL}(\pi_\theta \| \pi_{\text{target}}) = \frac{\Delta t}{2\sigma_t^2} \left[t(1-t) + \frac{1}{\Delta t}\right]^2 \cdot \|\mathbf{v}_\theta(x_t, t, c) - \mathbf{v}_{\text{target}}(x_t, t, c)\|^2$$

记权重 $w(t) = \frac{\Delta t}{2\sigma_t^2}[t(1-t) + 1/\Delta t]^2$，则：

$$\boxed{D_{KL}(\pi_\theta \| \pi_T) = \mathbb{E}_{t, x_t \sim \pi_\theta}\left[w(t) \cdot \|\mathbf{v}_\theta(x_t, t) - \mathbf{v}_T(x_t, t)\|^2\right]}$$

推论：零策略梯度方差

文本 LLM 中的 OPD（作为对照）：

  • KL 散度通过 token 级对数比来估计 → 依赖于学生 on-policy 采样 → 需要用 Policy Gradient 传播信号 → 高方差 + 不稳定

Flow-OPD 中的 OPD：

  • KL 散度有闭式解析解 → 等价于两个向量场之间的加权 L2 距离 → 直接用 MSE 回归优化 → 零方差 + 极稳定

从 Policy Gradient 的等价性来看：

$$E[\nabla_\theta \log \pi_\theta \cdot (-D_{KL})] \equiv \nabla_\theta(-D_{KL})$$

在离散空间中，等式右边的直接梯度在分析上是不可行的（需要遍历所有 token），所以LLM OPD 必须使用左边的高方差估计。但在连续流匹配空间中，$D_{KL}$ 有解析解，可以直接通过标准反向传播最小化 MSE 损失——这完全绕过了 Policy Gradient 估计器。

深层含义：流匹配 OPD 比文本 OPD 在理论上更优雅——它天生避免了 RL 中最大的痛点（方差）。这不是工程优化，而是数学结构决定的优势。

3.5 MAR：多教师反退化正则化

动机

多任务 OPD 中，学生为提升 OCR 准确率可能生成"白底黑字的教科书扫描页"——OCR 分数很高，但完全失去了美学和多样性（reward hacking）。

机制

一个冻结的、任务无关的锚定教师（如 DeQA 教师）提供全数据 KL 正则化：

$$\mathcal{L}_{\text{MAR}} = \mathbb{E}_{c, t, x_t \sim \pi_\theta}\left[w(t)\|\mathbf{v}_\theta(x_t, t, c) - \mathbf{v}_{\text{aesthetic}}(x_t, t, c)\|^2\right]$$

总损失：

$$\mathcal{L}_{\text{Total}} = \mathcal{L}_{\text{Flow-OPD}} + \lambda \cdot \mathcal{L}_{\text{MAR}}$$

  • λ = 0.02（MAR KL ratio）
  • 领域教师推动学生向各自的专精轴优化
  • 冻结锚定教师确保学生不偏离通用图像质量流形

MAR vs. 无 MAR（Figure 5）：

  • 无 MAR：背景模式坍塌、语义冗余、多实体生成相同特征
  • 有 MAR：背景多样化、结构多样性、精确语义遵循

类比 PRISM

MAR 的角色类似 PRISM 中"用原 Instruct 模型做隐式锚点"——两者都不是主动推动，而是防止退化。Flow-OPD 将这一思想显式化为 KL 正则项。

3.8 方法局限性与批判分析

  1. 仅测试 SD3.5 Medium：更大/更新架构（如 FLUX、SD3.5 Large）上的效果未知
  2. 教师训练成本高：N 个教师 = N × GRPO 训练 → 总计算成本显著高于单阶段方法
  3. 任务路由 token 手动设计：$\mathcal{R}(c)$ 是确定性的、预定义的——对于开放域/混合 prompt，路由可能不准确
  4. 仅 4 个奖励维度：扩展到 10+ 个维度的可扩展性未经测试
  5. 对离散扩散模型不完全适用：Flow-KL 定理的推导依赖于流匹配的连续时间 SDE 框架
  6. 教师能力上界限制：如果某个领域教师本身性能差，其错误监督会传播给学生（Figure 11）
  7. 师生架构同质要求：需要相同的模型架构来进行逐步骤的细粒度向量场监督

4.3 互补关系

Prune-OPD 能做但 Flow-OPD 不做的：

  • 逐位置监测师生兼容度
  • 基于兼容度的动态截断
  • 响应预算自适应调度
  • 在低兼容度场景下的梯度去噪效应

Flow-OPD 能做但 Prune-OPD 不做的：

  • 跨模态 OPD（文本→图像）
  • 多教师能力融合
  • 解析 KL 散度推导（Flow-KL 定理）
  • 多任务去干扰（任务路由 + MAR）
  • 超教师效应（协同增益）

两者结合的潜在方向：

  1. 将 Prune-OPD 的可靠性感知移植到 Flow-OPD：在流匹配去噪轨迹上监测师生向量场在每个时间步的兼容度，对低兼容度时间步衰减监督信号
  2. 将 Flow-OPD 的多教师框架引入 Prune-OPD：多个推理风格不同的教师（如证明风格 vs 直觉风格）同时蒸馏，用任务路由选择合适的教师
  3. 统一理论框架：Prune-OPD 的可靠性权重可以被视为一种状态依赖的 KL 散度调节器，与 Flow-OPD 中 MAR 的 KL 正则化在数学形式上可统一

5. 导师可能追问的20个问题

基础理解类（5题）

Q1：什么是 On-Policy Distillation？Prune-OPD 和 Flow-OPD 分别如何体现 "on-policy"？

OPD 的核心是让学生在自己的生成轨迹上学习教师分布，而非在教师预生成的静态数据上学习。

>

Prune-OPD 的 on-policy 体现：学生自回归采样推理链 y ∼ π_θ(·|x)，教师在相同的学生访问前缀 y_{

>

Flow-OPD 的 on-policy 体现：学生通过 SDE 采样去噪轨迹 x_t ∼ π_θ(·|c)，教师在同一采样状态上提供向量场 v_target(x_t, t, c)。on-policy 探索打破了离线 SFT 的性能天花板。

Q2：Prune-OPD 的"前缀漂移"是什么？为什么它对 OPD 是致命的？

前缀漂移是指：在自回归生成过程中，学生的推理前缀 y_{

>

致命原因：前缀漂移是路径依赖的——一旦在位置 p 处分叉，后续所有 token 都建在这个分叉之上。单个 token 的"重新对齐"无法消除。此时继续应用教师的密集奖励，相当于让教师批改一个已经完全跑题的论证——批改本身可能正确，但对学生没有指导意义，且占据大量计算。

Q3：Flow-OPD 中的 Flow-KL 定理为什么是突破性的？零方差意味着什么？

Flow-KL 定理证明：在连续流匹配模型中，学生和教师策略之间的 KL 散度有解析闭式解，等价于两个向量场之间的加权 L2 距离。

>

为什么是突破性的：文本 LLM 的 OPD 必须通过 Policy Gradient 估计 KL 散度的梯度——这引入了高方差，需要重要性采样、PPO clip 等复杂稳定化技术。而 Flow-OPD 可以直接通过标准 MSE 回归最小化向量场差异——策略梯度方差为零。

>

零方差的含义：训练极其稳定，不需要复杂的 RL 基础设施（优势估计、clip ratio 等），本质上退化为监督学习但保留了 on-policy 探索的优势。

Q4：Prune-OPD 的三个组件之间是什么关系？能否单独使用？

三个组件是级联关系："检测 → 决策 → 资源调度"：
- 组件 1（重叠率监测）：检测哪些位置发生了漂移
- 组件 2（可靠性权重 + 截断）：决策如何根据漂移累积来衰减奖励和终止 rollout
- 组件 3（动态响应预算）：调度如何在 batch 层面全局最优分配计算资源

>

可以部分使用：仅用组件 1+2（可靠性感知权重 + 截断，但固定预算）→ 仍有效果，但不如三组件全用。仅用组件 1→ 只是诊断工具，不改变训练。仅用组件 3（动态预算）但不做可靠性截断 → 就是简单的自适应长度，失去了 Prune-OPD 的核心优势。

Q5：Flow-OPD 为什么不直接把多个教师的输出混合起来做离线蒸馏，而要用 on-policy 方式？

离线混合蒸馏有两个致命问题：
1. 分布不匹配：教师在各自的数据分布上生成最优输出，但学生的 on-policy 采样分布可能完全不同——教师在其"舒适区"之外可能给出低质量监督
2. 无法处理梯度干扰：即使做离线多教师蒸馏，学生在不同任务上的参数更新仍然会互相干扰（今天学 OCR 的知识明天被美学目标覆盖）

>

On-policy 方式让学生在自己的当前分布上接受教师监督，且通过任务路由和 MAR 解耦了不同目标的梯度。Figure 4 清楚显示：冷启动 + GRPO-mix 远不如冷启动 + Flow-OPD。

深入技术类（5题）

Q6：Prune-OPD 的 w_base = 0.5 的作用是什么？如果设 w_base = 0 会发生什么？

w_base 有两个实际作用：
1. 防止硬开关：当 R → 0 时，L = R + w_base > 0，教师信号不会被完全切断。这保留了微弱的监督信息，在某些情况下（如 hard case 需要额外的探索信号）有用。
2. 权衡去噪与保留：w_base 控制了保留多少"弱教师信号"。w_base 大 → 更保守，保留更多后缀监督；w_base 小 → 更激进，后缀监督大幅衰减。

>

如果 w_base = 0：R → 0 时后缀位置完全失去教师监督。这相当于在低可靠性区域完全"盲飞"，可能对某些需要维持一定探索水平的场景不利。论文没有报告 w_base=0 的实验结果。

Q7：Prune-OPD 的 overlap ratio 和 top-p acceptance 有什么区别？为什么 overlap 更好？

Top-k Overlap Ratio：候选集级别的兼容度——学生和教师的 top-k 候选有多少重叠。关注的是"思考方向是否一致"。

>

Top-p Action Acceptance：动作级别的兼容度——学生实际采样的 token 是否在教师可见的核心集中。关注的是"具体选择是否被教师认可"。

>

为什么 overlap 更好：推理任务中存在多个合理路径。学生可能选了一个教师 top-p 之外的 token，但整体推理方向仍然正确（有多个合理 token）。Top-p acceptance 对此过分严格——它惩罚了所有"合理但不同"的选择，导致过度截断。Overlap 更宽松——只要候选集有足够重叠，就认为方向一致。

Q8：Flow-OPD 的任务路由是硬路由（hard routing）。软路由（soft routing，如加权混合所有教师的输出）会不会更好？

论文选择硬路由的原因：消除跨域梯度干扰。如果软混合所有教师的向量场（如 α·v_OCR + β·v_GenEval + γ·v_PickScore），在实际优化中这些目标的梯度仍然会互相冲突——α, β, γ 的调节变成了另一个需要解决的优化问题。硬路由将冲突的梯度在样本层面完全解耦。

>

但硬路由也有代价：边界样本（如既需要文字渲染又需要美学的 prompt）只能收一位教师的指导。软路由可能是未来的改进方向——例如用 Gumbel-Softmax 做可微分路由。

Q9：PRUNE-OPD 的动态预算控制器中的"命中率"具体是如何定义的？为什么要用"margin"？

Batch 命中率 h_t：
$$h_t = \frac{1}{B}\sum_{b=1}^{B}\mathbf{1}[E^{(b)} \geq M_t - m]$$

>

其中 E^(b) 是第 b 个样本的有效可靠长度，M_t 是当前最大响应长度，m = 100 是 margin。

>

为什么需要 margin？ 如果严格判断 E^(b) ≥ M_t，那么只要有效长度比 M_t 略小一点（如 12287 vs 12288）就算未命中。Margin 引入了一个容忍区间——有效长度接近上限就算命中。这避免了因微小随机波动导致的预算错误收缩。

>

另外，收缩需要连续 P=3 步均低于阈值——这防止了因单步波动而错误收缩（patience/耐心机制）。

Q10：Flow-OPD 的 MAR 正则化中，为什么选择 DeQA 教师作为锚点而不是原始 SD3.5-M？

DeQA 教师经过单奖励 GRPO 训练，已经将 SD3.5-M 的美学质量优化到了领域天花板。用 DeQA 作为锚点意味着：学生被约束在一个高美学质量流形内，而非仅仅是"不退化"。

>

如果只用 SD3.5-M 作为锚点，约束太弱——学生可以在 SD3.5-M 的分布范围内找到各种低质量生成。DeQA 提供了一个更紧、更高的质量下界。

>

本质上，MAR = "你可以专精，但必须维持在一个很高审美水平上"。

实验设计类（5题）

Q11：Prune-OPD 的实验为什么选择 5 组不同的师生配对？每组配对的实验目的是什么？

5 组配对覆盖了 OPD 的典型场景：

>

1. 1.5B / JustRL-1.5B：同尺寸、同家族的 RL 增强教师——测试最小能力差距下的兼容度
2. 1.5B / 7B：大教师小学生的跨规模蒸馏——测试极端能力差距导致的前缀漂移
3. 1.7B-Base / 4B-NT：最小 base 模型 + 思维模式切换——测试最差兼容度场景
4. 4B-Base / 4B-NT：中等 base 模型 + 思维模式切换——测试中等兼容度
5. 7B / Skywork-OR1-7B：高兼容度对照——验证 Prune-OPD 不会"滥杀无辜"

>

配对 2 的时间缩减最大（68.0%），验证了"大教师→更多前缀漂移→截断收益更大"的假设。配对 5 的时间缩减仅 2.9%，验证了 Prune-OPD 的自适应属性。

Q12：Prune-OPD 中 w_drop = 0.01 意味着什么？如果 w_drop = 0.1 会怎样？

w_drop = 0.01 意味着每次漂移事件降低 1% 的可靠性权重。对于典型的推理链（2000-12000 token），如果重叠率持续低于阈值，可靠性权重在大约 100 次漂移事件后归零。

>

w_drop = 0.1 会怎样：每次漂移事件降低 10% → 10 次事件后 R = 0 → 截断极快发生 → 可能丢失大量有用的中等兼容度后缀。尤其在训练早期，模型尚未稳定，overlap 波动较大，高 w_drop 会导致过度截断。

Q13：Flow-OPD 为什么选择 SD3.5 Medium 而不是更大的模型？

可能原因：
1. 计算资源约束：训练 4 个教师（各需 GRPO）+ OPD 融合 + 多基准评估 → 在 SD3.5 Large（8B）上成本过高
2. 实验可控性：SD3.5 Medium（2.5B）足够快，可以进行更多消融和分析实验
3. 对齐难度适中：SD3.5 Medium 的多任务对齐有一定难度但不过于极端，适合作为概念验证

>

局限：无法确定 Flow-OPD 在更大/更新架构（如 FLUX）上是否同样有效。这需要后续工作验证。

Q14：Prune-OPD 中为什么固定 Truncate 4k 的 OPD 基线在某些配对中表现尚可，但在其他配对中退化？

Truncate 4k 的效果取决于有用监督的分布：
- 如果 4k 以内的前缀已经包含了大部分可用的教师监督（如 1.5B/7B 配对中前缀漂移发生得非常早），固定截断能提升效率而不过多损失准确率
- 如果 4k 以后仍有大量有价值的监督（如 7B/Skywork-OR1 高兼容度场景），固定截断会丢弃有用的长推理信号 → 性能退化

>

Prune-OPD 的优势就在于：它不假设有用监督在哪里——而是通过兼容度信号动态发现截断点。

Q15：Flow-OPD 的超教师效应（Teacher-Surpassing）的实验证据是什么？如何确定不是随机波动？

证据：
1. OCR: Flow-OPD 0.93 > GRPO-OCR 教师 0.92 —— 在多个评估集上一致
2. DeQA: Flow-OPD (Merge) 4.31 > GRPO-DeQA 教师 4.23
3. 定性结果（Figure 3）：Flow-OPD 在某些边缘案例中成功，而所有单个教师都失败

>

论文的假设解释：知识交叉授粉——多教师同时监督使学生学到更全局的表示。单个教师受限于领域偏见（OCR 教师可能过度关注文字而忽略背景），而多教师监督迫使学生在所有维度间寻找平衡，反而发现了单个教师未探索的高质量区域。

>

当然，更严谨的做法应该是多次重复实验并报告标准差——论文没有做这个。

批判思维类（5题）

Q16：Prune-OPD 的 top-k 重叠率作为兼容度指标有什么根本性局限？有没有更好的替代方案？

根本性局限：
1. 词汇重叠 ≠ 语义对齐：都预测"因此"但后续推理可能完全不同
2. 无法捕捉排序差异：top-k tokens 相同但排序或概率分布差异巨大
3. 对"合理多样性"不鲁棒：推理任务中有多个合理的 top-k 候选集，两个都在合理范围内但重叠低

>

更好的替代方案：
- 语义嵌入空间的重叠：将 student/teacher 的 top-k token embeddings 投影到共享空间，计算语义相似度而非词汇交集
- KL 散度阈值：直接用 D_KL(p_t || q_t) 作为兼容度——更直接地测量分布分歧
- 学习式兼容度：训练一个小型判别器来判断 student prefix 是否仍在 teacher 的 support 内
- 轨迹级评估：不只看单步，而是看滑动窗口内的兼容度趋势

Q17：Flow-OPD 声称是"首个将 OPD 引入流匹配"的方法，这个声明的边界在哪里？有哪些相关工作？

这个声明限定在：使用 on-policy 采样 + 多教师密集轨迹级监督 + 冷启动 + MAR 正则化的完整框架。之前的 Flow-GRPO 是单奖励 RL，不是 OPD。DanceGRPO 是混合多奖励的 GRPO，也不是 OPD。

>

但以下几个接近的工作值得关注：
- DiffusionNFT：online RL with forward process，也有密集监督的思想，但无法兼容 CFG（影响性能天花板）
- GDPO：多奖励设置下的 GRPO 改进，但仍是标量奖励
- Flow-GRPO：单个教师 + 单奖励，没有多教师融合

>

Flow-OPD 确实在 OPD 框架迁移到流匹配方面是首个系统性工作。但其独创性的边界需要参照这些接近的工作来界定。

Q18：Prune-OPD 和 Flow-OPD 都依赖于白盒教师（需要访问 logits/向量场）。如果只能通过 API 访问教师，如何做类似的可靠性控制？

这是两篇论文的共同局限性。

>

对于 Prune-OPD：
- 可以用蒸馏一个 logits 代理：在小样本上微调一个开放模型来模仿教师 API 的 top-k 输出
- 可以用输出文本的重叠度作为近似兼容度指标：比较学生和教师 API 在相同前缀下的 next-token 生成，用生成 token 的一致性替代分布重叠
- 但这会显著降低精确度

>

对于 Flow-OPD：
- 目前没有办法在 API-only 设置下实现——它需要教师模型的完整向量场
- 替代方案是用多个 API 模型各自生成最终图像，然后做图像空间的知识蒸馏（而非向量场蒸馏）——但这不是 OPD 了

>

这突出了 OPD 与纯 RL 的核心差异：OPD 需要的是细粒度的分布匹配，而非仅需要最终奖励。

Q19：如果模型非常强（如 DeepSeek-R1-671B 作为教师），还需要 Prune-OPD 吗？

这取决于师生兼容度，而非教师的绝对强度：

>

1. 如果学生也是强模型（如 R1-Distill-70B 从 R1-671B 蒸馏）：兼容度可能很高 → Prune-OPD 几乎不做任何截断 → 退化为标准 OPD → 不需要
2. 如果学生是弱模型（如 1.5B 从 671B 蒸馏）：兼容度可能极低 → 前缀漂移非常严重 → Prune-OPD 的作用最大
3. 更根本的问题：对于极大的能力差距（671B → 1.5B），教师的大部分知识可能对小学生不可利用（distillability gap）——这不仅是前缀漂移，更是"学生连教师的第一步都看不懂"。Prune-OPD 兼容度信号在这种情况下会很快归零 → 有效 OPD 长度非常短 → 蒸馏几乎等于无效

>

所以，Prune-OPD 在强教师弱学生场景下最有价值但也最受限——它能识别出哪些部分可靠，但如果没有可靠的部分，截断解决不了根本的能力差距问题。

Q20：如果让你设计一个结合 Prune-OPD 和 Flow-OPD 优势的"统一 OPD 框架"，你会怎么设计？

一个自然的设计思路——可靠性感知的多教师 OPD 框架：

>

架构：
1. 多教师专精训练（借鉴 Flow-OPD Stage 1）：各教师单目标达到天花板
2. 冷启动初始化（借鉴 Flow-OPD）：SFT 或模型合并建立基础能力
3. 可靠性感知的 OPD 循环：
- On-policy 采样学生轨迹（自回归 token 或去噪 latent）
- 逐位兼容度监测（借鉴 Prune-OPD）：在 token 级（text）或向量场级（image）计算师生兼容度
- 任务路由 + 可靠性双重门控：先根据任务类型选择教师，再根据兼容度衰减该教师的监督信号
- 兼容度判据的模态适配：
- 文本模态：top-k 重叠率
- 图像模态：向量场余弦相似度或 L2 距离阈值
4. MAR 式锚定正则化（借鉴 Flow-OPD）：防止多任务优化中的某一维度崩塌
5. 动态响应预算（借鉴 Prune-OPD）：根据兼容度统计自适应调整序列长度

>

理论意义：
- Prune-OPD 提供了"教师监督在何处可靠"的位置级答案
- Flow-OPD 提供了"教师监督在多任务间如何分配"的任务级答案
- 两者结合 → 一个空间-任务联合可靠性分配框架

>

实际挑战：
- 需要在同一框架内统一处理离散 token 和连续 latent
- 多模态的兼容度指标可能不可直接比较
- 计算开销：同时运行多个教师 + 逐位兼容度计算

9. 附录：关键公式速查

Prune-OPD 公式

OPD 目标函数（标准形式）：

$$\mathcal{L}_{OPD}(\theta) = \mathbb{E}_{x, y\sim\pi_\theta(\cdot|x)} \sum_{t=1}^{T} D_{KL}(p_t \| q_t)$$

Top-k 重叠率：

$$\text{OverlapRate}(t) = \frac{|\text{TopK}(\pi_\theta, t) \cap \text{TopK}(\pi_T, t)|}{k}$$

前缀漂移事件：

$$B_t = \mathbf{1}[\text{OverlapRate}(t) < \tau]$$

累积漂移计数：

$$C(t) = \sum_{i=1}^{t} B_i$$

可靠性权重：

$$R = \text{clip}(1 - w_{\text{drop}} \cdot C,\ 0,\ 1)$$

损失权重：

$$L = R + w_{\text{base}}$$

缩放 OPD 奖励：

$$\tilde{r}_{t,j} = L \cdot r_{t,j}$$

有效可靠长度：

$$E = \sum_{t=1}^{T} \mathbf{1}[R_t > \epsilon]$$

Batch 命中率：

$$h_t = \frac{1}{B}\sum_{b=1}^{B} \mathbf{1}[E^{(b)} \geq M_t - m]$$

预算更新规则：

$$M_{t+1} = \begin{cases} \min(M_t + \Delta, M_{\max}) & \text{if } h_t \geq \rho \\ \max(M_t - \Delta, M_{\min}) & \text{if } h_t < \rho \text{ for } P \text{ consecutive steps} \\ M_t & \text{otherwise} \end{cases}$$

Flow-OPD 公式

流匹配训练损失：

$$\mathcal{L}_{FM}(\theta) = \mathbb{E}_{t, x_0, x_1} \|\mathbf{v}_\theta(x_t, t) - (x_1 - x_0)\|^2$$

SDE 采样（On-Policy 探索）：

$$dx_t = \left[v_\theta(x_t, t) + \frac{\sigma_t^2}{2t}(x_t + (1-t)v_\theta(x_t, t))\right]dt + \sigma_t d\bar{w}$$

学生转移策略（高斯形式）：

$$\pi_\theta(x_{t-\Delta t}|x_t, c) = \mathcal{N}(\mu_\theta(x_t, t), \sigma_t^2 \Delta t \mathbf{I})$$

任务路由：

$$\mathbf{v}_{\text{target}}(x_t, t, c) = \mathbf{v}_k(x_t, t, c), \quad k = \mathcal{R}(c)$$

Flow-KL 定理（核心）：

$$D_{KL}(\pi_\theta \| \pi_{\text{target}}) = \frac{\Delta t}{2\sigma_t^2} \left[t(1-t) + \frac{1}{\Delta t}\right]^2 \cdot \|\mathbf{v}_\theta - \mathbf{v}_{\text{target}}\|^2$$

即：

$$\boxed{D_{KL}(\pi_\theta \| \pi_T) = \mathbb{E}_{t, x_t \sim \pi_\theta}\left[w(t) \cdot \|\mathbf{v}_\theta(x_t, t) - \mathbf{v}_T(x_t, t)\|^2\right]}$$

Flow-OPD 损失：

$$\mathcal{L}_{\text{Flow-OPD}} = \mathbb{E}_{x_t \sim \text{SDE}} \left[w(t)\|\mathbf{v}_\theta(x_t, t, c) - \text{SG}[\mathbf{v}_{\text{target}}(x_t, t, c)]\|^2\right]$$

MAR 正则化：

$$\mathcal{L}_{\text{MAR}} = \mathbb{E}_{c, t, x_t \sim \pi_\theta}\left[w(t)\|\mathbf{v}_\theta(x_t, t, c) - \mathbf{v}_{\text{aesthetic}}(x_t, t, c)\|^2\right]$$

总损失：

$$\mathcal{L}_{\text{Total}} = \mathcal{L}_{\text{Flow-OPD}} + \lambda \cdot \mathcal{L}_{\text{MAR}}$$

摘要

在策略蒸馏（On-Policy Distillation, OPD）利用密集的教师奖励信号来增强推理模型。然而，将OPD扩展到长程任务时暴露了一个关键缺陷：随着学生模型生成的前缀不可避免地偏离教师的思维过程，教师的密集奖励失去了局部可利用性。在这些"漂移"轨迹上继续生成和评估token不仅降低了奖励质量，还造成了大量的计算浪费。为解决这一问题，我们提出了Prune-OPD，一个动态将训练预算与监督质量对齐的框架。通过持续监测学生与教师预测之间的局部兼容性（例如，通过top-k重叠度），Prune-OPD实时检测前缀漂移事件。一旦检测到严重漂移，它会单调地降低后续不可靠奖励的权重，并触发动态生成长度截断。这使得训练过程能够停止无意义的生成，并将计算资源严格重新分配到可靠的教师监督上。在多种教师-学生组合中，Prune-OPD始终将计算与监督可靠性对齐。当前缀漂移使密集教师奖励变得不可靠时，它将训练时间减少37.6%至68.0%，同时在具有挑战性的基准测试（AMC、AIME、HMMT）上保持甚至提升性能。当学生-教师兼容性保持较高时，它通过扩展训练窗口自动保留长上下文监督。这些结果表明，Prune-OPD并非通过盲目缩短生成长度来改进OPD，而是通过将计算重新分配到局部可利用的教师奖励上来实现改进。

1 引言

在策略蒸馏（OPD）已成为大语言模型后训练的核心技术。最近的系统如Qwen3 [36]、MiMo [34]和GLM-5 [45]在后训练流程中采用OPD风格的密集监督。Thinking Machines Lab [24]报告称，OPD方案能够以远低于结果奖励强化学习的计算量复现强大的推理增益。这使得OPD成为监督微调和可验证强化学习的有力补充：它在长推理轨迹上提供token级学习信号，而非等待稀疏的最终答案奖励。

OPD的吸引力在于其在策略特性。离策略蒸馏在固定的教师生成序列上训练学生，这会引发曝光偏差问题：在推理时，学生必须在并非由教师或参考策略生成的前缀下行动[2]。而OPD则从当前学生模型采样生成长度，并在相同的学生访问前缀上评估教师。这一设计也启发了最近的自蒸馏方法，其中模型在特权信息或反馈下充当自身的教师，并从自身的在策略经验中改进[14, 47, 30]。在长程数学推理中，这一区别尤为重要：单个解答可能包含数千个token，因此即使是微小的训练-推理不匹配也可能在整个轨迹上累积放大。

图1：Prune-OPD概念概述。 Prune-OPD沿学生生成长度监测局部学生-教师兼容性，在低重叠漂移事件后单调衰减OPD奖励，并在可靠的教师监督耗尽后截断响应。

然而，同样的在策略设计也带来了一个新的可靠性问题。教师不仅在被查询的前缀上其局部分布能提供有用的纠正，也在已经偏离教师推理过程的前缀上被查询。最近的OPD动力学分析指出，OPD的成功依赖于局部思维模式兼容性，并且奖励质量可能随轨迹深度而恶化[22]。我们将这一诊断视为设计约束：长程OPD不应将每个生成的token视为同等值得监督。

缺失的一环是在线可靠性控制。当前的OPD方案通常是在生成前选择一个生成长度预算，然后在采样的响应上均匀地施加密集教师奖励。这造成了一个糟糕的权衡。短的固定预算可能丢弃有用的长推理，而长的固定预算则花费大量计算来生成和评分那些教师信号可能不再局部可利用的后缀。实际上，单次生成长度可以同时包含两种状态：早期的前缀，其中学生和教师仍共享合理的下一token支持；以及随后的后缀，其中学生已经承诺了教师不会采取的推理选择。因此，OPD所需的不是简单增加或减少密集奖励，而是一种判断密集奖励在何处足够可靠以用于训练的方法。

我们提出Prune-OPD，一个面向长程OPD的可靠性感知修饰器，在训练过程中做出这一决策。Prune-OPD不过滤整个响应，也不施加固定的响应长度，而是提出一个位置级别的问题：在相同的学生前缀下，学生和教师是否仍然共享一个高概率候选区域？主要信号是每位置的top-k重叠率，教师top-p/top-k动作接受度作为一个更严格的变体。当选定的兼容性指标低于其阈值时，Prune-OPD记录一个前缀漂移事件。累积的漂移事件定义了一个单调可靠性权重，用于衰减后续的OPD奖励，而同样的原始可靠性信号则定义了动态生成长度控制的有效响应长度。预期的转变是从固定预算OPD转向可靠性预算OPD：密集监督应被分配到教师在学生轨迹上仍然可操作的位置。

我们进行了广泛的实验，以评估可靠性感知剪枝是否在实践中改善了长程OPD。结果验证了Prune-OPD的有效性：当密集监督变得不可靠时，它将训练时间减少了37.6%至68.0%，同时保持或提升了下游准确率。额外的实验表明，当可靠性信号保持较高时，控制器保留长上下文监督，支持了Prune-OPD重新分配计算而非盲目缩短生长度的论断。总之，我们的贡献如下：

  • 我们将长程OPD形式化为学生访问前缀上的可靠性分配问题，将轨迹深度退化与局部兼容性和奖励可利用性联系起来。
  • 我们提出了Prune-OPD，它将累积前缀漂移转换为单调的OPD奖励衰减和动态响应长度控制器，在禁用时不改变基线OPD路径。

3 Prune-OPD

Prune-OPD将局部学生-教师兼容性转换为OPD奖励上的位置级权重。该方法被设计为OPD的即插即用修饰器：它不改变教师奖励的计算方式，但改变每个访问位置应该信任该奖励的程度。它包含三个部分：每位置兼容性指标、累积可靠性权重和可选的动态响应长度控制器。

3.1 兼容性指标

在位置 $\tau$，我们的目标是判断教师在学生当前轨迹上是否仍然提供局部可利用的监督。因此，学生和教师在相同的由学生生成的前缀 $\mathbf{s}_\tau = (x, \mathbf{y}_{<\tau})$ 上进行评估。

我们首先将比较限制在每个模型的高置信度候选token上。设

$$\mathcal{K}_S = \text{TopK}\big(\pi_\theta(\cdot \mid \mathbf{s}_\tau), k\big), \quad \mathcal{K}_T = \text{TopK}\big(\pi_T(\cdot \mid \mathbf{s}_\tau), k\big) \tag{5}$$

为返回的top-k候选集。top-k大小是一个实验超参数。然后，我们用重叠率测量局部兼容性：

$$\mathcal{O}_\tau = \frac{|\mathcal{K}_S \cap \mathcal{K}_T|}{k}. \tag{6}$$

低重叠意味着教师的密集奖励是在其偏好的下一token支持已与学生支持分离的前缀下计算的。因此，我们定义前缀漂移事件为：

$$\mathcal{B}_\tau = \mathbb{1}\left[\mathcal{O}_\tau < \delta\right], \tag{7}$$

其中 $\delta$ 是兼容性阈值。这些漂移事件随后被累积，以衰减后续OPD奖励并定义动态生成长度控制的有效响应长度。

该指标直接遵循OPD机制分析：成功的OPD与逐渐增加的高概率重叠相关联，而失败的运行则在学生访问状态上表现出停滞或不稳定的重叠[22]。它衡量学生和教师是否仍共享合理的局部动作空间。低重叠意味着教师的密集奖励正在其偏好的下一token支持已与学生支持分离的区域中计算。我们还设计了一个替代的top-p动作接受度指标，其定义见附录A.10。

3.2 累积可靠性与损失加权

坏事件在响应上累积：

$$C_\tau = \sum_{i=1}^{\tau} \mathcal{B}_i. \tag{8}$$

原始可靠性权重是一个截断的线性衰减：

$$\tilde{R}_\tau = \text{clip}(1 - w_{\text{drop}} \cdot C_\tau, \; 0, \; 1), \tag{9}$$

其中 $w_{\text{drop}} \geq 0$ 控制每次兼容性失败的惩罚。原始权重沿每个有效响应单调非增。填充位置被强制设为零。

实际损失权重添加一个基础底线：

$$\mathcal{L}_\tau = \tilde{R}_\tau + w_{\text{base}} \tag{10}$$

对有效响应位置，且 $\mathcal{L}_\tau = 0$ 对填充位置。缩放后的OPD奖励为：

$$\tilde{\mathbf{r}}_{\tau,j} = \mathcal{L}_\tau \cdot \mathbf{r}_{\tau,j}. \tag{11}$$

基础权重有两个实际作用。第一，它防止Prune-OPD在 $\tilde{R}_\tau$ 达到零时变成硬开关。第二，它允许方法在去噪和保留弱教师信号之间进行权衡。具体的超参数值在实验设置中指定。

3.3 动态响应预算

Prune-OPD还可以在训练期间调整生成长度。定义一个样本的有效响应长度为：

$$\mathcal{E} = \sum_{\tau=1}^{T} \mathbb{1}\left[\tilde{R}_\tau > \varepsilon\right], \tag{12}$$

对于一个小容差 $\varepsilon$。此定义刻意使用 $\tilde{R}_\tau$ 而非 $\mathcal{L}_\tau$。因此，具有 $\tilde{R}_\tau = 0$ 和 $w_{\text{base}} > 0$ 的token仍可贡献少量的OPD奖励，但不被计为可靠长度。

4 实验

我们评估可靠性感知奖励缩放是否能在保持下游推理准确率的同时显著降低OPD训练成本。除最终基准准确率和训练时间外，我们还测量学生访问状态上的局部学生-教师动力学，包括重叠率、top-p接受度和有效可靠长度。

4.1 实验设置

训练数据。 我们在DAPO-Math-17K [44]上训练，遵循近期推理实验中使用的OPD设置。训练提示在每次运行前打乱。主要的强化学习结果奖励是最终答案正确性。然而，OPD提供密集的token级蒸馏奖励。

模型。 我们评估五对教师-学生组合，以在不同OPD动力学下测试可靠性信号。DeepSeek-R1-Distill-Qwen-1.5B从DeepSeek-R1-Distill-Qwen-7B蒸馏，后者是一个更大的同族推理模型，其更高的基准得分可能并不意味着局部可利用的token级反馈[10]。同一学生还从JustRL-DeepSeek-1.5B蒸馏，后者是一个同规模的RL改进版教师，由DeepSeek-R1-Distill-Qwen-1.5B通过RL获得[11]。Qwen3-1.7B-Base和Qwen3-4B-Base从Qwen3-4B（非思考模式）蒸馏，隔离了思考模式转变如何在同一模型族内与学生规模交互[36]。最后，DeepSeek-R1-Distill-Qwen-7B从Skywork-OR1-7B蒸馏，提供了一个高初始重叠的设置，其中Prune-OPD预期保留长上下文监督而非缩短生成长度。总体而言，这些组合在不同条件下测试同一论断：当可靠性衰退时控制器减少计算，当兼容性保持较高时保留密集监督。

基线。 我们比较基线OPD、固定长度截断基线和Prune-OPD变体。固定长度OPD使用与基线OPD相同的蒸馏目标，但将最大响应长度限制为固定预算。随机剪枝匹配Prune-OPD保留的token比例或保留的OPD奖励质量，同时独立于学生-教师兼容性选择剪枝位置。这些对照测试了收益是否来自学生-教师兼容性信号，而非来自简单的更短生成长度或更低奖励密度。主要Prune-OPD配置使用重叠率，阈值为 $\delta = 0.7$。我们还报告了教师top-p动作接受度变体，$p = 0.95$。两种变体均使用 $\text{top-k} = 16$、$w_{\text{drop}} = 0.01$、$w_{\text{base}} = 0.5$，以及动态长度命中率 $0.1$。除非另有说明，动态响应长度使用初始值 $2048$、最小值 $1024$、最大值 $12288$、更新步长 $100$、边距 $100$ 和收缩耐心 $3$。

评估。 我们在AMC23、AIME24、AIME25、HMMT24和HMMT25上进行评估。主要指标是固定评估协议下的pass@1准确率。我们还报告相对训练时间减少、响应长度统计、重叠率、top-p接受率和有效可靠长度。训练时间相对于同一教师-学生对下的基线OPD测量。

4.2 主要结果

主要结果是在不显著降低下游准确率的情况下实现一致的效率增益。在主要低兼容性运行中，重叠率变体将训练时间分别减少了35.7%、68.0%、37.6%和52.6%，而基准准确率保持接近相应的OPD基线。准确率差异在各个基准上混合存在，应视为次要的：Prune-OPD在若干AIME/HMMT得分上略有提升，但也降低了少数条目，例如DeepSeek-R1-Distill-Qwen-7B教师下的AIME24和JustRL-DeepSeek-1.5B教师下的HMMT24。这一模式与Prune-OPD作为可靠性感知效率机制而非独立的准确率提升方法的角色一致。top-p动作接受度变体通常更保守，且往往弱于重叠率变体，这表明精确采样token的可接受性对于推理轨迹可能过于严格，而候选空间重叠更好地捕捉了教师是否仍然提供可利用的局部监督。

OPD与简单截断。 我们在表1和表2中包含了OPD（截断4k）作为固定预算基线。该基线使用相同的OPD目标，但均匀地缩短每次生成长度，而不观察学生-教师兼容性。尽管简单截断可以降低成本，并且对某些教师-学生对可能有效，但它并非Prune-OPD的可靠替代。特别是，对于DeepSeek-R1-Distill-Qwen-1.5B / JustRL-DeepSeek-1.5B和DeepSeek-R1-Distill-Qwen-7B / Skywork-OR1-7B，在固定4K预算下截断会降低性能，因为它丢弃了有用的长前缀监督。这一失败模式突显了刚性长度规则的局限：它无法区分漂移的后缀与长但仍兼容的推理轨迹。

剪枝指标：重叠率 vs. top-p接受度。 指标消融在表1中报告。在已完成的运行中，重叠率是更强的默认选择：它提供与top-p接受度相等或更大的时间减少，同时通常更好地保持准确率。我们将此归因于其支持级别特性：它询问学生和教师是否仍共享高概率候选区域，而非要求采样的学生token落入教师的可见核内。这使得重叠率成为长推理轨迹的平滑可靠性信号，其中多个局部合理的延续可能保持有效。

Prune-OPD阈值消融。 我们在表3中消融了DeepSeek-R1-Distill-Qwen-1.5B / JustRL-DeepSeek-1.5B上的重叠率阈值。已完成的 $\delta = 0.7$ 设置提供了一个强大的工作点：它在保持OPD级别基准性能的同时将训练时间减少了35.7%。较低的阈值应更宽容，产生更少的坏事件和更长的有效蒸馏长度；较高的阈值应更早剪枝，如果设置过于激进可能移除有用的长推理。核心结论是 $\delta = 0.7$ 同时提供了性能保护和显著的训练效率提升。

5 相关工作

在策略蒸馏。 MiniLLM将OPD形式化为在逆KL目标下由策略梯度优化的大语言模型方法，强调了逆KL的模式寻求行为[9]。GKD通过在多种散度下插值在策略和离策略数据，拓宽了这一视角[1]。更近期的理论将OPD框架化为密集KL约束的强化学习，其中教师的每token对数比可以被解释为隐式奖励，甚至可以外推到教师标准强度之外[38]。OPD此后出现在主要的推理和后训练方案中[36, 24, 45, 34, 20, 17, 15, 7, 38, 8]。它还被扩展到自蒸馏和在线经验学习，其中模型在特权信息、反馈或样本路由下充当自身的教师[14, 47, 12, 30, 43, 26, 18, 42, 37, 21, 46, 6, 31]。这些工作确立了OPD作为强大的后训练原始语。Prune-OPD解决了一个互补的可靠性问题：即使密集教师奖励在策略上可用，长生成长度可能包含教师局部信号不再可利用的前缀。关于OPD的更多讨论见附录A.5。

6 结论

OPD为长推理链提供密集监督；然而，当学生的推理模式偏离教师时，产生的密集奖励变得不可靠。Prune-OPD将其视为位置级可靠性问题：它检查学生和教师在共享前缀下是否保持局部兼容，将累积兼容性失败转换为漂移信号，重新缩放OPD奖励，并基于可靠而非原始token计数控制响应长度。在多种蒸馏设置中，基于重叠的Prune-OPD在低兼容性情境下将训练时间减少了37.6%至68.0%，同时保持基准性能；当兼容性保持较高时，它保持长训练窗口打开。这些结果表明，高效的长程OPD不应仅由教师强度或固定生成长度预算主导。相反，密集教师监督应根据其对学生实际访问前缀的局部可利用性来分配。

附录

A.1 更广泛影响

本研究为开发专注于复杂推理的更高效、更可靠的大语言模型训练协议做出了贡献。通过引入Prune-OPD，我们提供了一种机制来缓解密集在策略蒸馏中固有的"奖励黑客"和训练不稳定风险——否则模型可能从低质量或漂移的教师信号中学习。训练计算量的大幅减少（最多68%）直接回应了大语言模型后训练中高能耗带来的环境关切。通过使复杂的推理模型能够以更少的资源进行训练，本工作使开发高性能AI的能力更加民主化，可能加速科学发现的进展。

尽管有这些益处，我们认识到增强大语言模型的推理能力可能在不经意间降低生成复杂错误信息或双重用途内容的门槛。虽然Prune-OPD关注的是学习过程而非数据内容，但由此产生的模型如果被用于欺骗目的，可能更具说服力或更难检测。为减轻这些风险，我们强调将Prune-OPD与安全对齐的教师模型和严格的可验证强化学习框架结合使用的重要性。我们致力于通过提供详细的实验设置和超参数配置来实现透明和可复现性，使社区能够审计这些训练动力学的可靠性，并确保推理能力的提升不以模型安全性或伦理对齐为代价。

A.3 局限性

Prune-OPD依赖于top-k局部分布统计量。主要的重叠指标可能遗漏学生和教师共享候选token但排名或评分差异很大的情况，而top-p动作接受度变体对于风格不同但有效的推理路径可能过于严格。当前的衰减是累积坏事件的线性函数，并假设局部兼容性与奖励可利用性相关；当低重叠前缀后来返回到教师兼容状态时，这一假设可能失败。实现上也仅重新缩放OPD奖励，且不为零可靠性token附加GRPO回退。最后，当前实验仅限于使用DeepSeek、Qwen和Skywork风格模型的数学推理；智能体和多轮设置仍然是未来工作。

A.4 未来工作

一个自然的扩展是将Prune-OPD与GRPO结合在可靠性门控目标中。在可靠性权重衰减到零之前，模型仍优化OPD损失并从局部兼容前缀上的密集教师指导中受益。在可靠性权重达到零之后，不可靠的后缀将切换到GRPO损失，允许学生使用结果级反馈继续探索，而非强迫其遵循不再局部可利用的教师分布。这种混合目标可以将教师引导蒸馏的样本效率与强化学习的探索优势结合起来，并可能进一步改进长程推理，超越仅依赖可靠性感知截断的方法。

A.5 附加相关工作

知识蒸馏与离策略蒸馏。 知识蒸馏通过匹配教师的软输出分布将信息从教师迁移到学生[13]。对于自回归序列模型，序列级蒸馏在学生上训练教师生成的输出[19]，这种离策略范式是许多紧凑语言模型蒸馏方法的基础[27, 16, 32, 8]。监督微调和指令调优同样通过在被管理的响应或示范上训练来改进下游行为[5, 28, 33]。共同的局限是训练-推理分布不匹配：学生在教师或参考轨迹上优化，但在推理时必须在其自身策略采样的前缀上条件化——一种在长生成中累积的曝光偏差问题[2]。Prune-OPD遵循OPD的动机，即蒸馏应在学生访问的状态上计算，但提出了一个进一步的问题：一旦学生处于在策略状态，哪些访问状态仍然允许可靠的密集教师监督？

OPD动力学与机制。 最近的OPD分析表明，OPD的成功由思维模式一致性以及教师是否贡献了超出学生已获知识的新知识所支配[22]。在token层面，成功的OPD表现出高概率token上的渐进对齐：top-k重叠上升、重叠token优势改善，且熵差缩小。同一分析进一步表明，奖励质量随轨迹深度退化，并且奖励可能在全局上与最终正确性相关，但无法在学生当前策略周围提供局部有用的梯度。Prune-OPD直接操作化这些诊断发现。它不是将重叠率、熵差或教师可接受性作为事后测量，而是将每前缀兼容性转化为在线可靠性信号，衰减后续OPD奖励并控制生成长度。

容量差距与可蒸馏性。 另一条研究线索探讨了教师何时过于强大、差异过大或复杂到学生无法模仿。研究表明，过于强大的教师可能损害学生表现[4]，并且引入了教师助手以弥合大的容量差距[25]。蒸馏缩放定律识别了教师质量、学生规模和数据量之间的非单调交互[3]。对于推理模型，小学生可能难以从具有长思维链轨迹的强大推理者那里学习，表明蒸馏复杂推理行为存在可学习性差距[23]。这些结果警示不应假设教师基准强度单独决定蒸馏质量。Prune-OPD从在策略、位置级的视角研究同一问题：教师可能在全局上是有用的，但在学生生成轨迹的特定深度上不可靠。

推理强化学习与长程监督。 现代推理模型依赖可验证强化学习、长思维链生成长度和大型数学训练集[29, 10, 44, 11, 39, 40, 41, 35]。长响应为搜索和自我纠正创造空间，但也使密集监督变得昂贵且更难以信任。先前的OPD结果识别了响应长度的最佳点：短响应提供的密集信号太少，而非常长的响应可能触发后期崩溃和后缀到前缀的不稳定性[22]。Prune-OPD专为此长程设置而设计。它不施加固定的响应预算；它估计哪些前缀仍承载可靠的教师信号，并使用该估计进行奖励缩放和动态响应长度控制。

A.6 可靠性理由

Prune-OPD的动机在于区分全局信息性教师奖励与学生访问前缀上局部可利用的token级监督[22]。因此，重叠率和相关兼容性指标被在线使用：重复的低兼容性事件被视为学生轨迹已漂移到统一密集OPD奖励不再可信赖的区域的证据。该方法不假设每个低重叠token是错误的；它仅假设累积兼容性失败是衰减后续后缀奖励的有用路径依赖信号。

单调可靠性衰减是一个故意保守的设计。后续token可能因为教师适应了已经漂移的前缀而变得局部兼容，而非因为完整的推理轨迹已返回到教师兼容状态。使用累积衰减避免了在重复漂移事件后重新放大后缀奖励，而基础权重 $w_{\text{base}}$ 将可靠性估计 $\tilde{R}_\tau$ 与优化尺度 $\mathcal{L}_\tau$ 分离。这使Prune-OPD能够降低不可靠后缀监督的权重，而不将方法变成脆弱的硬性过滤器。

A.7 实现细节

Prune-OPD作为OPD奖励张量上的后处理步骤实现。基线奖励张量具有形状 $[B, T, k]$，其中 $B$ 是批次大小，$T$ 是响应长度，$k$ 是top-k token维度。对于每个有效响应位置，该方法计算标量损失权重 $\mathcal{L}_\tau$ 并将该位置的每个候选奖励乘以相同的标量：

$$\tilde{\mathbf{r}}_{b,\tau,j} = \mathcal{L}_{b,\tau} \cdot \mathbf{r}_{b,\tau,j}. \tag{13}$$

填充位置具有 $\tilde{R}_\tau = 0$ 和 $\mathcal{L}_\tau = 0$。优势估计器保持为 token_reward_direct，因此缩放后的奖励直接用作token级优势。

当前代码路径保持基线隔离。当 prune_opd.enable=False 时，原始OPD/GRPO行为不变。当启用时，主要实验使用 overlap_ratio；teacher_top_p_accept 作为动作级变体保留。教师top-k大小由 actor_rollout_ref.rollout.log_prob_top_k 控制，在当前实验中设置为16。

A.10 Top-p动作接受度指标

除重叠率外，我们还评估了一个更严格的动作级兼容性指标。在位置 $\tau$，学生采样实际的下一token $y_\tau$，而教师在同一前缀下返回top-k token和概率：

$$\mathcal{K} = \{v_{\tau,1}, \ldots, v_{\tau,k}\}, \quad q_{\tau,1} \geq q_{\tau,2} \geq \cdots \geq q_{\tau,k}. \tag{14}$$

给定top-p阈值 $p$，定义累积可见质量：

$$S_{\tau,m} = \sum_{j=1}^{m} q_{\tau,j}. \tag{15}$$

如果存在最小 $m$ 满足 $S_{\tau,m} \geq p$，则可见核为：

$$\mathcal{A}_\tau(p, k) = \{v_{\tau,1}, \ldots, v_{\tau,m}\}. \tag{16}$$

如果返回的top-k质量仍低于 $p$，真实核超出观察集，因此我们保守地使用 $\mathcal{A}_\tau(p, k) = \mathcal{K}$。坏事件为 $\mathcal{B}_\tau = \mathbb{1}[y_\tau \notin \mathcal{A}_\tau(p, k)]$。在报告的top-p运行中，$p = 0.95$。

摘要

现有的流匹配（Flow Matching, FM）文本到图像模型在多任务对齐下面临两个关键瓶颈：由标量值奖励引发的奖励稀疏性，以及由联合优化异质目标导致的梯度干扰——这两者共同造成了竞争指标的"跷跷板效应"和普遍的奖励黑客行为。受在线策略蒸馏（On-Policy Distillation, OPD）在大语言模型社区中成功应用的启发，我们提出了 Flow-OPD，这是首个将在线策略蒸馏融入流匹配模型的统一后训练框架。Flow-OPD 采用两阶段对齐策略：首先通过单奖励 GRPO 微调培养领域专用教师模型，使每位专家在隔离状态下达到其性能上限；随后通过基于流的冷启动（Flow-based Cold-Start）方案建立鲁棒的初始策略，并通过三步编排——在线策略采样、任务路由标注和密集轨迹级监督——将异构专业知识无缝整合至单一学生模型。我们进一步引入了流形锚定正则化（Manifold Anchor Regularization, MAR），利用任务无关教师提供全数据监督，将生成过程锚定于高质量流形，有效缓解了纯 RL 驱动对齐中普遍出现的美学退化。基于 Stable Diffusion 3.5 Medium，Flow-OPD 将 GenEval 分数从 63 提升至 92，OCR 准确率从 59 提升至 94，整体性能相比原始 GRPO 提升约 10 分，同时保持了图像保真度和人类偏好对齐，并展现出涌现的"超越教师"效应。这些结果使 Flow-OPD 成为构建通用文本到图像模型的可扩展对齐范式。代码和权重将在以下地址发布：https://github.com/CostaliyA/Flow-OPD。

1 引言

流匹配（Flow Matching, FM）[1, 2, 3, 4] 已成为生成建模的优越范式，通过学习连续时间速度场，在采样效率和高保真合成方面均超越了传统扩散模型。然而，随着研究前沿从无约束图像合成转向高度可控的多维对齐，当前后训练方法的局限性已愈发明显。现代应用要求单一模型在统一生成空间中掌握多种任务——从精确文本渲染和复杂组合推理 [5, 6, 7, 8, 9, 10] 到严格遵循细腻的人类美学偏好 [11, 12, 13, 14]。

近期进展尝试通过将强化学习（Reinforcement Learning, RL）算法——如分组相对策略优化（Group Relative Policy Optimization, GRPO）[15]——移植到流匹配领域来弥合这一差距。

这些方法在单奖励场景中已展现出显著潜力，在线策略探索使模型能够优化其采样轨迹并改善特定指标，如 PickScore 或美学评分。然而，不同任务需要异质且相互冲突的特征表示。正如大语言模型对齐 [19] 中所指出的，稀疏标量奖励缺乏协调这些目标的粒度，从而导致零和的"跷跷板效应"——优化某些特征（如 OCR）不可避免地通过奖励黑客行为损害美学质量。这迫切需要转向密集的轨迹级蒸馏，以提供解耦的专家监督。

这一问题最近在大语言模型（Large Language Models, LLMs）领域找到了令人信服的解决方案：在线策略蒸馏（On-Policy Distillation, OPD）。受益于 OPD，DeepSeek-V4 [9]、Mimo v2 [20] 和 GLM-5 [19] 等模型通过从专业专家中蒸馏，成功协调了复杂的多领域能力。这一范式转变为视觉社区提出了一个关键问题：流匹配模型是否能类似地利用 OPD 将多个教师模型的多样化优势整合到单一鲁棒的学生模型中？为回答这一关键问题，我们引入了 Flow-OPD——首个将 OPD 融入 FM 模型后训练流程的框架。

我们提出了一种两阶段对齐策略，首先通过单奖励 GRPO 微调培养领域专用教师，确保每位专家在隔离状态下达到其性能上限。为促进学生模型的平滑过渡，我们开发了基于流的冷启动（Flow-based Cold-Start）策略，包含两种不同变体——基于监督微调（SFT）的初始化和模型合并（Model Merging）——旨在建立能够进行多任务学习的鲁棒基础策略。在此基础上，我们通过三步编排将 OPD 应用于流匹配过程：（1）执行在线策略采样以捕获学生模型当前的速度场；（2）执行任务路由标注，由不同专家为各自领域提供密集监督；（3）引入流形锚定正则化（Manifold Anchor Regularization, MAR），纳入任务无关教师提供全数据监督，有效将生成过程锚定于高质量流形，进一步提升合成图像的美学完整性。

跨多个基准和指标的实验结果表明，Flow-OPD 相比使用稀疏奖励的原始 GRPO 实现了 10% 的性能提升，为基于流的生成模型中的规模化对齐建立了新前沿。综上所述，我们的贡献包括以下三个方面：

  • FM 多任务训练分析：我们对流匹配模型中基于 GRPO 的多任务训练的失败模式进行了实证分析，特别识别了奖励稀疏性和梯度干扰的挑战。为解决这些问题，据我们所知，我们首次将 OPD 范式引入 FM 模型的后训练中。
  • Flow-OPD 框架：我们提出了 Flow-OPD，一个将专业知识获取与模型统一解耦的两阶段后训练框架。我们的框架引入了基于流的冷启动策略（SFT 和合并变体）、用于细粒度监督的任务路由密集标注机制，以及通过任务无关引导确保全局生成质量的新型流形锚定正则化（MAR）。
  • 卓越的性能和泛化能力：通过在四个主流基准上的广泛实验，我们证明 Flow-OPD 相比 GRPO 基线实现了约 10 分的显著提升。值得注意的是，统一学生模型在域内匹配甚至超越了专业教师的性能，同时展现出卓越的分布外（Out-of-Distribution, OOD）泛化能力。

2 相关工作

文本到图像模型的强化学习

基于 RL 的对齐在大语言模型中的成功最近启发了文本到图像（Text-to-Image, T2I）生成的强化学习。早期方法如 DDPO [23]、DPOK [24] 和 ImageReward/ReFL [25] 将扩散生成建模为策略优化，以美学、人类偏好或图文对齐作为奖励，而 Diffusion-DPO [26] 则利用偏好对来对齐扩散模型。更新的 GRPO 风格方法将 RL 扩展到现代视觉生成器，包括流模型 [27, 17] 和自回归范式 [28, 29, 30, 31, 32] 中的那些。然而，T2I 生成需要多个奖励来覆盖美学、对齐、保真度和组合正确性。现有解决方案仍然难以控制：DanceGRPO [17] 直接混合 HPS 和 CLIP 等奖励，往往在指标之间相互权衡；Flow-GRPO [27] 使用分阶段奖励/数据集课程，使结果对顺序和阶段设计敏感；GDPO [33] 表明 GRPO [9] 在多奖励设置下可能出现奖励归一化崩溃。这促使需要一种更可控的多奖励协调机制。

在线策略蒸馏

传统的离线蒸馏依赖于固定数据集，无法适应学生不断演化的轨迹。相比之下，在线策略蒸馏（On-Policy Distillation, OPD）将教师的监督信号与学生的探索空间动态耦合。在大语言模型领域，OPD 发展迅速：GKD [34] 建立了缓解曝光偏差的规范框架；MiniLLM [35] 和 DistiLLM [36] 引入反向和偏斜 KL 散度以改进模式寻求和优化稳定性；G-OPD [37] 在 KL 约束 RL 理论下统一了 OPD；Entropy-Aware OPD [38] 通过自适应散度函数保持多样性；Fast OPD [39] 通过前缀截断显著加速计算；PACED [40] 基于梯度信噪比分析实现了能力感知课程。尽管大语言模型取得了这些进展，OPD 在视觉流匹配模型中仍未被充分探索——后者需要在高维速度场内进行密集监督。我们提出 Flow-OPD，这是在线策略蒸馏在流匹配中的首次系统性迁移，利用多教师密集监督克服奖励稀疏性瓶颈。

3 预备知识

流匹配模型

流匹配（Flow Matching, FM）通过常微分方程 $dx_t = v_t(x_t, t)dt$ 将噪声分布 $p_0$ 映射到数据分布 $p_{\text{data}}$。在最优传输（Optimal Transport, OT）公式 [3] 下，路径为 $x_t = (1-t)x_0 + tx_1$，模型 $v_\theta$ 通过下式学习恒定速度 $(x_1 - x_0)$：

$$ \mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t, x_0, x_1} \left\| v_\theta(x_t, t) - (x_1 - x_0) \right\|^2 \tag{1} $$

遵循 Flow-GRPO [16]，我们将离散化的 ODE 积分概念化为序列马尔可夫去噪过程。通过将每个转移 $x_t \rightarrow x_{t-\Delta t}$ 建模为马尔可夫状态步骤，这一视角连接了连续生成动态与强化学习，为逐步策略优化定义了形式化轨迹。

在线策略蒸馏

知识蒸馏旨在通过最小化输出差异将教师能力压缩到学生模型中。为缓解分布偏移，在线策略蒸馏（OPD）[41] 要求学生模型 $f_\theta$ 在实时教师监督的引导下生成轨迹 $\tau \sim p_\theta(\tau)$。对于自回归（Autoregressive, AR）模型，该优化被形式化为最小化学生与教师分布之间的反向 KL 散度：

$$ \mathcal{L}_{\text{OPD}} = -\mathbb{E}_{y \sim p_\theta(y|x)} \left[ \log p_{\text{teacher}}(y|x) \right] = D_{\text{KL}}(p_\theta \parallel p_{\text{teacher}}) \tag{2} $$

通过在模型自身生成的分布上进行对齐，OPD 有效抑制了曝光偏差，确保了交互式或迭代生成任务中的鲁棒泛化。

4 动机

4.1 问题一：GRPO 为何有效？

标准 FM 依赖离线重建，从根本上将性能限制在静态数据集质量上，无法优化不可微的偏好。GRPO [9, 16, 17] 通过在线探索克服了这一问题。通过从当前策略 $\pi_\theta$ 主动采样 $G$ 个输出，它利用分组相对优势 $A(\mathbf{x}_1^{(i)}) = (r(\mathbf{x}_1^{(i)}) - \bar{r}) / \sigma$ 评估自身生成的状态。策略梯度于是由这些在线经验显式驱动：

$$ \mathcal{J}(\theta) \approx \frac{1}{G} \sum_{i=1}^{G} A(\mathbf{x}_1^{(i)}) \nabla_\theta \log p_\theta(\mathbf{x}_1^{(i)} | c) \tag{3} $$

这种对自身动态分布的持续探索使模型能够发现新颖的高奖励轨迹，成功突破了离线 SFT 的性能上限。

4.2 问题二：GRPO 为何失败？——多任务视角

尽管单奖励 GRPO 对特定目标有效，但它会在正交能力上造成严重退化（图 2）。这种灾难性遗忘源于共享参数空间 $\theta$ 中由稀疏标量奖励驱动的无约束梯度干扰。

对于由目标任务 $T_1$ 驱动（具有优势 $A_1$）的参数更新 $\Delta\theta$，其对未被监控的能力 $T_k$（$k \neq 1$）的附带影响可通过一阶泰勒展开近似：

$$ \Delta J_k \approx \nabla_\theta J_k \cdot \Delta\theta \propto \mathbb{E}_x \left[ A_1(x) \cdot \nabla_\theta J_k \cdot \nabla_\theta \log \pi_\theta(x|c) \right] \tag{4} $$

在高维空间中，发散的任务梯度经常相互冲突（$\nabla_\theta J_k \cdot \nabla_\theta J_1 < 0$）。由于缺少 $T_k$ 的监督信号，优化器会积极利用这些未被监控的自由度来最大化 $A_1$，从而破坏预训练的协同效应并导致流形崩溃。

这引出了一个自然的问题：我们能否通过简单混合多个数据集和奖励进行联合优化来解决这种退化？

4.3 问题三：混合训练能否解决问题？

为探索混合训练方法的可行性，我们在 Stable Diffusion 3.5 Medium（SD-3.5-M）[2] 上进行了受控实证实验。遵循 Flow-GRPO，我们逐步叠加四种不同的奖励函数：GenEval、OCR、PickScore 和 DeQA。如表 1 所示，混合标量奖励无法构建稳定的认知基础。

5 方法：Flow-OPD

Flow-OPD 通过对自生成轨迹进行密集监督来重新定义多任务对齐。我们首先使用 Flow-GRPO 训练领域专家教师。在冷启动初始化之后，学生经历多教师在线蒸馏，将在线样本动态路由到特定教师以获得细粒度引导。最后，流形锚定正则化解耦功能对齐与美学崩塌，保留固有的生成先验。

5.1 冷启动

为确保稳定的初始化 $\pi_{\theta_0}$ 并防止早期展开中的轨迹发散，我们探索了两种冷启动策略：基于 SFT 的初始化和模型合并初始化。我们的 SFT 协议遵循 Flow-GRPO，但利用从专业教师采样的轨迹，确保学生从一开始就继承专家级的知识分布。作为替代，模型合并将不同教师的各向异性先验叠加到统一参数状态中。这种"合并即初始化"的方法将学生定位在损失景观中的高能力区域，该区域的多任务协同效应已初步形成，为后续蒸馏提供了鲁棒基础。

5.1.1 多教师在线策略蒸馏

架接 OPD 与流匹配 如公式 2 所示，ThinkingMachines 的 OPD [41] 通过使用相对教师分布 $p_{\text{teacher}}$ 的反向 KL 散度作为在自主生成轨迹 $\tau$ 上的环境奖励来优化学生策略 $\pi_\theta$。为将此策略梯度（Policy Gradient, PG）范式转换到连续时间 FM 框架中，我们将离散的 token 序列映射到连续的潜在轨迹 $x_t \in \mathbb{R}^d$。自回归预测转化为由速度场 $v_\theta(x_t, t)$ 参数化的瞬时转移策略。关键在于，我们不是通过监督回归直接最小化向量场之间的距离，而是推导出精确的连续时间 KL 散度，并将其作为密集奖励信号通过 PG 引导策略探索。

在线策略采样 Flow-OPD 的基本前提要求学生暴露其自身的特定分布偏移。为促进充分的状态空间探索——这是 RL 中逃离局部最优的必要条件——我们通过将确定性概率流 ODE 转换为等效的随机微分方程（Stochastic Differential Equation, SDE）来注入随机性 [16]：

$$ dx_t = \left[ v_\theta(x_t, t) + \frac{\sigma_t^2}{2t} \left( x_t + (1 - t) v_\theta(x_t, t) \right) \right] dt + \sigma_t d\mathbf{w} \tag{5} $$

在时间步长 $\Delta t$ 上应用 Euler-Maruyama 离散化，学生的转移行为表现为局部各向同性高斯策略：

$$ \pi_\theta(x_{t-\Delta t} | x_t, c) = \mathcal{N}(\mu_\theta(x_t, t), \sigma_t^2 \Delta t \mathbf{I}) \tag{6} $$

通过对每个提示采样 $G$ 条独立轨迹，生成在线策略边际分布 $x_t \sim \pi_\theta(\cdot | c)$，作为随机行为策略。

任务特定教师标注 在每个探索状态 $x_t$，学生查询专家教师集成以获得局部监督。为消除域间梯度干扰，我们实现了硬路由机制 $\mathcal{R}(c) = k$，将文本条件 $c$ 映射到集成中唯一的对应领域专家 $k$。该机制选择性地激活单一教师提供参考速度场 $v_{\phi_k}^*(x_t, t, c)$。目标流因此定义为：

$$ v_{\text{target}}(x_t, t, c) = v_{\phi_k}^*(x_t, t, c), \quad \text{其中 } k = \mathcal{R}(c) \tag{7} $$

其中 $\mathcal{R}(\cdot)$ 表示确定性的任务到教师路由函数。这产生了任务特定的目标转移策略 $\pi_{\text{target}} = \mathcal{N}(\mu_{\text{target}}(x_t, t), \sigma_t^2 \Delta t \mathbf{I})$，作为评估学生在线策略轨迹的最终黄金标准。

推导流模型中的解析 KL 在大语言模型中，OPD 将密集优势定义为负反向 KL 散度：$A_t = -D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{target}})$。由于离散 token 词汇表阻止梯度直接通过采样过程流动，优化严格依赖于得分函数估计器（即策略梯度定理）：

$$ \nabla_\theta \mathcal{J}_{\text{LLM}} = \mathbb{E}_{s_t} \left[ \nabla_\theta \log \pi_\theta(a_t | s_t) \cdot A_t \right] \tag{8} $$

这种离散公式不可避免地引入了高梯度方差，需要计算昂贵的 logprob 跟踪、重要性采样和复杂的代理裁剪机制（如 PPO）来稳定训练。为将此框架迁移到流匹配模型，我们必须在数学上将 KL 计算适应到连续状态空间。根据 SDE 公式，学生转移策略 $\pi_\theta(\cdot | x_t)$ 和目标策略 $\pi_{\text{target}}(\cdot | x_t)$ 都是 $d$ 维多元高斯分布。关键的是，它们共享由前向 SDE 噪声调度严格导出的完全相同各向同性协方差矩阵 $\Sigma_t = \sigma_t^2 \Delta t \mathbf{I}$。对于两个一般高斯分布 $\mathcal{N}_1(\mu_1, \Sigma_1)$ 和 $\mathcal{N}_2(\mu_2, \Sigma_2)$，期望 KL 散度解析定义为：

$$ D_{\text{KL}}(\mathcal{N}_1 \parallel \mathcal{N}_2) = \frac{1}{2} \left[ \text{tr}(\Sigma_2^{-1} \Sigma_1) - d + (\mu_1 - \mu_2)^T \Sigma_2^{-1} (\mu_1 - \mu_2) + \ln \frac{\det \Sigma_2}{\det \Sigma_1} \right] \tag{9} $$

由于我们的策略共享相同的协方差（$\Sigma_1 = \Sigma_2 = \Sigma_t$），迹项求值为数据维度 $\text{tr}(\mathbf{I}) = d$，与 $-d$ 常数无缝抵消。同时，相同行列式的对数比求值为 $\ln(1) = 0$。因此，复杂的散度精简为仅包含马氏距离。代入具体的逆协方差 $\Sigma_t^{-1} = (\sigma_t^2 \Delta t)^{-1} \mathbf{I}$，KL 散度优雅地约化为其均值之间的 L2 距离 [16]：

$$ D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{target}}) = \frac{\|\mu_\theta(x_t, t) - \mu_{\text{target}}(x_t, t)\|^2}{2\sigma_t^2 \Delta t} \tag{10} $$

根据 Euler-Maruyama 离散化，策略均值 $\mu_\theta(x_t, t)$ 由预测向量场 $v_\theta$ 确定性参数化：

$$ \mu_\theta(x_t, t) = x_t + \left[ v_\theta(x_t, t, c) + \frac{\sigma_t^2}{2t} \left( x_t + (1 - t) v_\theta(x_t, t, c) \right) \right] \Delta t \tag{11} $$

当减去目标均值 $\mu_{\text{target}}$ 时，状态相关的基础项完全相同地消去。KL 散度优雅地简化为严格在向量场之间的缩放差异：

$$ D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{target}}) = \frac{\Delta t \left[ t(1 - t) + 1 \right]}{2 \sigma_t^2} \cdot \frac{1}{\Delta t} \left\| v_\theta(x_t, t, c) - v_{\text{target}}(x_t, t, c) \right\|^2 \tag{12} $$

将 OPD 引入流匹配模型 在大语言模型中，由于离散 token 词汇表禁止通过采样过程直接微分，OPD 必须依赖得分函数估计器（即策略梯度定理）以优化密集奖励 $r_t = -D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{target}})$：

$$ \nabla_\theta \mathcal{J}_{\text{LLM-PG}} = \mathbb{E}_{s_t} \left[ \nabla_\theta \log \pi_\theta(a_t | s_t) \cdot \left( - D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{target}}) \right) \right] \tag{13} $$

将此策略梯度公式直接迁移到流模型的连续状态空间会产生结构上相同的 Flow-OPD PG 更新：

$$ \nabla_\theta \mathcal{J}_{\text{Flow-OPD}} = \mathbb{E}_{x_t \sim \text{SDE}} \left[ \nabla_\theta \log \pi_\theta(x_{t-\Delta t} | x_t) \cdot \left( - D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{target}}) \right) \right] \tag{14} $$

在离散空间中，评估公式 13 需要高方差蒙特卡洛估计。然而，对数导数技巧的一个基本性质规定了 KL 散度的期望策略梯度在数学上等于期望 KL 散度本身的直接梯度。具体而言，在无限样本上计算 PG 期望在数学上收敛为：$\mathbb{E}[\nabla \log \pi \cdot (-D_{\text{KL}})] \equiv \nabla_\theta (-D_{\text{KL}})$。

虽然这种直接梯度对离散大语言模型在解析上不可处理，但我们的连续流公式具有完全可微的闭式解。因此，我们可以完全绕过高方差 PG 估计器、$\log \pi$ 计算和 PPO 代理边界。从根本上说，在流模型中直接最小化这一精确的 MSE 损失在数学上严格等价于在大语言模型中执行策略梯度 OPD，但有效地将梯度方差降至零。因此，公式 14 可以通过直接对标准时间加权 MSE 损失进行反向传播来简化：

$$ \mathcal{L}_{\text{Flow-OPD}} = \mathbb{E}_{x_t \sim \text{SDE}} \left[ w(t) \left\| v_\theta(x_t, t, c) - \text{SG}\left( v_{\text{target}}(x_t, t, c) \right) \right\|^2 \right] \tag{15} $$

其中 $v_\theta$ 保持连接到计算图以接收梯度，$\text{SG}(\cdot)$ 表示教师目标的停止梯度算子，且 $w(t) = \frac{\Delta t \left[ t(1 - t) + 1 \right]}{2 \sigma_t^2} \cdot \frac{1}{\Delta t}$。最终，该公式将在线策略 RL 的严格状态空间探索与回归的确定性优化效率无缝统一。

流形锚定正则化 激进地优化功能目标（如精确文本渲染或严格空间布局）经常引发奖励黑客行为，表现为视觉美学和生成多样性的严重退化 [16]。为将功能对齐与风格崩塌解耦，我们引入了一种受 Flow-GRPO 中 KL 惩罚启发的连续时间美学保持机制。

然而，不同于锚定到通用预训练模型，我们维持一个冻结的美学教师（例如，通过 DeQA 优化）以提供高保真正则化向量场 $v_{\text{aesthetic}}$。如先前推导的，SDE 框架中的反向 KL 散度优雅地转化为向量场之间的时间加权 L2 距离。在我们的实现中，优化公式化为最小化总损失 $\mathcal{L}_{\text{Total}}(\theta)$，即策略损失 $\mathcal{L}_{\text{Policy}}(\theta)$（定义为替代目标 $-\mathcal{J}(\theta)$ 的负值）与该密集 KL 惩罚的直接求和：

$$ \mathcal{L}_{\text{Total}}(\theta) = \mathcal{L}_{\text{Flow-OPD}}(\theta) + \beta \cdot \mathbb{E}_{c, t, x_t \sim \pi_t} \left[ w(t) \left\| v_\theta(x_t, t, c) - v_{\text{aesthetic}}(x_t, t, c) \right\|^2 \right] \tag{16} $$

该 KL 正则化作为连续的弹性锚运作。它保证在学生策略贪婪吸收多教师集成的功能智能的同时，始终被严格约束在高质量视觉流形上，完全避免单目标 RL 中典型的美学退化。

7 结论

我们引入了 Flow-OPD——首个将在线策略蒸馏融入流匹配模型的框架，有效解决了奖励稀疏性和梯度干扰问题。通过用密集的轨迹级监督替代标量奖励，Flow-OPD 打破了竞争指标的"跷跷板效应"。我们在 SD-3.5-M 上的结果表明，Flow-OPD 成功整合了组合和排版方面的专业知识，同时实现了涌现的"超越教师"效应。通过流形锚定正则化（MAR），该框架通过解耦功能对齐与美学保持来维持高视觉保真度。最终，Flow-OPD 为开发具有优越生成完整性的通用文本到图像模型提供了可扩展的对齐范式。

B.2 与 DiffusionNFT 的比较

DiffusionNFT [49] 引入了一种在线强化学习框架，将奖励反馈直接集成到前向扩散过程中，实现在噪声注入阶段的策略优化。尽管在基准分数上具有竞争力，DiffusionNFT 仍存在若干关键局限性。首先，它与无分类器引导（Classifier-Free Guidance, CFG）根本不兼容，这严重限制了其性能上限。其次，它遭受明显的奖励黑客行为。如图 10 所示，虽然模型正确生成了目标文本和"日落"元素，但同时幻觉出畸形的手部和多余的物体（如橙子），并伴有严重的过平滑、类塑料纹理伪影。当前的基准在很大程度上忽视了这些局部结构和美学失败。为解决这一评估盲点，我们采用 Qwenvl Score 进行更全面的评估。通过利用连续时间密集多专家监督和任务风格解耦，Flow-OPD 有效规避了这些奖励黑客行为，获得了比 DiffusionNFT 显著更高的 Qwen-VL 分数。这些发现也凸显了社区亟需开发更鲁棒、细粒度的文本到图像生成评估范式。

B.3 失败案例与局限性

尽管 Flow-OPD 在主观和客观基准上均表现出优越性能，但某些局限性仍然存在。一个主要限制是教师模型所施加的性能上限。如图 11 所示，当专业教师未能合成语义正确的图像时，这些不准确性会通过密集监督信号传播。这种错误引导会将噪声引入蒸馏目标，最终阻碍学生超越教师集成的固有限制。另一个固有局限性是教师和学生模型之间需要架构同质性方可实现细粒度的逐步监督。展望未来，我们旨在通过若干有前景的方向探索 Flow-OPD 的更广泛潜力，包括：（1）协同演化蒸馏（Co-evolutionary Distillation），其中教师和学生迭代地相互优化；（2）自蒸馏（Self-Distillation）机制，无需外部教师即可提升性能；（3）跨词汇表蒸馏（Cross-Vocabulary Distillation），以弥合异构模型架构之间的差距。

更广泛的影响

我们关于 Flow-OPD 的工作引入了一个面向生成模型中多任务对齐的鲁棒框架，既带来了积极的社会贡献，也带来了需要审慎考虑的潜在风险。

积极的社会影响

本工作的主要贡献是增强了 AI 生成内容的功能可靠性。通过改进布局连贯性和 OCR 准确率，Flow-OPD 可以显著造福专业领域，如自动化平面设计、教育内容创作以及面向视障人士的辅助技术。此外，我们的多教师范式推动了更平衡的优化目标，这减轻了单奖励强化学习中固有的"赢者通吃"偏差，有望催生更多样化和更具代表性的生成系统。

消极的社会影响

尽管有这些益处，生成高质量、遵循指令的图像的能力提升也可能被滥用于制造复杂的虚假信息或欺骗性视觉内容。虽然我们的模型继承了基础模型的安全过滤器，但增强的结构真实感可能被利用来生成更具说服力的伪造文件或误导性社交媒体资产。为缓解这一问题，我们倡导在下游应用中集成数字水印和来源追踪（如 C2PA）。此外，与所有大规模生成模型一样，存在专业教师可能隐藏训练数据中潜在偏差的风险，这些偏差可能被无意中蒸馏到学生模型中。我们鼓励社区在采用本框架的同时使用偏差检测基准，以确保在所有人群中的公平性能。
