## 一、改写目标

在 Vision-OPD 代码基础上，实现 MCDC（模态可信度感知的动态控制策略）：

1. 添加 Text 教师（纯文本模型）
2. 实现模态可信度计算（置信度 + 优势差）
3. 实现动态权重计算（softmax + 门控）
4. 修改蒸馏损失（从固定权重改为动态权重）

### 步骤 2：创建 MCDC 核心模块

**文件**：新增 `verl/workers/actor/mcd_distillation.py`

**功能**：
1. `compute_modality_confidence(teacher_logits, student_logits)`：计算模态置信度
2. `compute_advantage_gap(teacher_logits, student_logits)`：计算优势差
3. `compute_dynamic_weights(vl_scores, text_scores, tau, epsilon)`：计算动态权重
4. `mcd_distillation_loss(student_logits, vl_teacher_logits, text_teacher_logits, config)`：MCDC 蒸馏损失

**核心代码**：
```python
def compute_modality_confidence(teacher_logits, top_k=1):
    """计算教师的预测置信度（top-k 概率和）"""
    probs = F.softmax(teacher_logits, dim=-1)
    top_k_probs, _ = torch.topk(probs, top_k, dim=-1)
    return top_k_probs.sum(dim=-1)

def compute_advantage_gap(teacher_logits, student_logits):
    """计算教师相对于学生的优势差"""
    teacher_probs = F.softmax(teacher_logits, dim=-1)
    student_probs = F.softmax(student_logits, dim=-1)
    return (teacher_probs - student_probs).max(dim=-1).values

def compute_dynamic_weights(vl_scores, text_scores, tau=1.0, epsilon=0.1):
    """计算动态权重（softmax + 门控）"""
    # Softmax
    w_vl = torch.exp(vl_scores / tau)
    w_text = torch.exp(text_scores / tau)
    total = w_vl + w_text
    w_vl = w_vl / total
    w_text = w_text / total
    
    # 门控机制
    w_vl = torch.clamp(w_vl, min=epsilon)
    w_text = torch.clamp(w_text, min=epsilon)
    
    # 归一化
    total = w_vl + w_text
    w_vl = w_vl / total
    w_text = w_text / total
    
    return w_vl, w_text

def mcd_distillation_loss(student_logits, vl_teacher_logits, text_teacher_logits, config):
    """MCDC 蒸馏损失"""
    alpha = config.get('alpha', 0.5)
    beta = config.get('beta', 0.5)
    tau = config.get('tau', 1.0)
    epsilon = config.get('epsilon', 0.1)
    
    # 计算置信度和优势差
    vl_conf = compute_modality_confidence(vl_teacher_logits)
    vl_adv = compute_advantage_gap(vl_teacher_logits, student_logits)
    vl_scores = alpha * vl_conf + beta * vl_adv
    
    text_conf = compute_modality_confidence(text_teacher_logits)
    text_adv = compute_advantage_gap(text_teacher_logits, student_logits)
    text_scores = alpha * text_conf + beta * text_adv
    
    # 计算动态权重
    w_vl, w_text = compute_dynamic_weights(vl_scores, text_scores, tau, epsilon)
    
    # 计算加权 JS 散度
    js_vl = F.kl_div(
        F.log_softmax(student_logits, dim=-1),
        F.softmax(vl_teacher_logits, dim=-1),
        reduction='batchmean'
    ) + F.kl_div(
        F.log_softmax(vl_teacher_logits, dim=-1),
        F.softmax(student_logits, dim=-1),
        reduction='batchmean'
    )
    
    js_text = F.kl_div(
        F.log_softmax(student_logits, dim=-1),
        F.softmax(text_teacher_logits, dim=-1),
        reduction='batchmean'
    ) + F.kl_div(
        F.log_softmax(text_teacher_logits, dim=-1),
        F.softmax(student_logits, dim=-1),
        reduction='batchmean'
    )
    
    # 加权损失
    loss = w_vl * js_vl + w_text * js_text
    
    return loss, {'w_vl': w_vl.mean(), 'w_text': w_text.mean()}
```

### 步骤 3：在 dp_actor.py 中集成 MCDC

**文件**：`verl/workers/actor/dp_actor.py`

**修改内容**：

2. **添加 Text 教师加载**：
```python
def __init__(self, config, ...):
    # 原有代码
    ...
    
    # 加载 Text 教师
    text_teacher_path = config.actor.self_distillation.get('text_teacher_path', None)
    if text_teacher_path:
        from transformers import AutoModelForCausalLM, AutoTokenizer
        self.text_teacher = AutoModelForCausalLM.from_pretrained(
            text_teacher_path,
            torch_dtype=torch.bfloat16,
            device_map='auto'
        )
        self.text_teacher_tokenizer = AutoTokenizer.from_pretrained(text_teacher_path)
        self.text_teacher.eval()
    else:
        self.text_teacher = None
```

3. **修改 update_policy 方法**：
```python
def update_policy(self, data):
    # 原有代码：计算 VL 教师蒸馏损失
    # loss_vl = compute_vl_distillation(...)
    
    # 新增：计算 Text 教师 logits
    if self.text_teacher is not None:
        with torch.no_grad():
            text_inputs = self.text_teacher_tokenizer(
                data['text_prompts'],  # 纯文本 prompt（不含图像）
                return_tensors='pt',
                padding=True
            ).to(self.device)
            text_teacher_logits = self.text_teacher(**text_inputs).logits
    
    # 新增：计算 MCDC 损失
    if self.text_teacher is not None:
        loss_mcd, metrics = mcd_distillation_loss(
            student_logits=student_logits,
            vl_teacher_logits=vl_teacher_logits,
            text_teacher_logits=text_teacher_logits,
            config=self.config.actor.self_distillation
        )
        loss = loss_mcd
    else:
        # 降级为 Vision-OPD（单一 VL 教师）
        loss = loss_vl
        metrics = {'w_vl': 1.0, 'w_text': 0.0}
    
    # 原有代码：反向传播
    loss.backward()
    self.optimizer.step()
    
    return metrics
```

## 七、风险与应对

| 风险 | 应对 |
|------|------|
| Text 教师显存不足 | 用更小的模型（Qwen2.5-3B）或用 gradient checkpointing |
| MCDC 损失计算慢 | 优化代码，用 torch.compile |
| 动态权重训练不稳定 | 加门控机制 ε，或用 EMA 平滑 |
