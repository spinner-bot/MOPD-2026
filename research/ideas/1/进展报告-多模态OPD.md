## 一、前期调研

### 1.1 研究方向选择

选取方向：**多模态在线策略蒸馏（Multimodal On-Policy Distillation, MOPD）**

**选择理由**：
- **研究热度高**：OPD 已成为大模型后训练的标准范式，多模态扩展是前沿方向
- **问题明确**：多模态场景引入了模态异构性、教师选择困境等新挑战
- **应用价值大**：可提升多模态大模型的推理能力和泛化性能

### 1.2 核心问题识别

通过调研 8 篇前沿工作（H-OPD、DOPD、Open-MOPD、Uni-OPD、PRISM、VOLD、Flow-OPD、DiffusionOPD），识别出以下核心问题：

| 问题 | 描述 | 代表工作 |
|------|------|---------|
| 静态教师路由 | 任务级或样本级的教师路由过于粗粒度，无法适应同一推理轨迹不同 token 的需求 | H-OPD |
| 特权幻觉 | 给教师提供特权信息（如视觉标注），学生可能学到"捷径"而非真正能力 | DOPD |
| 模态坍缩 | 学生过度依赖强势模态教师，忽视弱势模态教师的互补信号 | Open-MOPD |
| 能力整合不平衡 | 多教师 OPD 中，不同领域的优化预算错配 | Open-MOPD |
| 教师监督不可靠 | 教师对学生 rollout 的监督信号不可靠 | Uni-OPD |

### 1.3 现有解决方案

**H-OPD（置信度感知的异构多教师 OPD）**：
- Token 级教师仲裁：在每个 token 处动态融合 VL 教师和纯文本教师的指导
- 视觉-语言描述迁移：利用 VL 教师提取图像描述，使文本教师间接获取视觉语义
- 置信度感知：基于教师置信度动态组合监督信号

**DOPD（双重在线策略蒸馏）**：
- 优势感知：根据每个 token 的特权优势差和师生置信度，动态决定蒸馏方式
- 四种 token 分类：关键知识 token、共识 token、不确定 token、探索性 token
- 效果：在 LLM 设置下平均提升 7.5 分，闭合了 89.8% 的初始师生差距

**Open-MOPD（诊断与修复多教师 OPD 的能力不平衡）**：
- 发现标准 M-OPD 只能恢复 35.6% 的性能提升
- 解决方案：Token-share balancing + Gap-aware 动态预算分配 + Student reward refresh
- 效果：将恢复率从 35.6% 提升至 83.4%

### 1.4 调研结论

1. **H-OPD 证明**：同一推理过程中不同 token 需要不同教师
2. **DOPD 证明**：不同 token 需要不同强度的监督
3. **Open-MOPD 证明**：多教师能力整合的关键是优化预算分配，而非 token 级分歧

**核心洞察**：将 H-OPD 的"动态选择教师"和 DOPD 的"动态控制强度"结合，可能是下一步最有潜力的突破方向。

## 二、Strand 1 分支：模态可信度感知的动态控制策略（MCDC）

### 2.1 核心思想

**问题**：多模态教师可信度不一致，被动接纳所有教师的监督信号会导致模态坍缩。

**解决思路**：主动控制不同模态教师在策略收拢过程中的参与程度。

### 2.2 方法设计

#### 2.2.1 模态可信度计算

在每个 token 处，计算每个教师的可信度分数 $c_k(t)$：

$$c_k(t) = \alpha \cdot \text{Conf}_{T_k}(t) + \beta \cdot \text{Adv}_{T_k}(t)$$

其中：
- $\text{Conf}_{T_k}(t)$：教师 $T_k$ 在时刻 $t$ 的预测置信度
- $\text{Adv}_{T_k}(t)$：教师 $T_k$ 相对于学生的优势差
- $\alpha, \beta$：平衡系数

#### 2.2.2 动态控制策略

根据可信度分数，动态计算每个教师的参与权重 $w_k(t)$：

$$w_k(t) = \frac{\exp(c_k(t) / \tau)}{\sum_{j=1}^{K} \exp(c_j(t) / \tau)}$$

#### 2.2.3 门控机制

为防止弱势模态教师完全被忽视，引入门控机制：

$$w_k'(t) = \max(w_k(t), \epsilon)$$

其中 $\epsilon$ 是最小权重阈值（如 0.1）。

### 2.3 方法优势

| 方法 | 教师选择 | 监督强度 | 模态控制 |
|------|---------|---------|---------|
| Vision-OPD | 单一 VL 教师 | 固定 | ❌ |
| H-OPD | Token 级仲裁 | 固定 | ✅（选谁来教） |
| DOPD | 固定教师 | Token 级动态 | ❌（单模态） |
| **MCDC（我们）** | **Token 级动态** | **Token 级动态** | **✅✅（选谁来教 + 怎么教）** |

**创新点**：
1. **模态可信度感知**：不仅考虑教师置信度，还考虑优势差
2. **双重动态控制**：既动态选择"谁来教"，又动态决定"怎么教"
3. **门控机制**：防止弱势模态被完全忽视，避免模态坍缩

### 2.4 理论保证

- **收敛性**：动态权重 $w_k(t)$ 是概率分布，保证梯度方向正确
- **稳定性**：门控机制 $\epsilon$ 防止权重极端化，避免训练不稳定

## 三、未来计划

### 3.1 实验设计

#### 3.1.1 Baseline

- **Vision-OPD**：单一 VL 教师的 OPD
- **H-OPD**：Token 级教师仲裁（选教师）
- **DOPD**：Token 级动态蒸馏（控制强度）
- **Static-Multi**：多教师固定权重

#### 3.1.2 评估基准

- **视觉推理**：ChartQA, DocVQA, InfoVQA
- **图文问答**：OK-VQA, A-OKVQA, GQA
- **细粒度视觉**：Visual7W, VQAv2

#### 3.1.3 评估指标

- **准确率**：标准任务指标
- **模态利用率**：统计不同模态教师的平均参与权重
- **训练稳定性**：loss 曲线、熵变化

#### 3.1.4 消融实验

- **可信度计算**：只用置信度 vs 只用优势差 vs 两者结合
- **温度参数**：$\tau \in \{0.1, 0.5, 1.0, 2.0\}$
- **门控阈值**：$\epsilon \in \{0, 0.05, 0.1, 0.2\}$

### 3.3 预期贡献

1. **方法**：提出模态可信度感知的动态控制策略（MCDC），解决多模态 OPD 的模态坍缩问题
2. **理论**：分析模态可信度与蒸馏效果的关系，提供理论指导
3. **实验**：在多个多模态推理基准上验证 MCDC 的有效性

### 3.4 风险与应对

| 风险 | 应对 |
|------|------|
| 动态权重训练不稳定 | 加门控机制 $\epsilon$，或用 EMA 平滑权重 |
| 计算开销增加 | 可信度计算可与前向传播合并，额外开销 <5% |
| 效果提升不显著 | 增加消融实验，分析失败案例 |

## 四、总结

已完成前期调研，识别出多模态 OPD 的核心问题（模态坍缩），提出 Strand 1 分支的研究方向：**模态可信度感知的动态控制策略（MCDC）**。

MCDC 结合了 H-OPD 的"动态选择教师"和 DOPD 的"动态控制强度"，通过模态可信度计算和门控机制，主动控制不同模态教师的参与程度，解决模态坍缩问题。

下一步计划在 Vision-OPD 代码基础上实现 MCDC，跑 baseline 实验，验证方法有效性。
