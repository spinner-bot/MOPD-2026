# 1049-T-自然 G0 标签稳健测量实现

**性质**：临时文档；1048 的 CPU 合约与 Slurm 执行实现记录

**创建时间**：2026-09-14 10:26（UTC+8）

**作者**：Codex (CINECA Leonardo)

**触发原因**：1048 已在自然结果前冻结四轮换语义聚合，需要把协议转成可执行、可拒绝漂移的代码路径，避免 B2a 完成后再临时改评分。

---

## 1. 已实现

1. `build_natural_label_rotation.py`：只接受 8/32/96 条通过 1017 合约的基础 manifest；排他创建四倍执行 manifest、rotation spec、summary 和哈希。
2. `exploratory_teacher_gap.py`：新增自然轮换 profile、基础 manifest 逐字段绑定、循环映射验证、语义 score 聚合、四语义 log-softmax、tie/abstain generation 诊断，以及按基础样本进入原统计裁决的路径。
3. runner/process：显式支持 `natural_rotation`，raw 保存基础样本、四轮换、语义 option 和映射 provenance；结果 gate 反查基础与轮换 manifest；新决定命令拒绝未完成的 4×4 记录。
4. `submit_exploratory_teacher_gap.sbatch`：先验证原 8/32/96 分区，再分别验证 canary/locked 轮换 manifest；实际规模改为 canary 32×4=128、locked 384×4=1,536；最终以 96 个基础样本为统计 N。

## 2. fail-closed 性质

- 任一基础字段、displayed option、正确 displayed label、mapping、rotation spec 或基础 manifest hash 变化均被拒绝；
- 任一基础样本缺少 rotation 0–3 或任一 rotation 缺少四条件均被拒绝；
- 聚合必须让每个语义选项取得四个有限 raw scores；
- generation 多数票并列输出 `null` 与 tie 标记，不以 A 优先进入统计；
- legacy 固定字母 `decide` 保留，仅用于复现旧运行；新 Slurm 只调用 `decide-natural-label-rotation`。

## 3. 验证

166 项 CPU 测试全部通过。新增测试覆盖：

- 8 条人工合约样本扩展为 32 条并保持源 provenance；
- 映射突变被拒绝；
- 强静态 A/B/C/D 先验经四轮换平均后不改变语义排序；
- 8 个 T-QA 错→对在基础 N=8 上进入 `GO_T_QA`，执行视图与条件记录只作为 32/128 记录，不膨胀统计 N；
- 自然轮换 preflight CLI 对基础 manifest、图片 checksum 与 tokenizer 联合绑定，零 GPU、零性能读取。
- 完整 `expanded raw → validate gate → parsed → semantic aggregate → decide` CLI 合成链以 128/128 记录通过，并只报告基础 N=8 的 `GO_T_QA`，验证没有把轮换视图当独立样本。
