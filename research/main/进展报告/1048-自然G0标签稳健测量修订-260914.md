# 1048-自然 G0 标签稳健测量修订

**性质**：重点文档；1017 自然 teacher-gap 的结果前测量修订

**创建时间**：2026-09-14 10:18（UTC+8）

**作者**：Codex (CINECA Leonardo)

**触发原因**：1047 证明固定单字母接口会遮蔽程序化任务中的 G 信号；自然 G0 尚无任何结果，因此需在其 manifest 与运行产生前修订主测量，避免把答案符号先验误当作方法效应。

---

## 1. 修订范围

1017 的自然数据来源、8/32/96 基础样本、人工验收、四条件输入、模型 revision、非 thinking、盲法、图像 cluster、Go/Revise/Stop 效应阈值均保留。本修订只改变答案选项的执行视图和从模型 score 到语义结果的聚合。

基础 manifest 中 A/B/C/D 被定义为四个**语义 option ID**，不再被视为一次固定显示字母。每个基础样本在运行时生成 rotation 0–3 四个不可选择的循环显示版本；四条件都完整运行四个版本。

## 2. 冻结映射与规模

使用与 1046 相同的唯一规则：

`semantic_index = (displayed_index + rotation) mod 4`。

每个语义选项在同一道题中各显示为 A、B、C、D 一次。执行记录规模为：

| 阶段 | 基础统计单元 N | 执行视图 | 四条件总记录 |
|---|---:|---:|---:|
| canary | 8 | 32 | 128 |
| dev | 32 | 128 | 512 |
| locked | 96 | 384 | 1,536 |

四轮换是同一基础样本的测量重复，**有效 N 仍为 8/32/96**，不得报告成 32/128/384，也不得把 1,536 条当作独立观测做显著性检验。

## 3. 主测量

对每个基础样本、条件和语义选项，取该语义选项跨四个 displayed labels 的 raw full-vocabulary label-sequence log-likelihood 算术平均，记为 `semantic_score`。在四个 `semantic_score` 上：

1. 最大项给出 `semantic_prediction`；完全相等按语义 option ID A、B、C、D 打破平局；
2. 对四个 `semantic_score` 做 log-softmax，正确语义项记为 `semantic_correct_log_prob`；
3. 正确项减最佳错误项记为 `semantic_margin`。

主 accuracy、配对翻转和 exact McNemar 全部使用 `semantic_prediction`。原 `ΔCorrectLP ≥0.15 nat` 条件改为同数值、同 bootstrap 规则的 `ΔSemanticCorrectLP ≥0.15 nat`；它先在四语义内归一化，消除条件导致“任一字母整体更像回答”的共同偏移。`semantic_margin` 为关键次指标。

constrained generation 仍保留并映射回语义，但只作接口诊断。四轮换多数票若并列则记为 tie/abstain，不得按 A 优先制造正确或错误；它不进入 Go/Revise/Stop。

## 4. 完整性与 provenance gate

除 1017 原 gate 外，新增：

- 每个基础样本必须恰有 rotation 0–3，且四条件齐全；
- 每个语义选项必须恰好占据 A/B/C/D 各一次；
- 问题、图片、guide、正确语义 option ID 与基础 manifest 一致；
- displayed option 文本、正确 displayed label 与映射逐项重算一致；
- 轮换 manifest 必须绑定基础 manifest SHA 与 rotation spec SHA；
- locked 必须 1,536/1,536 记录完整才可产生条件性能。

任一失败均为 `INVALID`。不得只保留模型生成成功、某个轮换 margin 大或某个 label 较稳定的子集。

## 5. 原统计裁决如何迁移

1017 §8 的比较对象仍是 T-Q−S 与 T-QA−S，Generic-T 仍是长度/结构控制，Holm、exact McNemar、10,000 次 source-image cluster bootstrap、0.08 accuracy 与 0.15 nat 门槛均不变。变化仅为：每个条件先从四个 displayed-label 记录还原成一个基础样本级语义观测，再进入原统计。

因此本修订没有增加自由度或降低 Go 门槛。它避免固定标签偏置污染处理前后比较，也避免用四倍伪样本夸大功效。

## 6. 对当前门禁的影响

1047 已证明当前 4B 与 T-QA 表示在程序化多步任务上能产生行为化 G 信号，故“消费配方完全不健康”的前置疑点已由 label-robust 测量解除。自然 G0 仍不得运行，直到：

1. B2a 获得真实人工审核并按 1039 路由；
2. B3–B5 形成互斥的 8/32/96 自然基础 manifest；
3. 本修订的自然轮换 finalizer、validator、聚合与合成测试完成；
4. 运行包在结果前冻结并推送。

当前关键阻塞仍是 B2a 的 0/32 人工签名；1047 的程序化结果不能替代它。

1049 已完成本修订的 CPU/Slurm 实现并通过 165 项测试；当前没有自然轮换 manifest 或自然性能结果。技术门禁已前移，待 B3–B5 基础清单出现后再结果盲冻结实际资产哈希。
