# 模型尺度迁移与 9B 训练解锁契约

**性质**：重点文档；在任何 9B 自然 teacher-gap 输出或 OPSD 训练结果产生前，冻结从 4B 机制发现到 9B 正式训练的证据桥与停止规则。

**创建时间**：2026-09-14 12:48（UTC+8）

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：现行自然 G0 明确使用 Qwen3.5-4B，G-PC0 的接口正控制也只验证了 4B；正式方案却计划以 9B 核心 2×2 的 3 seeds 支撑论文主结果。模型尺度会改变基线 ceiling、视觉读取、guide 消费、tokenizer 行为和训练稳定性，因此 4B 的 teacher gap 或训练收益不能自动授权昂贵的 9B 正式训练。

---

## 1. 两种模型尺度承担不同职责

- **4B 是发现与可转移性门**：完成自然 G0、G1 主要机制确认和 T-only pilot 的结构特异 transfer 检查；它用于低成本淘汰无信号的数据/G 表示和不可转移的训练配方。
- **9B 是论文尺度确认**：在相同科学假设上复核 9B 是否仍能读取 G、是否存在结构特异 teacher advantage、训练链是否健康；通过后才进入正式多 seed 比较。

“4B 有效”只说明当前任务与 G 在一个模型尺度上可用。它不等价于“9B 仍有提升空间”，也不等价于“9B 能把优势蒸馏给学生”。

## 2. 9B 正式训练前的三级桥接

9B 正式训练必须依次满足以下条件。

### 2.1 9B 接口正控制

以与 G-PC0 同类的程序化闭世界多步任务验证 9B 的图像输入、choice continuation、四标签轮换和 T-QA 消费链。9B 正控制必须使用冻结 9B 权重 inventory、完整运行 provenance 和语义标签聚合。

若正控制失败，先处理接口或 scoring；不得把自然 9B 的零效应解释为数据或方法失败。4B 的 `LABEL_INTERFACE_MASKED_G_SIGNAL` 不能替代这一步，因为标签偏置及 continuation 行为可能随模型尺度改变。

### 2.2 9B inference-only scale bridge

在 G1 的冻结题、图、四轮换、T/V payload 和评分协议上运行 9B，不训练。至少包含 S、入选 Real-T 及其逐题 matched Generic；若 4B G1 的机制主张包含 V 或 VT，9B 桥接同时保留 1078 的 V-real/V-sham 及相应控制格。桥接回答：9B 的 ceiling/floor 是否仍留下可测优势，以及真实 G/相关 crop 是否相对等预算控制提供结构特异信息。

桥接样本必须在读取任何 G1 条件结果前冻结。若预算只允许使用 G1 子集，子集大小、family/depth 分层和成员清单须在 4B 与 9B 的 G1 输出均不可见时锁定；不得从 4B 高增益题中挑选 9B 样本。优先使用同一基础题，以便报告 scale × condition 的配对差异。

### 2.3 9B 训练链烟测

在正式 3-seed 前，以冻结的小规模数据和单 seed 验证 9B 的 OPD-00、OPD-Generic、OPD-Real-T 三条路径均可完成 rollout、EMA/JSD、checkpoint 保存与无特权评测。至少报告 loss、吞吐、峰值显存、实际 teacher/student tokens 和失败重试；不得用烟测效果充当正式结论。

若沿用 Vision-OPD 作为对照，9B 是否需要官方 reproduction 在 9B 桥接门冻结时一并决定；任何省略都必须明确限制“相对 Vision-OPD”的尺度结论。

## 3. 训练解锁顺序

现行顺序冻结为：

```text
4B G0 teacher gap
  → 4B G1 机制确认
  → 4B T-only pilot 在独立 pilot-val 上出现结构特异 transfer
  → 9B 接口正控制
  → 9B inference-only scale bridge
  → 9B 训练链烟测
  → 9B 正式核心比较（至少 3 个共同 seeds）
```

4B pilot 必须用 1071 的 `OPD-00 / OPD-Generic / OPD-Real-T` 因果三角，在与 G0/G1 及未来正式测试均互斥的 `pilot-val` 上检查 `Transfer_specific=M_T-M_Generic` 的方向和实用幅度。pilot 的具体继续/停止门槛须依据已可见的 G0/G1 变异、但在任何 pilot-val 结果可见前冻结。该门只决定是否继续投入 9B，不能称为正式 transfer 结果。正式的 4B/9B transfer 主结果仍须等训练配方与所有 seeds 固定后，在 1072 的新 `Stage1-internal-test` 上一次性打开；不能为了决定是否运行 9B 先揭示 internal test。若 4B 只有 teacher gap、没有 pilot 结构特异 transfer，优先修订 OPSD 配方；此时扩大到 9B 不能解决“teacher advantage 未被学生内化”的证据缺口。

如果未来有充分理论或工程证据需要跳过 4B transfer 直接试 9B，只能在读取 9B 结果前另立带预算上限和停止条件的探索协议；该探索不得直接升级为正式主结果。

## 4. 9B bridge 的结果前门槛

精确数值应使用 G0/G1 的 4B 独立方差和 ceiling/floor 信息做 power analysis，但必须在读取 9B 输出前冻结。门槛至少包含：

1. 9B 正控制通过，且所有资产、rotation 和解析门禁有效；
2. `Real-T-S` 与 `Real-T-Generic` 分开报告，后者是结构特异主门；
3. accuracy 净翻转和 correct-answer log-prob 均报告，防止 9B 基线 ceiling 掩盖概率改善；
4. scale × condition 配对差异及 family/depth 分层有预注册区间；
5. 不得用“9B 比 4B 绝对准确率高”替代“9B 存在可蒸馏的 teacher advantage”。

结果路由：

| 9B bridge | 决策 |
|---|---|
| Real-T 相对 matched Generic 达到预注册正向门 | 进入 9B 训练烟测 |
| accuracy ceiling，但 paired log-prob 达到预注册正向门 | 可进入烟测，主张限定为概率层 advantage |
| Real-T 只优于 S、不优于 Generic | 不支持结构化 G 特异性；停止当前 9B Real-T 正式训练 |
| Real-T 与 Generic 均无优势 | 停止 9B 正式训练，报告尺度边界；4B 结果仍可独立成立 |
| 方向为负或门禁异常 | 停止并先诊断，不提交多 seed |

## 5. tokenizer、文本和 thinking 公平性

4B 与 9B 的 tokenizer 文件必须分别通过冻结 inventory 验证。即使名称、revision 或实测 tokenization 相同，也要保存两边实际 token 数与 hash，不能依据型号系列假定相同。

跨尺度桥接优先保持同一 Real-T 和同一语义模板的 Generic 文本。若两个 tokenizer 无法同时满足逐题 `≤10%` 长度误差，可生成 tokenizer-specific Generic 变体，但须保存共同语义模板、各自文本/hash/token 数，并把该输入差异列为尺度比较限制。不能为了匹配 9B 长度改写 Real-T。

non-thinking 是主要桥接条件，与 G0/G1 和无特权学生测试一致。thinking 只能在主桥接冻结后作为次级压力测试；不得按 thinking 的单题翻转筛选 9B 训练或测试数据。

## 6. 数据隔离与统计边界

9B inference bridge 属于训练前机制证据，可复用冻结 G1 基础题以形成跨尺度配对，但因此同样不得把这些图簇用于 Stage1 train、validation 或训练后 internal test。9B 的正式 transfer 必须在 1072 定义的独立冻结 internal test 上评估。

正式 9B 主比较至少 3 个共同 seeds，并遵守 1071 的 seed × image-cluster 不确定性。只有通过 1071 的 `M_T-M_Generic` 才能声称结构化 G 被迁移；`M_T-M_00` 仍只代表总 privilege training effect。

论文主尺度与尺度泛化措辞遵守 1080 的 S4：4B pilot-val 不计入 formal 显著性主链；9B bridge 未过时可在 internal-test 打开前改冻 4B 为主尺度，但不能看完 4B/9B formal test 后再选择较有利者。

若 9B experimental checkpoint 与 G generator 同权重，scale bridge 还须按 1081 在冻结作者敏感性子集上同时比较 model-authored 与 independently human-authored G。只对 model-authored G 扩大的 gap 可能是 self-author affinity，不能直接归因模型规模。

## 7. 当前状态与权限边界

当前只有 4B G-PC0 的程序化接口证据；自然 G0、G1、4B transfer、9B 正控制、9B bridge 和 9B 训练均为零结果。9B 本地 16/16 模型文件 inventory 已验证只证明资产身份，不证明接口、效果或训练稳定性。
