# Stage 1 结构特异迁移对照契约

**性质**：重点文档；在自然 teacher gap、G1 和任何新 OPSD 训练结果产生前，冻结从“teacher 能使用 G”到“student 内化 G 结构收益”的最小对照与主估计量。

**创建时间**：2026-09-14 12:31（UTC+8）
**创建作者**：Codex (CINECA Leonardo)  
**触发原因**：正式方案 v1.0 已要求 Base、final-answer SFT、OPD-00、Random-T 和 Real-T，但 Stage 1 最小模型组没有把与真实 G 逐题等长的 Generic teacher 明确列为主训练对照。G0 中 Real-T 优于 matched Generic 只证明未训练 teacher 的结构特异优势，不能自动证明训练后的学生增益来自该结构；额外 teacher token、teacher forward 计算和普通提示带来的训练动态仍可能混入 `M_T-M_00`。

---

## 1. 需要分开的三个问题

Stage 1 必须分别回答：

1. **OPSD 本身是否改变学生**：`M_00 - Base`；
2. **加入同长度普通 teacher context 是否改变学生**：`M_Generic - M_00`；
3. **真实推理路径相对同长度普通 context 是否被内化**：`M_T - M_Generic`。

只有第三项支持“G 的样本相关推理结构被蒸馏”。`M_T-M_00` 仍需报告，但它是总 privilege training effect，不能单独充当结构特异迁移证据。

## 2. 最小模型组

自然 G0 与 G1 均达到解锁门后，第一轮 T-only 训练的最小组改为：

| ID | 训练 | 作用 |
|---|---|---|
| `Base` | 不训练 | 原 checkpoint 参照 |
| `SFT-answer` | 仅最终答案监督 | 区分普通监督与 dense on-policy distillation；次要机制对照 |
| `OPD-00` | student/EMA teacher 均看 `I,Q` | 控制 rollout、优化器、EMA 和 JSD 更新 |
| `OPD-Generic` | teacher 看与本题真实 G 逐题 token 匹配的中性 context | 控制额外文本长度、teacher forward 负载和普通检查提示 |
| `OPD-Real-T` | teacher 看冻结的真实 T-Q 或 T-QA | 主方法 |

若 G0 选择 T-Q，`OPD-Generic` 必须用 Generic-Q；若选择 T-QA，则用 Generic-QA。若论文同时训练 T-Q 与 T-QA，二者必须各有对应的 Generic-Q/Generic-QA，不能用一个短 control 跨层比较。

Random-T 与 Shuffled-T 仍是有价值的内容/顺序消融，但不替代 `OPD-Generic`：random 可能含图像或任务相关词，shuffle 保留真实词汇；二者回答的问题与“同长度中性额外 context”不同。Privileged-response SFT 也保留为 off-policy 对照，不进入最小因果三角。

## 3. 训练公平性

`OPD-00`、`OPD-Generic` 与 `OPD-Real-T` 必须共享：

- 初始 checkpoint、训练样本和顺序；
- student 输入 `I,Q`、rollout 数、response 上限和学生生成 token 预算；
- optimizer、learning rate、batch size、epoch/更新步数、EMA、JSD、Top-K 与梯度累积；
- seed 集与 checkpoint 选择规则；
- 训练集 image/near-duplicate cluster 隔离。

Real-T 与 Generic 的 teacher context 在每个基础样本内按 1055–1058 的冻结 tokenizer 匹配，目标相对误差 `≤10%`，并在训练 manifest 中保存实际 token 数和文本 hash。两组因此构成 teacher-side token/计算的直接对照。

`OPD-00` 的 teacher context 天然更短。主表保持相同更新步数和学生 token 预算，不通过给 OPD-00 增加训练步数来“补算力”，因为这会改变优化剂量。另行报告实际 teacher tokens、GPU-hours、吞吐和 wall time；若需 compute-matched 曲线，只能作为预注册的次级效率分析。

相同 seed 只保证随机源与数据顺序对齐；模型更新后 on-policy rollout 可以分叉，不能声称不同训练条件共享完全相同的后续 token prefix。

## 4. 主估计量与统计单位

冻结无特权测试输入 `I,Q` 上定义：

\[
Transfer_{specific}=Perf(M_T;I,Q)-Perf(M_{Generic};I,Q),
\]

\[
Transfer_{total}=Perf(M_T;I,Q)-Perf(M_{00};I,Q),
\]

\[
GenericShift=Perf(M_{Generic};I,Q)-Perf(M_{00};I,Q).
\]

主要结构特异训练结论使用 `Transfer_specific`；另两项解释总收益与普通额外 context 的训练效应。内部选择题继续使用四轮换后的 semantic accuracy 和 correct-answer log-prob；外部 benchmark 服从官方指标。依据 1072，这些训练后主估计必须来自未参与 G0/G1 方法选择的新冻结 internal test，不能在 G1 上循环确认。

训练 seed 是泛化到训练随机性的重复单位，测试 item 是评测不确定性的重复单位。正式主比较至少 3 个同一 seed 集的独立训练；区间必须同时反映 seed 与 image-cluster 变异，可用预注册的 seed × cluster 分层 bootstrap 或层级模型。不能把单个训练 seed 下的数百测试题当作数百个独立训练重复来支持稳定性主张。

依据 1084，四个最小模型组还必须形成共同的 paired seed block 与完全相同的 frozen internal-test key set。共同基础设施故障只允许对同一 seed 的全部受影响组完整重跑；持续的方法特异 divergence/OOM 作为稳定性结果保留在冻结 seed 分母中，不得删除或替换该 seed。逐条件 complete-case 不能成为结构特异 transfer 主分析。

在未训练 checkpoint 上再定义等长结构 teacher advantage：

\[
Gap_{specific}=Perf(T)-Perf(Generic).
\]

可描述性报告受控闭合率：

\[
GCR_{specific}=Transfer_{specific}/Gap_{specific}.
\]

仅当分母为正且远离零时报告数值及区间；它可小于 0 或大于 1，不作有界比例。v1.0 原 `GCR=(M_T-M_00)/(T-S)` 保留为总路径描述，但需命名为 `GCR_total`，不能独自证明结构特异转移。

## 5. 结果解释

| 结果 | 允许解释 |
|---|---|
| `M_T>M_Generic≈M_00` | 真实 G 结构产生可蒸馏的特异收益 |
| `M_T≈M_Generic>M_00` | 额外 teacher context/训练动态有效，尚无 G 结构特异证据 |
| `M_T>M_Generic` 且两者均低于 `M_00` | G 减少部分负迁移，但当前训练仍未改善学生 |
| `M_T≈M_Generic≈M_00` 且 G0 teacher gap 为正 | teacher advantage 存在，但当前 OPSD 未转移 |
| `M_T<M_Generic` | 当前真实 G 的监督信号比中性 context 更有害，优先检查 fork suppression、泄漏和 teacher-student 分布冲突 |

所有主结果必须同时报告 Base、OPD-00、OPD-Generic、OPD-Real-T 的 absolute performance 与 paired differences，不能只展示对研究假设最有利的差值。训练数据不得按已观察的单题 teacher gap 筛选作为第一版主结果；advantage filtering 只能另开数据版本和次级实验。

## 6. 与当前路线的关系

本契约只冻结未来 Stage 1 的对照骨架和 estimand，不授权现在训练。当前仍须依次完成 B2a、B3–B5、自然 G0 和 G1；训练规模、学习率、最终 seed 数值、checkpoint 选择与 power 要在相应前置信息可见后、目标训练结果可见前另行冻结。

1077 进一步规定模型尺度顺序：4B 先以本契约的因果三角在独立 pilot-val 上检查结构特异 transfer，作为是否投入 9B 的开发门；9B 随后还要单独通过接口正控制、inference-only scale bridge 与训练烟测，才能进入正式多 seed。正式 internal test 仍须在配方与 seeds 固定后一次性打开，不能拿来决定是否跑 9B。4B 的正结果不自动证明 9B 有 teacher advantage 或可转移空间。

1078 为视觉路径建立对称控制：`M_Vreal-M_00` 是总视觉 transfer，只有 `M_Vreal-M_Vsham` 排除了额外视觉输入和 processor 预算后，才支持相关 crop 内容特异迁移。real V/T 2×2 的交互是 raw interaction；声称两种相关内容协同须完成 `Vreal/Vsham × Treal/Tgeneric` 控制格。

1080 将训练后主张按 S1 结构特异 transfer、S2 task-family transfer、S3 受控视觉/交互、S4 尺度与外部泛化顺序开放。Stage1-internal-test 的 primary 为四轮换 semantic accuracy 上的 `M_T-M_Generic`；correct-answer log-prob、paired flips 与总路径 `M_T-M_00` 必报但不竞争 primary。
