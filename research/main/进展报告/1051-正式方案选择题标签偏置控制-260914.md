# 1051-正式方案选择题标签偏置控制

**性质**：重点文档；正式方案 v1.0 的内部选择题测量勘误与扩展原则

**创建时间**：2026-09-14 10:38（UTC+8）

**作者**：Codex (CINECA Leonardo)

**触发原因**：正式方案 v1.0 §18 认为“正确标签近似均匀 + 一次随机 option order”足以支持 A/B/C/D choice scoring 和 generation accuracy；1045–1047 的实证显示，同一 4B 在 gold 全局平衡时仍可把 67%–97% 的输出压到 A，足以遮蔽真实 G 信号。

---

## 1. 勘误

全局 A/B/C/D gold 平衡只能控制“正确答案在数据集中的边际频率”，不能控制模型对某一道题的符号先验。一次随机顺序也只让每个语义选项抽到一个位置；若正确语义落在 B/D，而模型强烈偏 A，该样本的 teacher utility 可能被符号门槛吞没。

因此正式方案中“Choice scoring 用于机制分析，Generation accuracy 用于实际行为”的原表述不再足够。对于项目内部构造的四选一数据，主性能必须在语义空间定义；单次 displayed-letter generation 只能作为部署接口或偏置诊断。

## 2. 内部 controlled evaluation 的统一规则

每个基础样本保存四个语义 option ID 和正确语义 ID。评测时让四个语义选项按 1048 的循环规则各显示在 A/B/C/D 一次，并对每个 condition/model 完整运行四次：

1. raw label-sequence log-likelihood 映射回语义 option；
2. 每个语义 option 跨四轮取均值；
3. 四个均值的 argmax 定义主 semantic accuracy；
4. 四语义内 log-softmax 定义 correct semantic log-prob；
5. 正确语义分数减最佳错误语义分数定义 margin；
6. McNemar、bootstrap、factorial effect 和 subgroup 全以基础样本为统计单元。

四次轮换不得计作四个独立样本。自由生成/单字母 constrained generation 继续报告，但 mapped vote 平局记 abstain，且不替代主 semantic result。

四个循环轮换使每个语义选项恰好占据每个显示位置一次，因此控制的是显示位置/标签的主效应。它不穷尽全部 24 种排列，也不消除所有“某两个选项相邻或先后出现”等高阶顺序交互；这些残余交互作为测量局限报告，不在当前样本量下扩展为 24 倍评测。

## 3. 适用与不适用范围

| 场景 | 规则 |
|---|---|
| 1017 自然 teacher-gap | 1048/1049 已实现四轮换主测量 |
| Stage 0 N=400–600 internal screening | 使用同一语义聚合，N 仍是基础题数 |
| 正式内部 P/R/PR 测试集 | 主表使用 semantic accuracy；另报原始 generation interface |
| 外部 benchmark | 保留其官方 prompt、输出和 metric，不能为了本项目改协议；若允许 choice log-prob，可追加标签稳健 secondary analysis |
| 开放式回答数据 | 本勘误不直接适用；继续用冻结 exact/semantic judge 合同 |

## 4. 对训练数据的约束

正式 OPSD-v-t 训练不能让 `semantic_answer ↔ displayed_label` 的偶然关系变成捷径。所有 rotation variants 必须留在同一 image/question group 和同一 split。训练实现应在 Stage 1 结果前从以下二者选一并冻结：

- materialize 四轮换、每个 variant 权重 1/4；
- 每个 epoch 用 `sample_id × epoch` 的确定性规则选择一个 rotation，连续四个周期覆盖四个位置。

所有对照方法必须共享相同 rotation schedule 与基础样本权重。不能给文本方法更多有效样本，也不能依据 teacher gap 为某些样本增加轮换次数。

## 5. 对 v1.0 其他结论的影响

该勘误不改变 V/T/VT 条件定义、P/R/PR 理论、teacher/student 输入边界、数据质量要求或主效应问题。它修复 `Perf` 的内部选择题测量：`Perf` 应优先指 label-robust semantic performance，而不是单个 displayed label 的命中率。

1047 只证明程序化多步任务上的 G 机制可行性，尚未证明自然或训练后效果。这个测量修复提高证据可信度，不构成论文结果。
