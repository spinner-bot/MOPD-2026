# 1086-T-260914-1324 聚类稳健统计工具修复

**性质**：临时文档；记录 G1 统计静态审计发现的 silent cluster ignore 与修复验证。

**创建时间**：2026-09-14 13:24（UTC+8）

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：1037/1068 要求同图 P/R/PR 和多条件分析按 image cluster 处理相关性，但 `code/evaluation/statistical_tests.py::factorial_regression` 虽接受 `cluster_ids`，实际始终拟合普通 `statsmodels.Logit` 并完全忽略该参数；两个现行冻结 Python 环境又均未安装 statsmodels。该函数尚无调用方或正式结果，因此可在结果前修复。

## 修复

- 移除未安装的 statsmodels 运行依赖，以 SciPy BFGS 拟合 logistic MLE；
- `cluster_ids` 存在时按 cluster 聚合 score contribution，使用有限样本修正的 cluster-sandwich covariance；
- cluster 数少于 2、长度错位、设计矩阵非有限/不满秩或优化失败时显式返回 error，不再静默退化为普通标准误；
- 输出 `covariance_type`、`n_observations`、`n_clusters`、`analysis_role=descriptive_smoke_only` 和 `g1_confirmatory_model=false`；
- 用本地实现替代仅为 Holm 校正引入的 statsmodels，并拒绝未审核的其他 method；
- 增加四项回归测试：cluster sandwich 路径、退化 cluster 拒绝、Holm 数值与非 Holm 拒绝。

## 解释边界

修复后的函数可以做描述性 factorial smoke 和发现编码错误，但不等于 1037/1068 计划的 G1 混合效应确认模型。G1 仍须在结果前冻结具体模型式，至少处理 item 与 image cluster 的嵌套/重复结构；不得因为本工具现在给出 cluster-robust SE 就把它自动升级为 C1–C4 主分析。

本次没有读取 G1 或训练效果；当前自然 G0/G1/Stage1 结果仍为零。
