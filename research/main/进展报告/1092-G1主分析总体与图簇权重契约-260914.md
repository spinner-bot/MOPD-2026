# G1 主分析总体与图簇权重契约

**性质**：重点文档；在 G1 构建和任何性能输出产生前，冻结 C1/C2 的题目总体、图簇权重与 PR 角色。

**创建时间**：2026-09-14 13:47（UTC+8）

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：1080 将 C1 写为预注册的 R/PR 分析总体，并把合并权重留待 G1 前冻结；1037 规划 160 张图都有 P/R，只有约 80 张在自然成立时增加 PR。若 C1 可在 R-only、PR-only 或多种合并权重之间选择，PR 可供性与样本数差异会形成结果后总体选择，并让 C1/C2 使用不同图簇。

---

## 1. 两个结果盲 frame

### `G1_text_pair_frame`

由 G1 frozen manifest 中同时满足以下条件的 image/near-duplicate clusters 组成：

- 恰有预注册数量的同图 P 与 R 主问题；
- 两题均通过闭世界、唯一答案、证据/DAG、family 和 leakage 人工门；
- 两题均通过 1087 的 Real-G 节点/token/作者/人工帮助机会配平；
- 所有成员资格在模型输出前确定，并符合 1082 effect-selection firewall；
- 全部 required text conditions/rotations 满足 1084 完整块。

### `G1_visual_pair_frame`

是 `G1_text_pair_frame` 中进一步通过 1078/1088 real/sham 视角、证据覆盖和 visual opportunity 配平的预先锁定子集。它只承担 C3 视觉分量。C3 frame 可以比 C1/C2 小，但成员和原因必须在任何 G1 模型输出前冻结，不能按观察到的 V gap 形成。

## 2. C1 primary 固定为 R

C1 primary 使用 `G1_text_pair_frame` 中每个 cluster 的**唯一预注册 R 主问题**：

\[
C1_j=LP(T_{real};j,R)-LP(T_{generic};j,R).
\]

C1 estimand 是 clusters 等权的 `mean_j(C1_j)`。四个 label rotations 先聚合为一个语义 observation，不增加权重。若一个 cluster 在同一家族有多个候选题，只能在结果盲构建阶段按固定规则指定一个 `primary_question_id`；其余为 secondary，不得平均后让题多的 cluster 权重更大。

PR 不进入 C1 primary。其原因不是预期效果大小，而是 PR 只在具有额外自然可供性的部分图片存在，且已被 C4 指定为 V/T 内容互补总体。PR 上的 `T-real−T-generic` 必须报告为 secondary replication；R+PR 固定等权或 item-weighted 合并只能作 sensitivity，不能开启 C1。

P 上的 `T-real−T-generic` 同样完整报告，它是 C2 的组成部分，不与 R 竞争 C1 primary。

## 3. C2 使用完全相同的 clusters

C2 primary 在同一 `G1_text_pair_frame` 上定义：

\[
C2_j=[LP(T_{real})-LP(T_{generic})]_{j,R}
     -[LP(T_{real})-LP(T_{generic})]_{j,P}.
\]

estimand 仍为 clusters 等权的 `mean_j(C2_j)`。因此 C1→C2 的变化只有加入同图 P 对照，不改变来源、图片簇、作者 frame 或 cluster 权重。C1 通过后不能把 C2 改到“有 PR 的一半图”、某个 strategy/depth 或 positive-dependency 子集。

若某 cluster 在冻结后出现 A 类配置错误，按 1084 关闭并重跑完整条件块；不能只从 C2 删除。若结果盲质量门在运行前使一个 pair 不合格，它不进入 frame，但须保留在构建产率分母。

## 4. C3/C4 与 frame 的关系

- C3 文本分量沿用 C2 的 `G1_text_pair_frame`；视觉分量使用预先冻结的 `G1_visual_pair_frame`，并明确报告两个 frame 的 cluster 数与组成差异。双向 specialization 的主张要求两边各自完整通过，但不能把文本 C2 事后缩到视觉效果更好的子集重新优化。
- C4 使用独立的 `G1_PR_frame`：自然成立、文本/视觉机会与完整四格都在结果前锁定的 PR 问题。每 cluster 至多一个 primary PR，clusters 等权。PR 不足只降低 C4 power/可用性，不回流改变 C1/C2。

为检查 frame 差异，预注册报告 C2 在 visual-frame 交集上的 sensitivity，以及 C3 visual effect 在完整 visual frame 上的 primary；前者不能取代完整 text-frame C2。

## 5. 统计实现要求

每个 primary table 输出：frame manifest SHA、cluster 数、每 cluster primary question ID、family、每个 condition/rotation 完整性和权重。聚合器必须断言 cluster 权重和为 1、每 cluster primary 权重相等；禁止按题数、rotation 数、response token 数或是否答对加权。

G0 结果可用于在 G1 输出前确定最小实用效应、样本量和具体检验，但不能改变上述 frame/estimand 结构。若未来统计模型与 cluster-equal mean 给出不同结论，cluster-equal correct-LP estimand 是 C1/C2 的主目标；混合模型作为预注册支持/敏感性，不能事后取代。

## 6. 当前边界

当前 B2a 为 0/32，G1 未解锁，无 frame manifest 或结果。本契约没有依据 S/T/V 输出选择 R；R 是在用户核心问题和 G1 结果产生前指定的 C1 目标，PR 角色由其自然缺失模式和 C4 机制职责决定。
