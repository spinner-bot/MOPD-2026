## 1. 实现内容

### 1.1 schema 语义

`data_schema.py` 将旧 `dependency_score/guide_dependency_score` 明确限定为 semantic-review legacy 字段，禁止写入 experimental-model deletion effect。三个 legacy teacher-gap 字段默认值从 `0.0` 改为 `None`，并标明只兼容结果后分析；locked manifest 应把效果放在由 manifest hash 连接的独立 artifact。

### 1.2 selection firewall

新增 `data_pipeline/effect_selection_firewall.py`：

- G0/G1 locked、Stage1 validation/internal-test 和 external benchmark 必须显式 `selection_uses_model_effect=false`；
- 上述 confirmatory roles 携带非空 `teacher_gap*`、`model_utilization*`、`condition_effect*` 或 `evaluation_effect*` 即拒绝；
- `selection_uses_model_effect=true` 只允许 Stage1-train；
- effect-filtered train 必须同时给出 64 位小写 `parent_unfiltered_manifest_sha256` 与 `effect_selection_rule_sha256`；
- Stage1-train 不允许省略 result-selection 声明。

natural G0 finalizer 现逐条写入：

```json
{"dataset_role":"G0-locked-method-selection","selection_uses_model_effect":false}
```

shared `validate_locked_manifest` 在 GPU 前调用 firewall；新模块也进入 finalizer runtime code hash 集。

### 1.3 dependency analysis

`evaluation/dependency_test.py` 的 docstring 和返回值改为模型利用分析：每个 `DependencyResult`、pattern summary 和 partial-chain summary 均带 `analysis_only=true, selection_safe=false`。`is_critical` 保留作兼容，但明确只是 model-utilization threshold flag，不是语义关键节点。
