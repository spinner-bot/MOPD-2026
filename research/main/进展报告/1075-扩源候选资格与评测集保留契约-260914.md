**触发原因**：1039 已规定 B2a 为 1–7 或 0 时比较新来源，但“什么来源有资格”和“能否把已入库 benchmark 图片拿来构题”尚未固定。当前仓库同时保存训练来源和 ZoomBench、HR-Bench、V*、MME-RealWorld 等外部评测资产；若因 M3VQA 产率低而从这些 benchmark 挑图训练，后续外部泛化表会被污染。

## 1. 扩源不是结果导向挑图

替代来源先通过资产级资格审计，再按与 B2a 相同的 image-only 流程取固定 32 图盲样本。资格和样本成员不能读取：

- M3VQA B2a 的逐图 candidate/reject 内容；
- 机器 B1 proposal；
- 任一 S/T/V/VT 或训练后结果；
- 数据集论文宣称的“reasoning”标签。

B2a 档位只触发“是否执行已冻结比较”，不能用于从多个来源中先浏览图片再选择最像 R 的一个。若需比较多个来源，全部来源的名单、版本、抽样规则和 32 图包先冻结，再打开任何新来源的人类标签。

## 2. 图源资格

进入盲比较的来源必须同时满足：

1. **许可可用**：数据/图像许可允许当前学术构建、派生标注与论文发布；许可证文件、revision 和取得时间归档。仅有代码许可或仅有论文 CC 许可不等于图像许可。
2. **完整图自足**：单张完整图可独立查看；不依赖小说段落、Wikipedia evidence、检索网页、视频前后帧、交互式工具历史或未随图提供的规则。
3. **有结构可供性**：来源采集机制允许多实体、空间/连接/顺序/图表/状态关系自然出现，但不以已有问题标签直接判定 R。
4. **图像身份稳定**：文件可校验 SHA-256，存在稳定 source ID；可在全池建立 exact/near-duplicate cluster。
5. **规模与质量**：扣除损坏、极低分辨率和近重复后，仍足以供 G0/G1/Stage1 各角色按 1072 分离；小来源只能作为诊断，不能承担 8K 训练主源。
6. **来源可报告**：能说明自然照片、图表/示意图、合成谜题等域构成；不能把域差异伪装成 P/R 机制。

“视觉谜题/图片解谜”可以是高 R 可供性候选域，但既有谜题答案可能依赖题外规则或文化知识。它仍须逐题通过闭世界、唯一答案、最小必要证据和反事实检查，不能因类型名称直接放行。

## 3. 现有资产的用途边界

依据当前 `DATASET_MANIFEST.md` 和 1035，而非新增下载：

| 资产 | 当前角色 | 扩源边界 |
|---|---|---|
| M3VQA images | B2a 当前来源 | 等待 32 图盲校准；原题外部知识不决定图片可供性 |
| Vision-OPD 6K 原图 | Track A 复现与视觉侧来源 | 可用于 V/P 对照；若未来比较 R 可供性也必须另取 image-only 盲样本，不能沿用 crop 视角问题或 bbox 作为筛选线索 |
| VistaHop | 潜在长推理外部集 | 当前清单记载单独工具/多跳形态且代码许可待核；完成许可与单图自足审计前不进入自建训练源 |
| ZoomBench、HR-Bench、V*、MME-RealWorld、MMVP、POPE、VisualProbe | 外部评测 | 默认保留，不能因图片已入库而用于构题、训练或 validation |

若决定牺牲某个外部 benchmark 作为训练图源，必须在任何使用前书面移出外部评测主表，并按 image/near-duplicate cluster 划出永不训练的独立部分。使用之后不得继续报告该 benchmark 全集为 unseen 泛化结果。

## 4. 公平盲比较

每个合格来源采用：

- 固定 revision 的完整 image inventory；
- source 内 exact/near-duplicate cluster 后按 cluster 抽样，避免重复图增加命中率；
- 预先固定 seed 和 32 个 cluster，不按美观度、分辨率或机器分数挑选；
- 与 B2a 相同的无来源浏览器界面、字段、R/PR 定义和单 reviewer 完整门；
- 报告全部 32 为分母的 witness rate、usable rate、candidate/R/PR 数、Wilson 区间、每个合格目标的人工分钟和 B3 semantic pass；
- 来源身份在审核端隐藏，至少在所有来源第一阶段锁定前不揭示；图像域本身可被人猜出，这一限制如实记录。

分辨率和图像域可以事后作为描述性协变量，但不能删除失败图。若不同来源分辨率差异极大，可在结果前定义共同分层并同时报告原始总体与分层估计；不能只展示有利层。

来源选择首先依据可复核目标产率、B3 通过率、标注成本、许可和可扩规模。teacher gap 只在选定来源和问题冻结后测量，不进入来源选择。

## 5. 混合来源

若没有单一来源兼顾自然度、R/PR 可供性和规模，可以建立混合源，但必须：

- 在结果前冻结每个来源的目标比例与 role 分配；
- 每个 source × role 都做 cluster 隔离；
- G0/G1/Stage1 报告 source 分层和 `method × source` 敏感性；
- P/R/PR 的主要交互优先使用 1037 同图配对，不能用“来源 A 全是 P、来源 B 全是 R”代替；
- 不因某来源产生更大 teacher gap 而事后提高其 locked/test 权重。
