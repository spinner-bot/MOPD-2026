## 1. 一句话结论

第二阶段的核心产出不是验证“文本视觉特权信息自蒸馏”已经有效，而是完成了对该路线的严格可行性审计：

> 数据与任务定义暴露出严重的来源—瓶颈错配、外部知识污染、视角偏置和构题产率风险；与此同时，项目建立了较完整的闭世界人工校准、结果前冻结、运行 provenance、统计分母、模型资产和评估入口防绕过体系，但在自然数据上尚未获得 teacher-gap 结果，也未进入正式训练。

因此，第二阶段应被归档为：

```text
科学路线审计完成
工程与审计基础大幅加固
自然 teacher-gap 尚未测量
OPSD 训练尚未启动
```

---

## 2. 阶段目标与路线演化

第二阶段开始时，主要目标是把正式方案 v1.0 的 T00–T08 数据生产链跑通，并随后进入 Stage 0 的 privilege-gap screening。1012 中期评估后，研究重点发生了第一次收缩：

1. 不再把“完整流水线跑通”当作首要成功标准；
2. 优先回答 teacher gap 是否存在，以及其大小是否值得继续投资；
3. 将视觉特权 V、文本特权 T 和联合特权 VT 放回任务瓶颈框架，而不是按数据集名称直接分配 P/R；
4. 对 M3VQA 实施闭世界原则，禁止把 Wikipedia、地理、历史、药用等外部知识注入误认为文本推理能力；
5. 在任何自然 G0/G1 或训练前，先完成结果盲的数据、任务、人工审核和控制条件冻结。

第二阶段后半段进一步将原正式 Stage 0 拆成分级证据链：

```text
G-PC0 接口/机制正控制
→ B2a 图像来源与可构题性盲校准
→ G0 自然最小 teacher-gap 信号
→ G1 图内 P/R/PR 机制确认
→ Stage 1 transfer
→ OPSD 正式训练
```

这个顺序是本阶段最重要的研究设计结论之一。任何较早层级的通过，都不能替代后续层级的科学证据。

---

## 3. 已确认的科学认识

### 3.1 研究对象应由任务瓶颈定义

阶段内逐步明确：

- `Image Affordance = A(I)` 描述图像潜在支持哪些任务；
- `Task Family = F(I,Q,Minimal Evidence Path)` 描述当前问题实际依赖哪条最小证据路径；
- 图像来源、数据集名称或 `question_hop` 不能直接充当 P/R/PR 标签。

真正的 R 任务必须要求多个清晰视觉事实之间进行不可省略的关系整合；真正的 PR 任务还必须包含答案链中不可替代且确实难以感知的视觉节点。图片复杂、物体多或整体分辨率低，本身不足以构成 PR。

### 3.2 Vision-OPD 与 M3VQA 各有结构性局限

阶段审计确认：

- Vision-OPD 具有真实的 crop 资源和视觉困难，但部分原问题以 crop 视角书写；若直接用完整图像作为 S/T 输入、crop 作为 V 输入，V 会同时获得视觉信息和问题指代修复优势，无法干净估计视觉特权；
- M3VQA 具有较多多实体、多跳候选，但 `question_hop` 不等于视觉推理深度，且大量原题依赖外部知识；原题路线不能直接承担闭世界 R/PR 主实验；
- 两个来源分别承载 P 与 R，会把来源差异、图片风格和任务瓶颈混在一起；若要研究模态分工，应优先建设同图配对的 P/R/PR 任务。

### 3.3 文本特权至少有两个候选定义

- T-Q：教师接收引导问题序列，但仍需自行回答中间问题；
- T-QA：教师接收带验证中间答案的特权推理路径。

两者不能预先假定谁是主方法。G0 应先分别比较，并在结果前冻结匹配的 Generic-Q/Generic-QA 控制。若只有 T-QA 有效，研究主张应收窄为 privileged reasoning-state/path distillation，而不能笼统称为文本引导有效。

## 4. 第二阶段的工程与数据成果

### 4.1 基础资产和候选池

1013 汇总的基础状态为：

- 统一候选池 19,366 条：Vision-OPD P 6,241 条、M3VQA 粗标 R 12,033 条、M3VQA 粗标 P 1,092 条、正式 PR 为 0；
- 固定 revision、模型资产、图像和原始标注已建立 provenance 与 SHA-256 记录；
- 运行环境、Slurm 入口、run archive 和数据/代码分离规则已形成可复现基础；
- 正式 Stage 0 数据仍为 0 条。

### 4.2 T02 工程 pilot 的真实结论

T02 v2.1 是本阶段最明确的工程性正结果：

- 1,200/1,200 条记录完整；
- 353 条 accepted，845 条模型拒答；
- accepted bbox 与参考区域的 median IoU 为 0.894，97% 存在重叠，0 条越界；
- 非 thinking 吞吐约 1,375 条/h/4GPU；
- thinking A/B 中，非 thinking 的 70 条拒答有 42 条在 thinking 下翻转为 accepted，翻转定位与参考区域高度重叠；
- 但 thinking 的截断代价和约 14 倍成本说明它不能直接作为生产默认策略。

这些结果只证明视觉结构解析、坐标契约和 runner 基本可用，不证明文本引导有效，也不证明 T02 accepted 样本适合正式 P 主实验。尤其是 crop 视角问题会系统性污染后续 V/T 比较。

### 4.3 M3VQA teacher-gap 支路的结论

W2/A 支路经历了 r1–r7 多轮结构化输出、截断、答案基数和构造门禁修复。阶段性结论是：

- 多轮 screen runner 的结构稳定性可以通过，但结构通过不等于语义候选有效；
- 曾出现 repetition/no-repeat 约束破坏 JSON key、fallback 改变语义决定、开放式答案长尾截断、`answers`/`answer_evals` 多答案基数误读等问题；
- r6 产生的 13 条机器候选因答案契约误读作废；
- r7 修复答案 canonicalization 后，固定的 128 条原题路线最新语义重放结果为 0/128 可进入 construction；
- 这只能说明当前 M3VQA 原题路线不适合作为已冻结的自然 teacher-gap 主入口，不能说明 M3VQA 图像总体没有 R/PR 价值。

### 4.4 B2a 图像优先支路

B0 建立了 10,565 张唯一图像池，并通过独立抽样、图像哈希、解码和路径检查固定了 B2a 32 图盲审包。B2a 的目标不是评价原题，而是让真人在不接触来源、原问题、模型 proposal 或结果的情况下，判断图像是否能支持闭世界 R/PR 构题。

到第二阶段结束：

- 32/32 图片路径、哈希和解码门通过；
- loopback 在线界面和离线标注流程均已形成；
- 表格字段、匿名映射、回传和 finalizer 边界已固定；
- 真人语义审核仍为 0/32；
- 因此不能依据 B2a 对 M3VQA 图源作正面或负面科学结论。

## 5. G-PC0 的正确解释

G-PC0 是本阶段唯一出现“G 相关信号”的运行链，但它属于程序化机制正控制，而非自然数据实验。

其过程暴露并修复了固定 A/B/C/D 标签接口在 choice-scoring 下遮蔽 G 信号的问题；经过四轮 label rotation 后，程序化任务的接口门通过，得到有限的机制层观察：模型可以消费符合契约的 G，且 T-QA 在该程序化闭世界任务中出现净错转对。

但 G-PC0 不能支持以下任何结论：

- 自然图像上的文本 teacher gap；
- M3VQA 的 R/PR 可供性；
- T-Q 或 T-QA 的自然主方法选择；
- V/T 分工或 VT 互补；
- OPSD 训练收益；
- 论文主结果。

阶段内已明确将 G-PC0 与自然 G0、B2a、G1、训练数据和论文主表完全隔离。这一隔离应在后续研究中继续保留。

## 6. 阶段内完成的证据与审计体系

第二阶段后半段的主要工作从“增加实验条件”转向“防止无效证据被写成有效结果”。已完成或冻结的关键机制包括：

1. 自然 G0 唯一权威入口及机器可读评估注册表；旧固定标签决定器永久退役；
2. manifest、模型资产、tokenizer、运行代码和结果之间的 SHA/provenance 绑定；
3. natural G0 的四轮标签轮换、逐基础样本双长度 matched generic 和稳定性门；
4. 条件、rotation、seed 的完整块门控；配置失败必须对称重跑，不能逐条件删除；
5. 结果前冻结语义依赖 DAG，禁止按照 teacher gap、模型利用率或 condition effect 反向选样；
6. `G_gold`、`G_prod`、`G_raw` 分层，禁止把自动生产数据直接等同于人工金标准；
7. G1 同图 P/R 的文本帮助机会、Real-G、token、作者和视觉 payload 配平；
8. visual sham、同图 cluster 等权、primary question 和 PR secondary/interaction 角色冻结；
9. OPSD response logits、有效 response mask、EOS、Top-K/JSD 和梯度隔离的数值验收契约；
10. 评估入口 registry、旧旁路测试、B2a 严格盲法、离线包验收和 finalizer；
11. CPU 回归测试、`git diff --check`、模型资产 inventory 和固定 worktree/Slurm 归档机制。

这些成果提升了后续任何研究路线的可信度，但它们本身不是科学效果结果。

## 8. 必须保留的否定性边界

后续研究或汇报不得将以下内容表述为第二阶段已经证明：

- “1,200 条 T02 样本验证了文本引导有效”；
- “T-QA 在自然视觉推理任务上有效”；
- “M3VQA 是合格的 R/PR 数据集”；
- “G-PC0 结果证明了自然 teacher gap”；
- “数据生成流水线完成”等同于“正式数据集完成”；
- “模型/脚本/测试通过”等同于“科学假设通过”；
- “已有 teacher gap”或“已有 student transfer”；
- “B2a 32 图已经人工确认”。

第二阶段最准确的科学表述是：

> 在自然任务上，核心 teacher-gap 尚未获得测量结果；现有正向信号限于 T02 工程 grounding 和 G-PC0 程序化接口机制，不能外推到自然图像或训练收益。

## 9. 对后续研究转向的可复用资产

虽然研究路线即将转向，第二阶段并非无效投入。建议保留并按以下层次复用：

### 可直接复用

- 项目/文档命名与版本管理规范；
- run archive、SHA-256、provenance、固定 worktree 和数据/代码分离；
- fail-closed、结果前冻结、完整条件块和缺失值分母规则；
- 匿名人工盲审、离线交付、不可见来源和 finalizer 机制；
- cluster-aware 统计、配对分析和防结果后选样防火墙；
- 模型资产身份门、tokenizer/processor 验收和 CPU 回归测试体系。

### 只能作为历史参考

- Vision-OPD crop 视角 P 数据路线；
- M3VQA 原题 teacher-gap 支路；
- B2a 对 M3VQA 图像的来源裁决；
- G-PC0 的程序化任务和标签轮换结果；
- v1.0 中尚未运行的自然 G0/G1/Stage 1 规模设想。

### 不得直接迁移

- 未经新方向重新定义的 P/R/PR 标签；
- 未经新方向重新冻结的样本、条件、指标、主张层级；
- 任何旧模型结果、旧候选或旧 manifest 作为新方向的正式训练/评测数据；
- 任何由程序化控制或工程 pilot 得出的自然任务效果结论。

## 10. 阶段收尾判断

第二阶段已经完成其作为“原路线审计阶段”的主要职责：

1. 暴露了原路线中无法忽略的数据与任务错配；
2. 将自然科学问题压缩为可门控、可否证的 teacher-gap 链；
3. 识别了当前自然路线的关键阻塞点，而没有用自动结果替代人工语义判断；
4. 把大量潜在的统计、泄漏、身份、控制和结果后选择风险转化为机器可检查契约；
5. 在没有自然正结果时保留了严格的“未证明”边界。

因此，后续转向不应被记录为“第二阶段实验失败后简单换题”，而应被记录为：

> 第二阶段完成了对文本—视觉特权信息自蒸馏路线的前置可行性与证据质量审计；由于自然核心信号尚未形成、数据获取与构题成本高且原数据路线存在结构性混杂，项目进入新的研究阶段。新阶段可以复用本阶段的审计基础，但必须重新定义研究对象、数据角色、主张层级和解锁门槛。

---

## 11. 后续转向时的最低接续要求

在新方向正式立项或写入下一阶段首份报告前，至少应明确：

1. 新研究问题与可被证伪的主假设；
2. 哪些第二阶段资产继续保留，哪些正式作废；
3. 新数据的来源、任务角色和外部知识边界；
4. 训练前证据与训练后证据如何分开；
5. 新方向的最小 pilot、Go/Revise/Stop 门槛；
6. 旧 G-PC0、B2a、G0、G1 和 OPSD 结果在新论文或报告中的引用限制；
7. 新阶段的编号、版本、Git 分支和运行归档策略。

在这些事项冻结前，不应直接把旧路线的候选数据、控制条件或未运行配置搬入新研究。
