## 1. 实现

提交 `f392b19` 新增 `code/utils/verify_model_asset.py`。工具：

- 内置冻结 revisions TSV 与 model-files 清单的 SHA-256；
- 按 repo 唯一定位完整 revision，并用旧路径 basename 适配存储迁移；
- 要求当前模型顶层普通文件集合与 inventory 精确相等；
- 以 1 MiB 流式块校验每个文件 SHA-256；
- 排他写入 `model-asset-gate.json`，成功/失败均保留结构化原因；
- 拒绝覆盖既有 gate，防止同一 run 内用后来的验证替换原证据。

自然 G0、G-PC0、G-PC0 label rotation、image affordance screening、teacher-gap screening 和 teacher-gap construction 六个 `.sbatch` 都在首次 `srun` 前调用该工具。4B 入口固定 repo/revision，9B 入口固定其对应 repo/revision；自然/G-PC0 的 tracked runtime dirty gate还覆盖 verifier 与两份冻结 inventory。
