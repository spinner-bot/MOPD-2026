## 1. 本轮目标

把“V 对 P 有天然优势、T 需要 R/PR 才可能形成足够效果”的判断转化为可运行、不会循环论证的最小实验：

2. 在读取任何 teacher-gap 结果前冻结筛选规则、条件、指标和分流门槛；
3. 先运行冻结模型 teacher-utility 实验，区分 `T-Q` 的可部署引导收益与 `T-QA` 的 oracle 上界；

本轮不以“完成更多管线节点”为成功标准。成功标准是得到一个可证伪的实验协议，以及能够支持或否定文本特权路线的第一批配对证据。

## 2. 新视角：选择机制与效果估计必须隔离

当前最大的科学风险是循环选择：先用某个模型寻找“T 有效”的样本，再在同一批样本上宣称 T 有效。为避免这一问题，本轮采用三层隔离：

### 2.1 图像层：问题无关的可供性

仅依据图片结构记录 `p_affordance`、`r_affordance`、`pr_affordance` 候选特征，不读取 S/T 条件表现。该层回答“图片能自然支持什么问题”。

### 2.2 样本层：闭世界与最小证据路径

依据图片、题面和参考答案判断：

- 是否仅凭当前图片与题面可唯一作答；
- 是否需要未提供的百科、地理、历史、数学规则或小说上下文；
- 最小证据路径是否真的包含不可省略的关系转换；
- 问题指代是否对完整图像成立。

该层决定样本能否进入 R/PR pilot，不读取 teacher-gap 结果。

### 2.3 效果层：冻结样本后的配对比较

只有样本清单、引导和标签冻结后才运行 S/T/V/VT。结果用于判断方法，不反向修改当前 pilot 的纳入标准。失败样本可以为下一版本提供新假设，但必须开新 manifest 和 run_id。

## 3. 实验结构的优化方向

本轮将 teacher advantage 拆成三个层级，以免把“答案泄露”与“引导能力”混为一谈：

| 层级 | 条件 | 作用 |
|---|---|---|
| 基线 | `S = I,Q` | 当前模型无特权表现 |
| 可部署文本引导 | `T-Q = I,G_Q,Q` | 只提供引导问题，检验路径提示是否有用 |
| oracle 文本上界 | `T-QA = I,G_QA,Q` | 提供经验证的中间状态，估计可蒸馏信息上界 |
| 文本长度控制 | `Generic-T` | 排除任意额外文本或普通“仔细思考”提示 |
| 视觉参照 | `V-add` | 测量同批样本的视觉证据增益 |
| 联合条件 | `VT` | 观察 PR 上的互补或冲突 |

优先级是先确认 `T-QA` 是否存在足够大的 oracle envelope，再判断 `T-Q` 能否接近该上界。如果连 `T-QA` 都没有明显优势，继续扩大 G 生成或蒸馏训练的价值很低；如果 `T-QA` 强而 `T-Q` 弱，问题集中在引导问题设计或中间状态获取，不应直接否定文本特权。

正式数值门槛、样本量和统计方法由 Codex 在 `1016` 协议中冻结，必须早于任何目标条件输出。
