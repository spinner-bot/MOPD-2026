# 视觉特权内容特异性与视角不变性契约

**性质**：重点文档；在 G1 和任何新视觉特权训练结果产生前，冻结 real crop、visual sham、问题视角与视觉内容特异效应的最小因果边界。

**创建时间**：2026-09-14 12:53（UTC+8）

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：正式方案已提出 visual sham，但现行 G1 最小条件只明确 S 与 V，Stage1 最小结构控制又集中于文本 matched Generic。若 real V 只与无 crop 比较，增益仍混合相关证据、额外图像输入、视觉 token、重采样和问题视角修复；Vision-OPD 原题的 crop 视角错位已实际证明最后一项不是假设风险。

---

## 1. Generalized 主线固定使用 V-add

本项目 generalized Track B 的视觉条件固定为：

```text
S:      [I, Q]
V-real: [I, C_real, Q]
V-sham: [I, C_sham, Q]
```

`I` 是相同完整图，`C_real` 是覆盖冻结 required evidence 的附加局部图，`C_sham` 是同图、视觉预算匹配但不含 required evidence 的附加局部图。Track B 不以 `[C,Q]` 替换 `[I,Q]` 作为 V 主条件；替换式 V-crop 只用于严格 Vision-OPD reproduction 或明确标注的附加分析。

这样保持 S/T/V/VT 的完整图上下文一致。V privilege 的变化是附加相关局部证据，而不是丢弃全局图或把问题移到新的坐标系。

## 2. 问题视角不变性是准入门

每道进入 G1、训练或 internal test 的题都必须在只看完整图 `I` 时满足：

- 空间指代以完整图为参照；`左/右/上/下/中心/最近` 等不能暗指 crop 坐标；
- 问题中的对象集合、竞争对象和量词在完整图上定义完整；
- 加入 crop 只能提高必要证据的可见性，不能改变问题含义、唯一答案或排除原图竞争对象；
- `C_real` 不得含答案文字、选项字母、人工标注框或超出原图的信息。

审核者在未知任何条件结果时分别对 `I,Q`、`I,C_real,Q` 和 `I,C_sham,Q` 写出语义等价判定。任一视角改变、答案集合改变或竞争对象被隐式删除即拒绝。Vision-OPD 的旧 crop-perspective 问题只能在从完整图重写并重新人工验收后进入 generalized 主线；原题仍可留在 reproduction。

## 3. visual sham 的逐题匹配

每个 `C_real` 至少配一个 `C_sham`。正式 G1 若预算允许使用两个独立 sham，以观察 sham 位置的敏感性；sham 数量必须在条件结果可见前冻结。

`C_sham` 必须：

1. 来自同一完整图，且不覆盖任一 required evidence 或其近重复实例；
2. 与 `C_real` 的归一化面积、长宽比、导出分辨率和图像编码设置匹配；
3. 经过同一 image processor 后记录实际 grid/vision-token 计数；若模型 API 不暴露视觉 token，则记录全部可复核的 processor shape 与像素预算；
4. 使用相同的 crop padding、resize、颜色空间、压缩格式和 prompt slot；
5. 由确定性候选生成器提出，并在人类未知 S/V/T 输出时确认“无必要证据”。

默认几何门为面积相对误差 `≤10%`、长宽比相对误差 `≤10%`，实际 processor grid/vision-token 相同；若图像边界使其不可能满足，样本不得进入 visual content-specific 主分析，但仍可保留在满足其他契约的文本分析层。不得通过观察 real/sham 效果后重选 sham。

sham 可能因显著干扰物产生负效应，因此必须同时报告 `V_sham-S`，不能只报告 `V_real-V_sham`。若两个 sham 的方向高度不一致，visual content-specific 结果降级为敏感性不稳定，不能挑更有利者。

## 4. inference 层的四类估计量

对同一基础题定义：

\[
V_{total}=Perf(V_{real})-Perf(S),
\]

\[
V_{specific}=Perf(V_{real})-Perf(V_{sham}),
\]

\[
T_{specific}=Perf(T_{real})-Perf(T_{generic}),
\]

其中 `V_total` 回答附加真实 crop 的总体帮助，`V_specific` 才排除额外视觉输入与预算的普通效应。G1 的 `Spec_V` 应分别对 `V_total` 和 `V_specific` 计算，正式视觉内容特异性主张以后者为准。

原始存在/缺失 2×2 的交互仍定义为：

\[
Interaction_{raw}=Perf(V_{real},T_{real})-Perf(V_{real})-Perf(T_{real})+Perf(S).
\]

它回答两种完整 privilege 同时提供时是否非加性，但未排除普通额外图文输入。若要声称“相关视觉证据与真实 G 内容互补”，必须再运行等预算控制格：

\[
Interaction_{specific}=Perf(V_{real},T_{real})-Perf(V_{real},T_{generic})
-Perf(V_{sham},T_{real})+Perf(V_{sham},T_{generic}).
\]

未运行该四格时只能报告 `Interaction_raw`，不得把它改称内容特异协同。

## 5. Stage1 训练对应关系

未来训练模型按相同逻辑命名：

- `M_00`：无额外 privilege；
- `M_Vsham`：teacher 接收 `I,C_sham,Q`；
- `M_Vreal`：teacher 接收 `I,C_real,Q`；
- `M_Generic` 与 `M_Treal`：沿用 1071；
- VT 控制格使用 `Vreal/Vsham × Treal/Tgeneric`。

训练后视觉总效应为 `M_Vreal-M_00`，视觉内容特异 transfer 为 `M_Vreal-M_Vsham`。正式论文若只运行 real 2×2，可报告总效应和 `Interaction_raw`；若主张内容特异的 V transfer，必须把 `M_Vsham` 纳入同 seed 正式比较；若主张 V/T 内容协同，必须在至少一个预声明模型尺度上完成四格控制训练，并同时报告所有绝对性能。

控制格会增加训练成本，因此 1077 的 4B 发现优先级不变：先在 G1 inference 证明 `V_specific`/`Interaction_specific` 值得追踪，再在训练结果可见前冻结是只做 4B 控制格，还是将其提升到 9B 主结果。未投入控制格时收缩论文主张，不以弱控制换强结论。

## 6. P/R/PR payload 边界

- P 的 `C_real` 覆盖困难的单一主要必要视觉节点；
- R 若需要分散证据，V-real 使用冻结的多 crop 集合并保留完整图，不能给一张已合成答案关系的截图；V-sham 使用数量、顺序和逐项视觉预算匹配的多 crop 集合；
- PR 的 V-real 只放大困难视觉节点，不能把后续关系整合结果编码进 crop；
- 同图 P/R 配对各自独立生成 crop/sham，不能把另一题的关键区域故意当作 sham 来制造干扰。

全部 payload 保存原图 SHA、norm1000 与 pixel bbox、转换 provenance、导出图 SHA、processor shape/token 记录及 human no-evidence 判定。图像或 crop 的 near-duplicate cluster 仍按 1072 整组隔离。

## 7. 当前状态与权限边界

现有 T02 v2.1 的 bbox 几何与 source-bbox 重叠验证证明坐标转换可信，但其 353 条 accepted 来自旧 Vision-OPD 问题，不能据此判定视角不变或构成 V-sham。当前为零 G1 real/sham manifest、零 visual content-specific 自然结果、零相关训练。

本文只冻结未来准入、估计量和 claim boundary，不生成 crop/sham、不修改 B2a、不授权 GPU 或训练。B2a 仍为 0/32。

本文不向 Claude code (local) 新增任务。Claude 仍只执行 1038 的 C4-R 独立复核；不得实现 visual sham 或提交作业。
