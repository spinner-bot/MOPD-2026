# 2121-T-261012-S0与S1S3题目级翻转分析结果

## 1. 执行范围与数据门禁

本报告记录 Phase2 第 3 项工作对正式作业 `60011513` 的题目级配对翻转分析。分析范围严格限定为 S0、S1、S3：S0 为基线，S1 和 S3 为目标条件；SC、S2 未进入任何统计、图表或结论。

门禁结果：

- 三个条件各 2000 条；
- `(sample_id, condition)` 唯一；
- 三个条件的样本集合完全一致；
- 每个翻转题目均能回溯到 S0、S1、S3 原始 JSONL；
- token 长度来自正式 vLLM usage 的 `completion_tokens`；
- 分析脚本未重新推断 gold answer 或覆盖既有正确性字段。

## 2. 翻转数量

| 目标条件 | S0 错→目标对（gain） | S0 对→目标错（loss） | 净翻转 | 不一致总数 |
|---|---:|---:|---:|---:|
| S1 | 298 | 45 | +253 | 343 |
| S3 | 262 | 61 | +201 | 323 |

S1 和 S3 相对 S0 都表现为正净翻转。S1 的 gain 多于 S3，loss 少于 S3；这与总体准确率 S1 高于 S3 的结果方向一致。

## 3. 共同与特异翻转

在 S1/S3 的联合分类中：

- 共同 gain：214；
- 任一条件 gain：346；
- 共同 loss：26；
- 任一条件 loss：80；
- S1-only gain：84；
- S3-only gain：48；
- S1-only loss：19；
- S3-only loss：35；
- S1 与 S3 正确性不一致的题目：186。

共同 gain 数量明显高于共同 loss，说明两种短输出条件有相当一部分共同改善题目。但 186 个 S1/S3 不一致题目也表明二者不能简单合并为同一个条件，仍需分别研究。

## 4. 题目属性分布

翻转主要出现在四类任务：Count、Depth、Distance、Relation。其中 S1 gain 中 Distance 117、Depth 83；S3 gain 中 Distance 91、Depth 74。由于不同任务的总体样本量不同，本节只作描述性报告，不把数量最多直接解释为任务特异性效果。

S1 和 S3 的 gain/loss 均覆盖 2D 与 3D 数据：2D 主要来自 ADE20K、COCO，3D 主要来自 Omni3D。后续需要使用各任务的全体分母计算翻转率，而不能只比较翻转数量。

## 5. 输出 token 与翻转方向

### 5.1 S1

- gain 题目中，S1 相对 S0 的平均 completion token 变化为 `-77.4`，中位数为 `-60`；
- loss 题目中，S1 相对 S0 的平均变化为 `-77.1`，中位数为 `-69`；
- gain 与 loss 的 token 差异检验 `p=0.6492`。

S1 的 gain 和 loss 都伴随相近程度的输出压缩，因此不能把 S1 的翻转方向简单归因于“压缩更多”。更需要检查原始回答内容和题目视觉难度。

### 5.2 S3

- gain 题目中，S3 相对 S0 的平均 completion token 变化为 `-85.5`，中位数为 `-66`；
- loss 题目中，S3 相对 S0 的平均变化为 `-57.3`，中位数为 `-39`；
- gain 与 loss 的 token 差异检验 `p=0.0062`。

S3 的 gain 题目平均压缩幅度大于 loss 题目，说明 S3 的正确性翻转与输出长度变化之间存在更明显的关联。但这仍不是因果证据，可能反映题目难度、原始回答风格或格式行为差异。

## 8. 阶段性结论

S1、S3 相对 S0 都产生了大量正向翻转，且共同 gain 明显多于共同 loss，说明短输出条件的总体准确率优势可以具体落到一批题目级修正上，而不是只表现为总体均值变化。

同时，S1/S3 存在 186 个正确性不一致题目，且两种条件均有独立 loss。因此，后续研究重点不应是继续证明“短输出总体更好”，而应分析：

1. 哪类题目容易被短输出条件修正；
2. 哪类题目容易因压缩或格式约束而损失；
3. S1 的简洁回答和 S3 的单字符要求为何在不一致题目上表现不同；
4. gain/loss 是否由题目难度、任务类型或原始回答结构驱动。

本结果是题目级关联分析，不足以证明 system prompt 的内部作用机制。
