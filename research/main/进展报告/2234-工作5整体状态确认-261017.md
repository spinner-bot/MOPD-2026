## 4. 诊断分析（后续补充）

v4 报告完成了"各条件是多少、检验显著吗"，但未诊断三条评分来源是否在测量同一事物。补充分析已完成，结论如下：

| 发现 | 内容 |
|---|---|
| 嵌套结构 | **官方 ⊂ 判定 ⊂ 抽取**；官方判对的记录判定必然也判对（仅左对 = 0），官方在结构上只可能少计 |
| 精确分解 | `Δ官方 + Δ丢弃 = Δ判定` 在六评测集逐条成立；官方增益全部来自找回被格式规则丢弃的正确结果 |
| 异质性 | 官方效应 **I² = 95.3%**（Q = 105.4, df = 5），不可合并报告；判定 58.9%、抽取 46.2% 但方向一致为负 |
| 机制 | 非二元判官输出是**难度信号**（与正确率 r = −0.917），非长度信号（r = −0.155） |
| 类别差异 | 格式惩罚从 0.9 pp 到 59.1 pp，由类别主导 |
| 结构性故障 | **zoombench 官方准确率恒为 0**（845/845 判官输出非二元），该评测集官方分数应作废 |

**对"提示强度提升准确率"的判定**：不稳健。官方口径 +10.68 pp，另两条独立口径 −2.56 pp 与 −0.97 pp，方向相反。
