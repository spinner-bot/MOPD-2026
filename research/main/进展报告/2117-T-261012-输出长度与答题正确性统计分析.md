## 2. 对当前观察的整合

### 2.1 严格长度/格式约束尚未稳定生效

五个条件的严格格式遵从率均为 0%。因此，当前数据支持的表述是：现有 system prompt 能在一定程度上改变可见输出长度，但没有让模型稳定执行严格的单字符或固定格式要求。由于本轮没有 tokenizer 级 token 统计，不能把该结果直接表述为真实 token 限制能力。

### 2.2 输出长度与准确率的关系

五组中，输出字符数与答题正确性之间的 Pearson 和 Spearman 相关均为负：

| 条件 | Pearson r | Spearman ρ |
|---|---:|---:|
| S0 | -0.131 | -0.103 |
| SC | -0.091 | -0.081 |
| S1 | -0.161 | -0.164 |
| S2 | -0.074 | -0.124 |
| S3 | -0.140 | -0.301 |

这支持“较短输出与较高准确率同时出现”的观察，但相关强度总体较弱，且不能单独建立因果关系。答对样本的平均输出字符数在五个条件中均低于答错样本：

| 条件 | 答对平均字符数 | 答错平均字符数 |
|---|---:|---:|
| S0 | 423.6 | 557.8 |
| SC | 432.2 | 532.7 |
| S1 | 224.4 | 335.8 |
| S2 | 374.1 | 444.2 |
| S3 | 199.6 | 330.9 |

这说明输出长度差异不仅存在于五组总体均值之间，也存在于同一条件内部的答对/答错样本之间。后续应将题目难度、任务类型、图像复杂度等潜在混杂因素纳入分析，不能把长度差异直接解释为准确率提升机制。

### 2.3 S1、S3 与 S2 的比较

配对比较显示：

- S1 相对 S2 的准确率差为 +13.75 个百分点；
- S3 相对 S2 的准确率差为 +11.15 个百分点；
- S1 相对 S3 的准确率差为 +2.60 个百分点。

S1 与 S2、S3 与 S2 的配对差异均显著。S1、S3 均优于 S2 的数据事实成立；关于其原因，目前只能提出待验证解释：S2 的“输出选项字母”约束可能不足以稳定压缩输出，而 S1 的简洁回答约束和 S3 的单字符约束形成了不同的输出行为。该解释不作为本轮已验证机制。

### 2.4 S0 与 SC

S0 与 SC 的准确率分别为 61.60% 和 61.85%，差异为 +0.25 个百分点，McNemar 检验 `p=0.7611`。两者平均输出字符数分别为 475.2 和 470.5，中位数分别为 346.5 和 339.0。

因此，本轮可以认为内容中性的 system prompt 没有带来具有实际意义的准确率或输出长度变化。不能据此说它没有改变输入 token 数，因为 system message 本身已经改变了输入结构；能够支持的结论是其未造成明显的结果层面变化。

### 2.5 输出长度的右偏分布

五组平均字符数均高于中位数，偏度均为正：

| 条件 | 平均字符数 | 中位数 | 偏度 |
|---|---:|---:|---:|
| S0 | 475.2 | 346.5 | 6.80 |
| SC | 470.5 | 339.0 | 7.64 |
| S1 | 253.1 | 220.0 | 15.81 |
| S2 | 401.8 | 307.0 | 8.37 |
| S3 | 236.8 | 187.0 | 13.90 |

数据支持输出长度存在明显右尾，少数超长输出显著抬高平均值。长输出样本值得单独研究，但需要进一步区分：题目难度、视觉任务类型、重复或无关解释、格式约束失败，以及模型对困难样本的异常响应。

## 4. 当前结论边界

本轮结果支持以下描述：system prompt 能改变输出行为和输出长度分布，但严格格式遵从尚未实现；S1、S3 在本次配对样本上显著优于 S2；输出字符数与正确性存在弱负相关；输出长度分布具有明显右偏特征。

本轮结果不支持以下强结论：较短输出必然导致更高准确率；system prompt 已实现真实 token 上限控制；S1/S3 的准确率优势必然由输出长度变化造成；词法推理标记率可以证明模型存在可验证的内部推理过程。
