## 1. 实现结果

提交 `a4f967f` 完成主体实现：

- finalizer 对每一条基础样本分别计算 T-Q/T-QA token 目标，并独立构造 Generic-Q/Generic-QA；
- `dual_control=True` 从 corpus-median 门槛改为每条 matched pair 相对误差均 ≤10%；
- base manifest 每行保存算法 ID、中性词库 SHA-256、tokenizer 路径与 artifact SHA-256、两个 pair 的 token 数/误差/pass；
- `validate_locked_manifest` 拒绝缺失、非法或内部算术不一致的逐题 provenance；
- 历史 `dual_control=False` 继续使用 corpus median，G-PC0 可复现路径不变；
- 新增回归测试证明“总体中位数通过但一条严重失配”会被拒绝，并证明 generic 只依赖 token 目标而不依赖 guide 语义。

提交 `730f53a` 补强 rotation 审计：自然 rotation manifest 中同一基础样本的四个标签视图只计一次长度检查；若四份复制的 context 长度不一致则 fail-closed。这样 preflight 的 `sample_checks` 数等于基础 N，而不是 4N。

## 3. 输出合同

自然 base manifest 的每条记录新增 `generic_length_control`：

- `algorithm=neutral-prefix-nearest-per-sample-v1`；
- `neutral_word_bank_sha256`；
- `tokenizer_source` 与 `tokenizer_artifact_sha256`；
- `tolerance=0.10`；
- `T_Q_vs_T_generic_Q` 与 `T_QA_vs_T_generic_QA` 的 token 数、相对误差、sample ID 和 pass。

运行时仍重新用实际 processor tokenizer 计算长度，不依赖 manifest 自报值决定通过。manifest provenance 用于审计生成过程，运行 preflight 用于阻止环境或文本变化。
