# 2122-T-261013-八状态翻转与任务分母分析

## 1. 本次分析的范围

承接 2120 的分析计划与 2121 的初版结果，本次把同一题在 S0、S1、S3 下的正确性写成三位状态码；1 为正确，0 为错误。八种状态互斥，合计 2000 题。SC、S2 不进入统计。

成品报告采用 2 号工作成品报告的表达标准：图表与对应解释相邻；全文中英双语；以分母明确的统计和研究判断为主；案例折叠展示完整原始回答。题目级明细留在工作站派生文件中，不在成品 HTML 中排列数百行样本名。

## 3. 逻辑合并与条件分母

S0 错题共 768 题，其中至少一种提示修正 346 题（45.1%）；两种提示共同修正 214 题（27.9%）。S0 对题共 1232 题，其中至少一种提示造成损失 80 题（6.5%）；两种提示共同损失 26 题（2.1%）。S1/S3 正确性不一致的题目共 186 题，占全部样本 9.3%。

“至少一种提示修正”的 346 题是两个条件的并集，表示可恢复题目的覆盖范围；它不是可部署系统的准确率，因为事先不知道应针对哪一道题选择哪一个提示。

单条件净翻转仍分别为：S1 gain 298、loss 45，净增 253 题；S3 gain 262、loss 61，净增 201 题。

## 4. 任务构成与任务自身概率

初版只列翻转数，容易把“任务样本本来就多”和“该任务更易翻转”混为一谈。本次分别计算：

1. 翻转组内部任务构成：分母为 S1 gain、S1 loss、S3 gain 或 S3 loss 的组内样本数；
2. 任务内部修正率：分母为该任务的 S0 错题数；
3. 任务内部损失率：分母为该任务的 S0 对题数。

以 S1/S3 至少一种条件翻转的并集计算：

| Task | 该任务总数 | S0 错题中至少一组修正 | S0 对题中至少一组损失 |
|---|---:|---:|---:|
| Count | 424 | 21/306（6.9%） | 11/118（9.3%） |
| Depth | 515 | 90/119（75.6%） | 19/396（4.8%） |
| Distance | 516 | 138/224（61.6%） | 42/292（14.4%） |
| Relation | 545 | 97/119（81.5%） | 8/426（1.9%） |

最大信号是 Count 的 S0 错题在 S1/S3 下很少被修正，而 Relation、Depth、Distance 的可修正比例较高；Distance 同时有最高的并集损失率。任务与图像来源、2D/3D 划分并非独立分配，所以这里不能识别独立的任务因果效应。这些数字是后续人工审阅的优先级线索。

## 5. 输出长度与题目级证据

使用正式 vLLM 的 completion token 计数，以八状态分别比较 S0、S1、S3 的中位长度。共同修正 011 的输出 token 中位数为 S0 103.5、S1 54、S3 42；共同损失 100 则为 S0 133.5、S1 64.5、S3 63.5。两类题目都出现明显长度压缩，压缩本身不能决定正确性翻转方向。

成品报告保留 12 个折叠案例：六种发生翻转的状态各选一个大幅缩短的样本和一个接近该状态典型长度变化的样本。每个案例显示临时编号、状态、任务、题目与选项、标准答案、三组对错、三组 token 数、长度变化以及三组完整原始输出。原始 `sample_id` 降为灰色小字，只用于回溯。案例清单保存在 `derived/run-60011513/case_manifest.json`。

## 7. 结论边界与下一步

本报告可以描述“哪些题目在何种提示下被修正或损失”及其任务组成、任务内部概率和长度关联；不能从中证明提示如何改变模型内部推理，也不能把两个条件的并集收益当作单一可部署策略的收益。

下一步最有价值的是按 011、100、001、010、101、110 六类分别人工审阅原图与原始输出，制定可观察的错误模式，然后在独立样本上检验模式是否成立。
