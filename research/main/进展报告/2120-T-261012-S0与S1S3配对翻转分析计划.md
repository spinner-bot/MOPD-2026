# 2120-T-261012-S0与S1S3配对翻转分析计划

## 1. 分析目的

本报告规定下一阶段的题目级配对翻转分析。此前分析以五组总体结果为主；本阶段改为逐题比较 S0、S1、S3，识别哪些题目在短输出条件下被修正，哪些题目反而被损失，从而分析准确率差异背后的具体题目结构和输出行为。

本阶段只分析 S0、S1、S3：

- S0：基线条件；
- S1：简洁回答条件；
- S3：单字符输出条件。

SC 已完成中性 system prompt 对照作用，不再进入本阶段分析；S2 整体效果较差，也不进入本阶段分析。SC、S2 不参与翻转统计、图表、题目筛选或阶段性结论。

## 2. 数据范围与固定口径

- 数据来源：正式作业 `60011513`；
- 样本：冻结的 2000 个 `sample_id`；
- 配对单位：`sample_id`；
- 条件：S0、S1、S3；
- 正确性字段：既有 `per_sample.csv` 中的 `correct`；
- 输出长度：优先使用正式 vLLM `usage.completion_tokens`，同时保留字符数作为可见文本指标；
- 原始证据：五组 raw JSONL 中的原始回答，本阶段实际读取 S0、S1、S3 三组；
- 题目属性：`split`、`task`、`source`、gold answer、问题文本和选项。

不重新推断 gold answer，不重新解析正确性，不修改既有派生结果。若发现字段对齐异常，先停止统计并记录门禁失败。

## 3. 翻转类别定义

对 S1、S3 分别相对于 S0 定义四类：

1. `gain`：S0 错误，目标条件正确；
2. `loss`：S0 正确，目标条件错误；
3. `stable_correct`：S0 和目标条件均正确；
4. `stable_wrong`：S0 和目标条件均错误。

重点分析前两类。对于 S1 和 S3 还要生成交叉分类：

- 两者共同 gain：S0 错误，S1 和 S3 均正确；
- 两者共同 loss：S0 正确，S1 和 S3 均错误；
- S1-only gain/loss：只有 S1 相对 S0 翻转；
- S3-only gain/loss：只有 S3 相对 S0 翻转；
- disagreement：S1 与 S3 对同一题目方向相反。

交叉分类只用于解释两种短输出条件的共同点与差异，不把 S1/S3 合并为一个虚构条件。

## 4. 题目级分析内容

### 4.1 题目属性分布

分别统计 gain、loss、stable_correct、stable_wrong 在以下维度的分布：

- `task`；
- `split`；
- `source`；
- 选项数量；
- gold answer；
- 题目文本长度。

比较 S1 与 S3 的 gain/loss 是否集中在不同任务或数据来源。任务分布只作描述性分析，不在未预注册的细分组中反复寻找显著性。

### 4.2 输出长度与翻转方向

对每个目标条件分别比较：

- gain 题目中 S0 与目标条件的 completion token 数；
- loss 题目中 S0 与目标条件的 completion token 数；
- gain 与 loss 的长度差分布；
- 字符数与 token 数是否给出一致方向。

该分析用于观察翻转伴随的输出行为变化，不把输出变短解释为翻转原因。

### 4.3 原始回答行为

对全部 gain/loss 题目保留：

- 原问题与选项；
- gold answer；
- S0 原始输出、解析答案和正确性；
- S1 原始输出、解析答案和正确性；
- S3 原始输出、解析答案和正确性；
- 三组输出字符数、completion token 数和格式指标。

重点审查以下可观察行为：

- S0 是否出现冗长但错误的视觉判断；
- S1/S3 是否通过减少无关文本保留了正确选项；
- S1/S3 是否因过度压缩而丢失必要判断；
- 输出是否出现选项字母误读、答案自相矛盾、重复或达到 2048 上限；
- S1 与 S3 是否对同一题目表现出不同的取舍。

原始文本审查只描述可见行为，不声称能直接观察模型内部推理过程。

## 5. 统计方法

### 5.1 主要统计

报告每个条件的：

- gain 数量和比例；
- loss 数量和比例；
- 净翻转数 `gain-loss`；
- gain/loss 的 95% 二项区间；
- 相对于 S0 的配对准确率差。

### 5.2 题目属性分析

任务类型、数据来源和 2D/3D split 的分布使用计数、比例和标准化残差或效应量进行描述。分层样本量过小时只展示数量，不进行不稳定的显著性检验。

### 5.3 长度与翻转方向

对 gain/loss 的长度差使用中位数、IQR、均值和分布图；必要时使用 Mann–Whitney U 作为补充检验。所有结果明确标注为关联分析。

### 5.4 多重比较边界

S1 和 S3 是预先指定的两个目标条件。任务类型、来源和 split 的细分结果属于探索性分析，不把大量探索性 p 值包装为新的主要结论。

## 8. 结论边界

本阶段可以回答“哪些题目发生了正确性翻转，以及翻转与题目属性、输出行为有什么关联”，不能仅凭翻转统计证明某种 system prompt 的内部机制，也不能把 gain 题目直接解释为模型获得了新的视觉能力。

如果 S1 和 S3 的 gain 题目高度重合，说明两种约束可能存在共同的行为效应；如果差异明显，则需要分别解释简洁回答与单字符输出的作用。该判断必须以实际逐题结果为依据。
