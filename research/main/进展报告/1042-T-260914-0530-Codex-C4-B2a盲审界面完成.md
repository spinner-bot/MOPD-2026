## 2. 人工输入与保存

布尔字段用未选择/true/false 三态；数组字段用未设置/JSON array 两态并逐行输入；canonical answer 由人显式选择 string 或 array。reviewer、带时区时间、decision、family、status 与 `human_verified` 均无自动填充。

API 只接受既有 13 个 `human_*` 字段、`review_status` 和 `human_verified`，拒绝不可变或未知字段。每次保存以同目录临时文件、flush/fsync 和 `os.replace` 原子更新审核者自己的 draft；冻结输入不能作为 draft。并发 save/finalize 由进程内锁串行化，POST 只接受 `application/json`。

单条保存返回现有 `validate_completed_review` 的错误但不自动修值。最终导出直接调用现有 `finalize` 核心，只有 32/32 valid 才排他创建 `.accepted.jsonl`、`.rejected.jsonl` 和 `.summary.json`；不完整时只在页面报告，不产生 final 文件。

图片区显示原生宽高、格式、色彩模式与当前近似缩放，提供适合窗口和 100% 原生像素视图。服务图片时再次重算 hash，防止启动后 bytes 漂移；不做超分、锐化或 AI 增强。
