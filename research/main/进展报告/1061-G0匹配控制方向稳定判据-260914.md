# 1061-G0 匹配控制方向稳定判据

**性质**：重点文档；1017 v0.5 的 matched generic 结构门槛精确定义

**创建时间**：2026-09-14 11:36（UTC+8）

**作者**：Codex (CINECA Leonardo)

**触发原因**：逐条对照 1017 §8.3 与决定器时发现，协议要求 T-Q/T-QA 相对各自 generic 达到阈值“且方向稳定”，代码却只检查 accuracy 或 mean correct-log-prob 的点估计。少数极端 log-prob 样本可能满足 0.10 nat 均值而 paired bootstrap CI 包含 0，仍被错误判为 Go。自然性能结果仍为零，因此现在必须消除文字与实现歧义。

---

## 1. 冻结定义

对每个 `T∈{T-Q,T-QA}` 及其 matched generic，结构化内容优势满足以下任一分支：

### Accuracy 分支

1. `ΔSemanticAcc(T−Generic) ≥ 0.04`；
2. paired 错→对数严格大于对→错数。

第二项把“方向稳定”落实为正的净配对翻转。它不另设显著性门槛；G0 的两个主要假设仍是 T-Q−S 与 T-QA−S，并继续只对这两项作 Holm 校正。

### Correct-log-prob 分支

1. `mean ΔSemanticCorrectLP(T−Generic) ≥ 0.10 nat`；
2. 按 `source_image_id` 的 paired cluster bootstrap 95% CI 下界 `>0`。

只满足均值而 CI 包含 0 的情况进入 Revise，不能 Go。accuracy 与 log-prob 分支仍是 OR；但每个分支内部的效应量与稳定性要求是 AND。

## 2. 输出与统计边界

决定 JSON 必须为每个 T 条件同时报告：

- `accuracy_delta_vs_generic`；
- `mcnemar_vs_generic` 的 gains/regressions/discordant/raw p；
- `correct_log_prob_vs_generic` 的 mean/95% CI/bootstrap seed；
- 哪个分支满足及最终 `structured_advantage`。

generic 对照仍是结构性排除门槛，不增加 Holm 检验族，不替代相对 S 的主要效应、显著性和 0.15 nat 要求。Stop 条件继续只按 T-QA 相对 S 裁决；若 generic 异常强或结构化优势不稳定，则归入 Revise。

## 3. 结果盲实现验收

新增回归案例：T-QA 相对 S 满足强 Go 的全部主效应要求、相对 Generic-QA accuracy 为 0，但由单个极端样本使 mean log-prob 差超过 0.10 nat；若 paired CI 下界不大于 0，决定必须为 Revise。正常稳定的 T-Q/T-QA Go、null Stop、污染集 Revise 和自然 label-rotation 端到端测试不得回归。
