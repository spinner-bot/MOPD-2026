# 确认性主张层级与多重性控制契约

**性质**：重点文档；在自然 G0/G1 和任何新训练结果产生前，冻结从“G 有效”到“模态分工、互补和学生迁移”的主张层级，防止多条件、多家族、多指标和多尺度形成结果后选择。

## 1. G0 只选择一个文本分支

G0 继续严格执行 1017 的两项主要比较 `T-Q-S` 与 `T-QA-S`、Holm 校正和 matched-control 稳定门。它只产生以下路线决定：

- `T-Q` 入选；
- `T-QA` 入选；
- 两者均保留但在 G1 前指定一个 confirmatory primary、另一个 secondary；
- Revise 或 Stop。

不得在 G1 输出可见后再把 T-Q/T-QA 中较好者改称主方法。若 G0 规则出现并列，优先按 1017 已冻结的可部署性/guide 定义裁决；仍无法唯一决定时，须在 G1 manifest 冻结前用不含 G1 图簇的 construction/dev 数据解决。

## 2. G1 的递进主张

G1 使用 1068 已规定的 sample 内 correct-answer log-prob 差和 image-cluster 聚类不确定性作为机制层主要连续测量；四轮换 semantic accuracy、paired flips 和 absolute performance 必须同时报告，但不与主连续测量竞争“哪个显著”。

确认性主张按下列顺序开放：

### C1：真实 G 内容产生 teacher advantage

在预注册的 R/PR 分析总体上检验入选 `T-real` 相对逐题 matched `T-generic` 的配对优势。这是项目核心创新的第一确认性门。R/PR 的合并权重、是否分别要求 R 与 PR 同向及最小实用效应必须在 G1 输出可见前冻结。

### C2：G 对 R 瓶颈具有特异性

只有 C1 通过，才确认性检验：

\[
[T_{real}-T_{generic}]_R-[T_{real}-T_{generic}]_P>0.
\]

若 C1 通过但 C2 未通过，允许声称 G 有用，不允许声称 G 专门改善 reasoning-bottleneck 任务。

### C3：V/T 双向任务分工

只有 C2 通过，且 1078 的视觉内容特异对比

\[
[V_{real}-V_{sham}]_P-[V_{real}-V_{sham}]_R>0
\]

也达到其结果前冻结门，才支持“当前结构化 T 更帮助 R，相关视觉 crop 更帮助 P”的双向 specialization。两项构成交并条件；只通过其中一项不能用另一项的显著性补偿。

### C4：PR 上的 V/T 内容互补

只有 C3 通过，且完整运行 1078 的 `Vreal/Vsham × Treal/Tgeneric` 四格，才确认性检验 PR 的 `Interaction_specific>0`。仅有 real V/T 2×2 时报告 `Interaction_raw`，该结果为次级机制描述，不开启内容协同主张。

C1→C4 采用固定顺序 gatekeeping：每级单侧家族 `α=0.05`，前级未通过时后级 p 值和区间仍完整报告，但标为 secondary/exploratory，不再形成同一确认链的显著性结论。精确检验模型、cluster bootstrap/层级模型和最小效应在 G0 方差可见后、G1 输出可见前冻结；不得依据 G1 点估计切换方法。

## 3. 同一层内的多重性

- 一个确认层只允许一个 primary T 分支、一个 primary metric 和一个预声明分析总体；
- T-Q/T-QA 的非入选分支、raw accuracy、correct-LP 之外的 margin/entropy、第二个 sham、来源、深度和视觉难度切片均为 secondary/sensitivity；
- 若同一确认层预先保留多个等地位检验，必须在结果前指定 Holm/closed testing 等 family-wise error 控制；不能以“方向一致”替代校正；
- P/R/PR 的模型交互为主要 estimand 时，单个家族的显著/不显著切片只用于解释，不替代交互；
- 任何 data-source subgroup 只有在各来源采用同一协议且事前列为主层时才能形成确认结论，否则只报告异质性。

多项 absolute performance、效果量和 95% CI 始终全部展示。层级控制限制的是确认性措辞，不是隐藏失败结果。

1082 的 leave-one-out/partial/shuffle 属于 locked 后机制条件，不构成新的数据筛选器。某些 guides 的 model contribution 为零或负时仍计入 C1–C4 预声明分母；不能只在 positive-dependency 子集上确认主张。

## 4. Stage1 学生迁移主张

训练后的主张另开一条预先排序的链：

### S1：G 结构特异 transfer

在一次性冻结的 `Stage1-internal-test` 上，以四轮换 semantic accuracy 的

\[
Transfer_{specific}=Perf(M_T)-Perf(M_{Generic})
\]

作为学生主效果；correct-answer log-prob、paired flips 和 `M_T-M_00` 为必报支持指标。最小实用效应、检验和 checkpoint 规则在任何 formal internal-test 输出可见前冻结。

### S2：任务家族上的迁移特异性

只有 S1 通过，才把 `Transfer_specific(R)-Transfer_specific(P)` 作为确认性 family interaction。若训练数据或 internal test 没有通过 1037/1068 的同图与瓶颈审计，该层自动不可用。

### S3：视觉内容 transfer 与 V/T 训练交互

只有对应训练条件满足 1078 的同 seed V-sham/Generic 控制，才开放 `M_Vreal-M_Vsham` 或训练后 `Interaction_specific` 主张。否则只报告 total V transfer/raw interaction。

### S4：尺度与外部泛化

1077 的 4B pilot-val 只决定资源投入，不进入 formal S1–S3 显著性主链。预注册为论文主尺度的 9B formal seeds 承担主结论；4B formal、外部 benchmark 和 thinking stress 作为独立复现/泛化证据。若 9B bridge 未过而正式训练停止，4B 可以成为主尺度，但必须在任何 formal internal-test 结果打开前重写并冻结主尺度声明。

外部 benchmark 使用各自官方主指标，不能跨 benchmark 挑一个最有利结果声称“普遍泛化”。应预声明一个 primary external benchmark 或用跨 benchmark 的固定汇总规则；其余为 secondary。

模型家族泛化另受 1081 约束：只有 Qwen3.5 规模复现时，S4 最多支持同家族尺度证据；声称一般 MLLM 机制至少需要一个与 G generator 不同家族的冻结 inference-only 复核。

## 5. seed、item 与重复单位

正式训练 seed 是训练随机性的重复单位，image/near-duplicate cluster 是测试内容的重复单位。不能把多个 option rotations、多个 sham、同图 P/R/PR 或同一 checkpoint 的多个 benchmark item 当作独立训练重复。

正式模型比较使用共同 seed 集并报告每 seed 绝对性能、seed 间分布和 seed × cluster 区间。若某 seed 因预声明的工程失败规则被排除，所有相应条件必须按同一规则处理；不得只重跑或删除不利于主方法的 seed。

## 6. 结果表与论文措辞

每一级结果表必须含：所有条件绝对性能、主估计量、效果量与区间、未经校正和校正后的 p 值（若适用）、有效 cluster/item/seed 数、排除数及原因。表内给每行标记 `confirmatory-primary`、`confirmatory-gated`、`secondary` 或 `exploratory`。

论文标题、摘要和结论能使用的最高措辞由通过的最高层决定：

| 最高通过层 | 可支持的核心措辞 |
|---|---|
| C1 | 结构化文本内容为冻结 teacher 提供优势 |
| C2 | 该优势对已验证 reasoning bottleneck 更强 |
| C3 | 当前 T 与 V 内容在 R/P 上呈双向分工 |
| C4 | 两种相关 privilege 内容在 PR 上有受控互补 |
| S1 | G 的结构特异 teacher advantage 被迁移到无 privilege 学生 |
| S2/S3 | 迁移后仍保留任务特异性或受控 V/T 交互 |
| S4 | 结论在预注册主尺度/外部数据上复现或泛化 |

不通过某层不是隐藏后续图表的理由；它只限制确认性语言。
