## 2. 冻结门禁

每个会加载本地 Qwen3.5-4B/9B 的现行 Slurm 作业，必须在首次模型加载前仅由主任务执行一次 asset gate：

1. 校验 revisions TSV 与 model-files 清单自身哈希等于上述冻结值；
2. 要求 repo、完整 revision 和当前模型目录 basename 与 revisions TSV 唯一记录一致；
3. 从旧清单按 basename 重定位到当前目录，要求预期顶层文件集合与当前顶层普通文件集合精确一致；
4. 流式计算每个预期文件 SHA-256，任一缺失、额外或不一致均 fail-closed；
5. 以排他写入生成 `summaries/model-asset-gate.json`，记录当前解析路径、清单哈希、逐文件结果、总字节数和 `status=passed`；
6. 通过后才可进入 `srun`。run manifest 和 raw 中的 model revision 继续保留，但不得再单独作为模型身份凭据。

为避免 4 个 rank 重复读取 9–19 GiB 权重，asset gate 在 `srun` 外执行一次。该门只增加每个作业一次顺序磁盘读取，不改变推理输入、模型配置或指标。

## 3. 适用入口与验收

首轮统一覆盖六个现行入口：自然 G0、G-PC0、G-PC0 label rotation、image affordance screening、teacher-gap screening 和 teacher-gap construction。最低回归：正确 4B/9B 小型模拟 inventory 通过；错误 revision、manifest 自身哈希、缺失/额外文件及字节改变均拒绝；输出已存在时拒绝覆盖；六个 sbatch 通过 `bash -n`。

该实现不追溯改写既有运行档案。G-PC0 已完成结果继续按其当时的 revision、路径与归档证据解释；自然 G0 尚无结果，因此必须从首次运行起采用新门。
