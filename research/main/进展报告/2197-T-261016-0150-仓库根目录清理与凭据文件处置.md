# 2197-T：仓库根目录清理与凭据文件处置

**创建时间**：2026-10-16 01:50（UTC+8）  
**创建作者**：Claude Code (local)  
**触发原因**：项目所有者在仓库根目录发现数个来路不明的文件（含 `.ssh` 相关命名与疑似作业日志），要求全仓扫描同类残留并清理。扫描过程中另发现两处已被 git 跟踪的 API 密钥文件，一并处置。

## 1. 扫描范围与判据

对全仓库同时扫描**已跟踪文件**（`git ls-files`）与**工作区未跟踪文件**（`find`），判据分三类：

1. **畸形路径产物**：Windows 路径（如 `C:\Users\...`）中的反斜杠/冒号被 shell 吞掉后形成的文件名；
2. **误落位置的运行日志**：Slurm `*.out` / `*.err` 出现在仓库根目录等非归档位置；
3. **凭据**：SSH 私钥标记、常见 API 密钥格式（`sk-` / `hf_` / `AKIA` / `ghp_` / `github_pat_` / `glpat-`）、以及明文账号口令。

**关键前提**：`research/main/outputs/runs/**/logs/*.{out,err}` 与 `research/main/outputs/slurm/**` 下的作业日志**不是垃圾**——项目报告与文档管理规范要求保留运行证据，本轮一律未动。同理，`meeting/feishu/**` 下标题含全角冒号的文件（如「智能纪要：…」）属正常中文命名，为扫描误报。

## 2. 发现与处置

### 2.1 畸形路径产物（已删除）

- `C：Usershan.sshleonardo-cert.pub`（根目录）

文件名中的冒号是**全角 `：`（U+FF1A）**，系 `ssh`/`step` 相关命令中 `C:\Users\han\.ssh\leonardo-cert.pub` 被 shell 吞掉分隔符后生成。内容经核验为**SSH 公钥证书**（`ecdsa-sha2-nistp256-cert-v01@openssh.com`，principal `rqian000`），**不是私钥**。全仓库私钥标记扫描（`BEGIN ... PRIVATE KEY`）结果为空，无凭据外泄。

处置：`git rm` 删除。

### 2.2 根目录误落的作业日志（已归位，未删除）

- `mopd-vopd-audit-59907483.{out,err}`
- `mopd-vopd-audit-59918167.{out,err}`
- `mopd-vopd-audit-59944935.{out,err}`

系 1 号工作（Vision-OPD 输出审计）三个作业的 Slurm 标准输出/错误，内容含失败 traceback（如 `59907483` 的 `json.load` 异常）。核对后确认与归档目录中的 `vllm-server.log` 等**并非同一文件**，属独立的作业日志，不能被归档内容替代。

处置：**移动**至 `research/main/Phase2/1.vision_opd_output_audit/runs/<job>-hrbench4k/logs/`，保留失败证据而非删除。git 将其识别为重命名。

### 2.3 API 密钥（已删除；吊销待所有者处理）

`archive/previous-research/idea2/idea2/一期研究/API-key/` 下两个被跟踪文件：

| 文件 | 内容 | 所有者评估 |
|---|---|---|
| `deepseek按量.txt` | DeepSeek API key（`sk-601b29…`） | **仍在用**，将自行吊销/重建 |
| `百炼token-plan.txt` | 阿里云百炼签名 token（`sk-sp-H.DIDREE…`） | 已过期，无需处理 |

**漏网原因**：`.gitignore` 中已有 `research/main/idea2/一期研究/API-key/` 规则，但归档副本位于 `archive/previous-research/…` 下，**路径不匹配**，规则未生效。这正是"凭据目录规则写死单一路径"的典型失效方式。

处置：两个文件从工作区与版本库**彻底删除**。

> **边界声明**：删除只能清除工作区与后续版本，**密钥文本仍存在于 git 历史中**。彻底处置只能靠服务端吊销/重建。百炼 token 已过期，实际风险归零；DeepSeek 密钥的吊销由所有者在控制台完成，不在本轮范围内。

### 2.4 SSH 口令文件（本轮未改动，记录在案）
