# Guide 依赖性测量与效果筛选防火墙契约

**性质**：重点文档；在自然 G0/G1 和训练数据生产前，分离推理图的语义依赖与实验模型的利用效应，禁止按目标结果选择确认样本。

**创建时间**：2026-09-14 13:06（UTC+8）

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：正式方案 §12 把删除 guide 后的模型 log-prob 下降称为 Dependency Test，并写入“数据筛选”；旧 `data_schema.py` 又以 `guide_dependency_score` 数值门拒绝样本。现行 1035/1052 则禁止按 teacher gap 或条件效果筛题。若用同一实验模型的 `Contribution(g_i)` 决定 G0/G1/test 成员，最终 guide 有效性会成为筛选定义造成的循环证据。

---

## 1. 两类 dependency 不得共用字段

定义语义依赖：

\[
D_{sem}(g_i)=1
\]

当且仅当在固定 evidence/answer contract 下删除节点 `g_i` 会使后继中间结论或最终答案不再由剩余父节点推出。它由 DAG、反事实删除和人工/独立语义审核确定，不使用 S/T/Generic logits。

定义模型利用贡献：

\[
U_M(g_i)=\log P_M(A^*|I,G,Q)-\log P_M(A^*|I,G\setminus g_i,Q).
\]

`U_M` 是特定 checkpoint、prompt、tokenizer 和题目的实验结果。它可以为零或负，即使 `D_sem=1`；这说明模型没有利用语义必要节点或受其干扰，不说明审核必须改标签。

字段必须分别命名，例如：

- `semantic_dependency_verified`、`semantic_dependency_review`；
- `model_utilization_contribution`、`experimental_model_revision`。

禁止把 `U_M` 写回 `guide_dependency_score` 后再作为数据质量门。

## 2. 哪些信息可以决定数据准入

G0、G1、validation 和 internal-test 的准入只使用：

- 完整图上问题闭世界、唯一答案与视角有效；
- required evidence 的直接可见性与反事实必要性；
- reasoning DAG 的父子语义蕴含；
- 每个 guide 的 answerability、non-leakage、path relevance；
- `D_sem` 的盲审与仲裁；
- 图像/近重复身份、任务角色和确定性结构门。

任何 experimental model 的 accuracy、log-prob、margin、entropy、flip、`U_M`、teacher gap 或训练收益都不得决定这些集合的成员、P/R/PR 标签、depth、guide 数或样本权重。construction/dev 可以用模型输出来调 prompt，但修改后的配方必须进入新的未见图簇；不能把开发时高贡献的题搬进 locked 集。

## 3. G1 dependency 是全样本条件，不是过滤器

对 G1 冻结题一次性物化：

- Full ordered G；
- 每个 guide 的 leave-one-out；
- Shuffled-G；
- 按结果前规则定义的 Partial-G；
- 对应逐题 matched Generic。

全部条件对全部适用的 locked items 运行。若某题因链长不适用某类 ablation，原因在输出前由结构字段确定并计入分母；不得因 `U_M≤0` 删除该题或重写 guide。

主要 dependency 报告至少包括：每步 `U_M` 的均值/中位数/cluster CI、正/零/负比例、完整链相对 matched Generic 的优势、ordered−shuffled，以及 family/depth 交互。`min_i U_M(g_i)`、正贡献步数等摘要只能按预声明规则聚合，不能挑最好一步。

1080 的 C1–C4 主链不以“每步贡献都显著”为准入条件。Dependency ablation 是解释 C1 信号结构的次级/机制证据；若 C1 未过，局部正 contribution 仍只作探索结果。

## 4. 训练数据与 advantage filtering

Stage1 第一版主训练数据必须是通过 1076 的 `G_prod`，不能按该训练目标模型的单题 teacher gap 或 `U_M` 过滤。这样 `M_T-M_Generic` 回答可扩质量流程的平均 transfer，而不是“已知 teacher 喜欢的样本能否迁移”。

teacher-advantage filtering 只允许作为独立次级版本：

1. 在 training role 内计算，永不读取 validation/internal-test/external 效果；
2. 阈值、覆盖率报告和样本权重规则在该版本训练前冻结；
3. 保留未过滤主训练作为基线，并报告过滤前后 family/depth/source 分布；
4. 新版本使用独立 run ID/checkpoint，不能替换或重命名第一版主结果；
5. 若过滤依赖与 experimental student 同 checkpoint 的 teacher signal，论文明确其 model-specific curriculum 性质。

过滤版可能提升性能，但不能反向证明 G 在原总体普遍有效。

## 5. 代码和 manifest 门

后续 schema/finalizer 必须：

- 将旧 `dependency_score`/`guide_dependency_score` 标成 semantic-review-only legacy 字段或迁移到显式 `semantic_*` 字段；
- 拒绝在 construction/finalization quality gate 中读取 `teacher_gap_*`、`model_utilization_*` 或 evaluation 输出；
- effect 结果只写 analysis artifact，以 locked manifest SHA、condition schedule SHA、模型资产 SHA 和代码 commit 为外键；
- 任何 filtered training manifest 明示 `selection_uses_model_effect=true`、父级 unfiltered manifest 和阈值 hash；
- validation/internal-test manifest 必须为 `selection_uses_model_effect=false`。

现有 `evaluation/dependency_test.py` 可保留为结果后分析工具，但文档、返回值和调用方必须明确 `analysis_only`。它不能由 T03–T07 finalizer 调用来接收或拒绝样本。

## 6. 对正式方案旧文字的裁决

正式方案 §12 中“数据筛选中至少进行 leave-one-out”现改为：“locked 机制集上统一运行 leave-one-out 分析”。“Contribution≈0 则 guide 不是关键 reasoning node”改为：“该 experimental model 未体现该节点的正利用；语义关键性由独立 `D_sem` 决定”。

§76 的“删除关键 guide 会降低 teacher advantage”仍可作为高层机制证据，但只能在全体 locked 题上按预注册 estimand 检验，不能先删除没有下降的题再声称成立。§78 的 teacher-advantage filtering 降为独立次级训练版本。
