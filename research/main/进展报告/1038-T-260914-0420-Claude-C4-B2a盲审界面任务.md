界面是输入与校验工具，不是标注模型。不得调用 LLM/GPU，不得生成、建议、改写或默认填入任何人工判断。

## 4. 功能契约

1. 逐条显示无来源含义的 `review-item-NNNN`、进度、完整图片；可上一条/下一条或按该令牌跳转。真实 `calibration_record_id` 只留在服务端和 draft，不进入浏览器 API、保存请求或图片 URL。
1a. 同时显示原生宽高和当前缩放比例，提供适合窗口与 100% 原生像素查看；不得调用超分辨率、锐化、AI 增强或把放大插值后的细节当新证据。
2. 只允许编辑 13 个 `human_*` 字段，以及人工完成时显式设置 `review_status` 和 `human_verified`；其他字段只读且保存前逐项与原包比较。
3. boolean 使用明确的未选择/true/false 三态；初始必须未选择，不能默认 false。
4. decision、family 使用带空值的选择框；初始必须为空。
5. evidence、reasoning、counterfactual 和 difficult evidence 使用真正的字符串数组，不以逗号字符串代替；初始必须为空。
6. canonical answer 支持字符串或字符串数组，并让人工显式选择类型；不能自动猜测。
6a. R 的 difficult evidence 数组必须为空；PR 至少选择一项且只能选择 required evidence 中已有项目。界面可以通过选择控件保持一致，但不得替人工决定 R/PR 或困难节点。
7. reviewer 和带时区 ISO 8601 时间由人填写；不能自动写用户名或当前时间。
8. 保存草稿必须写到新路径，使用原子替换，不能覆盖冻结输入；界面重启后可继续载入自己的草稿。
9. 单条保存可显示现有 finalizer 的错误，但不得自动改值。最终导出必须对完整 32 条运行 finalizer；只有 `valid_signed_reviews=32` 才显示“第一阶段完成”。
10. 图片路径必须解析到当前 M3VQA images 根，且 bytes SHA-256 等于记录值；路径越界、缺失或哈希漂移均 fail-closed。
11. 服务默认且只能绑定 loopback；不得添加外网分享、遥测、账户登录或上传功能。

环境预检确认 fast Python 中 Pillow 可用，但 Gradio、Flask、FastAPI 均未安装。C4 使用 Python 标准库本地 HTTP 加 Pillow 完成最小界面；不得为 C4 下载新增框架依赖或启动外网服务。

## 5. 必测行为

测试至少覆盖：

- 冻结输入不被改写；
- 所有 human 字段初始为空且 UI/序列化不隐式填充；
- false 与“未选择”可区分；
- 数组字段保持 JSON array；
- immutable 字段修改被拒绝；
- machine/source-question firewall 字段或内容被拒绝；
- 图片路径越界、缺失与 SHA 不符被拒绝；
- draft 不能覆盖 frozen source；
- 未完成/未签名/类型错误记录不能最终导出；
- 32 条完整合法记录可调用现有 finalizer 得到 32 valid；
- 默认 bind host 为 `127.0.0.1`，无 share/public 模式。

测试必须使用临时小图片与合成 JSONL，不读取 32 张真实图片内容，不调用 GPU/LLM。
