## 一、评估结论：研究应从“完成流水线”转向“先验证核心信号”

项目当前最需要回答的并不是 T00–T08 能否完整运行，而是文本特权信息是否能在合适的视觉任务上形成足够大的 teacher advantage，并最终被学生吸收。T02 pilot 已经证明视觉结构预处理可以稳定运行，但它没有比较 S、T、V、VT 的答题表现，因此尚未验证文本引导有效，也没有验证 OPSD transfer。

把整项研究压缩后，只有两个连续问题：

1. **教师增强是否成立**：在同一冻结模型上，加入引导性问题序列 \(G\) 后，模型是否显著优于只看图和最终问题？
2. **能力转移是否成立**：如果 privileged teacher 已经更强，OPSD 能否把这部分优势转移给推理时不再接收 \(G\) 的 student？

对应地：

\[
Teacher\ Gap_T = Perf(I,G,Q)-Perf(I,Q)
\]

\[
Distillation\ Gain = Perf(Student_{after},I,Q)-Perf(Student_{before},I,Q)
\]

导师在研讨会中反复强调，第二步的上限受第一步约束：如果 teacher gap 只有很小的百分点提升，经过蒸馏后往往只剩更小的学生增益。其建议不是取消数据质量控制，而是改变投入顺序：先用一批人工确认的样本取得清楚的 teacher-gap 结果；有效后再扩建数据、补齐控制和进入训练；无效或过小时尽早修改 \(G\)、任务定义或数据来源。

这与会后形成的数据判断指向同一件事：Vision-OPD 的图像和问题都偏向感知瓶颈，天然有利于视觉 crop；若只在这类数据上验证文本特权，可能低估 \(G\) 的适用范围。M3VQA 提供了更可能支持关系推理的图片，但其原题常依赖 Wikipedia 等外部知识，不能直接作为本项目的 R 数据。接下来的关键不是在两个数据集之间二选一，而是依据图像可供性和具体问题的最小证据路径，构建无需外部知识的 P/R/PR 诊断样本，再先测 teacher gap。

本次评估据此形成一个明确的近期里程碑：

> 在一批对完整图像成立、无需外部知识、具有真实关系推理瓶颈并经人工确认的 R/PR 样本上，完成冻结模型的 S/T-Q/T-QA/V/VT 配对比较，获得第一张 teacher-gap 表，再决定是否扩大数据建设和启动 OPSD 训练。

## 二、统一后的科学主线：特权信息必须与任务瓶颈匹配

### 2.1 V 与 T 是两种信息条件

本项目中的 V 和 T 不应被机械地等同为“视觉能力”和“推理能力”。它们是训练期额外提供的两种信息：

| 条件 | 额外输入 | 主要缓解的瓶颈 | 可能的交叉作用 |
|---|---|---|---|
| V | 相关 crop 或附加局部图 | 目标定位、分辨率、细粒度观察 | 看清证据后也可能改善推理 |
| T | 引导问题或带中间答案的路径 | 证据搜索、实体跟踪、关系组织 | 引导注意后也可能改善感知 |
| VT | 视觉证据与文本路径同时提供 | 同时存在的感知与推理瓶颈 | 可能互补，也可能冲突 |

因此，“V 偏感知、T 偏推理”是需要用分层实验验证的统计趋势。项目不需要证明 T 在所有视觉问答上胜过 V；更有解释力的目标是确认 V、T 分别在什么瓶颈下有效，以及 VT 在真正需要两者的任务上是否互补。

### 2.2 图片有潜在倾向，具体任务由图片与问题共同决定

会后讨论提出了一个对数据建设很关键的假设：图片在提出问题之前，就已经具有不同程度的 P/R/PR **可供性**（affordance）。例如，小目标、遮挡和小文字提高 P 可供性；多实体、多区域关系和可组合事件提高 R 可供性；困难局部证据恰好位于一条全局关系链中时，图片才具有较强的 PR 可供性。

但图片倾向不等于样本标签。最终任务层仍由图片、问题及其最小证据路径共同实现：

\[
Image\ Affordance=A(I),\qquad
Task\ Family=F(I,Q,Minimal\ Evidence\ Path)
\]

| 最小证据路径 | 任务层 |
|---|---|
| 主要困难在看清、定位或识别局部证据 | P |
| 视觉证据可见，但必须完成不可省略的关系或多步整合 | R |
| 同一条必要路径同时依赖困难局部证据和全局关系证据 | PR |
| 感知与推理都很简单 | 非核心诊断题 |

真正的 PR 不是一张图同时存在小目标和复杂背景，而是同一道问题缺少局部证据或全局关系任一部分都无法唯一作答。这个定义把“数据适合某种方法”的直觉转化为可审核、可检验的机制假设：

\[
Gap_V\uparrow\; when\;P\text{-affordance}\uparrow
\]

\[
Gap_T\uparrow\; when\;R\text{-affordance}\uparrow
\]

\[
Interaction_{VT}\uparrow\; when\;PR\text{-affordance}\uparrow
\]

### 2.3 这解释了当前两个数据来源的互补与局限

当前统一候选池共有 19,366 条。这里的 P/R 只表示来源规则给出的预分流标签，还不是经过证据路径验证的正式任务标签：

| 来源 | 数量 | 当前预分流 | 已有信息与主要限制 |
|---|---:|---|---|
| Vision-OPD-6K | 6,241 | P | 有原图、teacher crop、训练图、bbox、四选项和答案；问题与选图偏局部感知，缺少 guide QA 与文本控制 |
| M3VQA | 12,033 | R | `question_hop>=2`；有图、实体、问答和外部 evidence，但 hop 常是知识检索深度，不等于视觉推理深度 |
| M3VQA | 1,092 | P | `question_hop=1`；仍需按图像证据和最小路径复核 |
| PR | 0 | — | 尚未形成正式候选 |

Vision-OPD 不只是原问题偏 P。其图片筛选本就面向 small target、fine-grained recognition 和 crop advantage，所以图片分布也可能偏 P-affordance。部分问题又采用 teacher crop 视角措辞：S/T 看完整图时指代不成立，V 看 crop 时才自然成立。若直接比较，V 同时获得“看得更清楚”和“问题视角被修复”两种优势，不能把全部差距归因于视觉特权。

M3VQA 的多实体图片可能保留较高的 R/PR 构题价值，但许多原问题需要地理、历史、药用、来源等外部事实。若 \(G\) 提供了这些事实，T 的收益就会变成知识注入，而非视觉推理组织。合理路线是双重筛选：

1. 原题在不读取外部 evidence 时仍能仅凭图片与题面唯一作答，则可进入低成本 R pilot；
2. 原题依赖外部知识，但图片具有高 R/PR 可供性，则暂存为后续重构原料，丢弃原问题并生成闭世界问题；
3. 图片本身没有可组合关系，则不强行延长推理链；
4. 用于构题、调参与训练的源图必须与冻结外部评测池按 `source_image_id` 和近重复簇隔离。

这不是为了得到漂亮结果而事后挑样本。合法的数据匹配要求在看模型结果之前定义图像可供性、外部知识依赖和最小证据路径标准，并报告各任务层的完整结果与 `method × task family` 交互。根据 T 的结果再删除失败样本，才会形成选择偏差。

### 2.4 数据构建需要同时保存“图像潜力”和“实际任务”

后续样本结构应至少区分两层标签：

- `image_affordance`：这张图适合构造哪些 P/R/PR 问题，可采用连续分数或多标签；
- `task_family`：当前问题实际依赖什么最小证据路径，只能在问题和证据链确定后验收。

当前 T02 的输入是“已有图片 + 已有问题”，它只能寻找当前问题相关的区域，无法判断该图还能否构造其他 R/PR 问题。若启动自建数据分支，应在 T02 之前增加与原问题无关的图像解析：实体、动作、关系、局部难点、分布式证据和候选推理路径先被识别，再决定出什么题，最后由现有 T02–T08 验收具体样本。

## 三、当前证据：T02 工程 pilot 已通过，科学假设仍未开始验证

### 3.1 T00–T08 与正式 Stage 0–9 是两层流程

T00–T08 是数据制作与验收流程：

```text
原始来源与资产
  → T00 登记来源、revision 与资产
  → T01 统一候选池并进行预分流
  → T02 判断图中是否存在问题证据并定位区域
  → T03 构建最小推理图和 guide QA
  → T04 物化四选项与 random / shuffle / generic 等控制
  → T05 机器质量判断与 accept / borderline / reject 分流
  → T06 人工分层审核
  → T07 按源图和近重复簇切分、冻结 manifest
  → T08 验证训练与评测代码能够只消费 frozen manifest
```

正式 Stage 0–9 才验证科学假设。Stage 0 在同一冻结样本和冻结 checkpoint 上比较 S、V-crop、V-add、T-Q、T-QA、VT 及控制条件，测量 privilege gap；通过后才进入 OPSD 训练与 student transfer。因此，T02 accepted 不代表答题正确，T00–T08 完成也不代表 H1/H2 成立。

### 3.2 T02 v1 到 v2.1 的结果说明了什么

T02 pilot 的 1,200 条全部来自 Vision-OPD P 候选。v1 作业链 `56995520` 虽完成全部记录，却因 thinking 未关闭、`max_new_tokens=512` 和坐标合约错误而无法使用：严格校验 0 accepted；宽松重解析只救回 93 条；82.0% 截断在推理中，10.6% 截断在 JSON 中；模型输出的 norm1000 bbox 又曾被旧逻辑误当像素坐标。

v2/v2.1 关闭 thinking、提高 token 上限、明确 norm1000、增加坐标换算和 provenance、EOS 截断标志、鲁棒 JSON 提取及 fail-closed canary。v2.1 最终取得：

- 1,200/1,200 记录完整；
- 353 accepted（29.4%）；
- invalid JSON 仅 2 条；
- accepted bbox 对参考 bbox 的 median IoU 为 0.894；
- 97% 存在重叠，0 越界；
- 吞吐约 1,375 条/h/4GPU。

这些结果证明 runner、结构化输出与坐标换算基本可信。29.4% accept rate 同时暴露了数据属性：不少问题从 teacher crop 视角撰写，对完整图像并不成立，所以非 thinking 模型会合理拒绝。这意味着当前 pilot 不能直接变成正式 P 数据。

thinking A/B 又显示，同批 96 条中有 42/70 从 non-thinking reject 翻转为 thinking accept，反向翻转为 0；其中 95% 的翻转 bbox 与参考区域重叠，median IoU 0.710。它说明 non-thinking 会系统性放弃部分困难目标，仅保留 353 条会把 P 层筛成容易样本；但 thinking 在 3,072 token 下仍有 33% 截断，吞吐成本约为 14 倍。生产策略应在问题视角修正后的数据上重新决定，不能把这次 A/B 解释成文本特权效果。

### 3.3 统一状态与真正阻塞点

| 节点 | 已有进展 | 尚缺内容 |
|---|---|---|
| T00 | 来源、资产与 revision 已登记 | — |
| T01 | 19,366 条统一候选已形成 | P/R 仍是粗分流，PR 缺失 |
| T02 | Vision-OPD 1,200 条 v2.1 工程 pilot 通过 | 问题视角修正、正式来源策略、全量运行 |
| T03–T05 | runner/validator 已修复 thinking、解析和截断同类问题 | 尚无真实全量输出；T05 还不是真正独立 checkpoint |
| T06 | 人工审核模板就绪 | 尚无正式输入 |
| T07 | dry-run 已完成 | 受 T03–T06 阻断，正式 split 未冻结 |
| T08 | manifest loader 骨架就绪 | 尚未用真实 frozen manifest 端到端验收 |
| Stage 0 | 尚未开始 | 没有 S/T/V/VT teacher-gap 结果 |

因此，当前工程上的最大成果是 T02 配置和坐标语义得到真实 GPU 验证；科学上的最大缺口仍是 teacher gap 为空。继续把资源集中在全量 T03–T08，会让核心可行性问题继续后移。

## 四、研讨会形成的根本判断

研讨会把正式方案中的大量假设、对照和步骤重新组织成一条以效果为中心的因果链：

```text
合适的任务与输入条件
  → privileged teacher 相对 S 出现足够大的优势
  → OPSD 尝试转移这部分优势
  → 无特权 student 在冻结 benchmark 上提升
```

导师认可训练前 teacher gap 与训练后 transfer 必须分开，也认可 V/T 可能作用于不同瓶颈、VT 未必简单叠加、引导模板可能限制模型的探索和泛化。其主要异议在于执行顺序：当前方案在第一个核心性能信号出现前就展开了较多策略、控制、消融和数据处理，增加了前端成本。

导师给出的经验先验是：视觉 crop 可使 teacher 大幅提升，而其先前尝试的文本补充只有较小提升。该经验不能替代本项目的可复现实验，但它把风险说得很清楚：文本信息“有用”不足以支撑论文，增益必须大到有机会经过蒸馏后仍留在 student 上。因此近期报告应直接回答方法、数据、样本量、绝对提升和错→对翻转，而不是先汇报完整流水线细节。

这也解释了导师对数据的态度。其认可 Vision-OPD 明显服务于视觉特权，也认可需要文本侧数据；对于 M3VQA，第一步应直接剔除需要外部知识的题并快速测试，先看是否存在明显效果。重写全部问题、建设大型 PR 集和穷尽引导策略都应放在信号成立之后。

这一建议应落成“探索阶段精简、确认阶段完整”：探索 pilot 可以缩小样本、条件和自动化规模，但仍需配对设计、人工 image-only 审核、固定 checkpoint 和完整日志；一旦要形成论文结论，random、shuffle、generic、visual sham、依赖性消融、无泄漏切分、统计区间和负迁移检查仍然不可缺少。

## 五、整合后的执行路线

### 5.1 第一阶段：最小 teacher-gap pilot

第一阶段不训练，只测试 privilege 是否提供足够大的可利用上界。

1. 从 M3VQA 预标 R 中筛出一小批候选，明显需要网页、百科、小说上下文或未提供常识的原题直接剔除；
2. 对剩余样本进行 100% 人工审核，确认答案和每个必要中间结论仅来自完整图像与题面；
3. 检查问题指代对完整图像成立，记录最小证据路径和 R/PR 标签；
4. 生成短而不可省略的 T-Q 与 T-QA，避免把答案或外部事实写进引导；
5. 使用同一 frozen Qwen3.5-4B、non-thinking、相同解码配置运行配对条件；
6. 第一轮至少比较 S、T-Q、T-QA、Generic-T；在预算允许时加入 V-add 与 VT，以观察模态对照和互补。

第一张结果表必须包含：各条件 accuracy、正确答案 log-prob、相对 S 的 paired gap、错→对与对→错翻转、外部知识剔除率、失败类型、代表性样例、吞吐和完整运行配置。样本量与转正式阈值应在读取结果前固定；除统计方向外，还需判断绝对增益是否为后续蒸馏留下实际空间。

### 5.2 第二阶段：根据结果决定数据投资

| pilot 结果 | 决策 |
|---|---|
| T-Q 在闭世界 R 上形成明显 gap | 保持 Guiding-Question PI 主线，扩大 R/PR 数据 |
| 只有 T-QA 明显有效 | 将主方法聚焦于 privileged reasoning path，T-Q 作为消融 |
| V 在 P 强、T 在 R 强、VT 在 PR 强 | 以“特权信息—瓶颈匹配”为核心机制叙事 |
| T/VT 只在外部知识题上有效 | 不能声称改善图像推理，需重新定义或停止该数据路线 |
| T-Q 与 T-QA 在合适样本上都接近零 | 暂停全量 OPSD，调整 \(G\)、任务构造或来源 |
| teacher gap 成立但 student 不提升 | 将问题定位到蒸馏效率、teacher-student mismatch 和损失设计 |

### 5.3 第三阶段：信号成立后建设正式数据和主实验

teacher gap 成立后，再将当前设想扩展为正式数据主线：

- 从完整图视角重写或重建 Vision-OPD-derived P；
- 对 M3VQA 高 R/PR-affordance 图片重构闭世界问题；
- 引入问题无关的 image-affordance screening；
- 尽可能在同一源图上构造 P、R、PR，并按 `source_image_id` 整组切分，以减少来源和风格混杂；
- 补齐 random、shuffle、generic、visual sham 与 guide dependency test；
- 用真正独立的 verifier 加人工审核完成 T05/T06；
- 冻结 T07/T08 后执行正式 Stage 0；
- Stage 0 Go 后才进入 1K–2K T-only OPSD pilot，并继续检查学生的目标提升和域外负迁移。

## 六、中期评估后的项目边界

当前已经形成的判断是：主比较采用 non-thinking；T02 thinking 只作为困难样本与成本压力测试；Vision-OPD 原问题不能直接代表文本推理任务；M3VQA 第一轮只使用无需外部知识的原题；数据切分必须以源图和近重复簇为单位；在 teacher gap 出现前不提交全量 T02–T08 作业链。

仍需由后续小实验决定的事项包括：T-Q 与 T-QA 哪个承担主方法；Vision-OPD P 采用问题改写还是完整重建；M3VQA 如何划分内部构建池与冻结外部评测池；PR 图片从哪里获得；正式效应门槛是多少；T05 是否更换真正独立模型。

这次中期评估的成果不是已经证明文本特权有效，而是把工程进展、数据偏差、方法风险和导师要求合并成了一个可执行的判断。T02 的 1,200 条完整记录、353 条 accepted 和 thinking 翻转率都是数据构建证据，不能代替 S/T/V/VT 的答题结果。下一步只有先取得可信的 teacher-gap 表，才能判断这条路线应扩大、调整还是停止。

本附录保存研讨会前后，spinner-bot 与 Codex 围绕“V 强、T 弱”、M3VQA 去外部知识、图片 P/R/PR 倾向和数据构建路线展开的讨论。正文已经把这些观点与研讨会结论合并；这里按讨论顺序保留原始问题与回应，供追溯论证来源。

### 1.1 spinner-bot 的原始想法

首先，spinner-bot 对整条方法主线提出了如下担忧：

> 我现在有一个担心：text 模态对应推理，而 vision 对应感知。现在做的事情是：让模型看图回答问题，并通过 OPSD-v-t 提升它的这项能力。但是，这似乎是一个陷阱：“看图”这本身即严重倾向感知层（P），推理在图片理解中的作用远没有感知重要，因此可推测，T 特权也远没有 V 特权效果好。我现在想要发顶会，数据必须漂亮（有成效），并且我是基于 Vision-OPD 的。但我和 Vision-OPD 的区别就是引入了 G（引导性问题序列，属于文本特权信息），其他仅为辅助或不影响大局（对照组、不同的引导策略、消融实验等）。从理论上讲，我怀疑可能不会产生很好的效果。但我同时认为，数据是决定效果的根源。这不是“造成果”，而是不同方法本来就有它擅长的数据子类。在这个实验的方法下，似乎更优的数据子类，是那些隐含大量逻辑信息的图片（推理层因此发挥更多作用，仅依靠感知不容易获取到信息）（如果这个图片同时具有一定感知难度，则可划分为 PR 倾向，如果感知难度低，则可划分为 P 倾向）（我能想到的例子：有一种推理/悬疑小说，其中有基于图片的解谜问题。这似乎是这项实验的一个理想数据来源……需要推理解谜（有的时候谜题还与数学、额外知识、小说上下文有关，这是需要注意的地方））但必须承认，制备这样的数据集，难度更高……总之，这一切还是我的思考，并没有明确的落地打算。我也很迷茫。

编者注：上段按原意存档；结合前后文，其中“感知难度低，则可划分为 P 倾向”很可能想表达“R 倾向”，后续定义以 P=感知、R=推理、PR=二者联合为准。

在讨论 M3VQA 是否应因外部知识依赖而整体舍弃时，spinner-bot 又提出：

> 我们是不是可以进行筛选：把需要外部知识的过滤掉。并在设计问题时，尽可能让回答无需依赖外部知识？不然，如果把整个 M3VQA 全扔出去了，我们好像就失去了一个 R 相关的重要数据来源。Vision-OPD 的原始数据集必定侧重 P；即使问题能修改，也不排除他们团队在初期筛选原图时，去除了一些“适合构建 R 系问题的图片（我简称 R 系图片）”，除非试图引入其他数据集。

随后，这一判断被凝练为：

> 我的假设是：图片本身也有 PR 倾向，而不仅仅取决于问题如何提出。

该想法承接此前对 Vision-OPD 与 M3VQA 的讨论：Vision-OPD 不仅原问题偏向细粒度感知，其原图也可能经过有利于小目标和 crop advantage 的选择；M3VQA 原问题虽有外部知识依赖，其多实体图片本身仍可能具有较高的 R/PR 构题价值。因此，不能只通过修改问题就假设两个来源拥有相同的任务潜力。

### 1.2 Codex 对“V 强、T 弱”风险及数据主线的回应

这个担忧触及了项目最核心的可行性风险，而且推理方向基本正确：如果目标问题的主要瓶颈是“看清局部证据”，视觉 crop 会直接改变可见信息，V teacher 获得很大的优势很自然；文本引导 G 若只是在模型已经看清的内容上重述步骤，T teacher 很可能只增加少量收益。当前 Vision-OPD 的图像选择和问题构造均偏向这种情形，所以不能用它单独判断文本特权路线是否有效。

但“视觉问答整体偏感知”并不能直接推出 T 特权无效。视觉问答中至少有两类可分离的瓶颈：

1. **证据可见性瓶颈**：目标太小、模糊、遮挡或需要 OCR，主要受益于 V；
2. **证据组织瓶颈**：模型需要确定先看什么、连接哪些实体、排除哪些干扰、完成哪些不可省略的中间判断，可能受益于 T。

G 的价值不在于替代图像，而在于降低第二类瓶颈。如果数据几乎只有第一类瓶颈，T 的弱势是任务与方法不匹配的结果，不能被解释为所有文本特权都无效。

因此，寻找更适合方法的数据子类本身是合理的机制设计，不等于为了结果挑数据。前提是先给出与模型结果无关的纳入标准，并同时报告不同层上的表现：

- P：主要需要困难局部证据，用作 V 优势锚点；
- R：图像证据可见，但必须经过多实体、多区域或多步关系整合；
- PR：同一条最小证据路径同时需要困难局部观察和关系推理。

如果只保留 T 表现好的样本再报告结果，就会形成选择偏差；如果先按可审计规则定义 P/R/PR，再检验 `method × task family` 交互，则是在验证“不同特权信息分别作用于什么瓶颈”这一研究假设。即使总体平均增益不最大，稳定且可复现的分层效应也能形成更有解释力的贡献。

悬疑图像、视觉谜题、图表推理、流程图、多人多物关系场景确实可能提供 R/PR 原料，但不能直接整包使用。数学知识、小说上下文、常识或网页知识一旦成为必要证据，T teacher 的收益就可能来自知识注入，而不是引导图像推理。第一版应优先选择闭世界样本：答案及每个必要中间结论都能由图像和题面给出，不需要未提供的外部事实。

M3VQA 因此不应整体丢弃。可先进行低成本分流：

1. 保留无需外部知识、仅依赖图像即可回答的原题；
2. 对原题依赖外部知识、但图片具有 R/PR 可供性的样本，丢弃原题并重写闭世界问题；
3. 对图片本身缺少可组合关系的样本，不强行构造 R/PR；
4. 将用于构题和训练的图片与冻结 benchmark 按源图及近重复簇隔离。

当前最稳妥的落地顺序不是立即制备一个大型新数据集，而是先做一个小规模、冻结模型的 teacher-gap 实验。对人工确认的闭世界 R/PR 样本，以同一底模比较 S、V、T、VT，报告准确率、正确答案概率、paired gap 和错→对翻转。这个实验直接回答三件事：T 是否有足够大的可利用上界；T 的优势是否集中在 R；VT 是否在 PR 上出现互补。只有这些信号成立，才值得投入大规模再标注、引导序列生成和蒸馏训练。

相应的决策逻辑是：

| 观察结果 | 对项目的含义 |
|---|---|
| T 在闭世界 R 上有明显 teacher gap | G 主线具备可行性，可扩大 R/PR 数据 |
| T 较弱，但 T-QA 明显更强 | 问题可能在引导形式或信息量，需要调整 teacher 定义 |
| V 在 P 强、T 在 R 强、VT 在 PR 强 | 最符合“特权信息—任务瓶颈匹配”的机制叙事 |
| T 与 T-QA 在合适样本上仍接近零 | 需缩小或调整文本特权主张，不宜先投入完整流水线 |
| teacher gap 存在但蒸馏后学生无提升 | 问题转移到蒸馏效率与 teacher-student mismatch |

所以，当前的迷茫可以转化成一个明确、可证伪的问题：在不依赖外部知识、具有真实关系推理瓶颈的图像问题上，G 能否让冻结 teacher 显著优于无特权基线？这比先争论整个视觉问答究竟更偏 P 还是 R 更快决定项目是否值得继续，也与导师提出的 effect-first 顺序一致。

### 1.3 Codex 对“图片具有 P/R/PR 倾向”假设的完整回应

这个假设成立的可能性很高，而且比“P/R/PR 完全由问题决定”更准确。更严谨的表述是：

> 图片具有潜在的 P、R、PR 可供性（affordance）；具体样本最终属于 P、R 还是 PR，则由图片、问题和证据路径共同决定。

可以写成：

\[
Image\ Affordance=A(I)
\]

\[
Realized\ Task\ Family=F(I,Q,Evidence\ Path)
\]

#### 图片为什么会有 P/R/PR 倾向

图片本身决定了能够构造什么样的真实问题：

| 图片属性 | 更可能支持 |
|---|---|
| 存在很小、模糊、遮挡或需要 OCR 的目标 | P 倾向 |
| 多个实体、动作和关系，证据分散在不同区域 | R 倾向 |
| 小目标同时处于一条多实体、多区域推理链中 | PR 倾向 |
| 单一主体、背景简单、没有可组合关系 | 很难构造真正的 R/PR |

例如，一张单独拍摄的杯子照片，即使人为写三道引导问题，也很难形成真正的 R；那些步骤往往只是把简单识别题拉长。

相反，一张机场全景中同时存在飞机、地勤人员、车辆和远处的小型工具，就天然具有 PR 倾向：

1. 根据人物与车辆的关系锁定目标人物；
2. 查看该人物手中的小物体；
3. 根据物体与接触对象判断行为。

这条路径同时依赖局部小目标的可见性、全局人物和物体关系，以及多步证据整合。

#### PR 倾向不是“同时有小目标和复杂背景”

如果图片左边有一个很小的标志，右边有几个人进行复杂互动，但两者彼此无关，那么它只是同时具备 P 和 R 素材，不一定具备 PR 倾向。

真正的 PR 图片要求存在一条联合路径：

\[
E_{small/local}
\rightarrow H_1
\rightarrow E_{global/relational}
\rightarrow H_2
\rightarrow A
\]

或者：

\[
E_{global}
\rightarrow \text{锁定局部目标}
\rightarrow E_{small}
\rightarrow A
\]

同一道题必须同时需要局部证据和全局关系：

\[
A\not\Leftarrow E_{local}
\]

\[
A\not\Leftarrow E_{global}
\]

\[
A\Leftarrow E_{local}+E_{global}
\]

这才是 PR，而不是把一条 P 题和一条 R 题机械拼在一起。

#### 这解释了 Vision-OPD 与 M3VQA 的差异

Vision-OPD 不只是“问题写成了 P”。它在图片和区域筛选阶段，本来就寻找小目标、crop 后明显更清晰的区域、细粒度属性和单个局部证据可以回答的问题。因此，它很可能同时产生两层偏差：

1. 图片选择偏向 P-affordance；
2. 问题生成偏向 P-task。

即使重写 Vision-OPD 的问题，也不能保证这些图片能提供足够丰富的 R/PR 关系结构。

M3VQA 则相反。它的图片经过多实体、多跳任务筛选，可能天然具有较高的 R-affordance，部分图片也可能有 PR-affordance。其原问题依赖外部知识，并不代表图片没有价值。

因此，对 M3VQA 更合适的处理是：

> 保留其可能具有 R/PR 倾向的图片，重新检查或生成 image-grounded 问题。

#### 数据集应采用双层标签

后续不应只保存最终的 `task_family`，还应保存图片层面的倾向，例如：

```json
{
  "image_affordance": {
    "p_score": 2,
    "r_score": 2,
    "pr_score": 2
  },
  "image_structure": {
    "num_entities": 7,
    "num_relations": 9,
    "num_candidate_regions": 3,
    "has_small_critical_object": true,
    "has_distributed_evidence": true,
    "candidate_reasoning_path_length": 3
  },
  "task_family": "PR"
}
```

两类标签含义不同：

- `image_affordance`：这张图片适合构造什么题；
- `task_family`：当前这道具体问题实际需要什么能力。

图片层标签更适合使用连续分数或多标签，因为一张图可能同时适合 P、R 和 PR。

#### 当前 T02 前需要图片倾向分析

当前 T02 是问题驱动的：

```text
已有图片 + 已有问题 → 寻找问题相关区域
```

它无法回答“这张图片还能不能构造其他 R/PR 问题”。因此，自建数据分支应先做一次与原问题无关的图片解析：

```text
原图
  → 实体、属性、动作、关系、局部目标解析
  → 候选证据图与候选推理路径
  → 计算 P/R/PR affordance
  → 按图片倾向生成 Final Question
  → 验证实际 task family
  → 进入现有 T02–T08
```

affordance screening 问“图片能支持什么问题”；当前 T02 问“当前这道问题需要看哪里”。二者不能相互替代。

#### 如何判断一张图有 PR 倾向

可以预先定义三个维度。

**P-affordance：**

- 是否存在面积较小的可识别目标；
- 是否包含小文字、细粒度属性或遮挡；
- crop 是否能显著提高证据可见性；
- 目标是否仍能在完整图中被合理指代。

**R-affordance：**

- 是否存在多个可区分实体；
- 是否存在人物—物体、人物—人物或物体—物体关系；
- 必要证据是否分布在多个区域；
- 是否存在至少两步不可省略的信息转换；
- 单个局部 crop 是否不足以回答。

**PR-affordance：**

- 推理路径中是否至少包含一个困难局部节点；
- 该局部节点是否与全局关系链直接连接；
- 局部证据或全局证据任一缺失时，答案是否无法确定；
- 是否能构造自然问题，而不是人为拉长链条。

#### 同图构造不同任务可以减少混杂

如果图片允许，可以从同一张图构造一道 P、一道 R 和一道 PR 题。例如：

```text
同一机场图片

P：远处工作人员手中的工具是什么颜色？

R：根据人员与车辆的关系，哪名工作人员负责装卸？

PR：先根据车辆关系锁定装卸人员，再识别其手中的小工具；
    该人员正在执行什么操作？
```

这样可以在相同视觉场景上比较 V/T/VT，减少来源、风格和图片复杂度带来的混杂。同一图片派生的所有问题必须按 `source_image_id` 一起进入同一个 split。

#### 该假设可以转化为可检验的机制预测

\[
Gap_V\uparrow
\quad\text{when}\quad
P\text{-affordance}\uparrow
\]

\[
Gap_T\uparrow
\quad\text{when}\quad
R\text{-affordance}\uparrow
\]

\[
Interaction_{VT}\uparrow
\quad\text{when}\quad
PR\text{-affordance}\uparrow
\]

如果正式结果支持这些关系，论文可以进一步说明：在看到具体问题之前，图片的视觉结构已经部分决定了哪种 privileged information 更有价值。

因此，不应直接丢弃 M3VQA。更合理的路线是将 Vision-OPD 和 M3VQA 视为具有不同图片选择倾向的原料库，先做问题无关的 P/R/PR affordance 分析，再决定哪些图片适合生成哪类问题。最终 P/R/PR 标签仍由具体问题及其最小证据路径确认。

## 附录 2：研讨会内容概述与重点

### 2.1 会议目的与讨论结构

2026-09-10 的研讨会围绕“视觉问答模型蒸馏研究如何从完整方案进入可验证实验”展开。汇报者先介绍文本—视觉特权信息自蒸馏的假设、P/R/PR 数据分层、引导策略、控制条件和 T00–T08 数据管线；导师随后从经验效果、论文贡献和执行效率三个角度追问，并把下一阶段工作收束到 teacher advantage 与 distillation efficiency 两个问题。

整场讨论可理解为四层递进：

1. 先确认 `G` 在训练前是否真的帮助同一模型答题；
2. 再确认这部分能力能否在移除 `G` 后转移给 student；
3. 用 P/R/PR 区分 V、T、VT 可能发挥作用的任务条件；
4. 调整执行顺序，先得到性能信号，再投入完整数据建设和消融。

### 2.2 汇报者提出的研究框架

汇报者把核心方法定义为：基线接收 `I,Q`，文本 privileged teacher 额外接收引导性问题序列 `G`。H1 检查训练前的 `Perf(I,G,Q) > Perf(I,Q)`，只证明 `G` 是有用信息；H2 检查 OPSD 后 student 在推理时删除 `G` 仍能提升，才证明发生了能力转移。

进一步的假设包括：V 主要帮助寻找和看清证据，T 主要提供寻找答案的路径；VT 可能互补，也可能因两种 teacher 信息不一致而冲突；结构化 `G` 应与 random、shuffle、generic 等“额外文本但非目标路径”条件比较；reasoning depth 应由从直接视觉证据到最终答案之间不可省略的信息转换定义；teacher gap 越大，通常越可能为蒸馏留下空间；固定格式的引导也可能压缩真实搜索，使学生在其他任务上的探索性和泛化下降。

数据层面，汇报者提出 P、R、PR 三类任务。P 的主要瓶颈是感知，R 的主要瓶颈是关系或多步推理，PR 要同时依赖两者。会议中还提出了图片本身可能具有 P/R/PR 倾向的观点：图像选择会影响后续能自然构造什么问题，最终分类则仍需结合具体问题。相同源图派生的不同问题必须作为整体切分，避免训练与测试共享图像。

文本引导 `G` 的候选构造方式包括层级定位、实体/关系链和分散证据整合。汇报者同时设计了 random、shuffle、generic 文本控制、visual sham 以及逐个删除 guide step 的依赖性消融，目的是判断收益究竟来自有效结构、任意额外上下文，还是某个可省略步骤。

### 2.3 导师的核心观点

导师对研究逻辑本身没有提出根本否定。其认可训练前信息效用与训练后能力转移必须分开，认可 V/T 的侧重点可能不同，也认可引导模板可能带来专门化和域外下降。导师最强烈的判断集中在 **effect size 和研究顺序**。

导师认为，蒸馏无法凭空放大一个很弱的 teacher advantage。其先前经验中，视觉局部图对 teacher 的帮助很大，而文本补充虽有正向作用但幅度较小。这个经验意味着项目不能满足于“加文本后略有提升”，而要先判断提升是否大到足以支撑 student 的最终增益和论文贡献。

因此，导师把可行路径归纳为两类：

- 找到一种输入或任务设计，使 privileged teacher 本身更强；
- 在 teacher 已经更强的前提下，提高优势向 student 的蒸馏效率。

两条路径最后都必须落到无特权 student 在目标 benchmark 上的表现。当前应先解决第一条，因为 teacher gap 还没有被正式测量。

### 2.4 导师对数据路线的判断

导师认可 Vision-OPD 数据是围绕视觉局部信息构造的，因此天然有利于视觉特权，在其上增加文本引导很可能只有较小效果。若项目要证明文本路径的价值，需要补充更适合关系推理的数据。

对于 M3VQA 的外部知识问题，导师给出的策略非常直接：第一轮先把需要外部知识的样本去掉，快速运行能够仅凭图像回答的部分；先看文本引导是否出现明显效果。若信号不存在，就不应先花大量时间重写全部问题；若信号成立，再扩大图片再标注和 PR 构建。

导师并未要求放弃多模态方向。相反，其提醒纯文本研究计算门槛较低、竞争更密集，项目应保留图像任务、GPU 实验和多模态蒸馏这一技术边界。因而合理的路线是以 R/PR 图像任务强化 T 的作用，而不是退化为不需要视觉证据的文本推理或知识问答。

### 2.5 对当前执行方式的修正

会议暴露的主要问题是汇报和执行都过早展开了完整矩阵。导师更希望看到一个直接结果：用了什么额外条件、在哪批数据上测试、多少样本、准确率提升多少、多少样本从错变对。数据处理的详细步骤应保留在审计材料中，在解释失败或复现时再展开。

据此，后续工作应分成两个节奏：

- **探索节奏**：小批量、冻结模型、不训练、人工确认、快速比较 S/T/V/VT，目标是确定效果是否存在及其量级；
- **确认节奏**：效果成立后扩大样本，完成正式数据管线、全部控制、冻结切分、统计检验和 OPSD transfer。

这一修正保留了方案的科学严谨性，同时让最可能使路线失败的问题最先被检验。

### 2.6 会议最终形成的行动重点

会议内容与会后审计合并后，下一步可以明确为：

1. 从 M3VQA 中剔除外部知识依赖题，得到一批 image-only R 候选；
2. 人工确认问题对完整图像成立，并构建最短有效 `G`；
3. 关闭 thinking，以冻结模型运行 S、T-Q、T-QA，预算允许时加入 V 与 VT；
4. 报告 N、accuracy、correct-answer log-prob、paired gap 和翻转数；
5. teacher gap 足够大时再扩建正式数据，并进入蒸馏；否则优先修改数据与引导定义。

这场研讨会的根本意义，是把项目从“先证明整套设计完整”转成“先证明核心因果链的第一环足够强”。
