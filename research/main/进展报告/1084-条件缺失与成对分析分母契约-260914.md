# 条件缺失与成对分析分母契约

**性质**：重点文档；在 G1、Stage 1 和正式 external evaluation 产生任何结果前，冻结条件失败、样本缺失、训练失败与统计分母的处理规则。

**创建时间**：2026-09-14 13:16（UTC+8）

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：1017 已要求自然 G0 的 1,920 条记录全部存在，1080 也要求训练 seed 对称处理，但未来 G1/Stage 1 尚未区分运行配置故障、模型可观察失败、结构性不适用和方法特异训练失败。若按条件删除 parse failure、只保留成功 seed 或在结果后重跑某一方法，成对比较会产生 survivorship bias，并可能系统性偏向更稳定的方法。

---

## 1. 冻结分析总体

每个确认阶段必须在任何目标条件输出可见前写入以下集合及其 SHA-256：

- `locked_items`：全部基础题及 image/near-duplicate cluster；
- `required_conditions`：该主张所需的完整条件块；
- `required_rotations`：内部选择题固定为四个语义标签轮换；
- `required_seeds`：训练比较的共同 seed 集；
- `applicability_mask`：只由冻结结构字段决定的机制分析适用性；
- `failure_policy_hash`：本契约及阶段特化规则的版本。

确认性主分析采用冻结总体（intention-to-evaluate）。不得依据某个条件是否答对、是否完成、某个 seed 是否有利或 guide deletion 效果来改写总体。P/R/PR、来源、深度与作者类型的分母同样在结果前固定。

## 2. 四类失败必须分开

### A. 资产、调度或配置故障

包括 manifest/hash 不一致、图片或模型资产缺失、代码漂移、记录键缺失/重复、rank 调度不完整、choice score 非有限、错误 chat template、由结果盲 canary 健康门证明的系统性 token 上限不足，以及节点/文件系统故障。它们不形成性能结果，整个预声明条件块 fail-closed。正式配置通过后只在个别方法/样本发生的拒答或截断属于 B/D 类，不能仅因不利于该方法而追认为公共配置故障。

修复后只可用同一 locked manifest、同一 condition/rotation/seed 集和新 run archive 完整重跑；旧档案保留并标为 invalid。不能把旧 run 的成功条件与新 run 的失败条件拼接。若效果已经打开，仍须记录错误证据、修复理由及新规则 hash，并完整重跑所有受影响条件，不能只重跑不利条件。

### B. 模型的可观察回答失败

在运行配置已通过 canary、token 预算和资产门后，合法的 abstain、tie、拒答、不受约束文本或官方评测可判定的无效答案属于模型行为。它们必须按预注册评分记为错误、abstain 或官方无分，不能变成缺失后从分母删除。

内部 choice-scoring primary 要求四项有限 score，因此 score 计算失败属于 A 类并关闭整块；constrained generation 只作次级接口诊断，其 parse failure 在 primary score 完整时作为生成失败保留。外部 benchmark 遵守官方主评分，同时额外报告 invalid/abstain 的分子与冻结总分母。

### C. 结果盲的结构性不适用

只允许用于 1082 的 leave-one-out、partial-chain 等机制条件，例如某题只有一个 guide 而不存在对应中间删除。`applicability_mask` 必须由 locked DAG/guide 长度在推理前确定。该题仍进入 C1–C4 和 S1–S4 的主条件分母；只在该特定机制分析中标为 `not_applicable`，并同时报告全体 N、适用 N 与不适用原因。

### D. 训练方法特异失败

loss divergence、OOM 或 checkpoint 损坏若只反复发生于一个方法，可能是方法稳定性的结果，不能自动归为可忽略工程故障。共同基础设施故障可按 A 类对同一 seed 的全部方法完整重跑一次；持续的方法特异失败必须报告在冻结 seed 分母中，并阻止依赖完整 paired seed 集的确认性层通过。不得删除该 seed、仅增加主方法 seed，或用另一个 seed 替换。

## 3. 各阶段的完整块

### 自然 G0

沿用 1017：`96 base items × 4 rotations × 5 conditions = 1,920` 条必须键唯一且全部通过 primary score gate。任一缺失、非有限 score、图片错误或截断使整个 locked run 不进入效果分析；只能按 A 类开新档案完整重跑。

### G1

C1/C2 的文本主块要求每个 locked item 对入选 `T-real`、逐题 matched `T-generic` 和必要基线具有相同四轮换记录。C3/C4 另要求 1078 对应的 V-real/V-sham 与 T-real/T-generic 完整受控格。缺一格时，依赖该格的确认层不开启，不能在可用子集上升级为确认结论。

允许把不依赖缺失格的较低层完整块按预注册顺序分析。例如文本块完整而视觉块因配置失败时，C1/C2 可在其独立 gate 通过后分析，C3/C4 保持 unavailable；前提是这些块及开放顺序已在结果前分别哈希，且运行器没有提前泄露条件聚合。

### Stage 1

`Base`、`OPD-00`、`OPD-Generic` 与 `OPD-Real-T` 使用完全相同的 frozen internal-test items/rotations；三个 OPD 训练组以共同 seed 集形成 paired seed block，未训练的 Base 固定评测一次并作为共同参照。若 `SFT-answer` 进入 seed 级比较，也使用同一 seed 集。每个训练 seed 必须保存训练状态、最终 checkpoint 身份和全部评测键。S1 的确认性结果要求所有预声明 seed block 完整；方法特异失败按 D 类处理。

checkpoint 选择只使用冻结 validation 规则。不能因为某方法某一 checkpoint 或 seed 在 internal test 上失败而回到 validation 改选。正式 internal test 的单项资产/调度故障按 A 类重跑完整模型条件块，不能拼接部分预测。

## 4. 统计与报告

每张主表必须同时给出：

- frozen item/cluster/rotation/seed 总数；
- 每条件 expected、observed、valid-score、abstain/invalid、not-applicable 数；
- A–D 四类失败的分子、分母、原因和受影响 run/seed；
- 主估计量实际使用的 item、cluster 和 seed 数；
- 是否满足完整块门；
- 所有重跑及旧 invalid archive 的引用。

逐条件 complete-case 删除不得成为主分析。若存在非结构性缺失，可另报 paired complete-case、best/worst-case bounds 或多重插补作为 sensitivity，但它们不能替代冻结总体，也不能开启 1080 的确认层。若缺失足以使主 estimand 无法定义，结论是 `UNAVAILABLE/FAIL-CLOSED`，不是“在剩余样本上无显著差异”。

rotation 不是独立样本。内部主分数仅在一个基础题的四个 rotation 均完整时聚合；因 A 类错误导致某一 rotation 不完整时关闭对应条件块，而不是删除该题。cluster、item 和 seed 的统计层级继续服从 1068/1071/1080。

## 5. 重跑决定的结果隔离

canary 只检查配置健康，不读取科学效果。正式块开始后，runner 在该块全部条件完成和 gate 通过前不得输出按条件 accuracy、gap 或排名。是否重跑只依据 A 类日志与结构门；修复说明必须在打开新效果前写入档案。

如果只有在效果打开后才发现确定性实现错误，允许纠正，但必须：

1. 保留原始运行并明确作废原因；
2. 冻结修复 commit、受影响范围和重跑集合；
3. 对全部受影响方法/条件/seed 对称重跑；
4. 报告错误是在何时、依据什么非效果证据发现；
5. 不修改 locked items、标签、guide、family 或主指标。

## 6. 与现行路线的关系

本契约补全 0011 所警示的 survivorship bias，并具体化 1017 的 G0 全记录门与 1080 的 seed 对称原则。它不改变 B2a、G0、G1 或训练解锁顺序，不授权 GPU、数据生成或训练。

当前自然 G0 manifest/result/job 均为零，G1 与 Stage 1 未解锁，因此本规则没有参考目标结果。现有 G0 实现已经采取最严格的完整块门；G1/Stage 1 实现时须把 `failure_policy_hash`、expected key set 与分母摘要接入各自 manifest 和 result gate。
