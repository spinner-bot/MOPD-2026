## 1. 研究对象的重新定义

“视觉模态对应感知、文本模态对应推理”只能描述当前方法中两类特权信息的主要形式，不能作为数据标签。图像本身既能提供细粒度感知证据，也能提供位置、连接、顺序、数量、状态和全局约束；文本既能给出推理引导，也可能只是复述显而易见的视觉事实。

因此本项目采用以下三层定义：

1. **图像可供性 `A(I)`**：一张图在不指定原问题时，可能支持哪些闭世界目标和证据结构。它是一组潜在任务，不是 P/R/PR 真值。
2. **任务瓶颈 `F(I,Q)`**：给定完整图像 `I` 和具体问题 `Q` 后，正确作答的最小充分证据链主要受感知限制、关系推理限制，或二者共同限制，才分别记为 P、R、PR。
3. **特权信息效应 `E(F,G,M)`**：对固定模型、固定题目和固定评价，视觉特权或文本引导 `G` 是否弥补了实际瓶颈。这个效应只能由冻结后的条件对照得到，不能由数据来源、题目名称或筛选模型的主观分数预先宣告。

由此，用户关于“图片本身也有 PR 倾向”的假设得到更精确的表达：图片确实有问题无关的 P/R/PR **可供性分布**，但最终标签仍属于 `(图片, 问题, 答案与评价契约)`。同一张交通图可以支持读小字的 P 题、比较路径的 R 题，也可以支持先读局部标记再规划路线的 PR 题。

这个定义也解释了两个看似冲突的现象：Vision-OPD 的既有题目和 crop teacher 强化了局部感知瓶颈，所以 V 特权很容易显效；M3VQA 图片未必缺少 R 可供性，但其原题按外部多跳事实构造，常把闭世界图像证据与百科知识混在一起，所以不适合直接检验纯 G 的作用。

## 2. 当前证据回答了什么

### 2.1 Vision-OPD T02 pilot：验证了视觉 grounding 管线，未验证 G

0010 已归档：v2.1 在 1,200 条 Vision-OPD pilot 上得到 353 条 accepted（29.4%），accepted bbox 与 source bbox 的 median IoU 为 0.894、97% 有重叠、0 越界；thinking A/B 又显示非 thinking 拒绝到 thinking 接受的翻转率为 60%，且翻转框大多与真值重叠。

这些结果有两项价值：9B 具备相应视觉理解能力；thinking、token budget、坐标系和 crop/full-image 视角会强烈改变数据生成质量。它们没有证明文本引导优于视觉特权，因为 pilot 来源及目标本身偏向局部感知，而且原问题常从 teacher crop 视角书写。

### 2.2 支路 A：M3VQA 原题的闭世界适配率很低

r7 在修复完整多答案契约后完成同一 C1-128：blind full 127/128，audit full 127/128，模型初选 8 条 image-only R。r7c 对这 8 条的构造结构复核为 7/8，说明表示契约基本稳定，但人工诊断已发现 6 条明显语义假阳性。

新版 CPU 语义门禁要求直接视觉 evidence、完整 canonical answer 覆盖、不得否定必要答案项，并禁止 explanation 一边承认答案未出现、一边声称图像蕴含。离线回放后，8 条机器候选只剩 `m3vqa-data_0000042` 与 `m3vqa-data_0000663` 两条。它们仍是机器候选，human_verified=0。

这说明当前原题支路的主要瓶颈不是 JSON，而是问题与闭世界视觉证据不匹配。2/128 也不能反推只有 1.56% 的 M3VQA 图片适合 R；它只估计这一固定样本中“原图 + 原题 + 完整答案契约”通过机器门禁的上界。

### 2.3 支路 B1：自由自评分不是可靠筛选器

| 轮次 | 结构结果 | 诊断 | 裁决 |
|---|---:|---|---|
| r1 `57597609` | 生成 0 条 | Python 被错误指向 large scratch；模型未加载 | 仅修运行路径 |
| r2 `57598570` | 1/8 有效；2 条最终截断 | 8 条 primary 均能描述图片；6 条 `candidate` 却自评 `r_score=1`，旧 fallback 锁死无效决定 | 修 fallback 与完整嵌套 schema，不放宽 validator |
| r3 `57599758` | 7/8 有效；零最终截断；7 条全为 candidate | 同一批简单场景被改写为“识别两个物体→复述前后/相邻”等假两步；文字阈值使分数从 1 变 2，却没有产生更深推理 | full 写入 0 条时主动取消；停止该配方 |

r3 的手工逐图检查只用于定位筛选器失效，没有填写 reviewer、时间和盲审字段，因此不是独立人工真值。它足以支持工程停止：如果一个分数随 prompt 中的最低分要求变化，而路径内容基本不变，就不能把该分数当作图像 R 可供性的测量量。

### 2.4 r8 与 r8b：语义门禁需要完整重跑

r8 `57599082` 在生成前被根目录安全检查拒绝：C1 旧路径经迁移软链接解析到 `.../sqs/data/...`，提交却使用 B0 新池的 `.../data/...`。两个位置均有图片副本，但严格 root 检查正确 fail-closed。本轮没有语义输出，不能评价新门禁。

r8b `57600241` 仅修正解析根并固定在提交 `8c5537f` 重跑。blind canary 为 8/8，blind full 为 127/128；audit canary 为 8/8，均通过结构门禁。audit full 运行到后段时，存储顶层从 `.../rqian000/sqs` 整体重定位到新建的 `.../rqian000/ICLR-2027-czy`：29 条从 input index 97 起的记录在四个 rank 上先后报告图片或旧根不存在。最终只有 95/128 条 audit 严格有效，parse rate 74.22%，gate 按设计失败并阻止联结。

有效的残缺前缀含 external 88、ambiguous 3、image-only/R 4，但最后 29 条中包含离线回放候选 `m3vqa-data_0000042`，所以 4 不是最终产率。此轮证明正确 root 在启动时可用，也证明“作业前校验”无法抵御运行中的整体迁移。由于支路 A 已有足够的低产率与语义假阳性证据，不再为精确机器计数消耗第四轮 4×A100；后续作业需等新根、仓库软链接和全量文件校验稳定后才提交。

1036 随后以三个可逆兼容软链接恢复旧入口，并对 C1 128 条、B0 256 条、B2a 32 条逐文件重算 SHA-256，缺失和不一致均为 0。该恢复保证后续人工审核可读取图片，但不改变 r8b 的失败状态，也不构成重提 r8 的理由。

## 3. 当前路线裁决

### 3.1 支路 A 冻结扩量

不运行 9,463 条原题 fullpool，不继续为 2 个机器候选做 GPU construct。待人工有空时，可对 r7 新门禁仍保留的两条做精度核查；其用途是校准原题筛选器，不是凑齐 136 条。即使两条都通过，也不能改变原题支路产率过低的结论。

### 3.2 支路 B 停止自由自评分，转入 B2a 先人后机校准

`20260914T0328-image-affordance-b2a-blind-calibration` 已从冻结的 256 图样本取前 32 张，输出 SHA-256 `b61839dd…a1057a58`。第一阶段只显示图片和身份哈希，不显示 B1 proposal、原问题、答案、官方 evidence、URL 或任何 teacher-gap 结果。人工必须先独立写出一个具体闭世界目标、答案、至少两项直接视觉证据、至少两步推理和反事实必要证据。

完成门禁不接受仅填写“这是一张 R 图”：

- candidate 必须给出可回答的具体问题与完整答案；
- R/PR 路径至少包含两项直接视觉证据和两项不可省的推理变换；
- 每项声称必要的证据都要说明移除后为何不能唯一作答；
- PR 必须再指出链上的困难视觉节点；
- 需要人物、地点、品牌、物种或事件记忆才能成立的目标不得作为闭世界 candidate；
- reviewer、带时区时间、`human_verified=true` 与 complete 状态都必须由人填写，代码不推断或补全。

`finalize_image_affordance_blind_review.py` 只校验字段、图像身份和防火墙；任何不可变字段被修改、记录缺失、机器信息混入或签名不完整都会 fail-closed。第一阶段文件锁定后，第二阶段才揭示同 ID 的 B1 输出，估计 proposal precision、candidate 漏检率、路径匹配率与假两步比例。

### 3.3 B3 只在人类校准后重启

32 图盲审完成前，不重新设计 B1 prompt，不生成新问题，不下载大型新数据集。盲审结果将决定：

1. **人工也几乎提不出具体 R/PR 目标**：说明这批 M3VQA 图片的可供性确实低；再按相同盲协议比较其他已入库来源或有针对性引入新来源。
2. **人工能提出而 B1 大量漏检/错配**：图片来源可保留，废弃自评分筛选器；B3 以人工目标和证据链为种子构题。
3. **人工与机器在具体路径上较一致**：才将机器 proposal 用作扩大候选池的召回工具，仍需 100% 人审。

如果重启机器筛选，新判断单位必须是一个具体 `(target, answer, evidence graph)`。模型需通过反事实必要性或独立解题器验证，而不是再次输出抽象 0–3 分。

## 4. effect-first 的实验顺序

文本 G 能否成为论文主贡献，最终取决于它在合适任务上的因果增益，而不是数据规模。冻结顺序保持 1017：

1. 取得至少 136 条人类签名、近重复簇互斥、问题与证据图固定的实际题目；
2. 固定 8/32/96 清单、模型 revision、prompt、解码和评分；
3. 同时运行 S、T-Q、T-QA 与 Generic-T；
4. 先看 T-QA−S 是否存在可靠 reasoning-state oracle envelope，再看 T-Q−S 是否说明仅 G 足够，最后用 Generic-T 排除额外 token 或普通“仔细想”效应；
5. 条件结果只用于裁决方法，不反向删题、改题或换层级标签。

这套顺序允许得到可发表的负结论，也防止为了“数据漂亮”把筛选过程变成按目标效果挑样本。若 T-QA 有效而 T-Q 无效，问题在 G 的信息质量；若二者都无效，停止当前配方并换任务结构或模型；只有出现预先定义的 teacher gap，才扩大 OPSD-v-t 数据与训练。

## 5. 对数据来源扩展的约束

保留 M3VQA 是合理的，因为它提供了 Vision-OPD 之外的图像分布；过滤需要外部知识的原题也合理。但“先过滤问题”与“先筛图片可供性”回答不同问题，必须保留两条来源标签：

- `question_origin=original`：估计数据集原问题对闭世界 G 实验的适配率；
- `question_origin=reconstructed`：估计同一图片经新目标设计后的可供性和 teacher gap。

若 B2a 证明 M3VQA 图片本身也缺少足够 R/PR 可供性，再考虑其他来源。候选来源必须先用小型问题防火墙盲样本比较，不因数据集名称或论文宣称直接贴 R 标签，也不在 teacher-gap 结果后追溯性选源。

## 6. 当前 claim boundary 与下一动作

目前可以声称：视觉结构生成管线已修复并能高质量定位；M3VQA 原题在当前闭世界完整答案契约下机器产率很低；9B 的自由 affordance 自评分不可用；一套先人后机的 32 图盲校准包和严格完成门禁已经冻结。

目前不能声称：M3VQA 图片整体偏 P；两条 r7/r8b 机器候选是真 R；G 已经有效；T 特权弱于 V 特权；OPSD-v-t 已具备扩训证据。

执行顺序冻结为：归档 r8b → 人工完成 B2a 32 图第一阶段 → 锁定并做 B2b 机器对照 → 按校准结果决定 B3 或新来源小样本 → 取得 136 条后执行 1017 teacher-gap。等待人工期间，不再提交新的同配方 4×A100 作业。
