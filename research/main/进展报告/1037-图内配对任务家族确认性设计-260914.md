# 1037-图内配对任务家族确认性设计

**性质**：重点文档；把“同一图片可承载不同任务瓶颈”的新视角转成信号成立后的确认性 P/R/PR 设计，用于分离图片选择、问题设计与特权模态效应。

**创建时间**：2026-09-14 04:05（UTC+8）

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：1012 和 1035 已明确图片可供性 `A(I)` 不等于具体任务家族 `F(I,Q)`。只用 Vision-OPD 代表 P、M3VQA 代表 R 会把图片来源、视觉风格、问题写法和任务瓶颈同时改变，无法干净解释 V/T specialization。需要在不延迟 1017 最小 teacher-gap pilot 的前提下，为正式实验预先冻结图内配对方案。

**上游依据**：正式方案 v1.0、1012、1017、1034–1036、`image_affordance_blind_review_guide.md`。

---

## 1. 它解决的核心混杂

若 P 题全部来自 Vision-OPD、R 题全部来自 M3VQA，观察到 `V>P` 或 `T>R` 时，差异至少可能来自：

- 图片内容和拍摄风格；
- 分辨率、目标尺度与对象密度；
- 原题生成方式和答案空间；
- 外部知识比例；
- 问题的真实感知/推理瓶颈；
- crop 是否同时修复了原题视角。

正式机制主张要求把这些因素拆开。最直接的设计是在同一张完整图上构造多个问题，使图像 bytes、来源、场景与全局难度固定，只改变答案所需的最小证据链。图片成为自己的对照。

本设计不要求每张图天生“属于 R”。它要求一张图具有多个可审核的 affordance，并分别物化成实际 P、R，条件允许时再物化成 PR 问题。

## 2. 两级实验，不拖慢当前 effect-first pilot

### 2.1 G0：沿用 1017 的最小信号实验

当前第一优先级不变：先取得 8 canary、32 dev、96 locked 共 136 个互斥源图，每图一道经人工确认的 R/PR 题，运行 S、T-Q、T-QA、Generic-T。G0 只回答文本 privilege 是否存在足够 teacher gap。

1037 不追溯修改 1017，也不要求先造完整 P/R/PR 配对集。若 G0 的 T-QA 和 T-Q 都达到 Stop 条件，当前配方停止，正式配对集不建设。

### 2.2 G1：仅在 G0 Go 后建设图内配对确认集

G0 出现预注册 teacher gap 后，G1 再回答机制问题：T 是否在 R/PR 相对 P 上更有效，V 是否在 P/PR 相对 R 上更有效，VT 是否在 PR 上互补。

建议正式规模为：

- 160 个互斥图像近重复簇；
- 每图一对 P 与 R，共 320 题；
- 其中 80 图在自然成立时增加 PR，共 80 题；
- 合计 400 题，处于正式方案 400–600 的预定范围。

160/80 是规划目标，不是为了凑数的最低质量豁免。实际 N 在 G0 的效应方差和计算预算可用于 power analysis 后一次性冻结；不得根据 G1 条件结果增删题。

## 3. 图内 P/R/PR 的构造契约

### 3.1 共用部分

同一 `task_pair_id` 下的题必须共享：

- 完全相同的完整图像 bytes 与 SHA-256；
- 相同的 source dataset、source image 和近重复簇；
- 同一问题防火墙，不能回看源问题或官方 evidence 来决定目标；
- 四选一输出形式、相近的问题长度与答案类型；
- 人工确认的唯一答案、完整图指代和闭世界边界。

题目之间可以有不同答案，但不能通过模板措辞直接暴露家族标签。

### 3.2 P 问题

P 题只有一个主要必要视觉节点，困难来自定位、分辨率、小目标、小文字、遮挡或细粒度属性。读取该节点后无需多步关系整合即可回答。若两个局部区域都不可缺并需要比较，它已不是纯 P。

P 的视觉特权必须指向真正困难的必要节点；crop 不能改变问题视角、排除原图中的竞争对象或包含额外答案提示。

### 3.3 R 问题

R 题至少包含两个清楚可辨的必要视觉证据和两步不可省略的信息变换。困难来自关系组合、比较、连接、顺序、状态变化或图结构，而不是看不清关键节点。

R 的任何一个单 crop 或单证据都不足以回答。若为 V 条件提供视觉特权，必须保存覆盖各必要证据的多区域集合或明确 V 不适用；不能只给包含答案的合成图。

### 3.4 PR 问题

PR 同时满足 R，并且其中至少一个必要 evidence 是困难局部视觉节点：

\[
A\not\Leftarrow E_{local},\quad
A\not\Leftarrow E_{global},\quad
A\Leftarrow E_{local}+E_{global}.
\]

PR 不能通过给 R 题随意加小字或背景物体得到。困难局部节点必须位于通向答案的最小路径；移除该节点或全局关系任一部分，答案都不再唯一。

### 3.5 反事实成对检查

人工在不知道任何 S/V/T 结果时，对每个问题完成三项反事实：

1. 遮住每个 required evidence，检查答案是否不再唯一；
2. 删除每个 reasoning step，检查链是否断裂或降为更浅任务；
3. 对 P/R 同图互换证据，检查各自答案不能由另一题的单一特权直接泄漏。

若同图只能自然构造一种家族，保留在非配对来源层，不强造配对；它不能进入 G1 的主要交互分析。

## 4. 条件矩阵与主要估计量

G1 至少运行 S、V、T-Q、T-QA、Generic-T；VT 使用与 T-QA 相同的 guide QA 加 V。若正式方案保留更多随机/shuffle/sham 控制，均在同一 locked 题上运行，不能另外选子集。

对家族 `f` 定义：

\[
\Delta_{TQ}(f)=Perf(TQ,f)-Perf(S,f),
\]

\[
\Delta_{TQA}(f)=Perf(TQA,f)-Perf(S,f),
\]

\[
\Delta_V(f)=Perf(V,f)-Perf(S,f).
\]

文本 specialization 的主要机制对比为：

\[
Spec_T=\Delta_T(R)-\Delta_T(P),
\]

视觉 specialization 为：

\[
Spec_V=\Delta_V(P)-\Delta_V(R).
\]

PR 的互补性为：

\[
Interaction_{PR}=Perf(VT,PR)-Perf(V,PR)-Perf(T,PR)+Perf(S,PR).
\]

T-Q 与 T-QA 分开计算，不能先挑更好者再报告。Generic-T 用于排除额外文字、检查步骤和 token 长度带来的普通提示收益。

## 5. 配对并不自动保证公平

同图控制了图像来源，但问题仍可能在语言和基线难度上不同，因此必须同时控制：

- P/R/PR 的正确选项 A/B/C/D 各自平衡；
- 问题长度、选项长度与答案类型分布；
- 不使用家族特有的明显模板词；
- guides 的 token 数和节点数分层报告；
- 不以 locked S accuracy 删去过难或过易的题；
- 只在独立 construction/dev 图上调整模板和预估难度。

主要统计使用 sample 内条件配对，并按 `image_cluster_id` 聚类。正式分析优先采用带 condition、task family 及其交互的混合效应 logistic 模型，至少含 question/item 截距和 image-cluster 截距；同时报告各家族原始 accuracy、paired flip、correct-answer log-prob 与 bootstrap CI。模型设定和排除规则在 G1 结果读取前冻结。

## 6. 数据结构与防泄漏字段

G1 每条题至少保存：

- `image_affordance_review_id`：回指独立 image-only 审核；
- `task_pair_id`、`question_id`、`image_cluster_id`；
- `question_origin=reconstructed`；
- `task_family=P|R|PR`；
- `human_required_evidence`、`human_reasoning_graph`、depth；
- 每项 evidence 的反事实必要性记录；
- P/PR 的困难视觉节点和 V payload provenance；
- T-Q/T-QA guide 链及依赖节点；
- 四选项、答案标签与所有 prompt/image hash；
- 两位独立审核者或一个审核者加独立 adjudicator 的记录。

所有派生题按图像近重复簇整组切分。同一图的 P/R/PR 不得跨 train/dev/test，也不得一部分用于 prompt 调试、另一部分用于 locked 结果。

## 7. 构建顺序

```text
B2a 32 图独立可供性盲校准
  → 判断 M3VQA 图片是否值得继续
  → B3 在 construction/dev 图上试造少量 P/R 对
  → 独立人工验证最小证据与反事实必要性
  → 先完成 1017 G0 teacher-gap
  → 仅在 G0 Go 后扩大图内配对
  → 冻结 G1 image clusters、题目、V/T payload 和统计方案
  → 一次性运行全部条件
```

B2a 当前每图只要求写一个最清楚的 R/PR 目标，它是校准图像来源和审核标准，不是要求审核者现在完成 P/R/PR 三题。配对构造留到 B3 construction/dev，避免在 teacher gap 尚未出现时投入 400 题成本。

## 8. 可支持和不可支持的论文结论

跨数据集分层结果可以说明某配方在某来源表现较好，但不足以证明 V/T 分别专门改善感知/推理。图内配对且通过反事实证据审核后，显著的 `condition × task_family` 交互才更接近该机制主张。

即使 `Spec_T>0`，也不能声称文本模态天然等于推理；准确表述应是：在固定图像上，当前结构化文本特权对人类验证的关系推理任务产生了更大的增益。若 `Spec_T≈0`，仍需区分 G 信息不足、模型不会使用 G 和任务家族未分离，而不能把结果改写成筛题规则。
