# 2106-T-261011-样本与结果可视化交付

## 1. 目的

为便于检查模型输出结构及其与视觉任务的对应关系，本次将最终有效审计任务（Slurm 59944935）的样本、题目、模型输出、答案正确性和输出类型整理为可直接浏览的 HTML 样本面板。

## 2. 展示内容

每个样本卡片包含：

- 样本编号与服务器原图对应的缩略图；
- 题目与选项；
- Thinking=True 与 Thinking=False 的回答；
- 两种设置相对于参考答案的正确/错误标识；
- 只有答案、相关推理/证据、有内容但与推理无关的归类；
- 是否先给答案、推理是否与决策相关；
- 视觉证据摘要和人工图像复核状态。

## 3. 当前结果

本次展示共包含 12 条样本：

- 两种设置均为 10/12 正确；
- 12/12 均被归为相关推理/证据；
- 0 条只有答案；
- 0 条有内容但与推理无关；
- 样本 393、127 的推理内容与题目相关，但最终选择错误。

相关推理/证据是对输出文本结构和内容的审计分类，不等于已经独立证明模型确实正确看到了图像。图像已从服务器原始路径生成低分辨率缩略图，并通过 GitHub 中转回本地；人工图像复核状态仍保留为 pending_image_review。

## 4. 交付物与使用方式

- viewable_audit_59944935.html：双击即可在浏览器中查看，也可从浏览器打印为 PDF；
- make_viewable_audit.py：根据两份 JSONL 输出和人工审计 CSV 重新生成页面；
- assets：服务器生成的 12 张缩略图，仅用于可视化展示，不替代原始 benchmark 数据；
- manual_audit_59944935.csv 与 manual_audit_59944935.md：结构化和文字版审计结果。

打开 HTML 后先看顶部摘要，再看逐样本卡片。重点样本为 393 和 127，它们说明有推理不能直接等同于答案正确。

## 5. 版本与可复现性

缩略图在 Leonardo 服务器端使用项目 VisAlloc 环境中的 PIL 生成，仅新增并提交 Phase2 审计资产，没有安装或修改公共系统环境，也没有使用 SSH 传递文件。资产通过服务器仓库提交、GitHub 中转、本地 no-ff merge 获取。页面由归档的 59944935 输出重新生成，没有重新提交 GPU 任务。
