# 2106-T-261011-样本与结果可视化交付

## 1. 目的

为便于检查模型输出结构及其与视觉任务的对应关系，本次将有效审计样本、题目、模型输出、答案正确性和输出类型整理为可直接浏览的 HTML 样本面板。

## 2. 展示内容

每个样本卡片包含：

- 样本编号与对应图像；
- 题目与选项；
- Thinking=True 与 Thinking=False 的回答；
- 两种设置相对于参考答案的正确/错误标识；
- 只有答案、相关推理/证据、有内容但与推理无关的归类；
- 是否先给答案、推理是否与决策相关；
- 视觉证据摘要和人工图像复核状态。

## 3. 当前结果

本次展示共包含 12 条样本：

- 两种设置均为 10/12 正确；
- 12/12 均被归为相关推理/证据；
- 0 条只有答案；
- 0 条有内容但与推理无关；
- 样本 393、127 的推理内容与题目相关，但最终选择错误。

相关推理/证据是对输出文本结构和内容的审计分类，不等于已经独立证明模型确实正确看到了图像。图像事实的独立复核仍待完成。

## 4. 交付物与使用方式

- viewable_audit_59944935.html：可直接在浏览器中查看，也可打印为 PDF；
- manual_audit_59944935.csv 与 manual_audit_59944935.md：逐样本结构化和文字版审计结果；
- make_viewable_audit.py：用于根据固定输入重新生成展示页面。

打开 HTML 后先看顶部摘要，再看逐样本卡片。重点样本为 393 和 127，它们说明有推理不能直接等同于答案正确。

## 5. 版本与可复现性

页面由固定的模型输出和人工审计数据重新生成。展示图像统一缩放并嵌入页面；页面不依赖外部图像文件。
