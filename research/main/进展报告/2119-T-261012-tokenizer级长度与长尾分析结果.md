# 2119-T-261012-tokenizer级长度与长尾分析结果

## 1. 执行概况

依据 2118 的固定方案，对正式作业 `60011513` 的五组原始 JSONL 执行 tokenizer 级长度分析。正式 vLLM 记录每条样本的 `usage.prompt_tokens`、`usage.completion_tokens` 和 `usage.total_tokens`，因此本次使用服务端实际计数，不使用替代 tokenizer 离线估计。

完整性检查结果：

- 五组各 2000 条，共 10000 条；
- 10000/10000 条均具有完整 `usage` 字段；
- 10000/10000 条均具有 `prompt_tokens` 和 `completion_tokens`；
- `(sample_id, condition)` 唯一组合数为 10000；
- 五组模型标识均为 `OPD-V-Qwen3.5-4B`；
- 与既有 `per_sample.csv` 一对一合并后仍为 10000 条。

## 2. Tokenizer 级主要结果

| 条件 | 输入 token 均值 | 输出 token 均值 | 输出 token 中位数 | 输出偏度 | Pearson r | Spearman ρ |
|---|---:|---:|---:|---:|---:|---:|
| S0 | 716.1 | 114.1 | 85.0 | 7.19 | -0.132 | -0.107 |
| SC | 741.1 | 112.7 | 82.0 | 8.02 | -0.091 | -0.088 |
| S1 | 750.1 | 60.4 | 52.0 | 17.54 | -0.160 | -0.177 |
| S2 | 750.1 | 95.1 | 72.0 | 8.58 | -0.074 | -0.138 |
| S3 | 761.1 | 55.7 | 43.0 | 14.25 | -0.137 | -0.324 |

相对 S0，输入 token 的配对平均增量为：SC `+25`、S1 `+34`、S2 `+34`、S3 `+45`。这说明 system message 确实改变了输入 token 数；因此不能说中性 system prompt 对输入 token 数没有影响。更准确的结论应区分输入长度和输出行为。

输出 token 的配对平均变化为：SC `-1.39`、S1 `-53.67`、S2 `-18.98`、S3 `-58.36`。S1、S3 的输出压缩幅度最大。

## 3. 答对与答错比较

| 条件 | 答对平均输出 token | 答错平均输出 token |
|---|---:|---:|
| S0 | 101.2 | 134.7 |
| SC | 103.1 | 128.2 |
| S1 | 53.3 | 80.7 |
| S2 | 88.3 | 105.4 |
| S3 | 46.7 | 78.4 |

五个条件中，答对样本的平均输出 token 数均低于答错样本。长度—正确性相关也全部为负，其中 S3 的 Spearman ρ 为 `-0.324`，最明显；但这些结果仍然是关联，不构成长度导致准确率变化的因果证明。

## 4. 长尾分析

| 条件 | P95 | P99 | 最大值 | P95 样本数 | P95 长尾准确率 |
|---|---:|---:|---:|---:|---:|
| S0 | 237.2 | 688.1 | 2048 | 100 | 45.0% |
| SC | 232.0 | 662.0 | 2048 | 100 | 48.0% |
| S1 | 110.0 | 275.0 | 2048 | 105 | 31.4% |
| S2 | 191.0 | 511.0 | 2048 | 204 | 53.0% |
| S3 | 106.0 | 233.2 | 2048 | 101 | 52.0% |

最大值达到 `2048`，与实验的 `max_tokens=2048` 一致，说明至少部分极端长输出触及生成上限，不能只作为普通自然长尾处理。后续需要结合 raw 输出确认这些样本是合理长回答、重复/循环、格式失败还是生成截断。

P95 长尾准确率并非全部低于总体准确率，因此“长输出必然错误”不成立。长尾分析应继续按任务类型、条件、格式合规和原始文本行为分层。

## 6. 阶段性结论

tokenizer 级结果确认了此前字符数分析的主要方向：S1、S3 的输出明显更短，答对样本普遍更短，长度与准确率呈负相关，且输出分布右偏。

同时，tokenizer 级统计补充了两个重要限制：第一，system prompt 会直接增加输入 token 数，不能把“没有明显输出变化”表述成“没有输入 token 影响”；第二，部分最大输出触及 `max_tokens=2048`，需要把截断/上限触发作为长尾审计的一部分。

当前最稳妥的研究结论是：不同 system prompt 改变了视觉问答模型的输入长度和输出行为，S1/S3 在本次配对实验中实现了更强的输出压缩并伴随更高准确率；其因果机制和跨重复稳定性仍需继续验证。
