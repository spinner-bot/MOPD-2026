## 0. 评估结论

项目的科学问题仍然成立，但当前最主要的风险不在 OPSD 训练实现，而在于尚未证明文本特权能够形成足够大的、正确方向的 teacher advantage。现阶段已经修复并验证了 T02 的工程管线，却尚未产生正式 Stage 0 的 S/T/V/VT 性能结果。

当前工作应从“先完成整套数据与全部消融”调整为“先完成一个小而可信的 teacher-gap 探索实验”。这个实验需要使用对完整图像成立、无需外部知识、具有真实推理瓶颈的 R/PR 样本，直接测量：

\[
Perf(I,G,Q)-Perf(I,Q)
\]

若该差距足够大，再扩建正式数据、补齐完整控制并进入 T-only OPSD pilot；若差距很小，应优先修改数据与 G 的构造方式，而不是直接扩大数据量或启动长时间训练。

本次评估还确认：Vision-OPD 的图片选择与问题构造均强烈偏向 P；M3VQA 的图片具有潜在 R/PR 价值，但其原始问题大量依赖外部知识。两者都不应未经处理直接承担 Track B 的完整数据角色。

## 2. 两层流程必须分开

项目包含两套不同编号：

### 2.1 T00–T08：制作并验收实验数据

```text
原始资源
  → T00 来源与资产登记
  → T01 候选池统一与预分层
  → T02 视觉结构与证据区域
  → T03 latent reasoning graph 与 guide QA
  → T04 四选项与文本控制
  → T05 独立质量判断与分流
  → T06 人工分层审核
  → T07 图像级无泄漏切分与冻结
  → T08 frozen manifest 消费接口验收
```

这是一条数据集构建—质量验收流水线。它的输出才是正式科学实验可以消费的数据。

### 2.2 Stage 0–9：验证科学假设

正式 Stage 0 在 T08 之后才开始。Stage 0 使用 frozen checkpoint 在同一批冻结样本上运行 S、V-crop、V-add、T-Q、T-QA、VT、T-random、T-shuffle、T-generic 九种条件，测量 privilege gap。只有 Stage 0 达到 Go 条件，才进入 T-only OPSD 训练与后续主实验。

因此：

- T02 runner 就绪不等于 T02 数据完成；
- T02 完整性 gate 通过不等于正式数据通过；
- T00–T08 完成不等于 Stage 0 Go；
- 当前没有 H1 或 H2 的正式结果。

## 3. 科学对象的重新澄清

### 3.1 V/T 是信息条件，不是能力的严格同义词

- V 增加聚焦的视觉证据，主要缓解定位、分辨率和细粒度观察瓶颈；
- T 增加结构化引导问题或中间状态，主要缓解证据搜索、实体跟踪和推理组织瓶颈；
- V 也可能改善后续推理，T 也可能通过引导注意改善感知。

因此“V 偏感知、T 偏推理”是待验证的统计趋势，不是预设恒等关系。

### 3.2 图片具有 affordance，样本类别由图片与问题共同实现

本次讨论形成如下工作假设：图片本身具有 P/R/PR 倾向，但具体样本的任务类别仍由图片、问题和最小证据路径共同决定。

\[
Image\ Affordance=A(I)
\]

\[
Task\ Family=F(I,Q,Minimal\ Evidence\ Path)
\]

| 感知瓶颈 | 推理瓶颈 | 任务层 |
|---|---|---|
| 高 | 低 | P |
| 低 | 高 | R |
| 高 | 高，且属于同一条必要证据链 | PR |
| 低 | 低 | 简单题，通常不进入核心诊断集 |

真正的 PR 不是“图片中同时有小目标和复杂背景”，而是同一道题同时需要困难局部证据与全局关系证据，任一部分缺失都无法得到唯一答案。

### 3.3 对论文主张的含义

更稳固的研究主线是：不同图像—问题结构形成不同信息瓶颈；V 缓解证据分辨率瓶颈，T 缓解推理路径组织瓶颈，VT 在真正 PR 任务上可能互补，也可能因 teacher disagreement 发生干扰。

项目不需要预设 T 在所有视觉问答上都优于 V。具有解释力的结果可以是 P 上 V 强、R 上 T 强、PR 上 VT 协同或出现可解释的冲突。

## 4. 当前源数据与候选池

### 4.1 实际候选组成

当前 `source-normalized.jsonl` 共 19,366 条：

| 来源 | 数量 | 当前预标 | 说明 |
|---|---:|---|---|
| Vision-OPD-6K | 6,241 | P，depth=1 | 原图、teacher crop、训练图、bbox、四选项与答案齐全；缺 guide QA 和文本控制 |
| M3VQA | 12,033 | R | `question_hop>=2` 的粗略预标，尚非正式 R 标签 |
| M3VQA | 1,092 | P | `question_hop=1` 的粗略预标，尚待复核 |
| PR | 0 | — | 当前尚未构建 |

会议和智能纪要中出现的 M3VQA P 数量“1,692”不正确，实际为 1,092。

### 4.2 Vision-OPD 的数据角色

Vision-OPD 不只是题目偏 P，其选图与区域筛选也面向 small target、fine-grained recognition 和 crop advantage，图片分布本身可能具有 P-affordance 偏差。

其原始问题还存在 teacher crop 视角措辞。若 S/T 看完整图，而 V 看 crop，V 条件同时获得“视觉证据增强”和“问题指代被修正”两种优势，会人为放大 V gap。

当前建议：

- 原始数据保留给 Track A 严格复现与视觉对照；
- Track B 可以复用许可允许的原图、bbox 和 crop；
- Track B 的 P 问题应改写或从完整图视角重新生成，并重新审核；
- 不应假设 Vision-OPD 原图足以提供 R/PR 所需的图片结构。

### 4.3 M3VQA 的数据角色

M3VQA 每条记录包含图片、实体、问题、答案、hop、外部文本 evidence、URL 和章节信息，具有多实体、多跳图片来源价值。但其 hop 经常是知识检索跳数，不等于本项目定义的视觉 reasoning depth。

大量原题依赖地理、历史、药用、食物起源等 Wikipedia 事实。若直接用于核心 R 层，测得的 T 优势可能来自外部知识注入，而非视觉推理路径。

建议分成两条支路：

1. **原题保留支路**：只保留不读取外部 evidence、仅凭图片与问题即可唯一验证答案的记录；
2. **图片再标注支路**：对外部知识依赖题丢弃原问题，保留具有 R/PR affordance 的图片，重新生成闭世界、image-grounded 的问题。

导师在会议中要求先执行第一条支路，快速测试效果；第二条支路在确认 teacher gap 后再投入，以控制前期成本。

M3VQA 在正式方案中同时承担外部长推理 benchmark 的候选角色。若其图片或问题进入方法选择、训练或内部数据构建，就不能继续把完整 M3VQA 当作未见外部 benchmark。必须提前在 `source_image_id` 及近重复/实体簇级别划分内部构建池与冻结外部评测池，或明确放弃官方全量 benchmark 的独立性主张。

## 5. T02 下午实验的事实与含义

### 5.1 v1：工程输出不可用于科学判断

- 作业链：`56995520`；
- 1,200 条全部来自 Vision-OPD P 候选；
- 严格校验 0 accepted，全部 `invalid_json`；
- 宽松重解析后 93 accepted（7.75%）；
- 82.0% 截断在 thinking 链中，10.6% 截断在 JSON 中；
- bbox 实际为 norm1000，旧程序按像素解释并静默通过。

该结果反映 runner、token budget、解析与坐标合约失败，不证明 9B 模型能力不足，也不测量 T teacher gap。

### 5.2 v2/v2.1：T02 工程配置得到验证

v2 关闭 thinking、提高 token 上限、显式采用 norm1000、增加确定性坐标换算、EOS 截断标记、鲁棒 JSON 提取与 canary。v2 首次 canary 因把 accept rate 错当配置健康指标而熔断；随后门控改为只阻断解析、截断、runner 错误和记录不完整等配置故障。

v2.1 全量结果：

- 1,200/1,200 条记录完整；
- accepted 353（29.4%）；
- invalid JSON 2；
- accepted bbox 对 source bbox 的 median IoU 0.894；
- 97% accepted 样本存在 bbox 重叠，0 越界；
- 吞吐约 1,375 条/h/4GPU。

这证明 T02 的结构化输出和坐标换算已基本可信。353 条只是 T02 accepted 候选，仍未经过 T03–T06，也不是模型答题准确率或正式 P 数据。

### 5.3 thinking A/B：发现选择偏差与成本边界

同批 96 条对照，thinking 3072 条件下：

- non-thinking reject → thinking accept：42/70（60%）；
- accept → reject：0/25；
- 翻转样本 bbox 95% 与参考区域重叠，median IoU 0.710；
- thinking 截断率 33%；
- 吞吐成本约为 non-thinking 的 14 倍。

该结果表明 non-thinking 对困难小目标存在系统性提前放弃；只沿用 353 条 accepted 会使 P 数据偏向容易、显著目标。它同时不能修复 crop 视角问题，也不能直接外推为全量 P 的真实接受率。生产 thinking 配置应在问题视角修正后的干净样本上重新比较。

## 6. 导师观点分析

### 6.1 导师认可的部分

导师明确认可：

- 训练前 teacher gap 与训练后 transfer 必须分开；
- V 与 T 可能有不同作用侧重；
- VT 不保证叠加最优，可能存在冲突；
- Qwen3.5 的主比较应关闭 thinking，以测量内化能力；
- 文本引导可能固定思维模式并降低探索或泛化，需要后续检查；
- Vision-OPD 数据明显偏向视觉特权，不利于观察较大的文本效应；
- 有必要建设更适合文本引导的数据。

### 6.2 导师的核心判断

导师把项目压缩为两个可操作问题：

1. 是否能通过输入条件显著提高 privileged teacher 的正确表现；
2. 是否能提高 teacher advantage 向 student 的蒸馏效率。

最终标准是学生在目标 benchmark 上的提升。导师特别强调 effect size：其早期经验中，视觉 crop teacher 可能提高二三十个百分点，而文本方案只提高两三个点；若初始 teacher advantage 很小，蒸馏后收益可能更小，难以形成有竞争力的贡献。

这组历史数字尚无当前仓库中的可审计配置与结果，不能作为正式基线，但应作为高优先级经验先验。下一步需要先取得新的、可复现的 teacher-gap 数据。

### 6.3 导师的执行哲学

导师认为当前方案在取得核心信号前展开了过多变量、消融和数据细节，要求：

- 先用直观方法做最小实验；
- 报告方法、样本量、提升幅度和翻转数；
- 有效果后再扩展和解释；
- 无明显效果时快速调整，避免数据预处理长期卡在前端；
- 保留多模态与 GPU 方向的技术门槛，避免退化为竞争拥挤的纯文本提示研究。

这一指导应转化为“探索阶段精简、确认阶段完整”，而不是删除正式研究所需的控制、冻结、统计和负迁移检查。

### 6.4 会议中的关键误解

导师询问 H1 使用多少样本时，会议中回答了“1,200”，智能纪要进一步写成“引导性问题序列在 1,200 个样本上已验证有效”。这与事实不符：

- 1,200 是 T02 预处理 pilot；
- 没有运行 S 与 T-Q/T-QA 的配对答题；
- 没有 accuracy gap、correct-answer log-prob gap 或 H1 结论。

下次向导师汇报时必须主动纠正。当前最准确的状态是“尚无 teacher-gap 性能结果”。

## 8. 主要风险

1. **teacher gap 尚未测量**：当前工作量较大，但最核心的可行性指标仍为空。
2. **P 层问题视角混杂**：crop-relative wording 会人为放大 V 相对 S/T 的优势。
3. **来源与任务层混杂**：P 几乎来自 Vision-OPD，R 几乎来自 M3VQA；后续的 P/R 差异可能是数据域差异。
4. **M3VQA 外部知识依赖**：T 可能变成知识注入，而非 reasoning-path privilege。
5. **M3VQA benchmark 污染**：内部使用后不能继续声称完整官方集是未见外部评测。
6. **PR 数据缺失**：当前无法验证 VT 互补的核心场景。
7. **同模型生成与校验偏差**：T03/T05 使用相同 checkpoint，可能产生相关错误；人工审核仍是必要门控。
8. **thinking 改变数据分布**：non-thinking 偏向容易目标，thinking 成本高且仍截断；选择策略必须留痕并分层报告。
9. **过度设计与后验解释并存**：前期实验过多会延迟核心信号，看到结果后再筛数据又会引入选择偏差。

## 9. 建议的最小执行路线

### 9.1 先做探索性 teacher-gap pilot

在正式 Stage 0 之前建立一个新的 exploratory run，不改写为正式结论：

1. 从 M3VQA 预标 R 中快速筛选一小批 image-only answerable 样本；
2. 暂时直接剔除明显依赖外部知识的原题，不在第一轮批量重写；
3. 对保留样本生成最小 T-Q/T-QA，并进行 100% 人工 image-only 审核；
4. 使用 frozen Qwen3.5-4B、non-thinking 运行配对条件；
5. 不训练，仅测 teacher advantage。

建议第一轮条件：

| 条件 | 用途 |
|---|---|
| S：`I,Q` | 基线 |
| T-Q：`I,G_Q,Q` | 检验纯引导问题序列 |
| T-QA：`I,G_QA,Q` | 检验中间状态 privilege |
| Generic-T | 排除普通提示效应 |
| V-add：`I,C,Q` | 与视觉 teacher advantage 比较 |
| VT | 初步观察互补或干扰 |

第一轮必须输出：样本量、各条件 accuracy、正确答案 log-prob、paired gap、错→对/对→错翻转、拒绝原因、外部知识剔除率、代表性成功与失败样例、吞吐和运行配置。

“足够大的效果”尚未形成量化共识。应在读取结果前固定探索转正式的门槛；至少要求方向一致、correct-answer log-prob 改善、效果明显高于随机波动，并具有继续蒸馏的实际空间。正式 Stage 0 仍执行方案 §22–§23 的完整 Go/No-Go。

### 9.2 根据 pilot 结果分流

| 结果 | 下一步 |
|---|---|
| T-Q 形成明显 teacher gap | 保持 Guiding-Question PI 主线，扩大正式数据 |
| 只有 T-QA 明显有效 | 主方法改为 Privileged Reasoning-Path Distillation，T-Q 保留为消融 |
| R 上 T 有效、P 上较弱 | 以瓶颈分层和适用范围为核心结论 |
| teacher gap 存在但学生无法转移 | 转向蒸馏损失、EMA、rollout 与 teacher-student mismatch |
| T-Q/T-QA 均无明显 gap | 暂停 OPSD，修改 G、任务构造或数据来源 |
| 只有知识依赖题有效 | 不能声称视觉推理增强；需重新定义研究范围 |

### 9.3 teacher gap 成立后再扩建数据

第二阶段再投入：

- 对 M3VQA 高 affordance 图片重新出闭世界 R/PR 问题；
- 从完整图视角重建 Vision-OPD-derived P；
- 增加 question-independent image affordance screening；
- 尽量在多个来源、甚至同一原图上构造 P/R/PR，降低来源混杂；
- 补齐 random、shuffle、generic、visual sham、dependency test；
- 完成 T05/T06 后再冻结 T07/T08；
- 正式 Stage 0 Go 后才进入 1K–2K T-only OPSD pilot。

### 已形成共识

- 主比较使用 non-thinking，thinking 单独做压力测试；
- 先取得可审计的 teacher-gap 数据，再扩大研究矩阵；

## 附录 A：会后关于图片 P/R/PR 倾向的讨论原文存档

本附录保留本次中期评估形成前，spinner-bot 提出的核心想法及 Codex 的回应。正文 §3.2、§4 与 §9 已吸收其结论；附录用于保存原始问题意识和完整论证过程。

### A.1 spinner-bot 的原始想法

首先，spinner-bot 对整条方法主线提出了如下担忧：

> 我现在有一个担心：text 模态对应推理，而 vision 对应感知。现在做的事情是：让模型看图回答问题，并通过 OPSD-v-t 提升它的这项能力。但是，这似乎是一个陷阱：“看图”这本身即严重倾向感知层（P），推理在图片理解中的作用远没有感知重要，因此可推测，T 特权也远没有 V 特权效果好。我现在想要发顶会，数据必须漂亮（有成效），并且我是基于 Vision-OPD 的。但我和 Vision-OPD 的区别就是引入了 G（引导性问题序列，属于文本特权信息），其他仅为辅助或不影响大局（对照组、不同的引导策略、消融实验等）。从理论上讲，我怀疑可能不会产生很好的效果。但我同时认为，数据是决定效果的根源。这不是“造成果”，而是不同方法本来就有它擅长的数据子类。在这个实验的方法下，似乎更优的数据子类，是那些隐含大量逻辑信息的图片（推理层因此发挥更多作用，仅依靠感知不容易获取到信息）（如果这个图片同时具有一定感知难度，则可划分为 PR 倾向，如果感知难度低，则可划分为 P 倾向）（我能想到的例子：有一种推理/悬疑小说，其中有基于图片的解谜问题。这似乎是这项实验的一个理想数据来源……需要推理解谜（有的时候谜题还与数学、额外知识、小说上下文有关，这是需要注意的地方））但必须承认，制备这样的数据集，难度更高……总之，这一切还是我的思考，并没有明确的落地打算。我也很迷茫。

编者注：上段按原意存档；结合前后文，其中“感知难度低，则可划分为 P 倾向”很可能想表达“R 倾向”，后续定义以 P=感知、R=推理、PR=二者联合为准。

在讨论 M3VQA 是否应因外部知识依赖而整体舍弃时，spinner-bot 又提出：

> 我们是不是可以进行筛选：把需要外部知识的过滤掉。并在设计问题时，尽可能让回答无需依赖外部知识？不然，如果把整个 M3VQA 全扔出去了，我们好像就失去了一个 R 相关的重要数据来源。Vision-OPD 的原始数据集必定侧重 P；即使问题能修改，也不排除他们团队在初期筛选原图时，去除了一些“适合构建 R 系问题的图片（我简称 R 系图片）”，除非试图引入其他数据集。

随后，这一判断被凝练为：

> 我的假设是：图片本身也有 PR 倾向，而不仅仅取决于问题如何提出。

该想法承接此前对 Vision-OPD 与 M3VQA 的讨论：Vision-OPD 不仅原问题偏向细粒度感知，其原图也可能经过有利于小目标和 crop advantage 的选择；M3VQA 原问题虽有外部知识依赖，其多实体图片本身仍可能具有较高的 R/PR 构题价值。因此，不能只通过修改问题就假设两个来源拥有相同的任务潜力。

### A.2 Codex 对“V 强、T 弱”风险及数据主线的回应

这个担忧触及了项目最核心的可行性风险，而且推理方向基本正确：如果目标问题的主要瓶颈是“看清局部证据”，视觉 crop 会直接改变可见信息，V teacher 获得很大的优势很自然；文本引导 G 若只是在模型已经看清的内容上重述步骤，T teacher 很可能只增加少量收益。当前 Vision-OPD 的图像选择和问题构造均偏向这种情形，所以不能用它单独判断文本特权路线是否有效。

但“视觉问答整体偏感知”并不能直接推出 T 特权无效。视觉问答中至少有两类可分离的瓶颈：

1. **证据可见性瓶颈**：目标太小、模糊、遮挡或需要 OCR，主要受益于 V；
2. **证据组织瓶颈**：模型需要确定先看什么、连接哪些实体、排除哪些干扰、完成哪些不可省略的中间判断，可能受益于 T。

G 的价值不在于替代图像，而在于降低第二类瓶颈。如果数据几乎只有第一类瓶颈，T 的弱势是任务与方法不匹配的结果，不能被解释为所有文本特权都无效。

因此，寻找更适合方法的数据子类本身是合理的机制设计，不等于为了结果挑数据。前提是先给出与模型结果无关的纳入标准，并同时报告不同层上的表现：

- P：主要需要困难局部证据，用作 V 优势锚点；
- R：图像证据可见，但必须经过多实体、多区域或多步关系整合；
- PR：同一条最小证据路径同时需要困难局部观察和关系推理。

如果只保留 T 表现好的样本再报告结果，就会形成选择偏差；如果先按可审计规则定义 P/R/PR，再检验 `method × task family` 交互，则是在验证“不同特权信息分别作用于什么瓶颈”这一研究假设。即使总体平均增益不最大，稳定且可复现的分层效应也能形成更有解释力的贡献。

悬疑图像、视觉谜题、图表推理、流程图、多人多物关系场景确实可能提供 R/PR 原料，但不能直接整包使用。数学知识、小说上下文、常识或网页知识一旦成为必要证据，T teacher 的收益就可能来自知识注入，而不是引导图像推理。第一版应优先选择闭世界样本：答案及每个必要中间结论都能由图像和题面给出，不需要未提供的外部事实。

M3VQA 因此不应整体丢弃。可先进行低成本分流：

1. 保留无需外部知识、仅依赖图像即可回答的原题；
2. 对原题依赖外部知识、但图片具有 R/PR 可供性的样本，丢弃原题并重写闭世界问题；
3. 对图片本身缺少可组合关系的样本，不强行构造 R/PR；
4. 将用于构题和训练的图片与冻结 benchmark 按源图及近重复簇隔离。

当前最稳妥的落地顺序不是立即制备一个大型新数据集，而是先做一个小规模、冻结模型的 teacher-gap 实验。对人工确认的闭世界 R/PR 样本，以同一底模比较 S、V、T、VT，报告准确率、正确答案概率、paired gap 和错→对翻转。这个实验直接回答三件事：T 是否有足够大的可利用上界；T 的优势是否集中在 R；VT 是否在 PR 上出现互补。只有这些信号成立，才值得投入大规模再标注、引导序列生成和蒸馏训练。

相应的决策逻辑是：

| 观察结果 | 对项目的含义 |
|---|---|
| T 在闭世界 R 上有明显 teacher gap | G 主线具备可行性，可扩大 R/PR 数据 |
| T 较弱，但 T-QA 明显更强 | 问题可能在引导形式或信息量，需要调整 teacher 定义 |
| V 在 P 强、T 在 R 强、VT 在 PR 强 | 最符合“特权信息—任务瓶颈匹配”的机制叙事 |
| T 与 T-QA 在合适样本上仍接近零 | 需缩小或调整文本特权主张，不宜先投入完整流水线 |
| teacher gap 存在但蒸馏后学生无提升 | 问题转移到蒸馏效率与 teacher-student mismatch |

所以，当前的迷茫可以转化成一个明确、可证伪的问题：在不依赖外部知识、具有真实关系推理瓶颈的图像问题上，G 能否让冻结 teacher 显著优于无特权基线？这比先争论整个视觉问答究竟更偏 P 还是 R 更快决定项目是否值得继续，也与导师提出的 effect-first 顺序一致。

### A.3 Codex 对“图片具有 P/R/PR 倾向”假设的完整回应

这个假设成立的可能性很高，而且比“P/R/PR 完全由问题决定”更准确。更严谨的表述是：

> 图片具有潜在的 P、R、PR 可供性（affordance）；具体样本最终属于 P、R 还是 PR，则由图片、问题和证据路径共同决定。

可以写成：

\[
Image\ Affordance=A(I)
\]

\[
Realized\ Task\ Family=F(I,Q,Evidence\ Path)
\]

#### 图片为什么会有 P/R/PR 倾向

图片本身决定了能够构造什么样的真实问题：

| 图片属性 | 更可能支持 |
|---|---|
| 存在很小、模糊、遮挡或需要 OCR 的目标 | P 倾向 |
| 多个实体、动作和关系，证据分散在不同区域 | R 倾向 |
| 小目标同时处于一条多实体、多区域推理链中 | PR 倾向 |
| 单一主体、背景简单、没有可组合关系 | 很难构造真正的 R/PR |

例如，一张单独拍摄的杯子照片，即使人为写三道引导问题，也很难形成真正的 R；那些步骤往往只是把简单识别题拉长。

相反，一张机场全景中同时存在飞机、地勤人员、车辆和远处的小型工具，就天然具有 PR 倾向：

1. 根据人物与车辆的关系锁定目标人物；
2. 查看该人物手中的小物体；
3. 根据物体与接触对象判断行为。

这条路径同时依赖局部小目标的可见性、全局人物和物体关系，以及多步证据整合。

#### PR 倾向不是“同时有小目标和复杂背景”

如果图片左边有一个很小的标志，右边有几个人进行复杂互动，但两者彼此无关，那么它只是同时具备 P 和 R 素材，不一定具备 PR 倾向。

真正的 PR 图片要求存在一条联合路径：

\[
E_{small/local}
\rightarrow H_1
\rightarrow E_{global/relational}
\rightarrow H_2
\rightarrow A
\]

或者：

\[
E_{global}
\rightarrow \text{锁定局部目标}
\rightarrow E_{small}
\rightarrow A
\]

同一道题必须同时需要局部证据和全局关系：

\[
A\not\Leftarrow E_{local}
\]

\[
A\not\Leftarrow E_{global}
\]

\[
A\Leftarrow E_{local}+E_{global}
\]

这才是 PR，而不是把一条 P 题和一条 R 题机械拼在一起。

#### 这解释了 Vision-OPD 与 M3VQA 的差异

Vision-OPD 不只是“问题写成了 P”。它在图片和区域筛选阶段，本来就寻找小目标、crop 后明显更清晰的区域、细粒度属性和单个局部证据可以回答的问题。因此，它很可能同时产生两层偏差：

1. 图片选择偏向 P-affordance；
2. 问题生成偏向 P-task。

即使重写 Vision-OPD 的问题，也不能保证这些图片能提供足够丰富的 R/PR 关系结构。

M3VQA 则相反。它的图片经过多实体、多跳任务筛选，可能天然具有较高的 R-affordance，部分图片也可能有 PR-affordance。其原问题依赖外部知识，并不代表图片没有价值。

因此，对 M3VQA 更合适的处理是：

> 保留其可能具有 R/PR 倾向的图片，重新检查或生成 image-grounded 问题。

#### 数据集应采用双层标签

后续不应只保存最终的 `task_family`，还应保存图片层面的倾向，例如：

```json
{
  "image_affordance": {
    "p_score": 2,
    "r_score": 2,
    "pr_score": 2
  },
  "image_structure": {
    "num_entities": 7,
    "num_relations": 9,
    "num_candidate_regions": 3,
    "has_small_critical_object": true,
    "has_distributed_evidence": true,
    "candidate_reasoning_path_length": 3
  },
  "task_family": "PR"
}
```

两类标签含义不同：

- `image_affordance`：这张图片适合构造什么题；
- `task_family`：当前这道具体问题实际需要什么能力。

图片层标签更适合使用连续分数或多标签，因为一张图可能同时适合 P、R 和 PR。

#### 当前 T02 前需要图片倾向分析

当前 T02 是问题驱动的：

```text
已有图片 + 已有问题 → 寻找问题相关区域
```

它无法回答“这张图片还能不能构造其他 R/PR 问题”。因此，自建数据分支应先做一次与原问题无关的图片解析：

```text
原图
  → 实体、属性、动作、关系、局部目标解析
  → 候选证据图与候选推理路径
  → 计算 P/R/PR affordance
  → 按图片倾向生成 Final Question
  → 验证实际 task family
  → 进入现有 T02–T08
```

affordance screening 问“图片能支持什么问题”；当前 T02 问“当前这道问题需要看哪里”。二者不能相互替代。

#### 如何判断一张图有 PR 倾向

可以预先定义三个维度。

**P-affordance：**

- 是否存在面积较小的可识别目标；
- 是否包含小文字、细粒度属性或遮挡；
- crop 是否能显著提高证据可见性；
- 目标是否仍能在完整图中被合理指代。

**R-affordance：**

- 是否存在多个可区分实体；
- 是否存在人物—物体、人物—人物或物体—物体关系；
- 必要证据是否分布在多个区域；
- 是否存在至少两步不可省略的信息转换；
- 单个局部 crop 是否不足以回答。

**PR-affordance：**

- 推理路径中是否至少包含一个困难局部节点；
- 该局部节点是否与全局关系链直接连接；
- 局部证据或全局证据任一缺失时，答案是否无法确定；
- 是否能构造自然问题，而不是人为拉长链条。

#### 同图构造不同任务可以减少混杂

如果图片允许，可以从同一张图构造一道 P、一道 R 和一道 PR 题。例如：

```text
同一机场图片

P：远处工作人员手中的工具是什么颜色？

R：根据人员与车辆的关系，哪名工作人员负责装卸？

PR：先根据车辆关系锁定装卸人员，再识别其手中的小工具；
    该人员正在执行什么操作？
```

这样可以在相同视觉场景上比较 V/T/VT，减少来源、风格和图片复杂度带来的混杂。同一图片派生的所有问题必须按 `source_image_id` 一起进入同一个 split。

#### 该假设可以转化为可检验的机制预测

\[
Gap_V\uparrow
\quad\text{when}\quad
P\text{-affordance}\uparrow
\]

\[
Gap_T\uparrow
\quad\text{when}\quad
R\text{-affordance}\uparrow
\]

\[
Interaction_{VT}\uparrow
\quad\text{when}\quad
PR\text{-affordance}\uparrow
\]

如果正式结果支持这些关系，论文可以进一步说明：在看到具体问题之前，图片的视觉结构已经部分决定了哪种 privileged information 更有价值。

因此，不应直接丢弃 M3VQA。更合理的路线是将 Vision-OPD 和 M3VQA 视为具有不同图片选择倾向的原料库，先做问题无关的 P/R/PR affordance 分析，再决定哪些图片适合生成哪类问题。最终 P/R/PR 标签仍由具体问题及其最小证据路径确认。
