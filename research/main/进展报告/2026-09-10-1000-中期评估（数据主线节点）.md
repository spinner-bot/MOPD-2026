## 0. 评估结论

项目的科学问题仍然成立，但当前最主要的风险不在 OPSD 训练实现，而在于尚未证明文本特权能够形成足够大的、正确方向的 teacher advantage。现阶段已经修复并验证了 T02 的工程管线，却尚未产生正式 Stage 0 的 S/T/V/VT 性能结果。

当前工作应从“先完成整套数据与全部消融”调整为“先完成一个小而可信的 teacher-gap 探索实验”。这个实验需要使用对完整图像成立、无需外部知识、具有真实推理瓶颈的 R/PR 样本，直接测量：

\[
Perf(I,G,Q)-Perf(I,Q)
\]

若该差距足够大，再扩建正式数据、补齐完整控制并进入 T-only OPSD pilot；若差距很小，应优先修改数据与 G 的构造方式，而不是直接扩大数据量或启动长时间训练。

本次评估还确认：Vision-OPD 的图片选择与问题构造均强烈偏向 P；M3VQA 的图片具有潜在 R/PR 价值，但其原始问题大量依赖外部知识。两者都不应未经处理直接承担 Track B 的完整数据角色。

## 2. 两层流程必须分开

项目包含两套不同编号：

### 2.1 T00–T08：制作并验收实验数据

```text
原始资源
  → T00 来源与资产登记
  → T01 候选池统一与预分层
  → T02 视觉结构与证据区域
  → T03 latent reasoning graph 与 guide QA
  → T04 四选项与文本控制
  → T05 独立质量判断与分流
  → T06 人工分层审核
  → T07 图像级无泄漏切分与冻结
  → T08 frozen manifest 消费接口验收
```

这是一条数据集构建—质量验收流水线。它的输出才是正式科学实验可以消费的数据。

### 2.2 Stage 0–9：验证科学假设

正式 Stage 0 在 T08 之后才开始。Stage 0 使用 frozen checkpoint 在同一批冻结样本上运行 S、V-crop、V-add、T-Q、T-QA、VT、T-random、T-shuffle、T-generic 九种条件，测量 privilege gap。只有 Stage 0 达到 Go 条件，才进入 T-only OPSD 训练与后续主实验。

因此：

- T02 runner 就绪不等于 T02 数据完成；
- T02 完整性 gate 通过不等于正式数据通过；
- T00–T08 完成不等于 Stage 0 Go；
- 当前没有 H1 或 H2 的正式结果。

## 3. 科学对象的重新澄清

### 3.1 V/T 是信息条件，不是能力的严格同义词

- V 增加聚焦的视觉证据，主要缓解定位、分辨率和细粒度观察瓶颈；
- T 增加结构化引导问题或中间状态，主要缓解证据搜索、实体跟踪和推理组织瓶颈；
- V 也可能改善后续推理，T 也可能通过引导注意改善感知。

因此“V 偏感知、T 偏推理”是待验证的统计趋势，不是预设恒等关系。

### 3.2 图片具有 affordance，样本类别由图片与问题共同实现

本次讨论形成如下工作假设：图片本身具有 P/R/PR 倾向，但具体样本的任务类别仍由图片、问题和最小证据路径共同决定。

\[
Image\ Affordance=A(I)
\]

\[
Task\ Family=F(I,Q,Minimal\ Evidence\ Path)
\]

| 感知瓶颈 | 推理瓶颈 | 任务层 |
|---|---|---|
| 高 | 低 | P |
| 低 | 高 | R |
| 高 | 高，且属于同一条必要证据链 | PR |
| 低 | 低 | 简单题，通常不进入核心诊断集 |

真正的 PR 不是“图片中同时有小目标和复杂背景”，而是同一道题同时需要困难局部证据与全局关系证据，任一部分缺失都无法得到唯一答案。

### 3.3 对论文主张的含义

更稳固的研究主线是：不同图像—问题结构形成不同信息瓶颈；V 缓解证据分辨率瓶颈，T 缓解推理路径组织瓶颈，VT 在真正 PR 任务上可能互补，也可能因 teacher disagreement 发生干扰。

项目不需要预设 T 在所有视觉问答上都优于 V。具有解释力的结果可以是 P 上 V 强、R 上 T 强、PR 上 VT 协同或出现可解释的冲突。

## 4. 当前源数据与候选池

### 4.1 实际候选组成

当前 `source-normalized.jsonl` 共 19,366 条：

| 来源 | 数量 | 当前预标 | 说明 |
|---|---:|---|---|
| Vision-OPD-6K | 6,241 | P，depth=1 | 原图、teacher crop、训练图、bbox、四选项与答案齐全；缺 guide QA 和文本控制 |
| M3VQA | 12,033 | R | `question_hop>=2` 的粗略预标，尚非正式 R 标签 |
| M3VQA | 1,092 | P | `question_hop=1` 的粗略预标，尚待复核 |
| PR | 0 | — | 当前尚未构建 |

会议和智能纪要中出现的 M3VQA P 数量“1,692”不正确，实际为 1,092。

### 4.2 Vision-OPD 的数据角色

Vision-OPD 不只是题目偏 P，其选图与区域筛选也面向 small target、fine-grained recognition 和 crop advantage，图片分布本身可能具有 P-affordance 偏差。

其原始问题还存在 teacher crop 视角措辞。若 S/T 看完整图，而 V 看 crop，V 条件同时获得“视觉证据增强”和“问题指代被修正”两种优势，会人为放大 V gap。

当前建议：

- 原始数据保留给 Track A 严格复现与视觉对照；
- Track B 可以复用许可允许的原图、bbox 和 crop；
- Track B 的 P 问题应改写或从完整图视角重新生成，并重新审核；
- 不应假设 Vision-OPD 原图足以提供 R/PR 所需的图片结构。

### 4.3 M3VQA 的数据角色

M3VQA 每条记录包含图片、实体、问题、答案、hop、外部文本 evidence、URL 和章节信息，具有多实体、多跳图片来源价值。但其 hop 经常是知识检索跳数，不等于本项目定义的视觉 reasoning depth。

大量原题依赖地理、历史、药用、食物起源等 Wikipedia 事实。若直接用于核心 R 层，测得的 T 优势可能来自外部知识注入，而非视觉推理路径。

建议分成两条支路：

1. **原题保留支路**：只保留不读取外部 evidence、仅凭图片与问题即可唯一验证答案的记录；
2. **图片再标注支路**：对外部知识依赖题丢弃原问题，保留具有 R/PR affordance 的图片，重新生成闭世界、image-grounded 的问题。

导师在会议中要求先执行第一条支路，快速测试效果；第二条支路在确认 teacher gap 后再投入，以控制前期成本。

M3VQA 在正式方案中同时承担外部长推理 benchmark 的候选角色。若其图片或问题进入方法选择、训练或内部数据构建，就不能继续把完整 M3VQA 当作未见外部 benchmark。必须提前在 `source_image_id` 及近重复/实体簇级别划分内部构建池与冻结外部评测池，或明确放弃官方全量 benchmark 的独立性主张。

## 5. T02 下午实验的事实与含义

### 5.1 v1：工程输出不可用于科学判断

- 作业链：`56995520`；
- 1,200 条全部来自 Vision-OPD P 候选；
- 严格校验 0 accepted，全部 `invalid_json`；
- 宽松重解析后 93 accepted（7.75%）；
- 82.0% 截断在 thinking 链中，10.6% 截断在 JSON 中；
- bbox 实际为 norm1000，旧程序按像素解释并静默通过。

该结果反映 runner、token budget、解析与坐标合约失败，不证明 9B 模型能力不足，也不测量 T teacher gap。

### 5.2 v2/v2.1：T02 工程配置得到验证

v2 关闭 thinking、提高 token 上限、显式采用 norm1000、增加确定性坐标换算、EOS 截断标记、鲁棒 JSON 提取与 canary。v2 首次 canary 因把 accept rate 错当配置健康指标而熔断；随后门控改为只阻断解析、截断、runner 错误和记录不完整等配置故障。

v2.1 全量结果：

- 1,200/1,200 条记录完整；
- accepted 353（29.4%）；
- invalid JSON 2；
- accepted bbox 对 source bbox 的 median IoU 0.894；
- 97% accepted 样本存在 bbox 重叠，0 越界；
- 吞吐约 1,375 条/h/4GPU。

这证明 T02 的结构化输出和坐标换算已基本可信。353 条只是 T02 accepted 候选，仍未经过 T03–T06，也不是模型答题准确率或正式 P 数据。

### 5.3 thinking A/B：发现选择偏差与成本边界

同批 96 条对照，thinking 3072 条件下：

- non-thinking reject → thinking accept：42/70（60%）；
- accept → reject：0/25；
- 翻转样本 bbox 95% 与参考区域重叠，median IoU 0.710；
- thinking 截断率 33%；
- 吞吐成本约为 non-thinking 的 14 倍。

该结果表明 non-thinking 对困难小目标存在系统性提前放弃；只沿用 353 条 accepted 会使 P 数据偏向容易、显著目标。它同时不能修复 crop 视角问题，也不能直接外推为全量 P 的真实接受率。生产 thinking 配置应在问题视角修正后的干净样本上重新比较。

## 6. 导师观点分析

### 6.1 导师认可的部分

导师明确认可：

- 训练前 teacher gap 与训练后 transfer 必须分开；
- V 与 T 可能有不同作用侧重；
- VT 不保证叠加最优，可能存在冲突；
- Qwen3.5 的主比较应关闭 thinking，以测量内化能力；
- 文本引导可能固定思维模式并降低探索或泛化，需要后续检查；
- Vision-OPD 数据明显偏向视觉特权，不利于观察较大的文本效应；
- 有必要建设更适合文本引导的数据。

### 6.2 导师的核心判断

导师把项目压缩为两个可操作问题：

1. 是否能通过输入条件显著提高 privileged teacher 的正确表现；
2. 是否能提高 teacher advantage 向 student 的蒸馏效率。

最终标准是学生在目标 benchmark 上的提升。导师特别强调 effect size：其早期经验中，视觉 crop teacher 可能提高二三十个百分点，而文本方案只提高两三个点；若初始 teacher advantage 很小，蒸馏后收益可能更小，难以形成有竞争力的贡献。

这组历史数字尚无当前仓库中的可审计配置与结果，不能作为正式基线，但应作为高优先级经验先验。下一步需要先取得新的、可复现的 teacher-gap 数据。

### 6.3 导师的执行哲学

导师认为当前方案在取得核心信号前展开了过多变量、消融和数据细节，要求：

- 先用直观方法做最小实验；
- 报告方法、样本量、提升幅度和翻转数；
- 有效果后再扩展和解释；
- 无明显效果时快速调整，避免数据预处理长期卡在前端；
- 保留多模态与 GPU 方向的技术门槛，避免退化为竞争拥挤的纯文本提示研究。

这一指导应转化为“探索阶段精简、确认阶段完整”，而不是删除正式研究所需的控制、冻结、统计和负迁移检查。

### 6.4 会议中的关键误解

导师询问 H1 使用多少样本时，会议中回答了“1,200”，智能纪要进一步写成“引导性问题序列在 1,200 个样本上已验证有效”。这与事实不符：

- 1,200 是 T02 预处理 pilot；
- 没有运行 S 与 T-Q/T-QA 的配对答题；
- 没有 accuracy gap、correct-answer log-prob gap 或 H1 结论。

下次向导师汇报时必须主动纠正。当前最准确的状态是“尚无 teacher-gap 性能结果”。

## 8. 主要风险

1. **teacher gap 尚未测量**：当前工作量较大，但最核心的可行性指标仍为空。
2. **P 层问题视角混杂**：crop-relative wording 会人为放大 V 相对 S/T 的优势。
3. **来源与任务层混杂**：P 几乎来自 Vision-OPD，R 几乎来自 M3VQA；后续的 P/R 差异可能是数据域差异。
4. **M3VQA 外部知识依赖**：T 可能变成知识注入，而非 reasoning-path privilege。
5. **M3VQA benchmark 污染**：内部使用后不能继续声称完整官方集是未见外部评测。
6. **PR 数据缺失**：当前无法验证 VT 互补的核心场景。
7. **同模型生成与校验偏差**：T03/T05 使用相同 checkpoint，可能产生相关错误；人工审核仍是必要门控。
8. **thinking 改变数据分布**：non-thinking 偏向容易目标，thinking 成本高且仍截断；选择策略必须留痕并分层报告。
9. **过度设计与后验解释并存**：前期实验过多会延迟核心信号，看到结果后再筛数据又会引入选择偏差。

## 9. 建议的最小执行路线

### 9.1 先做探索性 teacher-gap pilot

在正式 Stage 0 之前建立一个新的 exploratory run，不改写为正式结论：

1. 从 M3VQA 预标 R 中快速筛选一小批 image-only answerable 样本；
2. 暂时直接剔除明显依赖外部知识的原题，不在第一轮批量重写；
3. 对保留样本生成最小 T-Q/T-QA，并进行 100% 人工 image-only 审核；
4. 使用 frozen Qwen3.5-4B、non-thinking 运行配对条件；
5. 不训练，仅测 teacher advantage。

建议第一轮条件：

| 条件 | 用途 |
|---|---|
| S：`I,Q` | 基线 |
| T-Q：`I,G_Q,Q` | 检验纯引导问题序列 |
| T-QA：`I,G_QA,Q` | 检验中间状态 privilege |
| Generic-T | 排除普通提示效应 |
| V-add：`I,C,Q` | 与视觉 teacher advantage 比较 |
| VT | 初步观察互补或干扰 |

第一轮必须输出：样本量、各条件 accuracy、正确答案 log-prob、paired gap、错→对/对→错翻转、拒绝原因、外部知识剔除率、代表性成功与失败样例、吞吐和运行配置。

“足够大的效果”尚未形成量化共识。应在读取结果前固定探索转正式的门槛；至少要求方向一致、correct-answer log-prob 改善、效果明显高于随机波动，并具有继续蒸馏的实际空间。正式 Stage 0 仍执行方案 §22–§23 的完整 Go/No-Go。

### 9.2 根据 pilot 结果分流

| 结果 | 下一步 |
|---|---|
| T-Q 形成明显 teacher gap | 保持 Guiding-Question PI 主线，扩大正式数据 |
| 只有 T-QA 明显有效 | 主方法改为 Privileged Reasoning-Path Distillation，T-Q 保留为消融 |
| R 上 T 有效、P 上较弱 | 以瓶颈分层和适用范围为核心结论 |
| teacher gap 存在但学生无法转移 | 转向蒸馏损失、EMA、rollout 与 teacher-student mismatch |
| T-Q/T-QA 均无明显 gap | 暂停 OPSD，修改 G、任务构造或数据来源 |
| 只有知识依赖题有效 | 不能声称视觉推理增强；需重新定义研究范围 |

### 9.3 teacher gap 成立后再扩建数据

第二阶段再投入：

- 对 M3VQA 高 affordance 图片重新出闭世界 R/PR 问题；
- 从完整图视角重建 Vision-OPD-derived P；
- 增加 question-independent image affordance screening；
- 尽量在多个来源、甚至同一原图上构造 P/R/PR，降低来源混杂；
- 补齐 random、shuffle、generic、visual sham、dependency test；
- 完成 T05/T06 后再冻结 T07/T08；
- 正式 Stage 0 Go 后才进入 1K–2K T-only OPSD pilot。

### 已形成共识

- 主比较使用 non-thinking，thinking 单独做压力测试；

## 12. 中期结论

当前节点的主要成果是：数据与运行环境已经物化，T00/T01 完成，T02 的截断、解析和 bbox 坐标问题得到真实 GPU 结果验证，同时识别出 Vision-OPD P 层的 crop 视角混杂和 non-thinking 选择偏差。

当前节点的主要缺口是：正式 R/PR 数据尚未形成，T03–T08 尚未完成真实验收，最重要的文本 teacher gap 仍未测量。

因此下一里程碑应定义为：

> 在一批人工确认、无需外部知识、对完整图像成立的 R 样本上，获得第一张 frozen-model teacher-gap 表，并据此决定 T-Q、T-QA 或路线停止/调整。

在这一结果出现前，不应将 T02 的 1,200 条记录、353 条 accepted 或 thinking 翻转率表述为文本特权有效性的证据。
