## 1. 修改

提交 `401a942` 为六个仍保留的实验 Slurm 入口增加统一格式门禁：

- `submit_exploratory_teacher_gap.sbatch`；
- `submit_g_pc0.sbatch`；
- `submit_g_pc0_label_rotation.sbatch`；
- `submit_image_affordance_screening.sbatch`；
- `submit_teacher_gap_screening.sbatch`；
- `submit_teacher_gap_construction.sbatch`。

`MOPD_EXPECTED_CODE_COMMIT` 现在必须匹配 40 位小写十六进制；短哈希会给出明确错误。原有“完整 HEAD 精确相等 + 关键 tracked runtime files 无修改”门禁保持不变，没有放宽 provenance。

`research/main/docs/运行与留档规范.md` 同时固定提交方式：

```bash
PINNED_COMMIT=$(git rev-parse HEAD)
[[ "${PINNED_COMMIT}" =~ ^[0-9a-f]{40}$ ]]
```

禁止用 `git rev-parse --short HEAD` 或从 `git log --oneline` 复制缩写。文档中的 merge 参数也已与现行项目级版本管理规范对齐。

该修复只减少运行入口的人为配置错误。Slurm 内检查发生在 allocation 获得后，因此登录节点的提交前检查仍是避免排队/卡时浪费的第一道门禁。它不解锁 B2a、自然 G0、G1 或训练。
