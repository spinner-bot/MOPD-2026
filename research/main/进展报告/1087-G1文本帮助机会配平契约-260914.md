**性质**：重点文档；在 G1 构题和任何 family-specialization 结果产生前，冻结同图 P/R 的文本特权可用性、预算和作者配平，避免把不同强度的 G 当成任务瓶颈效应。

**创建作者**：Codex (CINECA Leonardo)

**触发原因**：1037 已在同图构造 P/R，并以 `T-real−T-generic` 的 R/P 双重差分支持文本对 reasoning bottleneck 的特异性；但现有规则只在每道题内匹配 Real 与 Generic 长度，没有要求 P 与 R 获得强度可比、同样合法的 Real-T。若 P 只有泛泛定位语，R 却有完整中间答案链，正交互会被 G 的信息量差异预置。

## 1. C2 的正确比较对象

C2 比较的是**家族适配、人工验证且帮助机会配平的结构化文本**在 P 与 R 上的内容特异 teacher advantage：

\[
Spec_T^{specific}=E_j[(T_{real}-T_{generic})_{j,R}-(T_{real}-T_{generic})_{j,P}].
\]

它不比较“R 有真实 G”与“P 没有 G”，也不把文本模态先验等同于推理。即使 C2 通过，准确措辞仍是：当前结构化文本在已验证 reasoning-bottleneck 任务上的受控增益更大。

## 2. P 与 R 都必须有可辩护的 Real-G

同一 `task_pair_id` 内，P/R 都使用 G0 入选的同一种主表示（T-Q 或 T-QA）和相同外壳。

- **P 的 G**：采用 hierarchical localization、entity disambiguation 或 attribute decomposition。它可以逐步确定“去哪里看、看哪个实体、读取哪个属性”，但中间答案不得给出最终待识别属性/文字/类别。最终困难视觉节点仍必须由模型从完整图中读取。
- **R 的 G**：采用 relation chain、logical bridge 或 evidence integration。它可以给出通向结论的中间实体/关系/状态；中间答案不得直接或语义排他地给出最终选项。
- **PR 的 G**：同时保留困难视觉节点与整合链；用于 C4/次级异质性，不替代 C2 的同图 P/R 主配对。

两边都须通过同一 answerability、relevance、closed-world、final-answer leakage、semantic dependency 和反事实有用性门。P 的 guide 不能只是“仔细看图”，R 的 guide 不能因链较长自动得到更宽松的泄漏标准。

若一张图无法为 P 或 R 之一自然构造符合门槛的 Real-G，该图可以进入图源/单家族描述集，但必须在任何模型运行前从 C2 pair frame 排除并保存原因；不能给缺失一边填 generic 后继续称为 specialization 配对。

## 3. Pair 内预算和作者配平

G1 构建前须冻结 pair-level guide budget。C2 主配对至少满足：

- P/R 使用相同 guide 节点数；若 G0 入选 T-QA，则两边 intermediate answer 槽位数也相同；
- 在目标 4B tokenizer 下，P/R 的 Real-G token 数相对差 `≤10%`；各自 Generic 仍按 1055–1058 逐题匹配自己的 Real-G；
- prompt shell、字段顺序、最终问题/选项格式一致；
- question 与 guide 总长度、答案类型和选项长度按 pair 记录，不能让家族标签由模板显露；
- 同一 constructor 可写一个 pair 的 P/R 初稿以共享图像理解，但 pair 在全体作者间随机分配；独立 reviewer 在隐藏 family 标签和任何模型结果时分别复做证据/DAG/G；
- 不允许作者只写 P 或只写 R 后把作者风格与 family 完全绑定。若多人协作，采用跨 pair 的平衡交叉分配并保存 `question_author_id`、`guide_author_id`、`reviewer_id`。

相同节点数不是要求相同语义：P 节点主要缩小视觉搜索/消歧，R 节点主要承载关系整合。若强行凑节点会产生冗余，就拒绝该 pair，而不是用无意义节点补齐。

## 4. 结果盲质量和机会测量

独立 reviewer 在看不到 S/T/Generic 输出时，对 P/R 两边记录：

- `guide_nodes_required`：每个节点对下一节点或最终读取是否必要；
- `final_visual_fact_withheld=true`：P 的最终困难视觉事实未由 G_QA 给出；
- `final_conclusion_withheld=true`：R 的最终答案未由 G_QA 给出；
- `expected_help_axis=search|disambiguation|integration|logical_bridge`；
- `human_helpfulness_ordinal=0..3`：G 是否实质缩短从图到答案的搜索/整合路径；
- `guide_token_count`、节点数、作者/审核者和分歧裁决。

C2 pair 要求两边 `human_helpfulness_ordinal≥2`；P/R 的 ordinal 分布和 token/node 差异必须报告。该人工量只做结果盲质量与敏感性，不依据目标模型表现校准，也不能在结果后删除低效 guide。

## 5. 分析与主张边界

C2 primary 继续使用 1068 的同图 correct-log-prob 双重差分，并按 image cluster 处理不确定性。结果前冻结的 sensitivity 至少加入 pair 内 Real-G token 差、helpfulness ordinal 差和 guide author；全部 locked pairs 保留。

以下任一情况使“reasoning bottleneck 特异性”不可确认：

- R 的 guide 节点、token 或 human-helpfulness 系统性高于 P，且共同支持域不足；
- P 的 G 泄漏最终视觉事实，或 R 的 G 泄漏最终结论；
- family 与 question/guide author 完全混杂；
- C2 只在未配平的单家族集合、positive-effect 子集或逐条件 complete-case 中出现；
- 加入预注册的机会差异敏感性后方向不稳定。

这种情况下仍可分别报告各家族 `T-real−T-generic`，但不能把两者差值解释为模态能力分工。

## 6. 与当前路线的关系

本契约只约束 G0 Go 后才建设的 G1，不增加当前 B2a/G0 工作量。G0 仍以 R/PR 题判断文本路径是否有最低机制信号；C2 的公平性成本只在 C1 teacher advantage 成立后承担。
