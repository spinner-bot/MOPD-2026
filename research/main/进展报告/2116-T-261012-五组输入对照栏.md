# 2116-T-261012-五组输入对照栏

## 目的 / Purpose

补充一个真实 case 的输入结构对照，明确“无 system prompt”不等于“没有 prompt 输入”。

## 展示内容 / Displayed content

报告最前新增“输入对照 / Input comparison”栏：

- 分别展示 S0、SC、S1、S2、S3 的 system message。
- S0 明确标注为没有 system message。
- 展示五组共同使用的图像归档路径、SHA-256 和 user text。
- 展示同一 case 的 JSON-like `messages` 结构。
- 图像字节在实际请求中以 data URI 发送；报告为可读性使用占位表示，原始图像仍在高清内嵌样本图和图像归档中保存。

## 校验 / Verification

- 五个条件标识均存在。
- `No system message` 标记存在。
- 输入对照栏位于结果摘要之前。
- 报告仍包含 17 个内嵌图像和 17 个点击放大处理器。
