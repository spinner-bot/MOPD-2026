## 二、5 个研究分支

| 分支 | 方法 | 核心思想 | 核心模块 | 状态 |
|------|------|---------|---------|------|
| `mcd` | 模态可信度动态控制 | 置信度+优势差 → softmax+门控动态权重 | `mcd_distillation.py` | ✅ 完整框架 |
| `mbd` | 模态平衡蒸馏 | 加平衡惩罚 `λ\|w_vl-w_text\|` 防坍缩 | `mbd_distillation.py` | ✅ 模块+测试 |
| `tamr` | 任务感知模态路由 | 任务分类器 → 任务级权重 | `tamr_distillation.py` | ✅ 模块+测试 |
| `modd` | 模态解耦蒸馏 | 分阶段：视觉→语言→整合 | `modd_distillation.py` | ✅ 模块+测试 |
| `amf` | 自适应模态融合 | 贝叶斯融合两个教师 logits | `amf_distillation.py` | ✅ 模块+测试 |

**核心问题**：多模态教师可信度不一致，被动接纳导致 OPD 质量下降。5 个分支从不同角度解决：
- mcd：动态控制参与程度
- mbd：强制平衡防坍缩
- tamr：按任务路由
- modd：解耦能力分阶段学
- amf：融合而非选择

### 3.2 mbd（模态平衡蒸馏）


### 3.3 tamr（任务感知路由）

```python
# 任务分类器预测任务类型，任务级权重
task_type = classifier(prompt_emb)
w_vl, w_text = task_routing_weights(task_type)
```

### 3.4 modd（模态解耦蒸馏）

```python
# 分阶段：视觉 → 语言 → 整合
Stage 1: L_vision = JS(student_vision || VL_vision)
Stage 2: L_language = JS(student_language || Text_language)
Stage 3: L_integrate = 融合两个教师
```

### 3.5 amf（自适应融合）

```python
# 融合 logits（非选择）
alpha = sigmoid((conf_vl - conf_text) / tau)
fused = alpha * VL_logits + (1-alpha) * Text_logits
L = JS(student || fused)
```

## 五、sync 部署包

每个分支的 `sync/` 目录是一键部署包，含：
- `code/`：蒸馏模块 + 单元测试
- `deploy.sh`：部署脚本
- `指令集.txt`：服务器操作指令

**部署流程**（每个分支）：
1. 上传 `sync/` 到服务器
2. `conda activate vision-opd`
3. `bash deploy.sh`（把模块放进 verl 框架）
4. `python test_<分支>_distillation.py`（验证）
5. 集成到 `dp_actor.py` 后训练

> 注：mbd/tamr/modd/amf 需先部署 mcd 基座（完整 verl 框架）。
