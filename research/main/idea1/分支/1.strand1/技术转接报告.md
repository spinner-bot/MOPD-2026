## 二、MCDC 方法与 Vision-OPD 的关系

### 2.1 Vision-OPD 的核心机制

Vision-OPD 是**单一 VL 教师的在线策略蒸馏**：

```
学生（Qwen3.5-4B）自采样 → VL 教师评分 → 密集 token 级监督
```

**蒸馏损失**：
```python
loss = JS(p_student(y_t) || p_VL_teacher(y_t))
```

**局限性**：
- 只用单一 VL 教师，无法利用纯文本教师的知识
- 固定权重，无法根据 token 处的模态可信度动态调整

### 2.2 MCDC 的扩展

MCDC 是**多模态多教师的动态控制策略**：

```
学生自采样 → [VL 教师, Text 教师] 评分 → 模态可信度计算 → 动态权重 → 密集 token 级监督
```

**蒸馏损失**：
```python
# 计算每个教师的可信度
confidence_VL = VL_teacher.top1_prob(t)
advantage_VL = VL_teacher.prob(t) - student.prob(t)
score_VL = alpha * confidence_VL + beta * advantage_VL

confidence_Text = Text_teacher.top1_prob(t)
advantage_Text = Text_teacher.prob(t) - student.prob(t)
score_Text = alpha * confidence_Text + beta * advantage_Text

# 动态权重
w_VL = exp(score_VL / tau) / (exp(score_VL / tau) + exp(score_Text / tau))
w_Text = 1 - w_VL

# 门控机制
w_VL = max(w_VL, epsilon)
w_Text = max(w_Text, epsilon)

# 归一化
w_VL, w_Text = normalize(w_VL, w_Text)

# 加权蒸馏
loss = w_VL * JS(p_student || p_VL) + w_Text * JS(p_student || p_Text)
```

### 2.3 技术差异

| 方面 | Vision-OPD | MCDC（我们） |
|------|-----------|-------------|
| 教师数量 | 1（VL） | 2（VL + Text） |
| 权重策略 | 固定（w=1） | 动态（w_k(t)） |
| 可信度计算 | 无 | 置信度 + 优势差 |
| 门控机制 | 无 | ε 最小权重 |
| 代码复杂度 | 低 | 中（需加可信度计算和动态权重） |

## 三、转接方案

### 3.1 代码复用

**直接复用**：
- 训练框架（verl）：分布式训练、rollout、FSDP
- 数据处理：Vision-OPD-6K 数据集和预处理脚本
- 基座模型：Qwen3.5-4B
- 评估脚本：eval 目录下的评估工具

**需要修改**：
- `verl/workers/actor/dp_actor.py`：添加 Text 教师加载和 MCDC 蒸馏损失
- `scripts/run_vision_opd.sh`：添加 Text 教师路径配置
- 新增模块：`verl/workers/actor/mcd_distillation.py`（MCDC 核心逻辑）

### 3.2 数据复用

**Vision-OPD-6K 数据集**：
- 6241 条多模态指令（图文问答、图表理解等）
- 每条包含：prompt + images + teacher_image（VL 教师的视觉标注）

**MCDC 需要的额外数据**：
- 无需额外数据！Text 教师可以直接处理相同的 prompt（忽略图像）
- Text 教师的输入：纯文本 prompt（不含图像）

### 3.3 模型配置

**学生模型**：Qwen3.5-4B（复用 Vision-OPD 的基座）

**教师模型**：
- **VL 教师**：Qwen3.5-4B（与 Vision-OPD 相同）
- **Text 教师**：Qwen2.5-7B-Instruct（纯文本模型，7B 参数）

**为什么选 Qwen2.5-7B-Instruct**：
- 纯文本模型，无法访问图像，与 VL 教师形成互补
- 7B 参数，比学生（4B）大，提供更强监督
- 开源，易下载

### 3.4 训练流程

**Vision-OPD 流程**：
1. 学生采样 rollout（带图像）
2. VL 教师评分（访问图像 + 文本）
3. 计算蒸馏损失（固定权重）
4. 更新学生参数

**MCDC 流程**：
1. 学生采样 rollout（带图像）
2. VL 教师评分（访问图像 + 文本）
3. Text 教师评分（只访问文本，忽略图像）
4. 计算模态可信度（置信度 + 优势差）
5. 计算动态权重（softmax + 门控）
6. 计算加权蒸馏损失
7. 更新学生参数

## 四、实施步骤

### 4.1 准备工作（1 天）

1. **下载 Text 教师模型**
   ```bash
   cd ~/vopd/models
   huggingface-cli download Qwen/Qwen2.5-7B-Instruct --local-dir Qwen2.5-7B-Instruct
   ```

2. **创建 MCDC 代码目录**
   ```bash
   cd ~/vopd
   cp -r code code-mcd
   cd code-mcd
   ```

### 4.2 代码修改（2-3 天）

1. **添加 Text 教师加载逻辑**
   - 在 `dp_actor.py` 中加载 Qwen2.5-7B-Instruct
   - 实现 Text 教师的前向传播（忽略图像 token）

2. **实现 MCDC 核心逻辑**
   - 新建 `mcd_distillation.py`
   - 实现模态可信度计算
   - 实现动态权重计算（softmax + 门控）

3. **修改蒸馏损失**
   - 在 `dp_actor.py` 的 `update_policy` 中调用 MCDC 损失
   - 替换原来的固定权重蒸馏

### 4.3 训练脚本修改（0.5 天）

1. **修改 `run_vision_opd.sh`**
   - 添加 Text 教师路径配置
   - 添加 MCDC 超参数（α, β, τ, ε）

2. **创建新脚本 `run_mcd.sh`**
   - 复制 `run_vision_opd.sh`
   - 修改为 MCDC 配置

### 4.4 实验（3-5 天）

1. **Baseline 实验**
   - Vision-OPD（单一 VL 教师）
   - Static-Multi（固定权重 0.5 + 0.5）

2. **MCDC 实验**
   - 调参：α, β, τ, ε
   - 消融实验：只用置信度 vs 只用优势差 vs 两者结合

3. **评估**
   - ChartQA, DocVQA, OK-VQA 等基准

### 4.5 论文撰写（2-3 天）

- 实验结果

## 五、风险评估

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| Text 教师加载失败（显存不足） | 中 | 高 | 用更小的 Text 教师（如 Qwen2.5-3B） |
| 动态权重训练不稳定 | 中 | 高 | 加门控机制 ε，或用 EMA 平滑 |
| 效果提升不显著 | 低 | 中 | 增加消融实验，分析失败案例 |
| 训练时间过长 | 低 | 低 | 减少 batch size 或 epoch |
