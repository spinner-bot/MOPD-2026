## 一、分支目标回顾

核心思路：在多模态 OPD 训练中，根据每个 token 上 VL 教师与 Text 教师的可信度（置信度 + 优势差），动态计算两个教师的参与权重（softmax + 门控），对 JS 散度蒸馏损失加权。

2. **单元测试**：`test_mcd_distillation.py`，覆盖置信度计算、动态权重（和 = 1）、门控下限、JS 散度等核心逻辑。

## 三、关闭原因

经 2026 年 8-9 月文献调研，发现与 mcd 思路高度重合的已发表/在投工作已存在：

- **H-OPD**（arXiv 2607.02592, Yin et al.）：置信度感知的异构多教师多模态 OPD，在共享学生轨迹的每个 token 处基于置信度动态组合 VL 与 Text 教师的监督信号。核心机制与 mcd 的"按置信度加权两教师"一致。
- **DOPD**：同样基于"优势差 + 置信度"的 token 级蒸馏策略分类。

mcd 的增量（"置信度 + 优势差 + softmax 门控"组合）与 H-OPD / DOPD 的方法在本质思路上重叠度较高，继续推进难以构成足够的方法贡献。
