# 分支概述：4.modd —— 模态解耦蒸馏（Modal Decoupled Distillation, MODD）

> 所属 Idea：1（多模态在线策略蒸馏 MOPD）  
> 分支名：4.modd  
> 核心问题：多模态教师的能力耦合导致学生学到"捷径"  
> 创建时间：2026-08-28

---

## 一、研究动机

### 1.1 问题：多模态教师的能力耦合

在多模态在线策略蒸馏（MOPD）中，VL 教师同时拥有视觉和语言能力。当它指导学生时，**视觉和语言能力是耦合在一起**的：

- 学生可能只学到语言的"捷径"，而没有真正学会视觉理解
- 因为语言信号更容易学（更稠密），视觉信号更难学（更稀疏）

**核心观察**：一个多模态教师同时教视觉和语言，学生容易"挑软柿子捏"，只学容易的语言，忽略困难的视觉。

### 1.2 现有方法的局限

| 方法 | 范式 | 问题 |
|------|------|------|
| MCDC（mcd） | 动态加权 | 仍是一个教师同时教视觉+语言，耦合未解决 |
| TAMR（tamr） | 任务路由 | 路由到 VL 教师时，仍是耦合指导 |
| AMF（amf） | logits 融合 | 融合后仍是混合指导 |

**共性**：所有方法都在"如何组合教师"，但没有**解耦教师内部的视觉和语言能力**。

### 1.3 研究问题

能否**解耦**多模态教师的视觉和语言能力，让学生分别学习，避免"只学语言捷径"？

---

## 二、核心方法

### 2.1 核心思想

**分阶段解耦训练**：把训练分成多个阶段，每个阶段聚焦一种模态能力，最后整合。

### 2.2 方法架构

```
Stage 1: 视觉能力学习
  - 用 VL 教师的视觉部分（视觉 token 的输出）
  - 蒸馏视觉特征，让学生学会"看"

Stage 2: 语言能力学习
  - 用 Text 教师的语言部分
  - 蒸馏语言推理，让学生学会"想"

Stage 3: 整合
  - 两个教师同时指导
  - 融合视觉和语言能力
```

### 2.3 阶段定义

**Stage 1：视觉学习**
```
输入：视觉 token 序列
监督：VL 教师在视觉位置（如 image token 后的位置）的输出
损失：L_vision = JS(student_vision || VL_teacher_vision)
```

**Stage 2：语言学习**
```
输入：文本 token 序列
监督：Text 教师在文本位置的输出
损失：L_language = JS(student_language || Text_teacher_language)
```

**Stage 3：整合**
```
监督：两个教师同时指导所有位置
损失：L_integrate = JS(student || VL) + JS(student || Text)
```

### 2.4 理论依据：课程学习

- **从易到难**：先学视觉（较难，但基础），再学语言（较易），最后整合
- **能力解耦**：每个阶段聚焦一种能力，避免耦合
- **课程设计**：视觉是感知基础，语言是推理基础，整合是关键

### 2.5 与 MCDC 的关系

| 方面 | MCDC（mcd） | MODD（4.modd） |
|------|------------|----------------|
| 训练方式 | 单阶段（联合） | **多阶段（解耦）** |
| 能力处理 | 耦合（同时教） | **解耦（分别教）** |
| 课程学习 | 无 | **有（从易到难）** |
| 捷径问题 | 不解决 | **专门解决** |

## 三、创新点

### 3.1 模态能力解耦

首次在多模态 OPD 中提出**分阶段解耦**训练：
- 把多模态教师的视觉和语言能力解耦
- 分阶段学习，避免耦合
- 专门解决"只学语言捷径"问题

### 3.2 课程学习视角

用课程学习理论设计训练顺序：
- 视觉基础 → 语言推理 → 整合
- 从易到难，逐步构建能力
- 有教育学/认知科学依据

### 3.3 专门解决"捷径"问题

- 发现：学生只学语言捷径，忽略视觉
- 解决：分阶段强制学生先学视觉，再学语言
- 针对性强，效果可解释

## 四、实验设计

### 4.1 Baseline

- **Vision-OPD**：单一 VL 教师
- **MCDC（mcd）**：动态加权
- **TAMR（tamr）**：任务路由
- **AMF（amf）**：logits 融合

### 4.2 核心对比

| 对比 | 目的 |
|------|------|
| MODD vs MCDC | 解耦 vs 联合，是否避免捷径 |
| MODD vs 单阶段 | 多阶段 vs 单阶段 |
| MODD vs 其他分支 | 整体对比 |

### 4.3 评估基准

- **视觉推理**：ChartQA, DocVQA, InfoVQA
- **图文问答**：OK-VQA, A-OKVQA, GQA
- **纯语言推理**：GSM8K, MATH, MMLU

### 4.4 评估指标

- **任务准确率**：标准指标
- **视觉能力单独评估**：纯视觉任务（验证视觉是否真正学会）
- **语言能力单独评估**：纯语言任务（验证语言是否受损）
- **能力解耦度**：视觉 vs 语言能力的相关性

### 4.5 消融实验

- **阶段划分**：2 阶段 vs 3 阶段 vs 4 阶段
- **阶段顺序**：先视觉 vs 先语言 vs 交叉
- **整合方式**：同时指导 vs 交替指导

## 五、预期结果

1. **相比 MCDC**：视觉能力显著提升（不再只学语言捷径）
2. **能力均衡**：视觉和语言能力都提升，不再偏向单模态
3. **可视化**：注意力图显示学生真正学会视觉感知
4. **理论验证**：课程学习假设成立
