# 分支概述：5.amf —— 自适应模态融合（Adaptive Modal Fusion, AMF）

> 所属 Idea：1（多模态在线策略蒸馏 MOPD）  
> 分支名：5.amf  
> 核心问题：现有方法都是"选择"教师，而非"融合"教师  
> 创建时间：2026-08-28

---

## 一、研究动机

### 1.1 问题：选择 vs 融合

在多模态在线策略蒸馏（MOPD）中，现有方法（MCDC、H-OPD、TAMR）都采用**"选择"**范式：在每个 token（或任务）处，**选一个**教师来指导。

**但"选择"存在根本缺陷**：
1. **信息丢失**：只用一个教师，丢失另一个教师的互补信息
2. **硬决策**：选择是离散的（要么 VL 要么 Text），缺乏连续性
3. **不可微**：离散选择无法端到端优化

**关键洞察**：为什么不**融合**两个教师的预测，而不是**选择**一个？融合能利用两个教师的互补信息，且是连续、可微的。

### 1.2 现有方法的局限

| 方法 | 范式 | 问题 |
|------|------|------|
| MCDC（mcd） | 选择（加权） | 软选择，但仍是"偏向一个" |
| TAMR（tamr） | 选择（路由） | 硬选择，信息丢失 |
| H-OPD | 选择（仲裁） | 离散选择，不可微 |

**共性**：所有方法都在"选教师"，没有真正"融合教师"。

### 1.3 研究问题

能否**融合**两个模态教师的预测，实现连续、可微、信息完整的蒸馏监督？

---

## 二、核心方法

### 2.1 核心思想

不是选择一个教师，而是**融合两个教师的 logits**，用融合后的分布作为监督信号。融合权重基于每个 token 的模态置信度，实现自适应。

### 2.2 公式

**logits 融合**：
```
fused_logits = α(t) * VL_logits + (1 - α(t)) * Text_logits
```

**融合权重**（基于模态置信度）：
```
α(t) = sigmoid(confidence_VL(t) - confidence_Text(t))
```

**蒸馏损失**：
```
L = JS(student || fused)
    其中 fused = softmax(fused_logits)
```

### 2.3 理论依据：贝叶斯融合

从贝叶斯角度看，两个教师的预测是对真实分布 $p(y|x)$ 的两个估计：
- VL 教师：$p_{VL}(y|x, v)$（有视觉信息 $v$）
- Text 教师：$p_{Text}(y|x)$（仅文本）

**最优融合**：如果两个教师独立，贝叶斯最优融合是：
```
p(y) ∝ p_{VL}(y)^{α} * p_{Text}(y)^{1-α}
```
取对数并近似为 logits 的加权和，即为我们的融合公式。

### 2.4 与 MCDC 的关系

| 方面 | MCDC（mcd） | AMF（5.amf） |
|------|------------|--------------|
| 范式 | 选择（加权两个损失） | **融合（合并两个 logits）** |
| 监督信号 | 两个独立的 JS 项 | **一个融合后的 JS 项** |
| 信息利用 | 部分（加权平均） | **完整（融合互补）** |
| 可微性 | 连续（softmax 权重） | **连续 + 可微（logits 融合）** |

## 三、创新点

### 3.1 从"选择"到"融合"的范式转变

首次在多模态 OPD 中提出**logits 融合**范式：
- 不是选一个教师，而是融合两个教师
- 利用互补信息，避免信息丢失
- 连续、可微，可端到端优化

### 3.2 贝叶斯融合理论

从贝叶斯角度推导融合权重：
- 最优融合是 logits 的加权和
- 权重由模态置信度决定
- 有严格的理论依据

### 3.3 自适应融合权重

- 融合权重基于每个 token 的模态置信度
- 置信度高的模态权重更大
- 自适应适应不同 token 的需求

## 四、实验设计

### 4.1 Baseline

- **Vision-OPD**：单一 VL 教师
- **Static-Multi**：固定权重（w_VL=0.5, w_Text=0.5）
- **MCDC（mcd）**：动态加权（两个独立损失）
- **TAMR（tamr）**：任务级路由

### 4.2 核心对比

| 对比 | 目的 |
|------|------|
| AMF vs MCDC | 融合 vs 加权，哪种更好 |
| AMF vs Static-Multi | 自适应融合 vs 固定权重 |
| AMF vs TAMR | 融合 vs 路由 |

### 4.3 评估基准

- **视觉推理**：ChartQA, DocVQA, InfoVQA
- **图文问答**：OK-VQA, A-OKVQA, GQA
- **纯语言推理**：GSM8K, MATH, MMLU

### 4.4 评估指标

- **任务准确率**：标准指标
- **融合权重分布**：α(t) 的分布（验证自适应）
- **信息利用度**：两个教师 logits 的融合效果

### 4.5 消融实验

- **融合方式**：logits 融合 vs 概率融合 vs log 融合
- **融合权重**：置信度差 vs 优势差 vs 随机
- **温度 τ**：τ ∈ {0.5, 1.0, 2.0}

---

## 五、预期结果

1. **相比 MCDC**：性能提升 2-4%，融合优于加权
2. **相比 Static-Multi**：性能提升 3-5%，自适应优于固定
3. **信息利用**：融合充分利用两个教师，无信息丢失
4. **可视化**：融合权重分布显示不同 token 的自适应

## 七、创新性评估（针对 CVPR）

### 7.1 为什么能发 CVPR

1. **范式新**：首次提出"融合"而非"选择"教师
2. **理论有**：贝叶斯融合理论推导
3. **方法简**：logits 加权和，实现简单
4. **效果优**：融合利用互补信息，预期优于选择

### 7.2 与导师"创新性不足"的回应

导师认为 MCDC 创新性不足，因为：
- 加权两个损失 = 已有技术

**AMF 的回应**：
- **从"加权损失"升级为"融合 logits"（范式转变）**
- **有贝叶斯理论支撑（不是工程 trick）**
- **信息利用更完整**

## 八、风险与应对

| 风险 | 概率 | 应对 |
|------|------|------|
| 融合后分布过于平滑 | 中 | 用 log 融合或温度控制尖锐度 |
| 融合权重不敏感 | 中 | 用优势差替代置信度差 |
| 效果提升不显著 | 低 | 强调理论贡献（贝叶斯融合） |

## 九、总结

AMF（自适应模态融合）提出从"选择"到"融合"的范式转变，用贝叶斯理论支撑 logits 融合。

- **创新点**：范式转变 + 贝叶斯理论 + 自适应权重
- **实现难度**：低（在 MCDC 基础上改损失函数）
- **CVPR 潜力**：中高（范式新 + 理论有 + 方法简）
