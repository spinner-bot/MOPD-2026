# 分支概述：3.tamr —— 任务感知模态路由（Task-Aware Modal Routing, TAMR）

> 所属 Idea：1（多模态在线策略蒸馏 MOPD）  
> 分支名：3.tamr  
> 核心问题：不同任务需要不同的模态教师组合  
> 创建时间：2026-08-28

---

## 一、研究动机

### 1.1 问题：任务与模态的错配

在多模态在线策略蒸馏（MOPD）中，学生面对的任务千差万别：
- **视觉推理**：图表问答、文档理解、细粒度视觉——需要 VL 教师的视觉能力
- **语言推理**：数学、常识、逻辑——需要 Text 教师的语言能力
- **混合任务**：图文结合——需要两个教师协作

**核心观察**：不同任务对模态的依赖不同。用统一的教师路由策略处理所有任务，会导致：
- 视觉任务上：Text 教师提供弱监督，拖累学生
- 语言任务上：VL 教师提供"特权捷径"，误导学生

### 1.2 现有方法的粒度问题

| 方法 | 路由粒度 | 问题 |
|------|---------|------|
| Vision-OPD | 单教师 | 无法利用多模态 |
| MCDC（1.strand1） | token 级 | 细粒度，但**未利用任务语义** |
| H-OPD | token 级 | 细粒度，但**计算开销大** |

**关键洞察**：现有方法都聚焦于"token 级"路由，忽略了**任务级**的先验信息——任务类型本身就强烈暗示了该用哪个模态教师。

### 1.3 研究问题

能否利用**任务类型**作为先验，实现高效、可解释的模态路由，同时避免 token 级路由的高开销？

---

## 二、核心方法

### 2.1 核心思想

**任务级路由**：根据任务类型，动态决定使用哪个（或哪些）模态教师，而不是在 token 级逐token选择。

### 2.2 方法架构

```
输入：任务（图文 / 纯文本）
  ↓
任务分类器（轻量，计算开销 <1%）
  ↓
任务类型 → 模态路由策略
  ↓
visual_reasoning → 主要用 VL 教师
language_reasoning → 主要用 Text 教师
mixed → 均衡使用两个教师
```

### 2.3 路由策略

根据任务类型，设置教师的参与权重：

```
if task_type == "visual_reasoning":
    w_VL = 0.7, w_Text = 0.3    # 侧重 VL
elif task_type == "language_reasoning":
    w_VL = 0.3, w_Text = 0.7    # 侧重 Text
elif task_type == "mixed":
    w_VL = 0.5, w_Text = 0.5    # 均衡
```

**蒸馏损失**：
```
L = w_VL * JS(student || VL) + w_Text * JS(student || Text)
```

### 2.4 任务分类器

- **轻量模型**：一个简单的文本分类器（如线性层或小型 MLP），基于 prompt 预测任务类型
- **计算开销**：<1%（远低于 token 级路由）
- **可解释**：能可视化任务-教师映射

### 2.5 与 MCDC 的关系

| 方面 | MCDC（1.strand1） | TAMR（3.tamr） |
|------|------------------|----------------|
| 路由粒度 | token 级 | **任务级** |
| 先验信息 | 无 | **任务类型** |
| 计算开销 | 高（逐token） | **低（<1%）** |
| 可解释性 | 低 | **高（任务-教师映射）** |

## 三、创新点

### 3.1 任务级模态路由

首次在多模态 OPD 中提出**任务级**路由：
- 利用任务类型作为先验信息
- 避免 token 级路由的高开销
- 简单高效，可解释性强

### 3.2 模态-任务适配分析

系统分析不同任务类型对模态的依赖：
- 视觉任务 → 依赖 VL 教师
- 语言任务 → 依赖 Text 教师
- 混合任务 → 依赖均衡

**实验发现**：VL 教师在视觉任务上贡献大，Text 教师在语言任务上贡献大，验证了任务级路由的合理性。

### 3.3 高效性

- **计算开销**：<1%（远低于 token 级路由）
- **可扩展**：任务分类器可预训练，训练时零额外开销
- **可解释**：能可视化任务-教师映射，便于分析

---

## 四、实验设计

### 4.1 Baseline

- **Vision-OPD**：单一 VL 教师
- **Static-Multi**：固定权重（w_VL=0.5, w_Text=0.5）
- **MCDC（1.strand1）**：token 级动态加权
- **H-OPD**：token 级教师仲裁

### 4.2 核心对比

| 对比 | 目的 |
|------|------|
| TAMR vs MCDC | 任务级 vs token 级路由，效果和开销对比 |
| TAMR vs H-OPD | 任务级 vs token 级仲裁 |
| TAMR vs Static-Multi | 任务感知 vs 固定权重 |

### 4.3 评估基准

- **视觉推理**：ChartQA, DocVQA, InfoVQA
- **图文问答**：OK-VQA, A-OKVQA, GQA
- **纯语言推理**：GSM8K, MATH, MMLU

### 4.4 评估指标

- **任务准确率**：标准指标
- **计算开销**：训练时间、显存占用（验证高效性）
- **路由准确率**：任务分类器的准确率
- **可解释性**：任务-教师映射的可视化

### 4.5 消融实验

- **路由策略**：侧重权重（0.7/0.3 vs 0.6/0.4 vs 0.5/0.5）
- **任务分类器**：无（用真实标签）vs 有（预测标签）
- **任务类别数**：2 类 vs 3 类 vs 5 类

---

## 五、预期结果

1. **相比 MCDC**：效果相当或更好，**计算开销大幅降低**
2. **相比 Static-Multi**：效果提升 3-5%，任务感知优于固定权重
3. **高效性**：训练时间减少 20-30%
4. **可解释性**：能清晰展示任务-教师映射

## 七、创新性评估（针对 CVPR）

### 7.1 为什么能发 CVPR

1. **视角新**：首次从"任务粒度"思考模态路由（现有都是 token 粒度）
2. **方法简**：轻量任务分类器，计算开销 <1%
3. **高效性**：相比 token 级路由，训练时间减少 20-30%
4. **可解释**：任务-教师映射可视化

### 7.2 与导师"创新性不足"的回应

导师认为 MCDC 创新性不足，因为：
- token 级动态加权 = H-OPD 已有

**TAMR 的回应**：
- **提出新的粒度视角（任务级 vs token 级）**
- **提出高效方案（轻量任务分类器）**
- **强调可解释性和计算效率优势**

---

## 八、风险与应对

| 风险 | 概率 | 应对 |
|------|------|------|
| 任务分类器准确率不高 | 中 | 用更强的分类器，或结合 prompt 特征 |
| 任务级路由粒度太粗 | 中 | 混合：任务级 + token 级（分层路由） |
| 效果提升不显著 | 低 | 强调高效性和可解释性优势 |

---

## 九、总结

TAMR（任务感知模态路由）从**任务粒度**思考多模态 OPD 的模态路由，与现有方法的 token 粒度形成对比。

- **创新点**：任务级路由 + 轻量分类器 + 可解释性强
- **实现难度**：低（在 MCDC 基础上加任务分类器）
- **CVPR 潜力**：中高（新视角 + 高效性 + 可解释性）
