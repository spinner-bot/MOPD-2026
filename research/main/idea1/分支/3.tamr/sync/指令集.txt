========================================
 TAMR（任务感知模态路由）服务器操作指令
 前置：先部署好 mcd 基座（含完整 verl 框架）
========================================

0) 上传 sync 文件夹到服务器
   （本目录即 sync，用 SFTP/拖拽上传 ~/ 下）

1) 进环境 + 设变量
   cd ~
   conda activate vision-opd
   export WORLD_SIZE=1
   export HF_ENDPOINT=https://hf-mirror.com
   export LD_LIBRARY_PATH=$CONDA_PREFIX/lib:$LD_LIBRARY_PATH

2) 部署 TAMR 模块
   # CODE_DIR 指向 mcd 基座部署目录，默认 ~/mcd/code
   bash deploy.sh

3) 运行单元测试
   cd <sync目录>
   python test_tamr_distillation.py
   # 应输出 === 全部测试通过 ===

4) 集成到训练框架
   # 参照 mcd 分支：在 dp_actor.py 中调用 TAMRDistillation
   # TAMR 需要额外的任务分类器（LightTaskClassifier），注意配置

5) 启动训练
   cd ~/mcd/code
   bash scripts/run_vision_opd.sh \
     actor_rollout_ref.model.path=$HOME/models/Qwen3.5-4B \
     actor_rollout_ref.model.trust_remote_code=True \
     data.trust_remote_code=True \
     2>&1 | tee train.log

6) 查看进度
   tail -40 train.log
