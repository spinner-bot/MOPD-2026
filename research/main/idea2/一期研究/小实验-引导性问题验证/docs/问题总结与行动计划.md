## 核心发现

### 🔴 最严重问题：版本完全不匹配

| 组件 | 当前版本 | 要求版本 | 差距 | 风险等级 |
|------|----------|----------|------|----------|
| torch | 2.6.0+cu124 | 2.10.0 | 主版本不同 | 🔴 **极高** |
| transformers | 4.51.3 | 5.5.0 | 主版本不同 | 🔴 **极高** |
| vllm | 0.8.6.dev0 | 0.18.0 | 主版本不同 | 🔴 **极高** |
| verl | 0.5.0 | 0.7.0 | 次版本不同 | 🟡 **高** |
| flash-attn | 2.7.3 | 2.8.3 | 补丁版本 | 🟢 **中** |
| CUDA | 12.4 | 12.9 | 次版本不同 | 🟡 **高** |

**结论**：当前 verl 环境**无法直接运行** Vision-OPD/Text-OPD 代码。

---

## 问题分类

### P0 - 必须立即解决

#### 1. 版本不兼容
- **影响**：训练代码无法运行，API 不兼容
- **根因**：verl 环境是旧版本，Vision-OPD 要求新版本
- **解决**：创建新的独立 conda 环境
- **耗时**：2-4 小时

#### 2. 图片数据未下载
- **影响**：无法进行数据预处理
- **根因**：仅缓存元数据，未下载图片
- **解决**：运行 prepare_data.py
- **耗时**：1-2 小时

### P1 - 重要但可稍后解决

#### 3. CUDA 版本较低
- **影响**：flash-attn 编译可能失败
- **根因**：系统 CUDA 12.4，要求 12.9
- **解决**：conda 安装 CUDA 12.9 或使用兼容版本
- **耗时**：30 分钟

#### 4. 引导性问题生成
- **影响**：数据准备的关键步骤
- **根因**：需要设计 prompt 并批量生成
- **解决**：设计生成策略，API 调用，人工审核
- **耗时**：1-2 天

### P2 - 可后续优化

#### 5. 代码适配
- **影响**：需要添加文本特权信息处理
- **根因**：Vision-OPD 仅有视觉特权信息
- **解决**：修改代码，添加 guiding_questions 字段
- **耗时**：1 天

## 历史教训

### 从之前的失败中学习

**vLLM 安装失败事件**：
- ❌ 在 verl 环境中直接升级 vLLM
- ❌ 依赖冲突严重，安装超 5 小时未完成

3. ✅ **先小范围测试**，确认环境可用再大规模运行
4. ✅ **并行处理**：环境安装和数据下载可同时进行

## 行动方案

### 方案 A：创建新环境（强烈推荐）

**优点**：
- ✅ 干净隔离，不影响现有环境
- ✅ 版本完全匹配，减少兼容性问题
- ✅ 可重复，其他成员也能复现

**缺点**：
- ❌ 需要重新安装，耗时 2-4 小时
- ❌ 可能遇到编译问题（flash-attn）

**步骤**：
```bash
# 1. 创建新环境
conda create -n text-opd python=3.12 -y
conda activate text-opd

# 2. 安装 CUDA 12.9（如需要）
conda install -c nvidia cuda-toolkit=12.9 -y

# 3. 安装依赖
cd ~/text-opd-code/
pip install --upgrade pip
pip install --no-deps -r requirements.txt
pip install -e . --no-deps

# 4. 编译 flash-attn
pip install flash-attn --no-build-isolation

# 5. 验证
python -c "import torch, vllm, verl, transformers; print('All imports OK')"
```

### 方案 B：升级现有 verl 环境（不推荐）

**优点**：
- ✅ 节省时间

**缺点**：
- ❌ 可能破坏现有 verl 环境
- ❌ 影响其他实验
- ❌ 依赖冲突可能导致安装失败
- ❌ 之前的失败教训

**风险**：高

### 方案 C：修改代码适配旧版本（不推荐）

**优点**：
- ✅ 无需重新安装环境

**缺点**：
- ❌ 需要大量代码修改
- ❌ 可能引入新 bug
- ❌ 违背论文原意
- ❌ 难以与原版对比

**风险**：极高

## 需要决策的事项

### 1. 环境策略

**问题**：是否创建新的独立环境？

**建议**：✅ 是，创建 `text-opd` 环境

**理由**：
- 版本差异太大，升级风险高
- 独立环境更稳定、可重复
- 不影响现有实验

### 2. 数据规模

**问题**：使用多大规模的数据集？

**选项**：
- A. 全量数据（6,241 条）- 训练时间长，效果好
- B. 子集（500-1000 条）- 快速验证，节省资源
- C. 极小子集（100 条）- 仅用于调试

**建议**：✅ 先用子集（500-1000 条）验证，成功后再用全量

### 3. 引导性问题生成策略

**问题**：如何生成引导性问题？

**选项**：
- A. 使用 API（GPT-4/Qwen-Max）- 质量好，但有成本
- B. 使用本地模型 - 免费，但质量可能不保证
- C. 基于规则生成 - 可控，但泛化性差

**建议**：✅ 使用 API 生成，人工审核

**缓解措施**：
- 先尝试 CUDA 12.9 编译

**缓解措施**：
- 先用小数据集测试
- 监控 loss 曲线

**缓解措施**：

import torch
