## 一、实验背景

### 1.1 研究动机

Vision-OPD 已验证：通过视觉模态特权信息（聚焦关键信息的裁剪图）进行自蒸馏，可以强化模型从低清大图中自发寻找关键细节的能力。

我们希望探索：**文本模态的特权信息（引导性问题）是否能强化模型的长线推理思考能力？**

### 1.2 核心假设

引导性问题作为文本特权信息，通过自蒸馏可以：
1. 帮助模型学习结构化的推理路径
2. 提升面对复杂问题时的分解能力
3. 增强长线推理的稳定性

## 二、实验设计

### 2.1 实验变量

| 变量类型 | 变量名 | 取值 |
|---------|--------|------|
| 自变量 | 文本特权信息 | 有 / 无 |
| 因变量 | 模型回答准确率 | 连续值 |
| 控制变量 | 基座模型 | Qwen3.5-4B |
| 控制变量 | 训练数据 | Vision-OPD-6K（子集） |
| 控制变量 | 训练参数 | 与 Vision-OPD 一致 |

### 2.2 实验分组

**简化设计（小范围验证）**：

| 组别 | 训练方式 | 教师输入 | 学生输入 |
|------|----------|----------|----------|
| Baseline | 无蒸馏 | - | 完整图 + 问题 |
| Teacher-T | 自蒸馏 | 完整图 + 问题 + **引导性问题** | 完整图 + 问题 |

**后续扩展（完整 2×2 设计）**：

| 组别 | 视觉特权信息 | 文本特权信息 |
|------|-------------|-------------|
| Student | ❌ | ❌ |
| Teacher-V | ✅ | ❌ |
| Teacher-T | ❌ | ✅ |
| Teacher-VT | ✅ | ✅ |

### 2.3 评估设计

#### 评估数据集

- 使用 Vision-OPD 的评估集
- 按问题难度分级（简单/中等/困难）
- 按推理深度分级（单步/多步/长链）

#### 评估指标

- 回答准确率（Accuracy）
- 推理步骤完整性
- 与 Judge 模型评分一致性

#### 分析维度

1. **问题深度**：引导性问题对不同深度问题的影响
2. **信息清晰度**：问题描述清晰度对效果的调节作用
3. **能力变化模式**：模型在哪类任务上获益最多

## 三、技术路线

### 3.1 数据准备

1. 从 Vision-OPD-6K 抽取子集（如 500-1000 条）
2. 为每条数据生成引导性问题
3. 构建训练数据对：
   - Teacher: 完整图 + 问题 + 引导性问题 → 回答
   - Student: 完整图 + 问题 → 回答

### 3.2 训练流程

```
基座模型 (Qwen3.5-4B)
    │
    ├──► Teacher 模式（带引导性问题）──► 生成回答
    │
    └──► Student 模式（无引导性问题）──► 生成回答
                │
                └──► 自蒸馏损失（KL 散度）
```

### 3.3 实现方式

基于 Vision-OPD 代码框架修改：
- 新增文本特权信息输入通道
- 修改 prompt 构造逻辑
- 添加引导性问题处理

## 四、预期结果

### 4.1 成功标准

- Teacher-T 组在复杂/多步推理问题上显著优于 Baseline
- 引导性问题帮助学生模型学习更好的推理策略

### 4.2 可能的发现

1. **正效应**：引导性问题提升推理能力
2. **无显著差异**：引导性问题效果有限
3. **负效应**：引导性问题引入噪声（需分析原因）

### 4.3 失败处理

如果实验效果不显著：
- 分析引导性问题质量
- 检查蒸馏策略
- 调整问题生成方式

## 六、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 引导性问题质量差 | 实验失败 | 人工审核 + 迭代生成策略 |
