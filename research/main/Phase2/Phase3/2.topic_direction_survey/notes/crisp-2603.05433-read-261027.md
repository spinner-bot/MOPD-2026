## 1. 一句话

同一套参数，教师 = 模型 + "be concise" 指令，学生 = 原模型；在**学生自己的 rollout** 上做 **per-token reverse KL**，教师权重每 M 步同步一次；不需要标准答案、不需要奖励模型、不需要难度估计。文本数学推理上，Qwen3-14B 把 MATH-500 长度压 56%（v1）/ 35%（v2），准确率不降反升。

## 2. 机制要点

| 组件 | 做法 | 备注 |
|---|---|---|
| 教师 | 同一模型 + 简洁指令 c（prompt 级特权） | 与"另一个模型"无关，是同一权重 |
| 学生 | 同一模型，无指令 | — |
| 训练信号 | 学生 rollout 上逐 token **reverse KL** `D_KL(q_t ‖ p_t)` | 无 GT、无 reward、无 advantage |
| 教师刷新 | 每 M 步 `θ_teacher ← θ_student`，默认 M=50 | M=1 崩溃（学生追移动目标）；M=100 等同冻结教师 |
| 计算 | 每 token 两次前向（教师 no-grad，可缓存） | 截断 rollout 1K–30K 均可训练 |
| 方向选择 | reverse KL（mode-seeking）优先于 forward KL | forward KL 在 Qwen3-8B 前 100 步崩塌，长度发散到预算上限 |

## 3. 主要结果（Table 2，30K token 预算，mean@8）

**Qwen3-14B**

| 指令 | MATH-500 | AIME 2024 | AIME 2025 | GPQA-D | MMLU |
|---|---|---|---|---|---|
| base | 93.0 | 75.0 | 69.2 | 62.2 | 85.1 |
| CRISP v1（统一简洁） | **96.3（+3.3），长度 −56.3%** | 73.8（−1.2），−37.5% | 62.9（−6.3），−32.1% | 61.9，−39.7% | 84.2，−43.1% |
| CRISP v2（难度感知） | 95.2（+2.2），−34.7% | 75.0（0），−19.7% | 67.1（−2.1），−16.8% | 62.0，−20.7% | 83.9，−22.4% |

- Qwen3-8B v1：MATH-500 95.7→95.7、−56.9%；AIME 2025 70.4→58.8（−11.6），说明最难题上强压缩会掉点。
- 越简单压得越狠：MATH-500 32%–57%，AIME 只有 5%–38%——难度自适应来自 KL 信号本身，不是显式估计。
- OOD（GPQA、MMLU）保持在一分以内；DeepSeek-R1-Distill-Llama-8B 上准确率全面提升且变短。
- 指令措辞是"压缩—准确率"旋钮：v1 压得多、难题掉得多；v2 保守但护住难题。五个变体结果接近，说明不是单条 prompt 调出来的。

## 4. 对我们的意义

1. **这是导师故事的第一幕，且已有实现**：单教师 + 简洁指令就是 G1 组；论文、代码、实验表都齐，可直接复现。纯 CRISP 不能再当创新点（与 2239/2241 一致）。
2. **它把"冲突假设"机制化了**：CRISP 的 reverse KL 会删掉"简洁教师不生成"的 token——如果这些 token 恰好是视觉证据驱动的长推理，压缩就会伤 grounding。这为"单教师叠两种特权会打架"提供了可检验的解释，而不只是叙事。
3. **空白仍在视觉侧**：CRISP 是文本模型、数学任务；没有视觉特权教师，也没有输出长度与 grounding 的联合评测。COPD 虽做 VLM 压缩，但用轻/重思考提示的 log-prob 差、2B 学生、不做双教师。
4. **可借的工程细节**：教师定期刷新（M）、reverse KL、截断 rollout、per-token 信号、无需 GT——这些都能直接进 G0–G3 实验设计。
5. **不可直接借的假设**：单模态文本、数学可验证答案、指令是唯一特权。迁到 VLM 时，教师提示里要同时放视觉上下文（zoom/mask）和简洁指令，冲突点正在这里。
