01结论摘要Summary

这个设想，谁做过、做到什么程度、我们还能主张什么？Who has done it, how far did they go, and what is left to claim?

1. “一个学生、两个教师、token 级仲裁”已被正式发表工作占位。最直接的是 H-OPD（EMNLP 2026，arXiv 2607.02592）：VL 教师（原图）+ 纯文本教师（问题 + 图像描述），在同一学生 prefix 上按预测熵做 token 级置信度仲裁。

2. 另外三个相关位置也已有先行工作：多教师信号冲突（Counteraction-Aware MOPD、DOPD、From Gradients to Capabilities）；OPSD 输出压缩（CRISP、COPD、BIRD、MPD 等）；视觉特权 OPSD（OPD-V、Vision-OPD、SCOPD 等）。

3. “视觉特权教师 + 简洁教师 + 输出压缩”这一具体组合未检索到直接对应工作。但它属于已有组件的交叉，审稿人可能判定为“H-OPD + CRISP”；novelty 必须落在新的仲裁机制或新的受控证据上。

4. 建议在投入代码前执行一项低成本对照实验，验证“同一教师叠加两种特权是否产生冲突”。该实验是当前选题成立的前提；若冲突不成立，应尽早终止。

04最直接的撞车：H-OPDThe closest collision: H-OPD

为什么说架构已被占位？Why the architecture is already taken.

H-OPD（Confidence Aware Heterogeneous Multi-Teacher Multimodal On-policy Distillation，EMNLP 2026）的设定：

  • 学生：只看原图 + 问题。
  • 视觉教师：VL 模型，看原图 + 问题。
  • 文本教师：同一模型的文本侧，看“问题 + 图像描述”（图像描述由视觉信息转换而来）。
  • 仲裁：两个教师在同一 student-generated prefix 上打分；以预测熵的负值为置信度，按 token 计算权重 λ_t，在统一 top-k 候选集上做 KL。
  • 目标：多模态推理提升，11 个基准；不做输出长度压缩。

与本设想的差异：H-OPD 的文本教师承担“图像描述”角色，不是“简洁”角色；目标是推理提升，不是压缩。差异真实存在，但“两个教师 + token 级仲裁”这个结构不再新。

汇报口径：不要说“和我们完全一样”，也不要把它当作可以忽略的先行工作。准确说法是“架构同构、目标与教师分工不同”。

05另外四篇必须知道的工作Four more papers that shape the story

如果只读五篇，读哪五篇？The minimum reading list.

工作核心做法与本选题的关系
CRISP
2603.05433		同一权重 + 简洁指令作教师，学生 rollout 上做 per-token reverse KL，教师每 50 步刷新；无需标准答案。“简洁教师”这一半的完整实现，也是故事第一幕的现成基线。Qwen3-14B 上 MATH-500 长度 −56%、准确率 93.0→96.3；AIME 2024 −37.5%、掉 1.2 分。
OPD-V
2608.05131		正教师（Zoom-In 图）+ 负教师（Mask 图），用两者对数概率差定义 Modality-Balance 信任域，只在该域内用 JSD 蒸馏正教师。“视觉特权教师”的最新形态，也是我们唯一复现过的基座；Qwen3.5-4B 平均 64.30→80.01。它用两个教师，但两个教师是同一特权的正负对照，不是“视觉 + 简洁”。
DOPD
2606.30626		特权教师 + 特权学生，按 advantage gap 做 token 级路由，研究“特权幻觉”。“两种信息条件会冲突/不可迁移”的相邻证据；支持“冲突”值得验，但不等于已有结论。
COPD/COPSD
2607.19046		同一模型在轻/重思考提示下的 log-prob 差作 token advantage，直接进策略更新；Qwen3.5-4B→2B 上压缩到 0.78K tokens 且准确率略升。最危险的压缩撞车对象：已在 VLM 上做 OPSD 内压缩，但无双教师、无视觉特权教师。
Counteraction-Aware MOPD
2605.27115		多领域教师，解耦冲突梯度（recovery vs. preservation）。“多教师冲突”不是我们首次提出；需要明确我们的冲突是“同一教师的两种特权”，不是领域间冲突。

06仍可主张的缝隙The remaining gap

如果继续做，卖点应该是什么？What can still be claimed?

直接检索未发现：“视觉特权教师 + 简洁特权教师 + token 级压缩仲裁”这一具体组合。但它是四个已有组件的交叉，单靠组合不足以支撑一篇 A 会论文。

建议主张（A）：视觉证据门控的压缩仲裁。

两个教师：视觉教师（Zoom-In/Mask 特权）+ 简洁教师（be concise 特权）。仲裁信号不是教师置信度，而是“该 token 是否依赖视觉证据”：视觉信息增益高的 token（物体属性、空间关系、OCR 结果）不压缩；视觉信息增益低的 token（重复描述、自验证、套话）交给简洁教师压缩。

与 H-OPD 的差异：H-OPD 按预测熵仲裁“谁更可信”；本方案按视觉证据仲裁“哪里该短、哪里不能短”。与 CRISP/COPD 的差异：它们没有视觉条件；本方案显式保护视觉 grounding。

可检验假设：单教师同时加两种特权，会在“视觉 token 该保留 vs. 简洁教师想删”上冲突；双教师 + 视觉门控能同时降低 token 并保持 grounding。

为什么必须先验冲突：如果单教师叠加两种特权并不冲突，双教师就只是把一件事拆成两件做，故事不成立，审稿人也会问“为什么要两个教师”。

07建议的决策实验Proposed decision experiment

写代码之前，用最小代价验证故事前提。Test the premise before building the architecture.

组别教师配置验证什么
G0标准 OPD-V / Vision-OPD 基线复现与评测口径
G1单教师 + 简洁指令（CRISP 式）压缩是否掉点；文本侧基线
G2单教师 + 视觉特权 + 简洁指令两种特权是否冲突（长度、准确率、grounding）
G3双教师（视觉 + 简洁），token 级仲裁分工是否优于叠加

观测指标：输出 token 长度、准确率、视觉 grounding（CHAIR / POPE 至少一项）。规模：小样本、1–2 天机时，不做全量。

判定标准：若 G2 相对 G1/G3 出现明显退化（长度或 grounding），且 G3 优于 G2，则“双教师必要性”成立，进入方案 A；若 G2 与 G3 无显著差异，则双教师故事不成立，应终止该方向。
