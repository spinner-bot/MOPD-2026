OPD-V：以“模态平衡”为特权信息的视觉 OPSDVisual On-Policy Self-Distillation with Modality Balance

A positive teacher sees a zoomed-in crop, a negative teacher sees the same crop with a region masked, and the student sees the original image. The log-probability gap between the two teachers defines a trust region: distill only where zooming in supports the student's token more than masking does.

正教师看放大后的证据区域，负教师看同一区域被随机遮挡后的图，学生看原图。两个教师对同一学生 token 的对数概率差定义信任域： 只在“放大后更支持该 token”的位置上做 JSD 蒸馏。它用两个教师，但两个教师是同一特权的正负对照，不是两种不同的特权。

01一句话与定位One-sentence summary and positioning

它解决什么问题？What problem does it solve?

视觉 OPSD 里，教师提供的特权信息可能被模型的语言先验淹没（Modality Imbalance）。OPD-V 构造“正教师（Zoom-In）+ 负教师（Mask）”两种图像条件，用两者对同一 token 的支持差判定该 token 是否依赖视觉证据，只在正差位置蒸馏正教师。

定位：这是视觉特权 OPSD 的一个新范式。与传统 OPSD 不同，教师不接收标准答案，而是接收变换后的图像；学生始终只看原图和原问题，推理时不需要任何额外输入。

论文状态：arXiv 2608.05131v2（2026-08-06），预印本，未见录用信息。工作5 复现的是它的 Qwen3.5-4B 模型与数据协议。

02问题：模态失衡The problem: Modality Imbalance

为什么已有的视觉特权信息不够用？Why existing privileged information underperforms.

  • MLLM 的每个预测同时依赖图像、文本问题和自回归前缀；强文本先验会压过图像证据。
  • 因此即使教师看到了更清晰的图，它给出的高置信度也可能主要来自语言先验，而不是视觉证据；学生学到的是“看起来很强的信号”，但不一定可迁移。
  • 论文用 Modality-Balance Attention Ratio 量化这一点：
ρ(c; y) = Σt∈Ty αVt(c) / ( Σt∈Ty αTt(c) + ε ) 式 (5)：αV、αT 分别为第 t 个位置对视觉/文本的注意力质量；ρ 越大表示越依赖视觉。

Figure 1 的三组匹配条件给出直接证据：Mask 图（负教师）的 ρ 最低（0.148），原图（学生）居中（0.226），Zoom-In 图（正教师）最高（0.263）。也就是说，同一模型、同一文本，仅改变图像条件，就能系统地改变模态分配——这使“模态平衡”可以被显式构造出来。

03方法：正负教师与信任域Method: positive/negative teachers and trust region

两个教师分别看什么，蒸馏目标是谁？What each teacher sees, and which one is distilled.

3.1 三种图像条件Three image conditions

角色图像输入构造方式作用
学生原图 I原始输入生成 rollout
正教师Zoom-In 图 Izoom训练数据自带的证据区域 bbox 裁剪并放大（字段 bbox_images）提供蒸馏目标分布
负教师Mask 图 Imask在 Izoom 上把随机矩形区域替换为黑像素提供成对比较，决定哪些 token 进入信任域

两个教师共享同一组 EMA 参数 θ̄，文本问题、prefix 完全相同，差别只在图像。学生 rollout 由原图生成，所以三个分布都在同一 prefix 上打分。

3.2 模态平衡对数边际与信任域Logits margin and trust region

δMBt = log q+t(yt) − log q−t(yt)   ;   RMB(y) = { t ∈ Ty : δMBt > 0 } 式 (7)(8)：只比较学生实际采样到的那个 token y_t 在两个教师下的对数概率。

正边际意味着：同一个 token，在放大证据区域后比在遮挡后更受支持。这些位置被认为“依赖视觉证据”，进入信任域。

3.3 目标函数Objective

LOPD-V(θ) = E [ (1 / Σt rt) · Σt∈RMB(y) rt δMBt · DJS( q+t ‖ pθ,t ) ] 式 (9)：只在信任域内蒸馏；δMBt 作为该 token 的权重；归一化按有效 token 数，不按权重和。
  • 蒸馏目标是正教师 q+，不是负教师；负教师只通过 δ 进入，决定“压不压这个位置、压多重”。
  • 散度用 Jensen–Shannon（β=0.5），不是 reverse KL。这是与 CRISP 的一个关键工程差异。
  • EMA 教师：每次更新后 θ̄ ← (1−τ)θ̄ + τθ，τ=0.05（保留 95% 旧教师参数）。

04算法逐行与工程细节Algorithm and engineering details

复现要看懂哪几行？The lines that matter for reproduction.

4.1 训练循环（Algorithm 1）Training loop

  1. 初始化教师参数 θ̄ ← θ。
  2. 每个训练步取 mini-batch B；对每个样本取 I_zoom（训练数据自带），生成 I_mask = Mask(I_zoom)。
  3. 每个 prompt 采样 n=8 条 rollout y ~ pθ(·|I,x)。
  4. 对每个生成的 token：计算 pθ,t、q+,t、q−,t；算 δ；只有 δ>0 且 r_t=1 时，计算 JSD 并加权累加。
  5. 按有效 token 数归一化 rollout 损失；batch 内按 n|B| 再归一化。
  6. 更新学生；随后更新 EMA 教师。

4.2 Top-K 蒸馏与尾部概率Top-K distillation with tail bucket

  • 只取学生分布的 top-K=100 个 token 作为候选集 K_t；正教师在同一集合上求概率。
  • 每个分布保留 top-K 概率，再加一个尾部桶 s_tail = 1 − Σ_{v∈K_t} s(v)，得到 K+1 维分布，避免物化全词表。
  • 论文称 top-100 之外的累计概率 <1×10⁻¹³，近似无损。
  • JSD 按标准混合分布 m=(q+ + p)/2 计算。

09对双教师项目的意义What this means for our project

我们在它的基础上还能做什么？What can we build on top of it?

1. 它是 G0 基线，且我们已经有它的 4B 模型与评测链。工作5 用的就是 OPD-V-Qwen3.5-4B；复现口径、官方判别器问题、人工审计结论都可直接继承。

2. 它已经用了“两个教师 + token 级选择”。这进一步压缩了“双教师架构”的新颖性，但也给了我们现成的工程模板：多教师前向、EMA、token 级信任域都可以复用。

3. 它的“正负对照”正好是我们要的冲突检测工具。如果再加一个“简洁教师”，就变成三路信号；冲突可能表现为：视觉信任域内的 token 被简洁信号要求删除。G2 可以在这个信任域上直接测长度与 grounding。

4. 可借的工程细节：top-K + 尾部桶、JSD、EMA 教师、δ 加权、按有效 token 归一化、图像字段 bbox_images、评测的不加权平均口径。

不能直接借的假设：① 它的 token 选择衡量“是否依赖视觉”，不衡量“是否冗余”；② 它的负教师是随机遮挡，不是“简洁”；③ 评测是选择题，grounding 指标（CHAIR/POPE）不在它的评测里，我们需要自己补；④ 论文未给学习率等完整超参，复现需读代码。

10口头报告提纲与可能追问Oral outline and likely questions

5 分钟怎么讲，导师会问什么。A five-minute script and the obvious follow-ups.

10.1 五分钟提纲Five-minute script

  1. 问题：视觉 OPD 的教师即使看到细节，模型也可能主要靠语言先验答题——模态失衡。
  2. 方法：正教师看放大证据，负教师看随机遮挡；同一 token 在两边对数概率差为正，才算“依赖视觉”，只在这些位置蒸馏正教师。
  3. 结果：4B 平均 64.30→80.01，超过 Vision-OPD 2.91 分；输出从 553.8 降到 140.9 tokens；单步反而快 31.8%。
  4. 消融：正、负教师缺一不可（74.62 / 71.98 / 80.01）；Zoom-In 与 Mask 都不能换成更弱的操作。
  5. 与我们的关系：它证明“两个教师 + token 选择”在视觉侧也已被做过；我们要再进一步，只能做“视觉证据 vs 简洁信号”的仲裁。

10.2 可能被问到的Likely questions

问题回答要点
“它的两个教师不就是双教师吗？”是双教师结构，但不是两种特权：两个教师共享参数，只是同一图像特权的正负对照。我们的设想是两个不同来源的特权（视觉 + 简洁）。
“它需要标准答案吗？”不需要；教师只看图像变换 + 问题 + prefix。这也是它能和 CRISP 并列的原因。
“为什么用 JSD 不用 reverse KL？”教师在训练中持续 EMA 更新，JSD 对称、稳定；CRISP 用旧快照 + reverse KL。两者都可行，但训练动力学不同。
“为什么要 top-K？”全词表 logits 对 VLM 太占显存；top-100 + 尾部桶近似无损。
“输出变短是好事还是副作用？”论文把它当效率结果报告，不是训练目标；它没有显式长度奖励。这恰好说明视觉信任域选择会顺带删冗余。
“我们能直接加一个简洁教师吗？”可以试，但冲突点就在信任域：视觉支持的 token 可能正是简洁教师想删的长推理。必须先做 G2。
