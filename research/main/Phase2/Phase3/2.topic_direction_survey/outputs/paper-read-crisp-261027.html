CRISP：用迭代自策略蒸馏压缩推理Compressed Reasoning via Iterative Self-Policy Distillation

A single model, two prompts: a conciseness instruction defines the teacher, the plain prompt defines the student. Per-token reverse KL on the student's own rollouts internalizes brevity without ground-truth answers. This report covers the method, the exact training configuration, the main results, every ablation, and what transfers to our dual-teacher project.

同一套参数、两个提示：教师加“简洁”指令，学生用原提示；在学生自己生成的轨迹上做逐 token reverse KL， 把简洁行为写回权重，不需要标准答案。本报告覆盖方法、完整训练配置、主结果、全部消融，以及对双教师项目的可迁移部分。

01一句话与方法定位One-sentence summary and positioning

它到底做了什么？What does it actually do?

同一模型，教师 = 模型 + “be concise”指令，学生 = 原模型；在学生自己的 rollout 上，对每个 token 最小化学生到教师的 reverse KL；教师权重每 M=50 步与学生同步一次。不需要标准答案、奖励模型、token 预算或难度估计。

方法定位：这是 on-policy self-distillation（OPSD） 的一个新应用——把“指令带来的简洁行为”当作特权信息蒸馏回权重，而不是在推理时一直挂着 prompt。它与 OPSD（Zhao et al., 2026）的关键区别是：OPSD 的教师看标准答案，CRISP 的教师只看简洁指令。

评测域：数学推理（MATH-500、AIME 2024/2025）为主，另有 GPQA-Diamond、MMLU 检验通用能力。纯文本、无视觉——这一点对我们最重要。

02方法：教师、学生与训练目标Method: teacher, student, objective

训练信号从哪里来，梯度的路径是什么？Where the signal comes from and where gradients flow.

2.1 两个策略Two policies, one set of weights

  • 学生 πθ(·|x)：原始问题 x，不加任何简洁提示。
  • 教师 πθ̄(·|x,c)：同一个模型，问题前加简洁指令 c；参数 θ̄ 是学生的“过期快照”（stop-gradient），不是另一个训练好的模型。
  • 数据：只有题目，没有答案。学生先生成 rollout y ~ πθ(·|x)，教师在同一 prefix y<t 上打分。

2.2 损失函数Per-token reverse KL

L(θ) = Ex~D, y~πθ(·|x) [ (1/|y|) Σt=1|y| DKL( πθ(·|x, y<t) ‖ πθ̄(·|x, c, y<t) ) ] 式 (1)：只有在学生实际生成的 token 位置上计算；教师前向不传梯度。
  • Reverse KL 的方向是 D_KL(student ‖ teacher)，梯度按学生自己的分布加权——学生只在自己真正会生成的 token 区域调整。
  • mode-seeking：删掉简洁教师不生成的 token，保留教师仍在用的推理步骤；更新幅度受学生当前分布约束。
  • 为什么不用 forward KL：forward KL 的梯度按教师分布加权，与学生当前状态解耦；在“教师是学生旧快照”的设定下不稳定。论文报告 Qwen3-8B 用 forward KL 在前 100 步内崩溃，准确率接近 0，长度发散到预算上限。
  • 为什么不用 JSD：JSD 是两者的对称插值，梯度部分学生加权、部分教师加权；论文主实验选 reverse KL，并在附录 G 讨论三者差异。

2.3 与 SFT / RL 压缩的区别Why not SFT or length-penalized RL

路线监督来源问题
SFT on compressed CoT外部整理的短轨迹分布偏移，学生学别人的推理，遗忘自身能力
RL + 长度惩罚标准答案 + 奖励需要可验证答案；过度压缩会损害探索与难题
Prompt / 解码时压缩推理时指令提示一撤效果就消失，不写回权重
CRISP学生自己的 rollout + 简洁指令无 GT、无奖励工程、无难度估计；但依赖基座的指令跟随能力

03教师参数化：周期刷新是关键旋钮Teacher parameterization: periodic refresh

为什么教师不能一直冻结，也不能每步都同步？Why neither a frozen teacher nor a per-step refresh works.

θ̄ ← θ    every M training steps   (默认 M = 50) 式 (2)：每 M 步把学生权重复制给教师；两次刷新之间教师固定、不传梯度。
  • 冻结教师（M=∞）：稳定，但学生学会初始简洁信号后，教师不再提供更强的压缩目标，压缩上限受限。
  • 周期刷新（M=50）：每次刷新后，新教师已经内化了上一轮压缩，在同样指令下会生成更短的轨迹，形成渐进压缩；同时离散刷新避免了连续互相追逐。
  • 每步刷新（M=1）：学生追一个随自己变化的移动目标，正反馈导致崩溃。论文 Qwen3-8B 上 MATH-500 准确率跌到 60.8%、AIME 2024 跌到 6.7%，且响应长度反而变长。
  • EMA 教师（附录 F）：θ̄ ← λθ̄ + (1−λ)θ，λ∈[0.99,0.999]；比冻结强、比 M=1 稳，但需要监控崩溃。主实验不用 EMA。

04训练算法与完整配置Algorithm and full training configuration

复现需要哪些细节？Everything needed to reproduce it.

4.1 每个训练步做什么Per-step procedure

  1. 每 M 步刷新教师：θ̄ ← θ。
  2. 取一个 batch 的题目，学生按原始 prompt 生成 rollout（每个 prompt 1 条）。
  3. 在 rollout 的每个位置计算学生分布 q_t 与教师分布 p_t（教师输入 = 题目 + 简洁指令 + 同一 prefix）。
  4. 逐 token 计算 reverse KL，按序列长度归一化，得到该样本损失。
  5. 只对学生反传；教师前向 no_grad，logits 分块计算、用完即释放。
  6. 所有 rollout 都用于训练，不按正确性过滤——因为没有标准答案。

容易被忽略的对照：“只加 prompt”本身就能压缩 20–43%，而且在 Qwen3-14B 的 MATH-500 上准确率反而升到 95.9。因此“prompt 压缩一定掉点”这个前提在 CRISP 的表格里并不普遍成立——掉点主要出现在 AIME 2025 这类最难题上。做故事第一幕时要把这个细节讲清楚，否则会被追问。

06消融：每个旋钮的作用Ablations: what each knob does

哪些设计真的重要？Which design choices actually matter?

6.1 压缩甜点区 ≈ 2×Compression sweet spot

训练越久越短，但准确率先在 AIME 2024、后在 MATH-500 下滑。MATH-500 长度从 4,823 降到约 2,000（2.4×），准确率在约 2× 压缩前保持 ~95%，之后降到 93%；AIME 2024 在 2× 后从 70–74% 掉到 57%。论文选 step 99（1.45×，偏保守），而不是训到 epoch 末尾。

6.2 教师刷新间隔 MTeacher refresh interval

M行为
1崩溃：学生追移动目标；MATH-500 60.8%，AIME 2024 6.7%，长度反而变长

6.3 简洁指令措辞Instruction variants

五个变体（v1 统一简洁、v2 难度感知、v3 指定可删/必留类别、v4 面向专家、v5 编号列表）结果接近，说明不是单条 prompt 调出来的。v1 与 v2 的取舍最清楚：

指令原文要点效果
v1 统一简洁“Solve concisely… avoid unnecessary elaboration, redundant steps, or restating the problem.”压缩最多（MATH-500 −56%），最难题掉点最多
v2 难度感知“Prioritize a correct final answer above brevity… For difficult or multi-step problems, do NOT over-compress…”压缩少约 20 个百分点，AIME 2025 只掉 2.1（14B）

6.4 采样温度与 rollout 长度Temperature and rollout length

  • 温度 0.3–1.5：MATH-500 准确率波动 ≤0.7pp，压缩率 30.8–33.3%；默认 1.0 在 AIME 上最稳（−1.6%）。
  • 训练 rollout 上限 1K / 4K / 8K / 30K：1K 就足以训练（29.8% 压缩、无准确率损失）；8K 最佳（31.6%、AIME −1.6%）；30K 最差（AIME −6.5%、只压 13.8%），因为无约束的长 rollout 让学生先强化了自己的啰嗦。

6.5 KL 方向Reverse vs. forward vs. JSD

附录 G：reverse KL 的梯度由学生分布加权，自带“不跑远”的正则；forward KL 由教师加权，在教师是旧快照时前 100 步崩溃；JSD 介于两者之间。这是方法能稳定训练的关键工程选择。

07理论解释（口头报告用）Theory in plain words

为什么这么简单的目标能同时压缩和保准确率？Why does it work?

  • Lemma 1：逐 token KL 之和等于序列级 KL D_KL(πθ(·|x) ‖ πθ̄(·|x,c))（自回归链式法则）。
  • Theorem 1（隐式奖励）：目标等价于最大化 r_t = log πθ̄(y_t|x,c,y<t) − log πθ(y_t|x,y<t)——教师比学生更支持某个 token 时奖励为正。相当于一个随策略变化的“简洁奖励”，但不需要显式长度惩罚。
  • Theorem 2（准确率界）：Acc(θ) ≥ Acc(teacher) − T − √(KL/2)，T 是教师相对基座的准确率差。简洁教师不掉点时，学生最多掉 √(KL/2)。
  • Prop. 1（难度自适应）：可压缩 token 的 KL 更大，难题的 essential token 占比更高，所以压缩压力随难度下降。
  • Prop. 3（复合误差）：若每个 token 独立以概率 p_err 引入错误，去掉冗余 token 会指数级降低复合错误——解释了“更短反而更准”。

一句话：它把“简洁”变成了一个策略内生的奖励，而不是外加的长度惩罚；教师只提供目标分布，不提供答案。

09对双教师项目的意义What this means for our project

这篇论文在我们的故事里站在哪？Where it sits in our story.

1. 它是 G1 的现成实现。“单教师 + 简洁指令”就是 CRISP；代码公开（github.com/HJSang/OPSD_Reasoning_Compression），训练配置完整。我们可以直接复现 G1，而不是从零写。

2. 它把“冲突假设”机制化了。reverse KL 会删掉简洁教师不生成的 token；如果这些 token 恰好是视觉证据驱动的长推理，压缩就会伤 grounding。这就是“单教师叠两种特权会打架”的可检验版本。

3. 它证明了“简洁教师”组件不新。novelty 不能放在“用简洁指令做教师”上，只能放在仲裁信号（视觉证据门控）和受控证据上。

4. 可以直接借的工程细节：reverse KL、教师周期刷新、每 prompt 单 rollout、截断 rollout、不做正确性过滤、分块 logits。这些都能进 G0–G3 实验。

不能直接借的假设：文本单模态、数学答案可验证、简洁指令是唯一特权。迁到 VLM 时，教师输入要同时改变图像和文本提示，冲突点正在这里；而且我们还要回答“压缩掉的是不是视觉证据”。

10口头报告提纲与可能追问Oral outline and likely questions

5 分钟怎么讲，导师会问什么。A five-minute script and the obvious follow-ups.

10.1 五分钟提纲Five-minute script

  1. 一句话：同一模型加简洁指令当教师，在学生自己的输出上做 reverse KL，把简洁写回权重。
  2. 为什么不需要答案：监督来自两个 prompt 的分布差，不来自正确性；所以能用在没有标准答案的场景。
  3. 三个关键工程选择：reverse KL（稳定）、教师每 50 步刷新（渐进压缩）、截断 rollout（便宜）。
  4. 结果：14B 上 MATH-500 短 56%、准确率反升 3.3 分；但 AIME 2025 掉 6.3，难题是代价所在。
  5. 与我们的关系：它就是“单教师 + 简洁”这一半；我们缺的是“视觉特权 + 简洁”放在一起会不会冲突的实验。

10.2 可能被问到的Likely questions

问题回答要点
“这不就是加个 prompt 吗？”prompt 只在推理时有效；CRISP 把行为写进权重，撤掉 prompt 仍保留。但论文表格确实显示 prompt 本身能压 20–43%，所以差异要用“撤掉 prompt 后的保留率”来证明。
“为什么用 reverse KL？”教师是学生旧快照，forward KL 会崩；reverse KL 的梯度按学生分布加权，自带信任域。
“教师为什么要刷新？”冻结教师的压缩上限低；每步刷新会追移动目标崩掉；M=50 是稳定与压缩的折中。
“为什么不用标准答案？”用了就变成普通 OPSD；不用 GT 才能迁到没有验证器的域。代价是依赖指令跟随。
“压缩为什么能提准确率？”冗余 token 本身会引入复合错误；去掉它们降低错误累积，前提是没有删掉 essential steps。
“能直接搬到视觉吗？”不能直接搬：单模态、数学域、无视觉特权；需要把视觉证据当额外特权，并重新测 ground。
