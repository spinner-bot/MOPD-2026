# Short-Output Prompt Study

本目录是 Phase2 的 2 号工作：在同一批视觉选择题样本上比较 S0、SC、S1、S2、S3 五种 system prompt 条件，评估输出压缩对准确率、格式遵循率和输出长度的影响。

## 目录结构

- `protocol.md`：实验协议与冻结规则；
- `prompts/`：五组 prompt 的固定版本；
- `scripts/`：样本冻结、推理、解析和统计脚本；
- `raw/`：冻结输入、图像索引、五组完整原始输出；
- `derived/`：由 raw 独立生成的派生指标；
- `figures/`：论文式统计图表；
- `report/`：最终图文分析报告；
- `runs/`：任务级运行记录和日志。

正式实验使用 CV-Bench 的 2638 条完整测试样本作为抽样框，从中固定随机抽取 2000 条。正式抽样前必须通过唯一性、字段完整性和图像可读性门禁。
