# Phase2 工作 4：五组输出的大模型重判与报告重建

本工作承接 2 号短输出提示词比较和 3 号 S0/S1/S3 配对翻转分析。既有 `analyze_outputs.py` 以正则规则抽取自由文本中的选项字母；案例审阅已确认规则抽取不可靠。工作 4 将保留每条旧规则判别结果，另行记录本地大模型判别及证据，再用新标签全面重做工作 2。工作 3 先比较纠正后的 S2 效应，依据配对统计、独有翻转和任务分布决定采用原版三模式范围或扩展到 S2。

## 目标

对正式作业 `60011513` 的五种条件 S0、SC、S1、S2、S3 各 2000 条原始回答（共 10000 条）重新识别模型最终作答选项，按冻结样本的 gold option 计算正确性；保留旧规则标签并完成判别器对照统计；重做工作 2 和按证据决定范围的工作 3，最终将其完整整合为本工作的一份双语图文报告。

报告保留 2 号工作的输入对照、五组结果、配对比较、输出长度与正确性分析、tokenizer 长尾分析、研究方向评估、任务观察、十个代表性案例（原图及五组完整原始回答）；并保留 3 号工作全部相应分析，必要时扩展为 S0/S1/S2/S3 16 状态。新增旧规则与大模型判别器一致性、分歧方向和正确性变化统计。所有依赖答对/错标签的旧结果均以本工作新判别结果重算。原始输出及冻结样本仍引用 2 号工作的权威文件，不复制或覆盖。

## 目录

- `protocol.md`：重判标签、判别提示、质量审查与重分析约定；
- `scripts/`：核验、推理、解析、统计与报告构建脚本；
- `raw/`：本工作生成的判别请求、完整判别器响应及版本信息；
- `derived/`：逐条最终选项、判别状态、正确性和重算指标；
- `figures/`：重分析图表；
- `report/`：合并后的中英双语成品报告；
- `runs/`：模型配置、调度记录、日志和质量门禁结果。

原始输入：`../2.short_output_prompt_study/runs/60011513/outputs/{S0,SC,S1,S2,S3}.jsonl`。样本、答案、图像和 token 依据分别回溯至 2 号工作的 `raw/` 与 `derived/run-60011513/`。3 号工作旧报告只作为内容清单，不再作为正确性标签来源。
