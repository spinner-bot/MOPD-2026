# 五组短输出 Prompt 研究协议

## 研究问题

在模型权重、图像、user query、推理参数和数据样本完全一致的条件下，逐级增加 system prompt 的输出约束，是否能降低输出成本并保持视觉选择题准确率？

## 条件

- S0：无 system prompt，保留官方评测接口；
- SC：中性 system prompt，只说明视觉问答角色和任务；
- S1：要求简洁回答，不输出不必要解释；
- S2：要求回答正确选项字母；
- S3：要求严格只输出一个字符 A/B/C/D。

## 固定规则

1. 从同一数据源无放回随机抽取 2000 条样本；
2. 固定随机种子并冻结样本清单；
3. 五组使用同一份样本、同一图像、同一 user query；
4. 只改变 system prompt；
5. 原始模型输出完整保存，不在推理阶段清洗；
6. 统计分析从 raw 产物独立生成；
7. 任何 prompt 或样本修改都生成新版本，不覆盖旧产物。

## 数据规模门禁与数据集

HRBench-4K 的完整公开 parquet 仅包含 800 条，不能通过重复采样达到 2000 条，因此不作为本实验的主数据源。

本实验采用 CV-Bench 的完整公开测试集合：2D 部分 1438 条、3D 部分 1200 条，共 2638 条。由于 S3 的标签空间固定为 A/B/C/D，排除超过四个选项或参考答案超出 A–D 的样本后，形成 2343 条合格抽样框，再无放回随机抽取 2000 条。抽样后报告实际的 2D/3D、任务类型和来源构成，以及排除数量。

正式抽样前必须完成两部分图像解码、题目字段、选项字段、答案字段和唯一 ID 的完整性检查。

## 主要指标

- 准确率；
- 有效选项率；
- 严格格式遵循率；
- 输出字符数和 Token 数；
- 空输出、异常输出和 API 错误；
- 样本级配对正确性变化。

## 统计方法

使用同一批样本上的配对比较；准确率差异报告 McNemar 检验或配对二项检验，并提供 bootstrap 置信区间。多组比较进行多重比较校正。输出长度报告配对差异、分布和分位数。
