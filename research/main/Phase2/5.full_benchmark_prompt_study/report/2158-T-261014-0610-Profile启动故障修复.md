# 2158-T：系统 Profile 启动故障修复

日期：2026-10-14

长上下文专项作业 `60414416` 在启动后2秒失败。错误日志显示 `/etc/profile` 在读取未定义的 `HISTCONTROL` 时退出；批处理脚本此前已启用 `set -euo pipefail`，故模型尚未加载、GPU推理尚未开始。

同一严格模式与 profile 加载顺序也出现在待执行的答案抽取、Vision-OPD原生评分及专项验证脚本中。现统一在 `source /etc/profile` 前暂时关闭严格模式，加载后立即恢复 `set -euo pipefail`，再加载 CUDA 模块。全量生成和输出冻结脚本不采用该profile加载路径。

本修复只针对启动环境，不改变输入、prompt、模型、精度、上下文、采样或判分行为。更新经GitHub同步后，对批处理文件运行 `bash -n`，随后重提长上下文单样本验证。验证通过前，长回答抽取适配仍未视为实测通过；全量推理数组继续等待调度。
