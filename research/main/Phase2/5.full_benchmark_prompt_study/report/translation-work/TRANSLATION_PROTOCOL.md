# 审阅页中文译文统一规程

本规程适用于审阅页中全部60个案例、全部300条条件记录，以及页面级说明。所有项目一律适用，不按样本、条件、回答长度、答案正确性、内容复杂度或预期研究价值改变处理标准。

1. **逐项完整翻译。** 对部署清单中指定的每个英文文本字段提供中文译文。不得跳过、摘要、删节、挑选或只翻译部分段落；重复内容也照常翻译。
2. **原文与译文并列。** 英文源文保持逐字不变，译文作为独立附加内容呈现。不得以译文替换、修正或覆盖源文。
3. **忠实保留内容状态。** 保留原文的命题、限定、否定、指代、推测语气、矛盾、自我修正、重复、选项字母、数字、公式、列表顺序及段落边界。不得替作者消除矛盾、纠错、补足论证或改写成更合理的回答。
4. **统一术语与符号处理。** 同一术语在上下文含义相同时采用一致译法；人名、地名、选项标签、变量、代码、公式标记及有意义的格式标记按同一原则处理。术语选择不得成为增删或重释内容的理由。
5. **分块仅是传输手段。** 长文本只可在完整段落边界处分块；块的顺序与边界必须可追溯，连接时恢复段落间距，不得丢失、重复、调换或改写源文段落。不得因文本长而降低翻译完整度。
6. **重复串的无损表示。** 对源文中完全相同且连续重复的片段，可在中间清单中记录源片段、Codex撰写的对应译句、分隔符和精确次数；生成时必须逐次展开到最终页面，并校验展开前源文指纹。不得在交付页面中用“重复N次”等记号代替原有内容。
7. **一致性审校。** 每个译文均检查其源文覆盖、顺序、数字/选项/公式、否定与不确定语气、重复及矛盾是否保留。审校标准对所有样本相同；任何发现的偏差按同一规程修正。

本规程约束处理方法，不预设任何案例的结论或质量判断。翻译不得改变原始实验记录及审阅判断对象。
