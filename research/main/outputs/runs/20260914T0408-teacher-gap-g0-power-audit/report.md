# 20260914T0408-teacher-gap-g0-power-audit

阶段：G0 结果产生前的配对 accuracy 功效审计。

**创建时间**：2026-09-14 04:08（UTC+8）  
**创建作者**：Codex (CINECA Leonardo)  
**触发原因**：1017 固定 96 个 locked 样本和两项 Holm 校正主要比较，但没有量化 McNemar 显著性对条件间总翻转率的敏感性。需要在任何 S/T 结果存在前明确最小 pilot 的解释边界。

## 方法

令 `b=P(S错,T对)`、`c=P(S对,T错)`、净 accuracy 增益 `δ=b-c`，总 discordance `d=b+c`。给定 `N,d,δ`，总 discordant 数服从 `Binomial(N,d)`；在 discordant 样本内，正向翻转概率为 `(d+δ)/(2d)`。本轮对每个可能的 discordant 数求单侧 exact McNemar 拒绝域，再对其无条件求和。

固定 `N=96`、`δ=0.08`、单侧 `α=0.025`。`0.025` 是两项主要比较在 Holm 第一步中的保守阈值；真实 Holm 门槛取决于两项 p 值顺序。这里仅审计 paired binary accuracy，不模拟 correct-answer log-prob、Generic-T 区分或人工泄漏复核。

## 结果

| 总 discordance `d` | 96 条功效 | 达到 80% 功效的最小 N |
|---:|---:|---:|
| 0.10 | 0.643 | 125 |
| 0.15 | 0.441 | 198 |
| 0.20 | 0.339 | 258 |
| 0.30 | 0.231 | 387 |
| 0.40 | 0.189 | 510 |
| 0.50 | 0.162 | 634 |

96 条上的 accuracy 分辨率是 `1/96=1.04` 个百分点，所以 `ΔAcc≥0.08` 实际至少需要净 8 次翻转，即 8.33 个百分点。如果恰有 8 次净翻转，8 对 0、9 对 1、10 对 2 的单侧 p 值分别为 0.0039、0.0107、0.0193；11 对 3 已是 0.0287，不能单独通过保守的 0.025 门槛。由此，同样的净增益在反向翻转更多时，显著性和稳定性都会下降。

## 裁决

96 条继续作为 1017 的**最小、大效应信号 pilot**，不追溯扩样，也不降低 Go 门槛。它适合回答“当前 G 是否产生足够大且方向稳定、值得扩展的 teacher gap”，不适合把一次未显著解释为文本特权普遍无效。

结果报告必须同时给出 `b,c,d`、净翻转和 exact p，而不能只给 ΔAcc。若观察到 `ΔAcc≥0.08` 却因反向翻转多而 Holm 后不显著，应按 1017 归入 Revise/不稳定，而不是 Stop。Stop 当前配方仍需联合满足小 ΔAcc、小或不确定的 ΔCorrectLP 和无稳定净翻转。任何正式机制确认样本量在 G0 后、读取 G1 结果前根据实际方差和预算一次性冻结，沿用 1037，不用本表事后挑选 N。
