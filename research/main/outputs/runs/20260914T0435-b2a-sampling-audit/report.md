## 审计结果

从 scratch 中的 10,565 图完整 B0 manifest 独立重算固定 seed `20260914` 的 `sha256(seed\0image_candidate_id)` 排名。八项 fail-closed 断言全部通过：完整池 ID 唯一；归档的 256 图与全池重算逐字典记录一致；256 图严格按哈希排列；其前 32 图等于绕过 256 中间层直接从全池取得的前 32 图；B2a 的 32 个 image ID 与该前缀逐项一致；source index 为 0–31；源题与机器 proposal 暴露标志均为 false。

因此，B2a 前 32 不是源输入的前 32，也不是按原题数量、原题类别、B1 分数或人工视觉印象挑选。B0 先按 `source_image_id` 聚合为一图一条记录，稳定 ID 只由该图片 ID 产生，随后才做哈希排名。即使一张图片关联多个 M3VQA 问题，`source_record_count` 也只在图片入选后保留作 provenance，不进入排名函数。

描述性核对与这一机制一致：完整池中 1,400/10,565（13.25%）图片关联多条源题，冻结 256 图为 36/256（14.06%），B2a 为 3/32（9.38%）；对应每图源记录均值为 1.2423、1.2383、1.0938。32 图很小，这些比例只用于发现明显管线错误，不能充当随机性检验或总体代表性证明。

本审计证明的是**抽样实现没有读取问题内容或按每图题目数加权**。固定哈希样本仍只是 M3VQA 已有图片总体的样本，不能纠正该数据集在最初采图阶段可能存在的 P/R 图像可供性偏向，也不能把单审核者 32 图结果直接外推为 10,565 图总体真值。该来源层风险仍由 1039 的 0、1–7、8–32 预注册路由和同规模外部图源比较处理。

本轮没有读取源问题文本，没有查看图片语义，没有产生或修改任何人工标签，`human_verified=0`。
