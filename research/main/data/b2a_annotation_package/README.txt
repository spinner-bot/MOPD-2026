B2a 盲审标注数据包
===================

本数据包用于完成 32 张图片的人工盲审标注任务。

## 文件说明

- 标注工具.html - 双击打开即可使用的标注界面
- 标注指南.md - 详细的操作指南（必读！）
- images/ - 32 张待标注的图片
- convert_results.py - 结果转换脚本（标注完成后使用）
- blind-review-32.jsonl - 原始元数据（转换脚本需要）

## 快速开始

1. 阅读《标注指南.md》
2. 双击打开《标注工具.html》
3. 逐张标注 32 张图片
4. 点击"导出全部结果"
5. 将整个文件夹打包回传

## 注意事项

- 必须独立完成，不得查看原问题、答案或任何机器标注
- 必须标注所有 32 张图片
- 答案必须完全来自图片，不需要外部知识
- 如有疑问，请仔细阅读标注指南中的示例和说明

## 技术支持

如果 HTML 文件无法打开，请尝试：
- 使用 Chrome、Edge 或 Firefox 浏览器
- 确保 images 文件夹与 HTML 文件在同一目录
- 检查浏览器是否禁用了 JavaScript
