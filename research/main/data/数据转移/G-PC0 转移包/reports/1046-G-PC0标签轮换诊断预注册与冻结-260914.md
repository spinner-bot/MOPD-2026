## 1. 诊断问题与边界

本诊断只回答：**固定 A/B/C/D 输出接口是否遮蔽了现有 T-QA 的语义信号？** 它不重新裁决 G-PC0 v1，不检验自然图片的 R/PR 可供性，不授权自然 G0、数据扩量或训练。

G-PC0 v1 的 `INGESTION_OR_RECIPE_FAILURE` 永久保留。本诊断是看到 v1 标签塌缩后新建的 posthoc diagnostic，不能追溯改写为事前实验。

## 2. 唯一允许改变的变量

冻结的 16 张图、问题、四个语义选项、正确语义选项、guide、四条件 prompt shell、Qwen3.5-4B revision、非 thinking、确定性生成及 choice scoring 全部不变。每个基础样本扩成四个循环映射：

`semantic_index = (displayed_index + rotation) mod 4`，其中 `rotation ∈ {0,1,2,3}`。

因此同一语义选项恰好各以 A、B、C、D 出现一次。64 个轮换样本仍分别运行 S、T-Q、T-QA、Generic-T，共 256 条 sample-condition 记录；只允许一次串行的 4×A100 allocation。

## 4. 唯一主聚合

对每个基础样本、每个条件和每个语义选项，把四次轮换中该语义选项所占 displayed label 的**原始单 token full-vocabulary log-likelihood**取算术平均。随后在四个语义均值中取最大项为聚合预测；完全相等时按语义 ID A、B、C、D 顺序打破平局。

此聚合使每个语义选项都恰好承受一次 A、B、C、D 的静态标签偏置。生成字母映射回语义后的多数票、T-Q、Generic-T、family 分层均只作描述，不参与主裁决，也不得替换原始分数聚合。

## 5. 结果盲裁决

先要求 256/256 记录通过完整性、provenance、四轮换映射、image checksum、score 有限值和 parse ≥99% gate。否则唯一决定为 `INVALID`。

通过 gate 后，以语义聚合的 S 与 T-QA 比较：

| 条件 | 唯一决定 | 含义 |
|---|---|---|
| S ≥14/16 | `ROTATION_CEILING_INCONCLUSIVE` | 消除标签偏置后基线接近天花板，不能测 teacher 增益 |
| S <14/16，且 T-QA 错→对 ≥4、净翻转 ≥3 | `LABEL_INTERFACE_MASKED_G_SIGNAL` | 固定字母接口曾遮蔽可行为化的 G 语义信号 |
| 其他 | `GUIDE_OR_MODEL_INGESTION_FAILURE_AFTER_ROTATION` | 标签轮换仍不能恢复预定 teacher utility；下一步只能另行冻结表示或模型诊断 |

16 个基础样本不作显著性主张。无论落在哪个分支，`natural_image_claim_authorized=false`、`training_data_authorized=false`，自然 G0 均不自动解锁。

结果后状态见 1047：run2 通过 256/256 gate，得到 S/T-Q/T-QA/Generic-T=3/3/9/2、T-QA 六个净增益和 `LABEL_INTERFACE_MASKED_G_SIGNAL`。本节冻结规则未作结果后修改。

## 6. 防止结果后自由度

1. 不根据单题结果删题、改图、改 guide、换答案文字或选择轮换子集。
2. 不在 raw 出炉后切换到 probability 平均、rank 平均、最大值、投票或其他聚合。
3. 不把正确标签绝对 log-prob 上升当作通过；只使用四语义聚合排序后的配对行为翻转。
4. 若失败，下一步必须先编号并冻结新的表示/模型摄取诊断；不得直接归因于自然图片或 G 理论。
5. 本包永不并入自然 8/32/96 manifest 或训练数据。
