## 技术细节

### Probe Logging 配置
```yaml
probe_logging:
  enabled: true
  interval: 10              # 每 10 步记录一次
  probe_batch_path: ./probe_data/probe_batch.jsonl
  output_dir: ./probe_logs
```

### 对齐度计算
```python
# JS 散度计算
vl_probs = softmax(vl_logits)
text_probs = softmax(text_logits)
m_probs = 0.5 * (vl_probs + text_probs)
kl_vl_m = sum(vl_probs * log(vl_probs / m_probs))
kl_text_m = sum(text_probs * log(text_probs / m_probs))
js_div = 0.5 * (kl_vl_m + kl_text_m)

# Top-1 一致率
top1_agree = (argmax(vl_logits) == argmax(text_logits))
```
