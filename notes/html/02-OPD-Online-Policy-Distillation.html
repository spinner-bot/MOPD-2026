第一章 · 萌芽期（2015–2017）

1.1 🌅 黎明：Rusu et al. (2015) 中的 "Online Distillation"

📄 Policy Distillation — Google DeepMind, ICLR 2016

arXiv: 1511.06295 | 作者: Andrei A. Rusu 等 9 人 | 引用: 1000+

Policy Distillation 论文提出了三种蒸馏模式，其中第三种——"Online Distillation"——创造了 OPD 这个概念。关键设计：教师与学生并行训练，DQN 教师一边与环境交互（在线 Q-learning），一边向学生提供蒸馏信号。学生每 N 步异步更新一次。

离线蒸馏：教师训练完 → 冻结 → 生成数据 → 学生训练 → 部署
在线蒸馏：教师 ─→ 训练中 ─→ 训练中 ─→ 训练中
               ↘         ↘         ↘
                学生 ←── 学生 ←── 学生 ←── （持续接收信号）
💡 本质区别

教师的知识是活的、进化的。学生学到的不是教师的"最终答案"，而是"教师在不同训练阶段如何思考问题"。这为后来的所有 OPD 研究埋下了种子。

1.2 🏛️ Distral (Teh et al., 2017) —— 蒸馏作为通信协议

📄 Distral: Robust Multitask RL — DeepMind, NeurIPS 2017

arXiv: 1707.04175 | 作者: Yee Whye Teh, Victor Bapst 等 (全 DeepMind)

Distral 提出了一个优雅的框架：将蒸馏视为任务特定策略与共享策略之间的"通信协议"。引入两级策略：$\pi_0$（共享/中心策略，捕获通用行为）和 $\pi_i$（任务特定策略，专门解决第 i 个任务）。

核心数学：联合目标函数

$$J(\pi_0, \{\pi_i\}) = \sum_i \mathbb{E}_{\pi_i}\left[\sum_{t \geq 0} \gamma^t R_i(a_t, s_t) - c_{\text{KL}} \gamma^t \log\frac{\pi_i(a_t|s_t)}{\pi_0(a_t|s_t)} - c_{\text{Ent}} \gamma^t \log \pi_i(a_t|s_t)\right]$$

逐项解读：① $\sum \gamma^t R_i$：标准 RL 目标；② $-c_{KL} \gamma^t \log(\pi_i/\pi_0)$：KL 惩罚——让任务策略不要偏离共享策略太远；③ $-c_{Ent} \gamma^t \log \pi_i$：熵奖励——鼓励探索。

交替优化过程

# Distral 的核心训练循环（伪代码）
for iteration in range(num_iterations):
    # Phase 1: 固定共享策略 π₀，优化所有任务策略 πᵢ
    for task_i in tasks:
        for step in range(steps_per_task):
            # 根据软 Q-learning 更新 πᵢ
            # πᵢ(a|s) ∝ π₀(a|s)^α · exp(Qᵢ(s,a)/β)
            # KL 惩罚使 πᵢ 不会偏离 π₀ 太远
            update_task_policy(task_i, shared_policy=π₀)

    # Phase 2: 固定所有 πᵢ，蒸馏到 π₀
    # π₀ = argmin Σᵢ D_KL(πᵢ || π₀)
    # 从所有任务策略中提取共性
    distill_shared_policy(task_policies, shared_policy=π₀)

软 Q-learning 视角

$$\pi_i(a|s) \propto \pi_0(a|s)^{\alpha} \cdot \exp\left(\frac{Q_i(s,a)}{\beta}\right)$$

任务策略 = 共享先验 × 任务特定的 Q 值。α 越大 → 越保守（偏向共享策略）；β 越大 → 越激进（偏向 Q 值驱动）。

💡 蒸馏作为"通信"

π₁ → 蒸馏 → π₀ ← 蒸馏 ← π₂。π₀ 学到的通用行为被 "广播"回所有任务策略（通过 KL 正则化）。蒸馏不再是单向的教→学，而是双向的、社会化的知识共享。

1.3 🔬 Actor-Mimic 中在线信号的精炼

Actor-Mimic (Parisotto et al., ICLR 2016) 的两个关键贡献：

① Q 值截断——教师不确定的状态跳过蒸馏：

$$\mathcal{L}_{\text{distill}}(s) = \begin{cases} D_{KL}(p_T\|p_S) & \text{if } \max_a Q_T(s,a) > \theta \\ 0 & \text{otherwise} \end{cases}$$

② 特征空间的结构化蒸馏：$\mathcal{L}_{\text{feature}} = \| f_T(s) - W_r \cdot f_S(s) \|_2^2$，学生不仅模仿"做什么"，还要模仿"怎么看"。

🧪 极简实现：基于 Actor-Mimic 的在线蒸馏

import torch, torch.nn.functional as F, numpy as np

class OnlineDistillationAgent:
    """基于 Actor-Mimic 思想的在线策略蒸馏智能体"""
    def __init__(self, student, teacher, T=0.01, q_threshold=0.5):
        self.student = student      # 学生 Q 网络
        self.teacher = teacher      # 教师 Q 网络 (frozen)
        self.T = T                  # 蒸馏温度
        self.q_threshold = q_threshold  # Q 值截断阈值

    def act(self, state, epsilon=0.1):
        """ε-greedy：学生用自己的策略探索"""
        if np.random.random() < epsilon:
            return np.random.randint(self.num_actions)
        with torch.no_grad():
            q = self.student(state)
            return q.argmax().item()

    def distillation_loss(self, states):
        """
        计算蒸馏损失。只对教师置信度高的状态进行蒸馏。
        """
        with torch.no_grad():
            teacher_q = self.teacher(states)

        # 只选择教师 max Q 值 > 阈值的状态
        max_q, _ = teacher_q.max(dim=1)
        mask = (max_q > self.q_threshold).float()

        if mask.sum() == 0:
            return torch.tensor(0.0)  # 所有状态教师都不确定

        # Q 值 → 概率分布 (温度 softmax)
        teacher_probs = F.softmax(teacher_q / self.T, dim=1)
        student_log_probs = F.log_softmax(self.student(states) / self.T, dim=1)

        # 加权 KL 散度
        kl_per_state = F.kl_div(
            student_log_probs, teacher_probs, reduction='none'
        ).sum(dim=1)
        weighted_kl = (kl_per_state * mask).sum() / mask.sum()

        return weighted_kl * (self.T * self.T)

1.4 📋 萌芽期总结

工作核心贡献与 OPD 的关系
Policy Distillation (2015)首次提出"在线蒸馏"OPD 的词汇和概念来源
Actor-Mimic (2016)自生成轨迹+特征回归+截断OPD 的技术组件
