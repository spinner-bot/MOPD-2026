### 2.2 flash_attn 编译安装
- **错误**：`ModuleNotFoundError: No module named 'flash_attn'`
- **原因**：训练 actor 模型时需要 `flash_attn.bert_padding` 的 padding 工具函数，PyPI 无预编译 wheel（torch 2.10 + CUDA 12.9 太新）
- **解决**：源码编译 flash-attn（约 30 分钟）
  ```bash
  pip install ninja packaging psutil
  pip install flash-attn --no-build-isolation
  ```

### 2.2 GPU 显存不足
- **错误**：`ValueError: Free memory on device cuda:0 (42.31/139.8 GiB) on startup is less than desired GPU memory utilization (0.5, 69.9 GiB)`
- **原因**：卡 1,2,3,4,5 被其他任务占用，显存不够
- **解决**：切换到卡 1 单卡训练（140GB 空闲）

### 2.3 tmux 保护训练
- **问题**：训练要跑 43 小时，SSH 断开会导致训练死亡
- **解决**：使用 tmux 会话保护训练
  - 创建：`tmux new -s vopd`
  - 脱离：`tmux detach`（不依赖 Ctrl+B D）
  - 重连：`tmux attach -t vopd`
  - 验证：`tmux ls` 看会话，`ps aux | grep run_vision_opd` 看进程

## 九、关键经验

1. **环境依赖一次到位**：flash_attn、CUDA toolkit 等在环境搭建时就装好
2. **国内服务器连 GitHub 不稳**：预编译 wheel 下载需代理，否则源码编译
3. **conda 装的 CUDA toolkit 不含驱动库**：需指向系统 `/usr/local/cuda-11.8/targets/.../stubs/libcuda.so`
4. **tmux 是长任务必备**：创建会话 → 跑程序 → `tmux detach` 脱离 → 关 SSH
5. **进展报告写"已完成"状态**：不写具体时间线，只写工作内容和耗时
