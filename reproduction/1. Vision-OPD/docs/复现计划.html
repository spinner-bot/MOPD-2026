Vision-OPD 复现计划

目标：在 8×H200 服务器上，半天内完成论文复现 策略：先推理验证（快），再训练对比（稳）

总体时间线

阶段1: 环境搭建      ~30 min   ← 一次性工作
阶段2: 预训练权重推理  ~1 h     ← 快速出成果（安全网）
阶段3: 训练数据准备   ~30 min
阶段4: 训练           ~2-3 h   ← 核心复现
阶段5: 结果对比       ~30 min
────────────────────────────────
总计:                 ~4-5 h    ← 半天内可完成

阶段1：环境搭建（~30 min）

Step 1.1: Clone 仓库

cd reproduction\1. Vision-OPD
git clone https://github.com/VisionOPD/Vision-OPD.git .

Step 1.2: 创建 Conda 环境

conda create -n vision-opd python=3.12 -y
conda activate vision-opd

Step 1.3: 安装依赖

pip install --upgrade pip
pip install --no-deps -r requirements.txt
pip install -e . --no-deps
pip install flash-attn --no-build-isolation
pip install causal-conv1d==1.6.1 --no-build-isolation

Step 1.4: 验证环境

python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"

阶段2：预训练权重推理（~1 h）

Step 2.1: 下载预训练权重

从 HuggingFace 下载 yuanqianhao/Vision-OPD-9B（或 4B 版本）

Step 2.2: vLLM 起服务

vllm serve yuanqianhao/Vision-OPD-9B \
    --gpu-memory-utilization 0.85 \
    --tensor-parallel-size 8 \
    --served-model-name Vision-OPD-9B \
    --trust-remote-code

Step 2.3: 跑评估

API_BASE="http://localhost:8000/v1/" \
OPENAI_MODEL_ID="Vision-OPD-9B" \
JUDGE_API_BASE="<JUDGE_API>" \
JUDGE_MODEL="<JUDGE_MODEL>" \
BENCHMARK="vstar,zoombench,hrbench-4k,hrbench-8k,mme-realworld,mme-realworld-cn" \
bash eval/run_eval.sh

Step 2.4: 记录结果

将评估结果填入对比表，与论文 Table 对照

阶段3：训练数据准备（~30 min）

Step 3.1: 下载数据

从 HuggingFace 下载 yuanqianhao/Vision-OPD-6K

Step 3.2: 预处理

python scripts/prepare_data.py --data-dir ./data

阶段4：训练（~2-3 h）

Step 4.1: 检查超参数

编辑 scripts/run_vision_opd.sh，确认： - 模型路径正确 - Batch size 适配显存 - 训练步数 / epoch 数

Step 4.2: 启动训练

bash scripts/run_vision_opd.sh

Step 4.3: 监控

观察 loss 下降曲线、GPU 利用率

阶段5：结果对比（~30 min）

Step 5.1: 合并 checkpoint

bash scripts/merge_checkpoint.sh

Step 5.2: 评估训练后模型

同阶段2的评估流程
