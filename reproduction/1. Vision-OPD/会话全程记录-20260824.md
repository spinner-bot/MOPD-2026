## 二、解决的问题（按时间顺序）

### 2.1 词表加载失败
- **错误**：`OSError: Unable to load vocabulary from file`
- **原因 1**：Qwen3.5-4B tokenizer 需远程代码，默认 `trust_remote_code=False`
- **原因 2**：模型路径用仓库名 `Qwen/Qwen3.5-4B`，走网络解析，断网报错
- **解决**：
  - 开 `trust_remote_code=True`（model 和 data 两处）
  - 模型下到本地目录 `~/vopd/models/Qwen3.5-4B`，训练指向它

### 2.2 FlashInfer JIT 编译失败
- **错误**：`nvcc fatal: Value 'c++20' is not defined for option 'std'`
- **原因**：系统只有 CUDA 11.8，不认识 `c++20`；FlashInfer 运行时 JIT 编译内核需要 CUDA ≥ 12
- **尝试过的方案**：
  - ❌ `VLLM_ATTENTION_BACKEND=FLASH_ATTN`：vLLM 对 H200+Qwen3.5 不生效，回退 flashinfer
  - ❌ `pip install nvidia-cuda-nvcc-cu12`：wheel 里没 nvcc 二进制
  - ✅ `conda install cuda-toolkit=12.9`：装了完整 CUDA 12.9 nvcc
- **解决**：conda 装 cuda-toolkit 12.9，`nvcc --version` 显示 12.9

### 2.3 链接器找不到 libcuda.so
- **错误**：`/usr/local/.../ld: cannot find -lcuda: No such file or directory`
- **原因**：conda 装的 CUDA toolkit 不含驱动库（libcuda.so），链接 FlashInfer 时找不到
- **解决**：
  ```bash
  export LIBRARY_PATH=/usr/local/cuda-11.8/targets/x86_64-linux/lib/stubs:$LIBRARY_PATH
  export LD_LIBRARY_PATH=/usr/local/cuda-11.8/targets/x86_64-linux/lib/stubs:$LD_LIBRARY_PATH
  ```

### 2.4 flash_attn 模块缺失
- **错误**：`ModuleNotFoundError: No module named 'flash_attn'`
- **原因**：训练 actor 模型时 `from flash_attn.bert_padding import ...` 找不到 flash_attn
- **当前状态**：⏳ 装 flash_attn 失败（GitHub 下载被墙），待解决

## 八、恢复会话后的第一步

```bash
# 1) 进环境
ssh H200
cd ~/vopd
conda activate vision-opd

# 2) 设环境变量
export WORLD_SIZE=1
export HF_ENDPOINT=https://hf-mirror.com
export LD_LIBRARY_PATH=$CONDA_PREFIX/lib:$LD_LIBRARY_PATH
export LIBRARY_PATH=/usr/local/cuda-11.8/targets/x86_64-linux/lib/stubs:$LIBRARY_PATH
export LD_LIBRARY_PATH=/usr/local/cuda-11.8/targets/x86_64-linux/lib/stubs:$LD_LIBRARY_PATH

# 3) 装 flash_attn（选一个方案）
# 方案 A：手动下载 wheel 后
# pip install flash_attn-*.whl

# 方案 B：源码编译（慢）
# pip install ninja packaging psutil
# pip install flash-attn --no-build-isolation

# 4) 重跑训练
CUDA_VISIBLE_DEVICES=5,7 bash scripts/run_vision_opd.sh \
  actor_rollout_ref.model.path=$HOME/vopd/models/Qwen3.5-4B \
  trainer.n_gpus_per_node=2 data.train_batch_size=24 \
  actor_rollout_ref.actor.ppo_mini_batch_size=24 \
  actor_rollout_ref.rollout.agent.num_workers=2 data.dataloader_num_workers=2 \
  actor_rollout_ref.rollout.gpu_memory_utilization=0.5 \
  +actor_rollout_ref.model.override_config.attn_implementation=sdpa \
  actor_rollout_ref.model.trust_remote_code=True data.trust_remote_code=True \
  2>&1 | tee train.log
```
