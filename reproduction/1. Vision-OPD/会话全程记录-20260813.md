1. **每个最小单元（不可再分）完成后立刻做一次 commit**，或通过分批 add + commit 实现。

## 五、错误与解决方案（重点，避免重复踩坑）

| # | 错误现象 | 原因 | 解决方案 |
|---|---------|------|---------|
| 1 | `git push` 报 `Permission denied (publickey)` | config 里 github.com 指向了 H200 的 id_rsa | 改成 `IdentityFile ~/.ssh/github_key` |
| 2 | MobaXterm 里 Ctrl+C 出现 `^C`，粘贴失败 | MobaXterm 无 Ctrl+C/V，Ctrl+C 是发中断信号 | 用**右键**或 Shift+Insert 或鼠标中键粘贴 |
| 3 | H200 上中文文件名/输出乱码 | Windows GBK vs Linux UTF-8 编码不同 | 文件重命名为 ASCII（`data.csv`/`main.py`），输出改英文 |
| 4 | `nvcc: command not found` | CUDA 工具链不在 PATH | `export PATH=/usr/local/cuda/bin:$PATH`（工具链是 11.8） |
| 5 | flash-attn 安装报 404 / 猜 wheel URL 失败 | **flash-attn 无 torch 2.10 预编译 wheel**（最新只到 torch 2.8 cu12、torch 2.9 cu13） | 跳过 flash-attn（FSDP 训练用原生 SDPA，不需要）；causal-conv1d 也无 mamba 导入，不需要 |
| 6 | 下载 GitHub wheel 报 `Remote end closed` / 403 / 404 | 国内连 GitHub 不稳 + 代理失效（gh-proxy 403、ghfast 404、gh-proxy.net 401） | 放弃代理，最终发现根本不需要 flash-attn wheel |
| 7 | `huggingface-cli: command not found` | huggingface_hub 1.9.0 的 CLI 改名/未装入口 | 用 Python 调 `from huggingface_hub import snapshot_download` |
| 8 | hf-mirror API 报 403 | urllib 默认请求头被识别为爬虫 | 不用 urllib，直接用 snapshot_download |
| 9 | `python *.py` 中文文件名乱码导致 FileNotFoundError | 文件名编码问题 | 重命名为 ASCII 名 |
| 10 | scp/粘贴命令被折行插入换行符 | 终端宽度 + 粘贴导致长命令断开 | 把命令写进本地 txt 文件，用户复制（避免折行） |
| 11 | wget 下载报 "missing URL" | 命令被换行截断 | 同上，用 txt 文件中转 |

### 关键结论（省时间必读）
- **flash-attn / causal-conv1d 对 Vision-OPD 训练都不需要**：FSDP 用原生 SDPA，模型无 mamba 层。部署脚本里的这两个 pip install 是模板遗留。
- **Vision-OPD 训练用的是基座模型 `Qwen/Qwen3.5-4B`**（不是已下载的 `yuanqianhao/Vision-OPD-4B` 微调权重——那个是阶段2推理验证用的）。

## 九、我（助手）总结的工作模式与流程

### 9.1 Git 操作纪律
- 一个文件 = 一个 commit，写完立即 commit + push。
- commit message 格式：`{N}-{Paper}: {action} {中文/英文说明}` 或 `docs:/test: 前缀 + 说明`。
- push 用 `git push origin main`（SSH 方式，remote 已指向新仓库名）。

### 9.2 H200 操作流程（已验证）
1. 传文件：MobaXterm SFTP 拖拽，或本地 `scp -r <path> H200:/user_mount/home/shiqiushi/spinner-bot/reproduction/`。
2. tmux 保护会话：`tmux new -s <名>`，脱离 `Ctrl+B` 再 `D`，重连 `tmux attach -t <名>`。
3. 激活环境：`conda activate vision-opd`。
4. 跑 Python：`python main.py`（文件名用 ASCII 避免乱码）。

### 9.3 下载 HuggingFace 资源（国内镜像）
```bash
export HF_ENDPOINT=https://hf-mirror.com
python -c "from huggingface_hub import snapshot_download; import os; snapshot_download('<repo>', repo_type='dataset', local_dir=os.path.abspath('data'))"
```
- 不用 `huggingface-cli`（命令缺失），用 Python API。
- 模型下载不带 `local_dir` 会进 HF 缓存，verl/vLLM 能直接读到。

### 9.4 避免命令折行
- 长命令写进本地 txt 文件，用户从文件复制（避免终端折行插入换行符）。
