🧠 RLHF — 大语言模型对齐的标准流程

RLHF = 用人类偏好训练的评分模型代替人工写死的奖励函数

Step 1
SFT
监督微调
模仿高质量回答
→
Step 2
训练 RM
收集人类偏好
训练奖励模型打分
→
Step 3
PPO + KL
用RM作奖励
最大化+KL约束

🔗 第三步 = OPD 结构！

$$\max_\pi \mathbb{E}\left[ R_{\text{RM}}(x,y) - \beta D_{KL}(\pi \| \pi_{\text{SFT}}) \right]$$

π_SFT = 先验策略 = "中心策略"的等价物
"任务奖励 + KL正则" —— 和Distral一模一样！

⚠️ RLHF 的痛点

• 奖励模型单独训练 → 过程复杂
• PPO 训练不稳定 → 需要大量调参
• 维护三个模型（策略+参考+奖励）
• 奖励模型可能被"钻空子"（reward hacking）

DPO 的目标：简化这一切。

🎯 DPO — 把 RLHF 变成分类问题

DPO 发现：带KL惩罚的最优策略有闭式解——根本不需要奖励模型！

📐 推导链（3步）

① OPD闭式解：
$\pi^*(y|x) \propto \pi_{\text{ref}}(y|x) \cdot \exp(R(x,y)/\beta)$

② 反解出 R：
$R(x,y) = \beta \log\frac{\pi^*(y|x)}{\pi_{\text{ref}}(y|x)} + \beta\log Z(x)$

③ 代入偏好模型 → DPO损失：

$$\mathcal{L}_{\text{DPO}} = -\mathbb{E}\left[\log \sigma\left(\beta \log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]$$

✅ 为什么这是革命性的？

• 零奖励模型——损失只依赖π_θ和π_ref
• 直接从静态偏好对 (x, y_w, y_l) 学习
• 本质是二分类：给好回答更高相对概率
• 训练稳定、实现简单、无需PPO

关键转化："先训RM再PPO"的两阶段流水线 → 一个简单的分类损失函数。OPD的KL约束结构是这一切的数学起点。

📋 静态偏好对 — DPO 的燃料

📦 什么是静态偏好对？

事先收集好、不再变动的人类偏好数据。

每条数据 = (x, y_w, y_l)：
• x = 提示（问题）
• y_w = 被人类偏好的回答（win）
• y_l = 不被偏好的回答（lose）

🔄 静态 vs 在线

静态（DPO）：数据离线收集，训练时不再与环境/人类交互。简单、稳定。

在线（OPD）：学生自己生成轨迹，实时蒸馏教师信号。灵活、但存在梯度场消失风险。

2025 趋势：Online DPO 将两者融合——在线采样 + 偏好对比信号。

🤝 多智能体 RL — 上帝视角 → 局部决策

👁️ 集中式教师（训练时）

拥有上帝视角：
• 同时看到所有智能体的观测
• 访问所有通讯信息
• 做出全局最优决策
• 知道"整盘棋"该怎么下

📡 分散式学生（部署时）

只能看到局部信息：
• 自己的传感器数据
• 邻近智能体的有限通讯
• 独立决策（无中央协调）
• 但凭教师教导，做出接近全局最优的决策

范式：集中训练 → 蒸馏 → 分散执行。教师只在训练时存在，部署时仅运行学生。学生受限的是信息视野。

🤖 机器人控制 — 教师=仿真/通用，学生=真实/专用

🖥️→🌍 Sim-to-Real

仿真无限试错→教师学到理想策略→蒸馏给学生→少量真实数据微调。
教师=理想行为，学生=适应噪音。

🦾→🦿 硬件异构

标准仿真机器人训练精通任务的教师→蒸馏到不同形态的学生（六轴/七轴/双足/四足）。
教师=任务理解，学生=适应新身体。

✋ 灵巧手操作

20+关节高维动作空间，从零探索几乎不可能。教师仿真训练→蒸馏引导掌握复杂手指动作。
"在接近物体时，你大概应该这样弯关节"。

🔗 共同范式

都是"教师先见多识广→蒸馏→学生专精特定场景"。区别仅在于受限类型：多智能体=信息视野受限，机器人=物理形态/环境精度受限。

✋ 灵巧手 — 为什么是"高维动作空间"？

💬 讨论

📐 动作空间 vs 状态空间

• 动作空间维度 = 需要控制的关节数量。灵巧手有 20+ 个自由度，每个都需要独立的连续力矩指令 → 动作向量极长

• 状态空间维度 = 传感器读数（关节角度、触觉阵列、物体位姿等）。状态当然也高维，但核心难点是动作。

• 搜索空间 = 每个维度取值数量的乘积 → 20+维连续空间 → 天文数字

🧭 为什么必须靠教师引导？

从零探索：20个关节随机乱动 → 几乎永远碰不到"成功抓住物体"的状态组合。

教师的作用：
仿真中教师用全部状态信息训练出稳健策略 → 蒸馏时教师说：
"手指接近物体时，这些关节大概应该这样弯"
→ 学生不盲目探索，而是在教师限定的子空间内精细调整。

🌡️ 蒸馏温度 T — 工程调参指南 (2023)

$p_i = \exp(z_i/T) / \sum_j \exp(z_j/T)$  |  这些值是搜索起点，非绝对

任务类型推荐 T原因经验法则
🎮 离散控制 (Atari)0.01–0.1动作少(~18)，Q值差异大。低温≈硬标签，防噪声确定性越强→T越低
🕹️ 连续控制 (MuJoCo)1–5连续动作用高斯分布，中温增加方差鼓励探索动作越连续→T越高
🔀 多任务蒸馏2–10高温充分软化，暴露不同任务的动作分布差异任务差异越大→T越高
🤖 Sim-to-Real0.5–2平衡：不能过拟合仿真特异模式(T太低)，也不能信号过弱(T太高)环境噪声越强→T越高

💡 调参直觉

任务差异越大、环境噪声越强 → T适当提高。任务确定性越强、需要精确复刻 → T适当降低。这些经验是 OPD 工程落地的实用速查表。
