工业共识

💡 四大工业共识

共识 1：OPD 是 RLVR 的必要补充，而非替代
几乎所有 2026 年工业级多模态后训练 pipeline 都包含 OPD 阶段。三阶段范式 SFT → OPD → RLVR 正在被主流框架（TRL、verl）原生支持。OPD 提供密集 token 级信号引导探索，RLVR 提供稀疏序列级目标——两者互补而非竞争。
共识 2：黑盒 OPD 是当前工业部署首选
PRISM 的 MoE 判别器方案证明：不需要访问教师模型内部即可实现有效 OPD。这对工业界至关重要——闭源 API（GPT-4o、Gemini）可作为教师，兼容任何模型架构。
共识 3：数据效率是核心卖点
CORD（80k 合成样本）和 Ark-ASR（100k 小时 vs 20M 小时）证明 OPD 可极大降低数据需求。对中小型团队而言，OPD + 小数据 > 传统训练 + 大数据——这是 OPD 最直接的商业价值。
共识 4：Reverse KL / Top-K JSD 成为事实标准
从 Vision-OPD 到 VLA-OPD 到 CORD——跨视觉、音频、机器人三域，Reverse KL 和 Top-K JSD 已取代 Forward KL 成为多模态 OPD 的默认散度选择。原因一致：对抗跨模态分布差异导致的熵爆炸。
