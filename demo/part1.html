💡 核心创新

提出三种蒸馏模式，其中第三种 = Online Distillation：
• 教师与学生并行训练
• 教师边与环境交互边向学生提供信号
• 学生学的是"训练过程"，不是"最终结果"

# 模式1：离线蒸馏（传统）
# 教师先训练完 → 再教学生
teacher.train() # 冻结
student.clone(teacher)

# 模式3：在线蒸馏 (OPD)
# 师生一起训练！
while training:
  teacher.step() # 在线学习
  student.distill(teacher)
  # 教师知识是活的↗

🧠 Distral (2017) — 联合目标函数

核心目标：找到一个共享策略 π₀ 和一组任务策略 {πᵢ}

$$J(\pi_0, \{\pi_i\}) = \sum_i \mathbb{E}_{\pi_i}\left[\sum_{t \geq 0} \gamma^t R_i - c_{\text{KL}} \gamma^t \log\frac{\pi_i}{\pi_0} - c_{\text{Ent}} \gamma^t \log \pi_i\right]$$
①
标准 RL 奖励
Σ γᵗ Rᵢ
完成第 i 个任务
最大化累积回报
②
KL 惩罚项
−c_KL · log(πᵢ/π₀)
别离中心策略太远
实现知识共享
③
熵奖励项
−c_Ent · log πᵢ
保持策略随机性
鼓励探索新动作

KL 正则化 = 橡皮筋：可以撑开走远，但会越来越费力，迫使你在"拿高分"和"别走偏"之间权衡

🎯 最优策略的闭式解 & 贝叶斯直觉

最大化 J 后，πᵢ 的最优形式为：

$$\pi_i(a|s) \propto \pi_0(a|s)^{\alpha} \cdot \exp\!\left(\frac{Q_i(s,a)}{\beta}\right)$$

α = c_KL/(c_KL+c_Ent) · β = c_KL+c_Ent

📜 先验 Prior π₀^α
中心策略的集体智慧
×
🎯 似然 Likelihood exp(Qᵢ/β)
任务自身的价值判断
=
✅ 后验 Posterior πᵢ
融合先验与经验的最优策略
α
先验强度
α 大 → 策略保守，紧跟中心
α → 0 → 完全由 Q 值驱动
β
温度参数
β 大 → 策略随机，偏探索
β 小 → 策略贪婪，偏利用

🔄 "蒸馏作为通信" —— 双向知识流

📥 阶段一：蒸馏 Distill
π₁ → π₀ ← π₂

各任务策略把经验"上交"给中心

  • π₀ = argmin Σᵢ D_KL(πᵢ ‖ π₀)
  • 汇聚所有子策略的共性智慧
  • 中心策略是"集体笔记"

🧑‍🏫 此时：子策略 = 教师，中心 = 学生

⇄
📤 阶段二：广播 Broadcast
π₀ → π₁, π₂

中心把通用行为"广播"回各任务

  • 通过 KL 正则：πᵢ ∝ π₀^α · exp(Qᵢ/β)
  • 约束子策略不要偏离集体智慧
  • 引导探索方向，稳定训练

🧭 此时：中心 = 文化约束/行为锚点

🔬 Actor-Mimic (2016) — 带筛选的蒸馏

条件蒸馏损失：只学教师"有把握"的状态

$$\mathcal{L}_{\text{distill}}(s) = \begin{cases} D_{KL}(p_T\|p_S) & \text{if } \max_a Q_T(s,a) > \theta \\ 0 & \text{otherwise} \end{cases}$$
✅ max Q_T(s,a) > θ
蒸馏！模仿教师

教师对这个状态很有把握
这是值得学习的好经验

❌ max Q_T(s,a) ≤ θ
跳过，损失 = 0

教师自己也很困惑
不学垃圾经验，避免噪声污染

🎯 Q 值截断的直觉

类比：只总结学霸有把握的解题方法，
不学他们瞎蒙答案时的做法。

🔗 特征回归

不仅模仿"做什么"（动作），
还模仿"怎么看"（中间层特征），
让学生的内部表征也向教师对齐。
