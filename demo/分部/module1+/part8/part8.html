什么是框架与工具箱？

🎯 框架与工具箱 = C1 + C2，但教师仅提供 API
与白盒 OPD 的核心区别：教师 logits 不可访问——教师仅输出文本或标量评分。无法进行 token 级 KL 散度匹配。需要用标量信号（评分/偏好/判别器）替代 logit 级监督。

信号类型：对抗判别器 · 语言评分 (0-9) · DPO 偏好对比 · Rubric 评分 · Oracle 编辑
📐 前总 · 2/3

黑盒 vs 白盒：信号密度 vs 通用性

白盒 OPD：逐 token KL 散度 → 信号密集、精细 → 但需要教师 logits 可访问 → 仅限开源模型
框架与工具箱：标量/序列级信号 → 信号稀疏、粗糙 → 但任何 API 可用 (GPT-4/Claude/Gemini) →模型无关的通用性

核心权衡：信号密度 ↔ 通用性。白盒更高效但受限，黑盒更灵活但信号更弱。

框架与工具箱 信号谱系

六种信号类型构成从最弱到最强的谱系：语言评分 (OVD) < Oracle 编辑 (SPOT) < Rubric (ROPD) < DPO 偏好 (SODA) < 对比学习 (ORPO) < 对抗判别器 (GAD)。信号越强→学生提升越大→但获取成本也越高。
📋 后总 · 2/2

框架与工具箱 的未来

核心趋势：信号构造方法越来越强——从简单评分到对抗判别器。GAD 证明框架与工具箱 的能力上限可达 GPT-5 水平。未来的融合方向：黑盒信号 + 白盒内部 logits 的混合监督——兼顾通用性与效率。
