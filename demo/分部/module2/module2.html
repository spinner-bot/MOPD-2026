Part 1 知识结构图

时间线 · 2020–2022

ViT · 2020.10
arXiv: 2010.11929 · ICLR 2021 · Google · 引用 50,000+
ViT — An Image is Worth 16×16 Words
核心贡献：首次将标准 Transformer 直接应用于图像——把图像切成固定大小的 Patch，当作"视觉单词"序列处理，打破 CV 和 NLP 的架构壁垒。

ViT 架构：图像 → Patch → Transformer

🔑 关键创新

图像不需要专门的卷积操作。把图像切成 Patch 后线性投影，变成和文本 token 一样的向量序列——Transformer 自然地就能处理。这打破了 CV 和 NLP 的架构壁垒。

⚠️ 局限

ViT 需要大量数据预训练（JFT-300M）才能超越 CNN。缺少卷积的归纳偏置——平移等变性、局部性——在小数据集上不如 ResNet。

CLIP · 2021.01
arXiv: 2103.00020 · OpenAI · 4亿图文对 · 引用 30,000+
CLIP — Contrastive Language–Image Pre-training
核心贡献：用对比学习在4亿图文对上训练，将图像和文本映射到同一个语义空间。"一只狗"的文字和狗的照片在这个空间中距离极近。

CLIP 架构：双塔 + 对比学习

DALL·E 1 · 2021.01
OpenAI · 2021.01 · Zero-Shot Text-to-Image Generation
DALL·E — 首个大规模文本→图像生成
核心创新：分两步——① 用dVAE将图像压缩为离散token序列；② 用自回归Transformer像GPT一样逐token生成这些图像token。首次证明语言和视觉可在同一token流中统一建模。

核心问题：如何让 Transformer 生成图像？

🎯 根本矛盾
Transformer 是为一维离散序列（文本token）设计的——每个位置是词表中一个整数索引。但图像是二维连续像素值（256×256×3个数字）。

解决思路：能不能把图像也变成一串整数索引？就像把中文翻译成数字token一样，把一张图也"翻译"成一串数字。这样Transformer就能用完全相同的方式处理文本和图像。

dVAE：图像的"翻译器"

两步流程：dVAE + 自回归 Transformer

Codebook 训练细节 & 为什么必须离散化

📖 Codebook 如何训练

① 编码器输出连续向量 z_e → ② 与8192个条目计算距离 → ③ 选择最近的条目e_k → ④ argmin不可导→用直通估计器(STE)：前向用量化e_k，反向传梯度给编码器 → ⑤ codebook通过指数移动平均(EMA)更新。条目逐渐变成常见纹理/边缘/色彩模板。

🔑 为什么必须离散化

如果直接预测连续像素值→MSE损失→输出成为所有可能图像的平均值(模糊)。
离散token将生成从"连续回归"变成"分类问题"→可用标准交叉熵训练Transformer。
代价：量化误差(有损压缩)，但保留语义、剔除噪声。

支线：自回归生成 & 潜空间

📝 自回归生成

模型逐个token生成序列。每步预测下一个token的概率分布→采样→拼回输入→预测再下一个。DALL·E中：先输入文本token，再逐个生成1024个图像token。

🌐 潜空间 (Latent Space)

神经网络的压缩表示空间。VAE将512×512×3图像压缩至64×64×4——数据量1/48。保留语义信息，剔除高频纹理噪声。

MSE均值回归 · 四种生成方案

⚠️ 均值回归

MSE最优解=E[y|x]——期望值。当真实分布多峰时，期望落在峰间→模糊的叠加平均。这是所有确定性损失函数的宿命。

✅ 四种方案

VAE高斯+KL正则偏模糊
GAN对抗采样不稳定
扩散分步MSE慢
离散化量化+交叉熵量化误差

设计哲学：连续 vs 离散

💡 两种哲学，同一个核心目标
离散搭桥：连续→离散token→Transformer(交叉熵)→离散→连续。代价=量化误差，收获=稳定训练。
连续分步：不一步预测，分几百步去噪。每步MSE目标变成确定的高斯噪声→完全避开均值回归。
共同核心：如何避开"直接预测连续多峰分布"这一灾难。

Stable Diffusion 三组件

SD 采样伪代码逐行解释

def sd_sampling(prompt, num_steps=50):
  text_embed = CLIP_text_encoder(prompt)  # ① 文本→条件向量
  z = torch.randn(1, 4, 64, 64)          # ② 随机噪声(潜空间64×64×4)
  for t in reversed(range(num_steps)):
    noise_pred = UNet(z, t, text_embed)  # ③ 预测当前噪声(条件=文本)
    z = denoise_step(z, noise_pred, t)  # ④ 减去噪声 → z更接近干净潜变量
  image = VAE_decoder(z)              # ⑤ 潜空间→像素
  return image
关键洞察：每步MSE预测的是噪声(确定性),而非最终图像(多峰分布)。将一次生成拆成50步→每步MSE目标都是确定值→完美避开均值回归。

桥接模式：视觉 → 语言的理解路径

Flamingo (2022.04)

Perceiver Resampler：将变长视觉特征压缩为固定64个token→通过交叉注意力注入LLM每一层。首个大规模VLM，80B参数，强大Few-shot能力。

BLIP-2 (2023.01)

Q-Former：轻量Transformer(仅100M参数)。可学习query tokens从ViT特征中提取语言相关信息→输出固定数量视觉token→作为软提示(soft prompt)输入冻结LLM。

从单模型到完整技术栈 · 笔记06 深度补充

内容结构图

横向浏览 → 在进入每个部分前高亮当前位置

1. CLIP 未公开的数据管线

OpenAI 在 CLIP 论文中描述了使用4亿图文对进行训练，但从未公开数据收集和筛选的具体方法。开源社区面临核心问题：如何复现甚至超越 CLIP？

两条路径：① 大规模数据筛选基准 (DataComp) ② 逆向工程 OpenAI 的数据管线 (MetaCLIP)。

2-1. DataComp (2023)

核心贡献：建立大规模多模态数据筛选的标准化基准。DataComp 不是一种数据筛选方法，而是一个竞赛平台——提供统一的原始数据池和评估协议，让不同筛选算法在公平条件下比较。

关键发现：数据筛选算法的重要性远超模型架构——最好的筛选策略用较小模型就能达到甚至超越 CLIP 的性能。

2-2. MetaCLIP — 逆向工程 OpenAI 数据管线

核心方法：使用元数据驱动的策展 (Metadata-driven Curation)——从 Wikidata/WordNet 获取概念词条，按概念平衡采样，而非简单的网络爬取。在相同数据量下超越原始 CLIP。

关键在于"概念平衡"：原始网络爬取会导致高频概念（如"狗"、"车"）占据大量训练样本，而稀有概念（如"鸭嘴兽"）几乎不可见。MetaCLIP 确保了每个概念都有足够的训练样本。

2-2a. 什么是概念平衡？

⚖️ 概念平衡采样的含义

不按数据出现频率采样，而是按概念多样性采样。每个概念（来自 Wikidata 的数万个条目）获得大致相等的样本配额。这避免了模型被高频概念主导，强制学习长尾知识。

📊 三个核心结论 (2-2rs)

① 概念平衡显著提升零样本迁移——尤其对稀有类别
② 数据量不是越多越好——平衡的4亿样本超越不平衡的10亿
③ 元数据策展成本极低——Wikidata/WordNet 是免费知识库

2-2b. MetaCLIP 核心方法精讲

三步管线：① 从 Wikidata/WordNet 获取数十万概念词条作为查询 → ② 对每个概念查询网络数据，按配额采样（每概念约5000样本）→ ③ 用平衡后的数据集训练 CLIP。

关键洞察：OpenAI 的"4亿图文对"并非随机网络爬取——MetaCLIP 通过逆向工程发现，其优越性来自隐式的概念平衡策展。这解释了为什么简单扩大网络爬取数据（如 LAION-5B）并不能线性提升性能。

3. SigLIP — sigmoid 替代 softmax

核心创新：将 CLIP 的对比损失从softmax（全局归一化）替换为sigmoid（逐对独立）。

CLIP: 对每个样本，计算它与批次中所有其他样本的 softmax 概率（需全局归一化，batch size 敏感）。
SigLIP: 对每个图文对 (i,j)，独立判断它们是否匹配——一个二分类问题（0=不匹配, 1=匹配），不再需要 batch 内全局归一化。

3pre. softmax vs sigmoid

softmax (CLIP)

$$\mathcal{L}=-\frac{1}{N}\sum_i\log\frac{\exp(s_{ii})}{\sum_j\exp(s_{ij})}$$所有 N 个候选竞争一个"正确"位置。需要大 batch，且 batch size 直接影响性能。

sigmoid (SigLIP)

$$\mathcal{L}=-\frac{1}{B^2}\sum_{i,j}[y_{ij}\log\sigma(s_{ij})+(1-y_{ij})\log(1-\sigma(s_{ij}))]$$每个 (i,j) 对独立二分类。本质：将对比学习解耦为 B² 个独立的二分类问题。

4. EVA-CLIP 与缩放定律

EVA-CLIP 的核心工作：系统研究 CLIP 训练的缩放行为——模型大小、数据量、训练计算量三者如何影响最终性能。

精讲要点 (4-1 → 4-2 → 4-9)：
• 4-1：在给定计算预算下，更大的模型 + 更少的 epoch优于小模型多轮训练
• 4-2：数据质量和多样性比数据量更重要——呼应 MetaCLIP 的发现
• 4-9 核心洞察：CLIP 训练的最优数据量随模型规模呈幂律增长

5. CLIP 生态全景 · 小结

CLIP未公开管线 → DataComp建立基准 → MetaCLIP逆向概念平衡 → SigLIP用sigmoid解耦 → EVA-CLIP量化缩放定律。
核心主线：数据质量 > 模型架构 > 训练技巧。CLIP 的真正秘密不在于双塔对比学习，而在于其未公开的数据策展。

非原生 = 把视觉模块"外挂"到语言模型上，中间加个翻译器。

就像：非原生是把翻译器接到只会中文的人耳边；原生是让这个人从小在多语言环境长大，直接用每种语言思考。

Ch2 · 视觉编码器演进

从 ViT 到多尺度巨人

ViT 之后，视觉编码器沿三条路径演化：① 层级化(Swin/ConvNeXt) ② 自监督(DINOv2) ③ 分辨率扩展(AnyRes/DynamicRes)。

路径一：层级化 (Swin / ConvNeXt)

🔑 核心思想

标准 ViT 所有层使用相同的空间分辨率（14x14 patch）。层级化引入金字塔结构——早期层高分辨率，后期层低分辨率，不同层输出不同尺度的特征图。

📊 代表模型

Swin Transformer：窗口注意力+patch合并→层级特征。ConvNeXt：卷积风格的ViT。VLM中多尺度特征使模型能同时看清细节和把握全局。

路径二：自监督 (DINOv2)

🔑 核心思想

不需要图文对，纯视觉数据即可训练。DINOv2 使用自蒸馏：教师网络(EMA更新)指导学生网络。学到的特征语义连续性极强——相似物体在特征空间自然聚集。

📊 VLM 中的价值

低资源场景：先在大量无标注图像上预训练→少量图文对微调→接近甚至超越CLIP效果。

路径三：分辨率扩展

🔑 核心思想

CLIP/ViT 最初固定 224x224。AnyRes 将高分辨率图切成多个子图分别编码→拼接送入LLM→动态分辨率支持。

📊 关键发现 (Apple MM1)

图像分辨率是VLM性能最重要的单一变量——超过模型大小、连接器设计。直接提升OCR、文档理解。

视觉编码器选择决策树 (2026)

通用VLM：SigLIP-SO400M (性价比最优) 或 EVA-CLIP-18B (性能最强)
高分辨率需求：AnyRes + 层级化编码器
3D/视频：VideoViT / 3D 点云专用编码器
低资源：DINOv2 自监督预训练 + 少量图文对微调

① 交叉注意力 (Flamingo)
