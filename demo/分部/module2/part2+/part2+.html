Ch2 · 视觉编码器演进

从 ViT 到多尺度巨人

ViT 之后，视觉编码器沿三条路径演化：① 层级化(Swin/ConvNeXt——多尺度特征) ② 自监督(DINOv2——无需标注的视觉理解) ③ 分辨率扩展(支持任意分辨率输入)。

2.1 三条演化路径

层级化 (Swin/ConvNeXt)

引入多尺度金字塔结构，不同层输出不同分辨率特征→VLM可利用多尺度视觉信息。

自监督 (DINOv2)

纯视觉自监督训练，无需图文对。学到的特征语义连续性极强——相似物体在特征空间自然聚集。

分辨率扩展

支持动态分辨率输入(非固定224²)。AnyRes/DynamicRes等方案使VLM能看清细节。

2.4 视觉编码器选择决策树 (2026)

通用VLM：SigLIP-SO400M (性价比最优) 或 EVA-CLIP-18B (性能最强)
高分辨率需求(文档/图表)：AnyRes + 层级化编码器
3D/视频：VideoViT / 3D 点云专用编码器
低资源：DINOv2 自监督预训练 + 少量图文对微调
Ch3 · VLM 架构

VLM 架构：三大连接器家族

① 交叉注意力 (Flamingo)

在LLM层间插入交叉注意力，视觉特征作K/V。最强表达能力，训练成本最高。

② Q-Former (BLIP-2)

轻量Transformer压缩视觉token→作为软提示。平衡效果与效率。

③ 线性投影 (LLaVA)

最简单的MLP映射。视觉token→LLM嵌入空间。最易训练，效果意外地好。

LLaVA 家族演化树

LLaVA 1.0 (2023.04) → 1.5 (2023.09, MLP+更高分辨率) → 1.6 (2024.01, 动态分辨率) → NeXT (2024.05, 任意分辨率) → OneVision (2024.08, 统一单图/多图/视频) → LLaVA-CoT (2024.11, 推理链)。核心趋势：分辨率不断提升，模态不断融合，推理能力不断增强。
Ch4 · 训练策略

训练 Pipeline 与关键发现

LLaVA 两阶段

① 预训练对齐：冻结视觉编码器+LLM，只训练连接器→视觉特征对齐到语言空间
② 指令微调：解冻LLM，多模态指令数据微调→模型学会看图回答问题

Apple MM1 消融发现

① 图像分辨率是最重要的单一变量
② 视觉token数量>连接器设计
③ 数据混合配比：45% caption + 45% 交错图文 + 10% 纯文本

Ch6-8: 视频 · 音频 · 3D

Ch6: 视频理解

核心挑战：时序建模——如何从几十帧中提取运动信息。四大路线：帧采样+平均池化/时序Transformer/3D卷积/Memory Bank。

Ch7: 音频/语音

Whisper/SALMONN/Qwen-Audio→语音理解+生成。全双工是圣杯：同时听和说，像人类对话一样自然。

Ch8: 3D多模态

Point-BERT→PointLLM→3D-LLM。三条路线：点云→文本/多视图投影/隐式场表示。

Ch9-10: 统一生成 · Agent

Ch9: Any-to-Any 统一

五大路线：① 多模态token化(将所有模态离散化) ② 扩散统一 ③ MoT混合 ④ 解耦设计(Janus-Pro) ⑤ 大一统Transformer。Bagel (ByteDance 2025) 开创MoT范式。

Ch10: 多模态 Agent

从"看懂"到"会用"——纯视觉GUI控制(OS-Atlas/CogAgent)。关键技术：截图→操作指令、动作空间离散化、自我纠错循环。

Ch11-12: 缩放定律 · 安全与幻觉

Ch11: VLM缩放定律

三大发现：① 视觉编码器规模比LLM规模更重要 ② 最优数据量随模型规模幂律增长 ③ 多模态训练存在"涌现分辨率"——低于阈值时性能停滞。

Ch12: 安全与幻觉

多模态特有风险：① 视觉幻觉(描述图中不存在的内容) ② 越狱攻击(通过图像绕过文本安全过滤) ③ 偏见放大(视觉刻板印象)。缓解方案：RLHF/DPO+对抗训练+检索增强。
