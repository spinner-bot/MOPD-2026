Janus-Pro：理解与生成的解耦设计

🧠 理解路径 (SigLIP)

目标：语义压缩——从图像提取"这是什么"的高层语义，扔掉无关细节。需要语义对齐的编码器。输出：文本描述、问答、推理。

🎨 生成路径 (VQ-VAE)

目标：像素重建——从文本恢复"这长什么样"的每个像素细节。需要重建保真度高的编码器。输出：生成图像。

💡 为什么必须解耦
理解追求丢弃信息（抽象），生成追求保留信息（还原）。这两个目标本质矛盾——Janus 的"解耦"是对这个矛盾最诚实的回应。

名词解释：MoT (Mixture of Transformer Experts)

🧩 MoT 是什么

共享注意力层（通用推理）+ 为不同模态分配独立的 FFN 专家（模态特定处理）。文本用文本专家，图像用图像专家——共享"思考"部分，分离"感知"部分。

📊 Bagel (2025)

ByteDance 的 Bagel 是 MoT 范式开创者——从零开始同时训练文本、图像理解和图像生成。证明不同模态可以在共享推理框架下协同训练。

Ch11 · 缩放定律

VLM 效率的最优配置

Ch11: VLM 缩放定律 — 反直觉发现

🔥 ICLR 2025: 最优配置 = 极少数 visual token + 大 LLM
在固定推理预算下，最优配置是最大化 LLM 参数量 + 最小化 visual token 数量——极端情况下只需 1 个 visual token。这意味着之前所有 VLM 都在"浪费"计算在过多的 visual token 上。

推论：token 压缩比是 VLM 效率的关键杠杆——回报高于增大 LLM 或视觉编码器。

缩放定律的实践指导

约束优先投入方向原因
推理延迟敏感视觉token压缩→编码器效率Token数量二次影响注意力计算
训练数据有限增大LLM→数据增强大LLM有更好的zero-shot
推理预算充足增大图像分辨率分辨率是准确率的最强杠杆
追求全能分辨率+多编码器不同任务需不同视觉特征

Ch12: 安全与幻觉 — 五种幻觉类型

① 物体幻觉

"图中有狗"——但图中没有狗

② 属性幻觉

"红车"——但车是蓝色的

③ 关系幻觉

"A在B上面"——但A在B下面

④ 文本幻觉

编造图中不存在的文字

⑤ 上下文幻觉

忽略图像，回答"一般情况"而非"图中情况"

安全缓解方案 + 核心未解问题

🛡️ 缓解方案

• RLHF/DPO：偏好对齐减少幻觉
• 对抗训练：对抗越狱攻击
• 检索增强：用外部知识验证视觉内容
• 专门评估基准：HallusionBench, POPE, AMBER

🔮 核心未解问题

理解+生成统一是否带来1+1>2的协同效应？更好的文本编码能改善图像生成——但在理解任务上，统一模型是否优于专用模型？这个问题截至2026年7月仍在验证中。
