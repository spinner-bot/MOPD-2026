核心风险

⚠️ 多模态 Shortcut：文本捷径的隐秘侵蚀

PALR 诊断 (Privileged Answer Leakage Rate) — ViGOS (2026.06)
跨三个基准的测量显示：17–26% 的 token 级监督来源于文本参考而非图像内容。教师传递的信号中，近四分之一是「答案驱动」而非「图像驱动」——学生被悄悄教会了「蒙答案」。

这意味着什么？

🔸 教师（冻结副本）给学生（训练副本）的监督信号中，有相当比例来自语言的统计相关性，而非视觉证据
🔸 学生在 OPD 过程中发展不均：文本推理能力飞速提升，视觉基础能力原地踏步
🔸 最终模型在 benchmark 上分数不降 → 但视觉注意力已悄然发散 → 幻觉、错误绑定随之而来

这是 Part 0 中「感知-推理耦合退化」的精确量化：RL/OPD 优化机制本身就会系统性地偏向文本捷径。

KL 散度战场

🔥 Forward KL：在视觉 token 上的灾难

Forward KL 的本质：Mode-Covering（模式覆盖）
$$\min_{\pi_S} D_{KL}(\pi_T \|\pi_S) = \min_{\pi_S} \sum \pi_T \log \frac{\pi_T}{\pi_S}$$ 学生必须覆盖教师的所有高概率区域——只要教师有概率的地方学生给不够，惩罚就爆炸。学生被迫保留所有可能性。

为什么视觉 token 上尤为严重？

🔸 视觉 token 天然高熵、多义——同一图像块可能对应多种合理描述，教师分布平滑、无锐利峰值
🔸 文本 token 有明显峰值（某个词往往是唯一正确），但视觉是宽泛的「语义场」
🔸 Forward KL 强制学生去匹配这个宽泛的支持集 → 学生把概率质量撒在极大空间上

📊 结果：熵爆炸——学生输出的视觉分布熵极高，丧失判别力，注意力发散

直观比喻：考试制度被恶意利用——学生发现把所有选项涂一点（全均值分布）就能在 Forward KL 下得「不错」的分数，于是心安理得地停在模糊状态，永远学不会精确的视觉辨别。

KL 散度战场

💎 Reverse KL / JSD / Top-K JSD 的救赎

🔄 Reverse KL · Mode-Seeking

$$\min_{\pi_S} D_{KL}(\pi_S \|\pi_T)$$ 学生只追教师的峰值——在教师低概率区浪费概率会被严惩。对抗熵爆炸，学生视觉决策变「尖」。代价：可能丢失多样性，但在多模态理解中锐度 > 多样性。

⚖️ JSD · 对称折中

$$\frac{1}{2}D_{KL}(\pi_T\|M)+\frac{1}{2}D_{KL}(\pi_S\|M)$$ 其中 \(M=(\pi_T+\pi_S)/2\)。不过度覆盖也不过度追寻，在锐度和多样性之间平衡。对视觉 token 既减轻熵爆炸，又不陷入极端模式崩塌。

✂️ Top-K 截断 · 噪声修剪

先截断教师分布到 Top-K，只在这 K 个 token 上计算散度。进一步排除尾部噪声——很多视觉 token 概率在教师那也是均匀噪声，直接裁剪掉避免学生浪费容量拟合无意义的背景模式。

💡 一句话：Forward KL = "覆盖所有可能"（被恶意利用→全均值） → Reverse KL = "精准命中峰值"（模型被迫学会真正的视觉辨别） → JSD / Top-K 是进一步的保险

范式 ①

🟣 同模型跨上下文 OPSD

核心论文：Vision-OPD · Visual-OPSD · ViGOS · ViCuR

核心问题
如何在不依赖外部教师模型、不需要额外标注数据的情况下，提升 VLM 的视觉理解鲁棒性？
核心思想
教师和学生是同一个模型，只是看到的视觉上下文不同。教师=冻结副本看完整/高质量图像；学生=训练副本看被破坏/受限的视觉上下文。目标：让学生从部分推断整体。

运作机制：

① 冻结一份预训练 VLM 作为教师 → ② 同一图像，学生看裁剪版、教师看完整版 → ③ 同一问题，教师产生完整视野输出分布，学生产生受限视野分布 → ④ Reverse KL / JSD 让学生模仿教师的分布

✅ 零外部依赖：不需要更强的教师，不需要新数据，只需已有的图文对

典型实例：Vision-OPD 的 crop-vs-full 自蒸馏 → 将「视觉放大」能力内化到模型中，而非依赖推理时外部工具调用。

范式 ②

🔴 跨模态教师蒸馏

核心论文：VOLD · X-OPD · CORD · SightSound-R1

核心问题
如何将一种模态上已经训练好的强能力，迁移到另一种模态的模型上？（text LLM 推理能力 → VLM；VLM 视觉理解 → 音频模型）
核心思想
教师和学生来自不同模态，输入/输出空间可能完全不同。必须让学生在自己的模态里采样轨迹，教师评估轨迹质量后提供反馈——这正是"在线"的不可替代之处。

运作机制（四步）：

① 冷启动 SFT 对齐（必需前置）→ ② 在线采样：学生在目标模态生成轨迹 → ③ 教师评估：似然度打分 / 生成参考轨迹 / 价值函数评估 → ④ 策略更新：根据教师信号进行 RL 更新 + KL 约束防偏离

📌 关键：冷启动 SFT 是必不可少的——没有它，文本教师的分布与 VLM 学生的采样分布差距过大，蒸馏完全失败（VOLD 的核心发现）

典型场景：VOLD（Text LLM→VLM）· X-OPD（VLM→语音LLM）· SightSound-R1（多模态推理链蒸馏）

范式 ③

🟡 OPD + RL 混合系统

核心论文：PRISM · PTD-PO · HDPO · Distill-R1

核心问题
多模态任务的奖励通常极其稀疏（只有最终答案对错、生成质量评分），纯 RL 探索极难。如何提供逐 token 密集信号引导探索，同时保留 RL 对稀疏奖励的优化能力？
$$\mathcal{L} = \mathcal{L}_{\text{RL}} + \lambda \cdot \mathcal{L}_{\text{OPD}}$$

OPD 扮演的两种角色：

🔸 预对齐阶段：先用纯 OPD（大量教师数据）让学生学会基本合理行为，避免 RL 阶段从零开始乱撞
🔸 辅助损失（软护栏）：RL 训练中 OPD 损失一直存在，防止策略为追求稀疏奖励而崩溃——如防止模型为拿高分而输出乱码

典型论文：PRISM（黑盒对抗 OPD 预对齐）· PTD-PO（特权辅导+偏好优化）· Distill-R1（SFT蒸馏→RL微调的标准框架）

💡 核心挑战：λ 权重的平衡——OPD 太强→学生不敢探索；OPD 太弱→RL 阶段崩溃
