Part 0 知识结构图

时代背景

RL 后训练：从文本到多模态的迁移

2025–2026 年间，GRPO、DAPO、PPO 等强化学习方法在纯文本 LLM 上取得显著推理能力提升：

🔹 DeepSeek-R1：纯 RL 驱动的推理涌现
🔹 Qwen3：RLVR 规模化验证

然而，当这些范式迁移到多模态模型（MLLM / LVLM / LALM）时——遇到了三个根本性瓶颈。

⚠️ 三大瓶颈：RL 后训练在多模态的困境

瓶颈 1
稀疏奖励
Sparse Reward
可验证奖励仅对最终答案打分，失败 rollout 中每个 token 获得相同惩罚 → 信用分配失效，模型无法区分「看错」vs「推错」
瓶颈 2
感知-推理耦合退化
Entanglement
RL 优化可能牺牲视觉感知换取文本推理的奖励提升 → 模型学会「蒙答案」而非「读图」→ shortcut learning
瓶颈 3
分布漂移
Distribution Drift
SFT 基于静态数据，RL 基于自采样轨迹 → 两分布 gap 导致训练不稳定，甚至灾难性遗忘

瓶颈 1 深度分析

稀疏奖励 → 信用分配失效

RL 后训练的标准范式是 RLVR（RL with Verifiable Rewards）：模型生成完整 rollout，用验证器给最终答案打分。但——

❌ 每条失败的 rollout 中，每个 token 获得相同的惩罚信号

这导致根本性的信用分配（Credit Assignment）问题：

🔸 模型不知道是「看错了」（视觉编码器提取了错误的特征）
🔸 还是「推错了」（语言解码器在正确特征上推理失败）

对于纯文本 LLM，这还可以接受（只有一种模态）；但对于 MLLM，视觉感知的错误和文本推理的错误被混为一谈，优化信号完全模糊。

瓶颈 2 深度分析

感知-推理耦合退化 → Shortcut Learning

RL 优化的目标是最大化最终答案奖励。在多模态场景下，这产生了一个危险的捷径：

模型可以通过「猜测」正确答案的文本质地
来获得高奖励，而不真正依赖图像内容

具体机制：

🔸 RL 梯度倾向于增强「奖励最大化的路径」
🔸 如果文本先验（language prior）已足够强 → 图像信号被边缘化
🔸 最终：模型在 benchmark 上分数可能不降，但视觉基础（visual grounding）完全丧失

这是笔记 03 中讨论的 shortcut learning 问题在 RL 阶段的复现——而且比 SFT 阶段更隐蔽，因为 RL 的探索机制会主动寻找这类捷径。

瓶颈 3 深度分析

分布漂移 → SFT → RLVR 的鸿沟

主流的 MLLM 后训练 pipeline 是两阶段串行：

📌 第一阶段 SFT：在静态标注数据上监督微调，数据分布固定
📌 第二阶段 RLVR：模型自采样轨迹，用奖励模型打分

两个阶段的数据分布之间存在本质 gap：

🔸 SFT 阶段：模型「阅读」人类写好的教材
🔸 RL 阶段：模型「自己解题」，但题目来自它自己的生成分布

后果：训练不稳定、loss 剧烈震荡、灾难性遗忘（RL 阶段损失 SFT 已学到的能力）。这一 gap 在多模态模型中比纯文本模型更大——因为模态间的对齐本身就很脆弱。

解决方案

💡 OPD / OPSD 的核心洞见

核心理念
学生用自己的策略生成轨迹 → 教师在相同轨迹上提供逐 token 密集监督 → 对齐两者的分布。

与传统 RL 的稀疏序列级奖励不同，OPD 提供：

✅ 逐 token 的密集信号 → 信用分配问题被自然解决
✅ 教师与学生共享轨迹 → 感知-推理耦合可被诊断和分离
✅ 分布匹配而非奖励最大化 → 缓解 SFT→RLVR 的分布漂移

在多模态语境下，教师和学生通常是同一模型的冻结副本和训练副本——区别仅在于教师看到了特权信息（privileged information）。

数学框架

OPD 的核心公式

在 on-policy 轨迹上的分布匹配：

$$\mathcal{L}_{\text{OPD}} = \sum_{t} D_{\text{KL}}\big(p_{\theta_{\text{old}}}(\cdot|x_{\text{priv}}, y_{<t}) \;\|\; p_\theta(\cdot|x_{\text{student}}, y_{<t})\big)$$

其中：

🔸 p_θold：教师（冻结副本），条件为 $x_{\text{priv}}$ = 含特权信息的输入
🔸 p_θ：学生（训练副本），条件为 $x_{\text{student}}$ = 标准推理输入
🔸 D_KL：KL 散度（Forward KL / Reverse KL / JSD 视场景而定）
🔸 y_<t：前缀 token 序列（学生自采样的轨迹上下文）

本质上，这是在学生自己走出的路上，用教师的分布作为参照——而非让教师划定一条最优路径让学生盲从。

自蒸馏本质

为什么多模态 OPD 偏爱自蒸馏？

多模态 OPD 中，教师和学生通常是同一个模型的冻结副本和训练副本——这被称为 OPSD（On-Policy Self-Distillation）。

为什么是自蒸馏？

✅ 效率：无需依赖更大的外部模型（外部多模态教师稀缺）
✅ 数据瓶颈：多模态推理数据极度稀缺，自蒸馏可利用无标签图文对
✅ 跨模态对齐：同一模型架构保证教师-学生之间的特征空间兼容

教师与学生的唯一区别：

教师看到了「特权信息」——训练时可用、推理时无法获取的额外信息

特权信息

👑 什么是"特权信息"？

定义
特权信息（Privileged Information）是只在训练时可用、推理时无法获取的"开卷答案"。在标准教师-学生框架中，教师和学生看到同样的输入；而在特权教师设定中，教师能额外获得训练时独有的信息——就像老师拿着标准答案批改作业，考试时谁都看不到答案。

特权信息在 OPD 中的角色：

🔸 提供更高质量、信息更丰富的监督信号
🔸 提升学生模型的学习上限
🔸 但如果使用不当 → 特权幻觉（Privilege Illusion）

风险警示

⚠️ 特权幻觉（Privilege Illusion）

如果特权信息设计不当，会引发一系列连锁问题：

🔸 能力假象

教师的高性能源于信息不对称，而非真正的推理能力

🔸 学习偏差

学生模仿的是利用特权的「捷径」，而非可迁移的推理能力

🔸 泛化失败

学到的能力依赖特权 → 推理时无法获得 → 完全失效

🔸 训练崩溃

模型过早收敛（熵崩塌），甚至后期性能下降

🔸 抑制探索

学生被"喂答案" → 主动探索能力被摧毁

🔸 灾难性遗忘

特权移除后，模型性能断崖式下跌

🔑 特权信息的三种获取方式

方式一 · 高风险
📝 标准答案 / 推理链
教师直接使用标准答案（Ground Truth）或完整推理链（CoT）作为特权。教师「看着答案说理由」，表现虚高。
⚠️ 致命陷阱：学生学到的是「如何映射到答案分布」而非「如何看图理解」→ 熵崩塌 · 捷径学习
方式二 · 中风险
👁️ 视觉线索 · ViCuR
不告诉答案，只告诉「看哪里」——教师看到图像 + 高亮区域/边界框，学生仅看完整原图。
✅ 优势：学生学会「自动聚焦」能力 → 训练-推理较一致
⚠️ 风险：需区域标注，可能过度依赖视觉分支
方式三 · 零风险
🔬 局部感知 · Vision-OPD
完全不引入外部数据或标签。教师看裁剪的局部特写（细节清晰），学生看模糊全局图（视野广但细节丢失）。学生从全局中恢复教师从局部提取的特征。
✅ 最优：零外部依赖 · 训练推理完全对齐 · 强迫空间注意力缩放机制

📊 三种特权方式的全面对比

维度🟡 标准答案🟣 视觉线索 ViCuR🟢 局部感知 Vision-OPD
特权来源外部数据集标签外部检测/分割标签图像自身的空间尺度缩放
是否依赖标注严重依赖中度依赖✅ 完全不依赖
推理一致性极差（严重捷径）较好（学特征非答案）✅ 极高（自洽）

代表范式早期 LLM 蒸馏ViCuR (2026.06)Vision-OPD (2026.05)
训练效率中等中等✅ 高（无外部瓶颈）

💡 设计特权信息的关键：平衡「强大」与「可迁移」——理想的特权并非越强越好，而是要避免特权幻觉

Part 0 小结

🎯 从问题到方法

三大瓶颈迫使多模态社区重新思考 RL 后训练范式：

① 稀疏奖励 → 信用分配失效
② 感知-推理耦合退化 → 视觉基础丧失
③ 分布漂移 → 训练不稳定

OPD / OPSD 用逐 token 分布匹配替代稀疏序列级奖励——核心在于特权信息的精心设计。

三种特权范式从「给答案」演进到「给线索」再到「用自身尺度优势」——最终指向 Vision-OPD 式的零外部依赖自蒸馏。
