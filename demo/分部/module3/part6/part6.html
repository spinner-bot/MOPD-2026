Part 6 知识结构图

协同本质

🤝 为什么需要 OPD + RLVR 混合？

🔴 纯 RLVR 的困境

• 奖励仅在序列终点出现

• 长序列梯度在时间轴上弥散

• 信用分配完全失效

• 前期探索纯随机 → 低效

🟢 纯 OPD 的局限

• 缺乏客观终极目标

• 教师可能有偏/能力上限

• 特权幻觉风险

• 学生永远超不过教师

✨ 混合后的效果
OPD 提供逐 token 的软约束（KL 散度）——不是 "这一步奖励 +1"，而是 "你这一步输出的分布应该是这样"。RLVR 提供终点的客观判决——答案对错、测试通过与否。→ 全程有教师轻声提示，终点有裁判一锤定音。

💡 这是 2026 年最重要的工程趋势——OPD 不再作为独立范式，而是与 RLVR 深度集成。

适用域分析

🎯 "正向容易 · 逆向困难"：OPD+RLVR 的黄金地带

核心洞察
RLVR 适用的前提条件：存在一个客观的、可自动计算的单向验证函数。正向判别廉价且无歧义（给你结果 → 瞬间判断对错），逆向生成搜索空间巨大（给你需求 → 生成正确结果极难）。这正是 OPD+RLVR 量身定做的场景。

✅ 正向判别容易

• 代码 → 运行测试（毫秒级）

• 数学表达式 → 代入验证

• 动作序列 → 物理引擎仿真

• 棋局 → 终局胜负规则

• SQL → 返回结果集比对

• 化学合成路线 → 产物验证

❌ 逆向生成困难

• 需求 → 正确代码（空间巨大）

• 问题 → 完整推理链

• 目标 → 最优动作序列

• 初始状态 → 获胜策略

• 自然语言 → 精确查询

• 目标分子 → 合成路径

"单项"不是指简单，而是指存在可自动计算的单向验证函数。只要这个条件成立，RLVR 提供无偏终极信号，OPD 提供过程护航。

核心论文

🟣 PTD-PO：教方法不教答案 (2026.06)

Shizhe Xiang 等（天大·北理工·新加坡管理大学·小米）· arXiv:2606.07000

核心哲学
传统 OPD 的特权包含参考答案 → 导致 shortcut。PTD-PO 构造不暴露答案的特权提示（空间注意力引导 + 中间推理步骤），教师通过 in-context learning 利用这些提示生成逐步 token 分布监督。

❌ 传统 OPD 特权

包含完整参考答案 → 学生学到 "如何映射到答案分布" 而非 "如何看图理解" → 特权幻觉

✅ PTD-PO 特权

不暴露答案——只提供空间注意力引导 + 中间推理步骤提示 → 学生仍需自己得出答案

关键技术：Top-K JSD 稳定化
在引导/非引导上下文的分布偏移下，聚焦信息量最高的 token 概率——既防止 Forward KL 的熵爆炸，又防止 Hard CE 的熵坍塌。

效果：2B–8B LVLM 持续超越 RLVR 和蒸馏基线 · 有效缓解熵坍塌  |  代码：github.com/XszNeverSleep/PTD-PO

🟡 HDPO 理论保证 + Distill-R1 开源框架

🔴 HDPO (2026.03)

Ke Ding 等 · arXiv:2603.23871

核心贡献：理论保证

过滤后的特权生成在硬阈值极限下精确恢复最优 KL 正则化 RL 策略。这为 OPD+RL 混合方法首次提供了坚实的理论根基——不再是工程直觉，而是有数学保证。

🟢 Distill-R1 (2026.03)

ByungKwan Lee 等 · github.com/ByungKwanLee/Distill-R1

核心贡献：工程标准化

首个开源 VLM RL+在线师生蒸馏框架。支持 Qwen2-VL / 2.5-VL / 3-VL，兼容 GRPO / DAPO / REINFORCE++ / RLOO / GSPO / CISPO / SAPO 七种 RL 算法。标准化了 VLM OPD+RL 的实验基准。

💡 HDPO 给理论、Distill-R1 给工具——两者共同标志着OPD+RL 混合范式从实验走向成熟。

Part 6 小结

🎯 RL+OPD：从独立到集成

2026 年最重要的工程趋势：OPD 不再作为独立范式，而是与 RLVR 深度集成。

🔹 协同本质：OPD 的逐 token 软约束 + RLVR 的终点客观判决 = 全程提示 + 终点裁决
🔹 黄金地带：正向判别容易、逆向生成困难 — 只要存在可自动计算的验证函数，混合范式最优
🔹 PRISM：首次证明 OPD 预对齐是 SFT→RLVR 的必要中间步骤（4B +4.4 / 8B +6.0）
🔹 PTD-PO：革新特权设计 — "教方法不教答案" + Top-K JSD 稳定化
🔹 HDPO：理论保证 — 过滤特权生成恢复最优 KL 正则化 RL 策略
🔹 Distill-R1：工程标准化 — 首个开源框架，兼容 7 种 RL 算法

核心规律：密集信号 + 稀疏奖励 = 互补最优。只要「正向可验 · 逆向难成」的条件成立，OPD+RLVR 就是最优解。
