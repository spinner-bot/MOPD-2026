以下对 CR-OPD、GAE-OPD 和 StepOPSD 进行精讲。这三项工作都发表于 2026 年，是对在线策略蒸馏（OPD）在 LLM 推理场景中关键瓶颈的深度修补，分别从**信号聚焦、时序信用和层级粒度**三个维度提升了蒸馏效率与稳定性。

## 一、CR-OPD：反事实路由
**论文**：arXiv 2606.22793（与 GAE-OPD 同篇）  
**核心问题**：大词表上 KL 散度受无关 token 微小概率噪声影响，学习信号被稀释。

### 1.1 问题本质
在标准 OPD 中，每个 token 的蒸馏损失是教师分布 \(\pi_T\) 与学生分布 \(\pi_S\) 的 KL 散度（通常为 Reverse KL）：
\[
\mathcal{L}_t = D_{KL}(\pi_S(\cdot|s_t) \|\pi_T(\cdot|s_t)) = \sum_{v \in \mathcal{V}} \pi_S(v|s_t) \log \frac{\pi_S(v|s_t)}{\pi_T(v|s_t)}
\]
词表 \(\mathcal{V}\) 通常有 50k~200k 个 token。教师和学生对于绝大多数 token 的概率都接近 0，但这些微小概率在 log 比值的放大下，贡献了大量噪声项。尤其是在教师和学生稍有差异的尾部分布上，微小数值波动会使梯度估计方差巨大，淹没了真正关键的决策点。

### 1.2 创新：限制支持集到“合理备选 token”
CR-OPD 的核心思想是：**只在那些教师和学生都认为有一定可能性的 token 上计算 KL 散度**，抛弃那些显然不可能的选择。它定义了一个**动态支持集** \(\mathcal{C}_t\)，取师生各自 Top-K 分布的并集：
\[
\mathcal{C}_t = \text{TopK}(\pi_T(\cdot|s_t), K_T) \;\cup\; \text{TopK}(\pi_S(\cdot|s_t), K_S)
\]
然后在 \(\mathcal{C}_t\) 上重新归一化得到截断分布 \(\hat{\pi}_T, \hat{\pi}_S\)，并计算 KL 散度：
\[
\mathcal{L}_t^{\text{CR}} = \sum_{v \in \mathcal{C}_t} \hat{\pi}_S(v|s_t) \log \frac{\hat{\pi}_S(v|s_t)}{\hat{\pi}_T(v|s_t)}
\]
这样，模型不必为教师概率近乎为 0 的 token 浪费梯度，信号纯度大幅提升。实验表明，这能显著降低梯度噪声并加速收敛。

### 1.3 “反事实路由”名称由来
“反事实”指如果教师在该语境下认为某 token 是可能的选择，我们才考虑它；否则就忽略。这相当于在学生策略更新时，只考虑那些符合教师“合理备选空间”的反事实动作。与之前仅基于值函数的反事实推理不同，这里通过支持集剪枝直接嵌入教师的先验知识。

### 1.4 效果
在数学推理蒸馏中，CR-OPD 将有效学习信号（关键决策 token 的梯度占比）提高约 3 倍，同时缓解了长尾噪声导致的训练不稳定。

## 二、GAE-OPD：时序信用分配
**论文**：arXiv 2606.22793（与 CR-OPD 同篇）  
**核心问题**：当前 token 的蒸馏损失孤立计算，忽略了之前所有 token 的累积效应，导致关键决策点的信用被稀释。

### 2.1 问题本质
在 LLM 推理中，生成过程是自回归的：\(s_t = (x, y_{<t})\)。前面的 token 决定了当前语境，进而影响教师的分布。如果我们只对每个 token 独立施加 KL 惩罚，那么一个早期关键决策（例如是否分支、采用哪种解法）可能只在它自己的那一 token 上受到轻微惩罚，但其后果会影响后续整条链。标准 OPD 无法将后续的失败（或成功）追溯归因到早期 token。

### 2.2 创新：引入 GAE 累积未来 KL
GAE（Generalized Advantage Estimation）原是 RL 中用于稳健估计优势函数的方法。GAE-OPD 将其思想移植到 KL 散度序列上。定义每个 token 的**即时蒸馏信号**为 \(d_t = D_{KL}(\pi_S(\cdot|s_t) \|\pi_T(\cdot|s_t))\)。我们希望每个 token 的学习目标不是 \(d_t\)，而是**未来累积的 KL 加权和**：
\[
G_t = \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l}
\]
其中 \(\delta_t = d_t + \gamma V(s_{t+1}) - V(s_t)\) 类似于时序差分误差，但此处 \(V(s)\) 可理解为一个学习到的“预期未来 KL 散度”。通过类似 GAE 的机制，\(G_t\) 可以在偏差-方差之间取得平衡，并且能够把后面的高 KL（比如推理失败导致的后段偏离）信号向前传播，增强早期决策 token 的学习权重。

### 2.3 实际效果
关键决策 token（如解法选择、逻辑分支点）的梯度被显著增强，填充 token（如“的”、“首先”、“根据”）的梯度被压缩。这使得模型更加聚焦于学习推理逻辑本身，而非表面语言风格。与 CR-OPD 结合后，蒸馏效率得到 1.5~2 倍的提升。

### 2.4 与 OPD 框架的衔接
这实际上是对 OPD 中“逐 token KL 惩罚”的时序泛化。原来的 OPD 隐式假设每个 token 的决策是独立的，而 GAE-OPD 承认了自回归生成中的时间依赖性，使信用分配更加合理。

## 三、StepOPSD：从 Token 级到步骤级的蒸馏
**论文**：arXiv 2605.27140  
**核心问题**：长步骤（包含大量 token）主导总损失，淹没了简短但关键的高层逻辑步骤。

### 3.1 问题本质
人类推理是分层级的：题目 → 理解 → 列式 → 计算 → 验证 → 答案。每个步骤的语义重要性并不与它包含的 token 数量成正比。例如，一个“答案”步骤可能只有几个 token（如“最终答案是 42”），但它是整个推理链的终极目标。而“计算”步骤可能占几十个 token。如果按 token 平均加权，那么长步骤会获得不成比例的损失占比，模型会被迫过度优化这些冗长部分，而忽略核心逻辑跳跃。

### 3.2 创新：步骤切分 + 信用预算归一化
StepOPSD 首先将推理链切分为有意义的步骤。切分可以基于规则（标点、换行）或训练一个轻量级分段器。得到 \(M\) 个步骤，第 \(k\) 个步骤包含 \(L_k\) 个 token。

关键在于**每步信用预算归一化**：无论步骤包含多少 token，分配给该步骤的总损失权重都相等（或按预设比例）。这可以通过对步骤内的 token 级 KL 取平均，再对步骤加权和实现：
\[
\mathcal{L}_{\text{StepOPSD}} = \sum_{k=1}^{M} w_k \cdot \frac{1}{L_k} \sum_{t \in \text{step}_k} D_{KL}(\pi_S(\cdot|s_t) \|\pi_T(\cdot|s_t))
\]
其中 \(w_k\) 可以均等，也可以基于步骤类型（如答案步骤给予更高权重）。这种设计确保每个逻辑步骤对总损失的贡献不受 token 数量影响。

### 3.3 进一步：防止长步骤内部噪声
在步骤内取平均还可以缓解长步骤内部因 token 数量多而引入的方差放大问题。因为长步骤往往包含更多重复或低信息量 token，取平均能够压缩它们的个体噪声。

### 3.4 效果
在数学和代码推理蒸馏中，StepOPSD 使得模型对答案正确率和推理逻辑完整性的优化更加平衡，不会因忽略短步骤而答非所问。最终准确率提升显著，尤其在高难度多步推理任务上。

## 总结：三项技术的协同
- **CR-OPD** 解决了信号聚焦问题（在什么地方计算损失）。
- **GAE-OPD** 解决了时序信用分配问题（如何将未来的信号传回过去）。
- **StepOPSD** 解决了层级粒度问题（在什么层级上聚合损失）。

它们共同把 OPD 从最初的逐 token 独立 KL 惩罚，升级为**稀疏聚焦、时序感知、步骤等权**的精细蒸馏框架，是 LLM 推理蒸馏走向成熟的关键组件。在 PPT 中，你可以用一张三层递进的示意图展示它们各自作用的维度，非常直观。

## 失效模式一：学生前缀扭曲教师

### 表现
在线策略蒸馏中，输入教师的前缀（上下文）是由**学生**自己生成的。如果学生能力弱，它生成的前缀往往混乱、低质、甚至错误。教师在这种受污染的前缀上，被迫“将错就错”地输出——例如学生的推理已经偏了，教师也只能基于错误中间步骤勉强给出一个“合理但并非最优”的后续。学生再从这个受污染的教师信号里学习，进一步生成更差的前缀，形成**恶性循环**。

### 根因
标准 OPD 要求学生在自己采样到的状态（即自回归生成的 token 序列）上模仿教师。这本来是为了让学生在自己常犯错的区域得到纠正。但当学生太弱时，其状态分布几乎不与教师擅长的状态分布重叠，教师的输出在这些劣质状态下根本体现不出其真正的推理能力。本质上是**教师输入被学生分布污染**，教师被强行拉入了自己从未训练过的低质量区域。

### 修复：Stop-Gradient Top-K KL
修复分两步：
1. **Stop-Gradient（停止梯度）**：在计算教师分布时，确保梯度**不会从学生流向教师**。这听上去理所当然，但在某些实现中（尤其是共享计算图时），教师分布的计算可能会被学生的参数更新间接影响。显式切断这条路径，保证教师输出是完全冻结的、不受学生污染。
2. **Top-K KL**：教师仅对学生前缀中**自己有把握的 Top-K token** 进行蒸馏。方法是将教师分布截断到概率最高的 K 个 token 上，只在它们上面计算 KL 散度。这相当于教师说：“你这个前缀我只在少数确信的 token 上给你指导，其余你自己看着办。” 这样就避免了教师在其不擅长的劣质语境下被迫输出低质量分布，切断了恶性循环的传导链。

## 失效模式二：Top-K +1 偏差

### 什么是“截断”？
LLM 词表很大（50k~200k token）。逐 token 计算全词表的 KL 散度，计算和存储开销巨大。因此工程上常做 **Top-K 截断**：只取教师分布中概率最高的 K 个 token（如 K=256），假设其他 token 概率为 0，构成一个稀疏向量来近似原分布，然后在此之上算 KL。

### 截断如何影响概率分布？
标准概率分布必须满足 \(\sum_{v \in \mathcal{V}} \pi(v) = 1\)。当我们截断到 Top-K 时，直接扔掉剩余 token 的概率质量，然后**不经修正地**计算 KL，就产生了一个严重问题：

令原分布为 \(P\)，Top-K 集合为 \(\mathcal{K}\)，剩余 token 总概率为 \(P_{\text{rest}} = 1 - \sum_{v\in\mathcal{K}} P(v) > 0\)。直接只用 \(\mathcal{K}\) 内的概率值计算 KL，隐式假设了 \(\sum_{v\in\mathcal{K}} P(v) = 1\)，这是错的。因为学生分布 \(\pi_S\) 也会在 \(\mathcal{K}\) 之外的 token 上分配概率，这些概率没有被计入 KL 中。

### 如何导致偏差？
KL 散度的标准定义要求两个分布定义在相同的完整支持集上。截断后，我们在一个不完整的集合上强行计算，产生两种偏差：
- **缺失质量偏差**：\(P_{\text{rest}}\) 被忽略，导致教师分布的“尾部”信息丢失。
- **归一化偏差**：学生分布 \(\pi_S\) 也需在 \(\mathcal{K}\) 上重新归一化来匹配教师，但通常实现中可能未做或做了不一致的处理，使得 KL 估计既不无偏也不一致。

长期训练中，这种系统偏差会累积，导致学生策略偏离预期行为。这在数学推理等对精确度要求极高的任务中尤其致命。

### 修复：显式加入“其他”类别
解决方法是**概率补全**。在截断后，显式创建一个虚拟的“其他”token，将剩余概率质量 \(P_{\text{rest}}\) 分配给它。于是我们得到严格有效的分布 \(\hat{P}\)：
\[
\hat{P}(v) =
\begin{cases}
P(v) & \text{if } v \in \mathcal{K} \\
P_{\text{rest}} & \text{if } v = \text{<other>}
\end{cases}
\]
学生分布也同样处理：在 \(\mathcal{K}\) 外加上 <other> 条目，吸收其剩余概率质量。然后在这扩展后的 \((K+1)\) 个类别上计算 KL 散度。这样数学上严格，从根本上消除了截断带来的偏差。

## 失效模式三：PI-free margin

### 表现
学生蒸馏后，在训练集分布内表现极好，甚至逼近教师。但在分布偏移（如新题型、变换问法）时，性能断崖式下跌。它只是**背下了答案模板**，却没有真正掌握推理逻辑。

### 根因
这源于学习到的**PI-free margin（策略不变的安全区）**。意思是学生找到了一种策略，在**训练分布内**恰好能使 KL 散度很低（与教师输出高度一致），但该策略并不依赖对推理的真正理解，而是利用了一些表面统计关联（例如“看到题目有‘总共’，就猜答案在最后一句”）。当测试分布改变，这些关联失效，策略立刻崩溃。本质上，学生只学到了**分布依赖的表层模式**，而非分布无关的深层因果推理。

### 为什么标准蒸馏容易导致此问题？
标准蒸馏让学生直接模仿教师的 token 级输出。学生可以通过记忆教师语料库中的常见模式、偏好的措辞、特定题型的结构来压低 KL 损失，而无需内化推理的因果逻辑。这类似于学生背会了所有作业题的答案，但考试换一道题就不会了。教师在训练数据中的表现太“完美且一致”，反而让学生走了记忆的捷径。

### 修复：先 RLVR-adapt 教师，再 SFT-warm 学生
修复思路是**让教师的知识先经过环境压力测试**，滤掉那些只会导致表面模仿的信号，保留真正的推理精华。

- **RLVR-adapt 教师**：  
  RLVR（Reinforcement Learning with Verifiable Rewards）是用可自动验证的奖励函数（如最终答案对错、代码是否通过测试）对教师进行强化学习微调。教师被暴露在**多样化的环境交互**中（包括它自己生成的不完美推理链的后果），被迫学会在分布扰动下仍然正确的推理路径。经过这一过程，教师输出的推理链不再只是“流畅的文本”，而是被环境验证过的、具有一定鲁棒性的逻辑序列。

- **再 SFT-warm 学生**：  
  用经过 RLVR 压力测试的教师数据，对学生进行监督微调（SFT）作为热身。此时，教师数据中包含了更多样的情况、更多自我纠正的例子、更本质的逻辑链条。学生从中学到的是“为何如此推理”而非“如此措辞”。之后再进行在线蒸馏时，学生已经具备了初步的因果推理能力，不再那么容易滑向记忆模板。

### 类比
原始教师：一个只会解书上标准题的学霸。
RLVR-adapt 教师：学霸去参加了模拟考试，考完还被自动判卷指出错在哪里，纠正了自己的理解偏差，真正搞懂了原理。
SFT-warm 学生：用学霸修正后的笔记学习，从一开始就学到的是真懂的知识。
原学生：直接抄学霸作业，考试换题就废了。

## 总结表格

| 失效模式 | 核心问题 | 修复思路 | 作用机制 |
|----------|----------|----------|----------|
| 学生前缀扭曲教师 | 学生劣质输入污染教师输出 | Stop-Gradient Top-K KL | 教师冻结，只在高置信 token 上指导 |
| Top-K +1 偏差 | 截断破坏概率归一化 | 显式“其他”类别 | 恢复严格有效分布，消除系统性偏差 |

这三项修复覆盖了 OPD 在 LLM 推理场景中从**数据质量、数学严谨性到知识深度**三个层面的脆弱点，是 2026 年工程落地的重要指南。放入 PPT 时，你可以先提出这三个诡异现象（明明训练正常，推演时却崩了），再逐一剖析根因并给出对策，逻辑感会很强。
