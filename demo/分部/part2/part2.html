🚀 Kickstarting Deep RL (2018)

📄 Schmitt et al., DeepMind · arXiv: 1803.03835 · DMLab-30 平台

核心思想：教师先推一把，然后放手让学生自己跑

$$\boxed{\mathcal{L}_{\text{kick}}(\omega, x, t) = \underbrace{\mathcal{L}_{\text{RL}}(\omega, x, t)}_{\text{标准RL目标}} + \underbrace{\lambda_k \cdot H\big(\pi_T(\cdot|x_t) \;\|\; \pi_S(\cdot|x_t, \omega)\big)}_{\text{逐渐衰减的蒸馏信号}}}$$

🔑 关键创新：λ_k → 0

ω = 学生网络权重；x_t = 当前状态
H(π_T‖π_S) = 交叉熵，等价于最小化 D_KL(π_T‖π_S)
λ_k 训练初期大（强引导）→ 中期减弱 → 后期为 0（完全自主）

💡 为什么不用 KL 散度？

交叉熵 H(π_T‖π_S) = −Σ π_T log π_S
与 D_KL(π_T‖π_S) 相差一个常数（教师熵不依赖学生参数），优化等价但计算更简单。

🎯 为什么 Kickstarting 能超越教师？

❌ 问题：如果学生只模仿

如果学生在整个训练过程中始终强依赖教师信号（λ_k 不衰减），学生的性能上限就是教师水平——永远无法超越。

✅ 解决方案：逐渐放手

蒸馏应该像教孩子骑自行车——开始时父母扶着（大λ_k），然后慢慢松开（λ_k衰减），最后孩子完全自己骑（λ_k=0），可能比父母骑得更好。

🧬 PBT：自动调参

Population Based Training：40个智能体并行训练。表现差的复制表现好的超参数（λ_k、衰减率、学习率、熵系数）并加扰动。自动找到最优衰减曲线。

设置结果
单教师训练速度 1.5×
多教师（每任务一专家）9.58× 加速！性能超越 42.2%
学生 vs 教师多任务上学生显著超越

📐 先理解：什么是"梯度场"？

📊 梯度 = 方向指示器

训练神经网络时，对损失函数求参数 ω 的导数，得到梯度向量——它指向"损失下降最快的方向"。梯度下降 = 沿着反方向走。

ω_{new} = ω_{old} − η · ∇_ω L(ω)

🗺️ 梯度场 = 所有位置的梯度集合

参数空间里每个点都对应一个梯度向量。这就像一片"场"——每个位置都有箭头告诉你该往哪走。

梯度场不存在 = 某些区域的箭头全部消失（为零向量），梯度下降卡住，无法继续优化。

⚠️ Theorem 1: 梯度场不存在定理

⚠ Theorem 1

核心发现：标准的 on-policy 蒸馏更新规则不对应于任何损失函数的梯度。

$$\Delta\theta = \mathbb{E}_{s \sim d_{\pi_\theta}} \left[\nabla_\theta H(\pi_T(\cdot|s) \;\|\; \pi_\theta(\cdot|s))\right]$$

学生参数 θ 变了 → 策略变了 → 访问的状态分布 d_{π_θ}(s) 变了 → 蒸馏损失的定义域已经漂移。永远在追一个因自己移动而移动的目标。

🔑 一句总结

如果学生策略是随机的（softmax输出），在学生已收敛到某个局部最优时，梯度完全消失——即使学生还很差。训练停止，无法逃离。

🔍 根因：学生状态分布差

🤖 学生策略差
→
🕳️ 只访问差状态
→
👀 在差状态看教师
→
💀 学不到精华

🎯 核心矛盾

学生只能从自己实际跑出来的状态里学习教师。但学生策略不成熟 → 永远访问低奖励状态 → 在这些状态下，教师也只会给出平庸动作 → 学生永远看不到教师真正的"神之一手"。

♟️ 围棋类比

一步错棋 → 100步后局面崩溃 → 学生整盘都在劣势区挣扎 → 根本看不到教师妙手所在的"优势区"。
长horizon下，状态分化更严重。

✅ Theorem 2: 梯度场重建

✅ Theorem 2 · 修正

核心思路：打破"状态必须来自学生"的限制。

$$\boxed{\mathbb{E}_{\pi_\theta}\left[\sum_t -\nabla_\theta \log\pi_\theta(a_t|s_t) \cdot \underbrace{\sum_{i=t}^{\infty} \hat{r}_i}_{\text{累积未来修正奖励}} + \underbrace{\nabla_\theta \ell_t}_{\text{直接蒸馏梯度}}\right]}$$

在每个时间步添加"未来蒸馏损失"作为修正奖励，恢复梯度场性质。

🔧 修正方法一：N步未来蒸馏损失

不只模仿教师当前状态的动作，而是沿教师轨迹看未来N步，每一步都计入损失：

$$\mathcal{L}_{\text{future}} = \mathbb{E}_{(s,a) \sim \mathcal{D}_T}\left[ \sum_{k=0}^{N-1} \gamma^k D_{KL}(\pi_T \| \pi_S) \right]$$

🔧 修正方法二：教师价值加权

用教师价值函数给状态分配重要性权重。教师认为价值越高的状态，学生必须越认真模仿：

$$\mathbb{E}_{s \sim \mathcal{D}}\left[ \exp\!\left(\frac{V_T(s)}{\beta}\right) \cdot D_{KL}(\pi_T \| \pi_S) \right]$$

🕰️ 长 Horizon 任务 — N-distill 的最佳舞台

📏 Horizon 是什么？

Horizon = 一个 episode 的时间步数量。走迷宫200步到达出口（horizon=200）；围棋一局200手（horizon=200）；长horizon = 步骤极多、奖励极其稀疏（甚至只在终点给一个奖励）。

短Horizon
学生容易碰运气到达终点
梯度场问题影响较小

长Horizon
学生靠自己几乎摸不到终点
N-distill 是救命稻草

💡 为什么 N-distill 适用长 Horizon？

教师轨迹 D_T 包含了完整的成功路径。训练时，学生被强制在教师的高价值状态上模仿：
• 看到好状态——虽然自己还去不了，但网络已学会"如果到了这个状态该怎么做"
• 引导探索——一旦偶发接近好状态，模仿过的经验让它做出合理动作 → 正反馈

就像给你一张藏宝图——即使你一开始在沙漠，也知道该往宝藏方向走。

🎲 Expected Entropy Regularization

📐 策略熵 H(π) = 随机性度量

$H(\pi(\cdot|s)) = -\sum_a \pi(a|s) \log \pi(a|s)$
熵大 → 动作均匀（探索性强）
熵=0 → 完全确定选一个动作（无探索）
期望熵 = 对状态分布取期望：E_{s∼d^π}[H(π(·|s))]

🔧 熵正则化

在损失函数中显式加入学生策略熵：

$$\mathcal{L} = \mathcal{L}_{\text{imitation}} - \lambda_{\text{ent}} \cdot \mathbb{E}_{s}[ H(\pi_S(\cdot|s)) ]$$

作用：防止学生模仿时变成完全确定的拷贝，保持探索能力。笔记标注为"最通用（作者推荐）"。

💡 与 Part 1 的联系

这和 Distral 里的熵奖励项 −c_Ent·log πᵢ 是一脉相承的——都在防止策略过早坍缩到确定性策略。

🏆 Teacher V Reward — 教师变成奖励函数

💬 讨论

🔀 完全不同的思路

不需要模仿动作分布。教师直接用自己的价值函数 V_T(s) 或 Q_T(s,a) 构造奖励信号：

$$r_t^{\text{teacher}} = V_T(s_{t+1}) - V_T(s_t)$$

或直接用 $r_t = Q_T(s_t, a_t)$

学生不模仿动作，而是用自己的策略去最大化这个"教师奖励"——完全从头跑RL。

🎯 使用场景

• 教师能提供精确的 V_T 或 Q_T
• 环境奖励太稀疏（教师有全局知识）
• 动作空间不对齐：教师和学生的动作维度不同时，无法直接模仿动作分布——但 V_T(s) 只评估"状态好坏"，不关心具体动作

💡 本质

教师的价值函数 = 奖励函数生成器。差分奖励 V_T(s_{t+1})−V_T(s_t) 表示"教师认为这一步让状态变好了多少"。

🔗 逻辑链：
同策略蒸馏 → 梯度场消失 → 用教师数据打破状态依赖（N-distill）→ 加教师价值加权（Teacher V Reward）→ 保持学生探索（Expected Entropy Reg.）
每一环都在解决前一环的致命缺陷。
